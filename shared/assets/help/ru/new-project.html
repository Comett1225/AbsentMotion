Нажмите круглую кнопку + внизу главного экрана. Снизу выдвигается панель. Она открывается со значениями, которые вы использовали в прошлый раз (форма, разрешение, частота кадров и фон; имя всегда новое). Нажмите «Назад», чтобы закрыть её, ничего не создавая.

Проект или ресурс

Переключатель вверху имеет два варианта: Проект (по умолчанию) и Ресурс. Ресурс — это многоразовая заготовка с прозрачным фоном: его настройка фона заблокирована на «Прозрачный». См. Ресурсы, шаблоны и пресеты.

Имя

Имя по умолчанию — «New Project 1», «New Project 2» и так далее (у ресурсов — «New Asset»). Нажмите X в поле, чтобы очистить его. Пустое имя заменяется значением по умолчанию.

Форма изображения (соотношение сторон)

Кнопки для 16:9, 9:16, 4:5, 1:1 и 4:3, а также кнопка с карандашом для пользовательского соотношения сторон. По умолчанию — 1:1. Выберите 9:16 для видео на телефон, 16:9 для горизонтального видео.

Разрешение

Строка Разрешение показывает размер холста, например 1920 x 1080. Для пяти форм это список по короткой стороне:

ВариантКороткая сторона
2160p (4k)2160
1440p (QHD)1440
1080p (FHD), по умолчанию1080
720p (HD)720
540p (SD), 360p, 270p, 180pсогласно названию

Длинная сторона зависит от формы. Проект 16:9 в 1080p — это 1920 x 1080, проект 4:5 — 1080 x 1350, а проект 4:3 — 1440 x 1080.

При Своё соотношение сторон список превращается в два числовых поля для ширины и высоты с круглой кнопкой Ссылка между ними. Когда «Связать» включено, изменение одной стороны сохраняет соотношение, которое было у двух полей в момент включения «Связать». Каждая сторона может быть от 32 до 4096 пикселей; приложение исправляет значение, когда вы покидаете поле.

Чтобы сохранить размер для дальнейшего использования, нажмите + Сохранить размер под полями и задайте имя (например, «Баннер»). Сохранённые размеры появятся рядом в виде кнопок; нажмите одну из них, чтобы заполнить ширину и высоту. Удерживайте сохранённый размер (на компьютере щёлкните правой кнопкой), чтобы переименовать или удалить его. В редакторе те же сохранённые размеры доступны в настройках проекта при выборе своего соотношения сторон.

Больший холст выглядит резче, но требует больше памяти и дольше экспортируется. 1080p — хороший выбор для большинства проектов. Разрешение можно изменить позже в настройках проекта в редакторе, при этом слои не масштабируются.

Частота кадров

Выберите 12, 15, 18, 20, 24, 25, 30, 48, 50, 60, 90 или 120 кадров в секунду. По умолчанию — 60. Используйте 24 или 30 для кинематографичного вида и меньших файлов, а 60 — для плавного быстрого движения. 90 и 120 подходят для очень плавного движения на экранах с высокой частотой обновления; не каждый телефон может экспортировать видео с такой частотой, и экран экспорта сообщит, если ваш телефон не может этого сделать. Это задаёт, как часто редактор и экспорт отрисовывают картинку. Видеоклипы сохраняют свою частоту кадров; см. параметр интерполяции кадров на странице Экспорт.

Фон

Цвет за вашими слоями: Чёрный, Белый, Светло-серый, Зелёный, Синий или Прозрачный (показан шахматной доской). При новой установке по умолчанию стоит «Прозрачный». Прозрачные области экспортированного видео становятся чёрными; при экспорте GIF и изображений можно выбрать, чем станут прозрачные области, а PNG сохраняет их.

Кнопки внизу

  • Создать проект (Создать ресурс для ресурса) создаёт проект и открывает редактор на нём.
  • X под ними закрывает панель.

Если недостаточно места для хранения, приложение сообщает об этом и не создаёт проект.
