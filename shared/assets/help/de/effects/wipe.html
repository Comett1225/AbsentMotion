Wischblende

Key · Hinzugefügt in Version 3.0.0

Blendet die Ebene von zwei gegenüberliegenden Seiten aus. Animiere Start oder Ende für einen Wischübergang.

Wischen blendet die Ebene von zwei gegenüberliegenden Seiten aus. Animiere Start oder Ende, um die Ebene mit einer geraden Kante einzublenden oder zu entfernen. Winkel ist die Richtung der Kante, und Weichzeichnung macht sie weicher. Für einen Wisch wie ein Uhrzeiger nutze Radialer Wisch.
