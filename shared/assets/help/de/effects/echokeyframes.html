Keyframe-Echo

Bewegung · Hinzugefügt in Version 3.0.0

Zeichnet Kopien früherer Zustände der Ebene entlang ihrer Animation.

Echo-Keyframes zeichnet Kopien der Ebene so, wie sie einen Moment zuvor aussah. So hinterlässt eine bewegte Ebene eine Spur. Sekunden gibt an, wie weit zurück die Kopien liegen, Anzahl, wie viele es sind, Alpha, wie sichtbar sie sind, und Zusammensetzen ob sie Dahinter oder Darüber der Ebene liegen.
