Text entlang Pfad

Text · Hinzugefügt in Version 4.2.0

Setzt den Text Buchstabe für Buchstabe entlang eines Bogens, eines Kreises oder der Kontur der Ebene direkt darunter, wobei Satz, Schriftarten und Emojis des Textes erhalten bleiben.

Wähle den Pfad: einen Bogen oder einen Kreis um die Textebene (ziehe seine Punkte auf der Arbeitsfläche oder gib sie ein), oder Ebene darunter, um dem zu folgen, was in der Ebenenliste direkt unter dem Text liegt: ein Stiftpfad, eine Form, die Striche einer Zeichnung oder die Buchstaben eines anderen Textes. Bei einem Kreis oder einem anderen geschlossenen Umriss setzt Position bei 50 % den Text oben, von links nach rechts gelesen, und 0 % ist unten. Mit eingeschalteter Pfad umkehren setzt 0 % den Text unten entlang, ebenfalls von links nach rechts gelesen. Ein Pfad mit mehreren Teilen wird Teil für Teil nacheinander verfolgt. Text auf einem Pfad bricht nicht innerhalb seines Textfelds um: Beginne für eine zweite Zeile selbst eine neue Zeile.
