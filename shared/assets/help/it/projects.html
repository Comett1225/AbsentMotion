Salvataggio

Non c'è un pulsante Salva. Dopo ogni modifica, l'editor scrive il progetto sul telefono poco dopo, in un modo che non può lasciare un file a metà. Mentre trascini un elemento viene scritta anche una bozza. Se il salvataggio non riesce perché il telefono è pieno, l'app mostra "Impossibile salvare il progetto. Libera un po' di spazio di archiviazione." e riprova.

Cronologia versioni

L'app conserva le versioni precedenti di ogni progetto. Una versione viene salvata quando apri il progetto, quando lo chiudi, e dopo un salvataggio se l'ultima versione risale ad almeno due minuti prima. Ne salva una anche prima di un ripristino e prima di rispondere a una domanda di recupero dopo un arresto. L'app conserva le 20 versioni più recenti e l'ultima di ciascuno degli ultimi sette giorni, ed elimina le più vecchie.

Aprila dal menu della scheda del progetto (Cronologia versioni) oppure nelle impostazioni del progetto nell'editor (Versioni precedenti). Ogni riga ha una miniatura, l'ora ("Oggi alle 14:05", "Ieri alle 09:30") e Ripristina. Il ripristino chiede prima conferma: "Il progetto torna com'era... Lo stato attuale viene conservato nella Cronologia versioni, quindi non si perde nulla."

Recupero dopo un arresto

Se l'app si ferma in modo imprevisto mentre un progetto è aperto, all'avvio successivo compare AbsentMotion si è chiuso inaspettatamente con il motivo in una frase, per esempio "Ha esaurito la memoria durante l'esportazione." Se c'erano modifiche non salvate, chiede "Vuoi ripristinare le ultime modifiche a ...?" con Ripristina e Scarta. Una bozza scartata resta nella cronologia versioni del progetto.

Ogni arresto viene anche scritto in Log arresti nelle Impostazioni: ora, motivo in una frase, versione di app e Android, modello del telefono, cosa stavi facendo e il dettaglio tecnico. Ne vengono conservati gli ultimi 20. Non viene mai inviato nulla; puoi copiarne uno per inviarlo tu stesso.

Un progetto danneggiato

Se un file di progetto non può essere letto, la sua scheda mostra Danneggiato: ripristina una versione. Toccala per ripristinare una versione precedente oppure eliminala.

File multimediali

Foto, video e audio che aggiungi vengono, per impostazione predefinita, copiati nel progetto, così il progetto non dipende dalla tua galleria. Per disattivarlo, usa Mantieni una copia dei media importati nel progetto nelle Impostazioni, se vuoi risparmiare spazio.

  • Raccogli i media nel progetto (menu della scheda del progetto) copia nel progetto ogni file che il progetto legge ancora dall'esterno della sua cartella. Prima cerca di ritrovare i file che risultano mancanti.
  • Media mancanti. Quando un file non è più sul telefono, all'apertura del progetto l'app lo cerca nella libreria di foto, video e audio per nome esatto e dimensioni, e lo usa se corrisponde un solo file. Per sistemarlo a mano, seleziona il livello, apri Info media nel menu del livello e scegli Sostituisci file multimediale. Se esporti con file mancanti, l'app ti avvisa e lascia fuori quei livelli.

Backup e ripristino

In Impostazioni, gruppo Backup:

  • Esegui il backup di tutti i progetti crea un unico file, AbsentMotion-backup- seguito da data e ora, che termina con .absbackup, in Documents/AbsentMotion. Contiene tutti i progetti con la loro cronologia versioni, i modelli con i relativi media, i preset, le tue tavolozze di colori, i font importati, i risultati AI e tutti i media conservati. Richiede spazio libero pari più o meno alle dimensioni del contenuto più 50 MB. Il file resta sul telefono anche se disinstalli AbsentMotion; copialo su un computer o in un servizio cloud per conservarlo al sicuro.
  • Backup automatico settimanale (solo progetti) è disattivato per impostazione predefinita. Se è attivo, qualche secondo dopo l'apertura dell'app, se sono passati sette giorni dall'ultimo backup, scrive AbsentMotion-weekly-...absbackup con i soli progetti (senza media) ed elimina il file settimanale precedente. I backup manuali non vengono mai eliminati dall'app.
  • Ripristina da backup ti chiede di scegliere un file di backup. Un progetto già presente e identico viene lasciato com'è; un progetto con lo stesso nome ma contenuto diverso viene ripristinato come copia separata. Non viene sovrascritto nulla di ciò che esiste. Il ripristino può essere interrotto e rieseguito più tardi.

Importare i file di progetto

Puoi aprire un file di progetto da un'altra app (per esempio un gestore di file) con Condividi o Apri con. Per avere un pulsante di importazione nella schermata iniziale, attiva Mostra la scheda di importazione nell'elenco progetti: sopra i tuoi progetti compare allora la scheda Scegli file.

FileCosa ottieni
.absproj creato da AbsentMotionUn progetto normale con i suoi media
Un pacchetto di progetto da un altro editor (.amproj)Ogni scena diventa un modello, e le eventuali risorse restano risorse
Un semplice file XML di scenaUn progetto normale. I collegamenti ai media non vengono seguiti per sicurezza, quindi i media risultano mancanti a meno che non si trovino nella galleria.
Un file di Adobe Animate (.fla)Un progetto normale: vedi File di Adobe Animate

Gli effetti presenti in AbsentMotion vengono convertiti. Gli effetti che non ha restano nel file ma non vengono disegnati. Dopo un'importazione, un rapporto elenca solo ciò che non è stato trasferito: effetti che non può eseguire, impostazioni che non è stato possibile trasferire, media non trovati e font non installati. Quando tutto è stato trasferito, il rapporto non viene mostrato. I file di backup (.absbackup) si ripristinano da Impostazioni, non si importano qui.

Ci sono dei limiti per proteggere il telefono. Per esempio, un pacchetto può contenere al massimo 2000 file e 32 progetti, avere al massimo 2 GB una volta decompresso, e una scena deve avere dimensioni di al massimo 16384 pixel e una frequenza di fotogrammi da 1 a 240. L'app indica quale regola ha violato un file.

File di Adobe Animate

AbsentMotion importa i file .fla salvati da Adobe Animate o Flash CS5 e versioni successive. Aprine uno come un qualsiasi altro file di progetto: con Scegli file, Condividi o Apri con. Su computer, usa File, Importa progetto… oppure trascina il file nella finestra; lì funziona anche un file .xfl, purché il resto della sua cartella sia accanto ad esso. Sul telefono, comprimi una cartella XFL in un file ZIP e importa quello.

Il file diventa un unico progetto con le dimensioni del palcoscenico, la frequenza di fotogrammi e il colore di sfondo del file Animate, e le sue scene vengono riprodotte una dopo l'altra.

  • Viene importato: forme con riempimento a tinta unita, a sfumatura a due colori o con immagine, e i loro contorni; simboli, ciascuno come gruppo con la propria timeline; immagini; tween classici come keyframe, con i relativi easing; alpha, tinta e luminosità; livelli maschera; e suoni MP3 sulla timeline principale.
  • Escluso: campi di testo, ActionScript, filtri, metodi di fusione, altri effetti di colore, percorsi guida di movimento, livelli camera, componenti e clip compilate, video, pose ossee (IK) e simboli della libreria che non sono sul palcoscenico. Un tween di forma mostra la sua forma iniziale e un tween di movimento il suo primo keyframe. Le sfumature con più di due colori ne mantengono due, le linee tratteggiate e le altre linee speciali vengono disegnate piene, e gli easing che non possono essere letti diventano movimento lineare.

Dopo l'importazione, il rapporto elenca entrambe le categorie, con un conteggio per ciascuna: Importati dal file Animate e Non importati (visualizzati senza questi elementi).

I file .fla più vecchi, di Flash CS4 e precedenti, usano un altro formato. In quel caso l'app dice: "Questo file .fla è stato salvato con Flash CS4 o una versione precedente. Si possono importare solo i file .fla di Flash CS5 e versioni successive."

Formati dei file e dove si trovano le cose

  • Un progetto è un unico file di testo XML. I media si trovano accanto ad esso, nella cartella privata del progetto.
  • Un .absproj è uno ZIP: project.xml, un manifest.json e i file multimediali in media/. I modelli 3D conservano i loro file in una cartella.
  • Un .absbackup è uno ZIP con tutti i progetti, i preset, i modelli, i font e i file multimediali.
  • Archiviazione privata dell'app (eliminata quando disinstalli): progetti e relative miniature, cronologia versioni, media conservati, modelli, preset, tavolozze di colori, bozze di recupero, log degli arresti, font importati, il modello per i sottotitoli, copie di anteprima e risultati AI.
  • Archiviazione condivisa (resta quando disinstalli): Movies/AbsentMotion (video), Pictures/AbsentMotion (GIF, fotogrammi singoli, sequenze di immagini e immagini delle tavolozze), Music/AbsentMotion (esportazioni audio), Documents/AbsentMotion (.absproj, XML, backup e file delle tavolozze) e DCIM/AbsentMotion (foto e video dalla fotocamera integrata nell'app).

AbsentMotion non usa l'autorizzazione generale "tutti i file": salva tramite l'archiviazione multimediale di Android.
