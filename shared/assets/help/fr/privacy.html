AbsentMotion ne collecte, ne stocke ni ne partage aucune donnée personnelle. Il n’y a ni compte, ni publicité, ni analyse, ni suivi. Cette page résume la politique de confidentialité ; le texte complet se trouve dans le fichier PRIVACY.md du code source.

Vos projets et vos médias

Les projets, les images, vidéos et audios importés, ainsi que tout ce que vous exportez, restent sur votre téléphone. Les autorisations photos, vidéos et audio permettent à l’application d’afficher votre bibliothèque et d’utiliser les fichiers que vous choisissez, sur le téléphone. Rien n’est envoyé en ligne.

Les autorisations de la caméra et du microphone ne servent qu’à la caméra intégrée à l’application, pendant qu’elle est ouverte. Les enregistrements sont sauvegardés sur le téléphone. Les sauvegardes sont écrites dans Documents/AbsentMotion sur le téléphone et restent là.

Pendant un export, l’application affiche sa progression dans une notification, de sorte que l’export peut se poursuivre lorsque vous passez à une autre application. Sur Android 13 et versions ultérieures, elle demande l’autorisation d’afficher des notifications lors du premier export ; les exports fonctionnent de la même façon si vous refusez.

Si l’application se ferme de manière inattendue, elle conserve un journal de plantage dans son propre espace de stockage : le moment du plantage, la raison en une phrase, les versions d’Android et de l’application, le modèle du téléphone, ce que vous faisiez et l’erreur technique. Seuls les 20 derniers sont conservés ; ils ne sont pas inclus dans les sauvegardes du téléphone et ne sont jamais envoyés nulle part. Vous pouvez les lire, les copier ou les supprimer dans les paramètres.

Quand l’application utilise Internet

L’application demande l’autorisation Internet uniquement pour les usages suivants :

  • Polices. Lorsque vous choisissez l’une des polices téléchargeables, l’application la télécharge depuis Google Fonts. Google reçoit la demande pour cette police ainsi que votre adresse IP, comme pour toute requête web.
  • Sous-titres automatiques. La première fois que vous générez des sous-titres, l’application vous indique la taille du modèle de reconnaissance vocale (environ 57 Mo) et le télécharge depuis Hugging Face. La reconnaissance vocale s’effectue sur le téléphone.
  • Lissage AI et Amélioration AI. La première fois que vous utilisez l’un des deux, l’application vous indique la taille du modèle nécessaire (environ 1 à 11 Mo) et le télécharge depuis GitHub. Le traitement IA lui-même s’effectue sur le téléphone.
  • Suppression d’arrière-plan AI 2.0. Uniquement si vous choisissez Suppression d’arrière-plan AI 2.0 pour supprimer les arrière-plans, l’application télécharge son modèle une seule fois (environ 62 Mo) depuis GitHub. La découpe elle-même s’effectue sur le téléphone.
  • Téléchargeur de vidéos. Uniquement si vous utilisez Outils > Téléchargeur de vidéos : la première fois, l’application télécharge son module complémentaire (environ 25 Mo) : Python depuis python.org et yt-dlp depuis GitHub (github.com, servi depuis objects.githubusercontent.com ou release-assets.githubusercontent.com). Tant que le module complémentaire est installé, il demande au plus une fois par jour à GitHub s’il existe une version plus récente de yt-dlp et la télécharge le cas échéant. Lorsque vous collez un lien, le module complémentaire contacte ce site (par exemple YouTube, Instagram ou TikTok) pour lire les informations de la vidéo et télécharger les parties que vous choisissez, exactement comme le ferait un navigateur web ; les fichiers sont enregistrés sur l’appareil.
  • Vérification des mises à jour. Si vous l’autorisez (l’application le demande une fois ; l’interrupteur se trouve dans les paramètres), l’application envoie une seule requête HTTPS classique à GitHub à chaque ouverture, pour lire le dernier numéro de version. Rien d’autre n’est envoyé. GitHub voit votre adresse IP, comme pour toute requête web.

Rien d’autre n’est envoyé nulle part. La synthèse vocale utilise les voix déjà présentes sur le téléphone et fonctionne hors ligne.

Enfants

L’application ne s’adresse pas aux enfants et ne collecte rien auprès de qui que ce soit.
