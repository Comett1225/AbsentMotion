Page cornée

Distorsion · Ajouté dans la version 5.1.0

Tourne le calque comme une page : un coin se soulève et s’enroule, révélant le verso. Animez la progression pour tourner la page. Avec Suivre la forme activé, la page se tourne à partir des bords de ce qui est visible : une image ronde ou un modèle 3D se recourbe depuis son propre bord et non depuis une boîte invisible.
