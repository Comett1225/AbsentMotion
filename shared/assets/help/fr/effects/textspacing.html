Espacement du texte

Texte · Ajouté dans la version 5.3.2

Modifie l’espace entre les lettres et entre les lignes d’un calque de texte. Espacement des lettres écarte les lettres, ou les rapproche en dessous de 0 %. Interligne règle l’écart entre les lignes : 100 % est la valeur normale et 200 % le double. Ajoutez des images clés à l’un ou l’autre pour animer l’espacement.
