Correspondance de palette

Couleur · Ajouté dans la version 3.0.0

Associe chaque pixel à la couleur la plus proche d’une palette : choisissez jusqu’à huit couleurs ou utilisez une palette de 512 couleurs maximum issue d’un préréglage ou d’un fichier importé. Les motifs de tramage mélangent les couleurs voisines pour créer davantage de nuances. Alpha mélange les couleurs obtenues avec le calque d’origine.
