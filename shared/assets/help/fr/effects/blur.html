Flou

Flou · Ajouté dans la version 2.1.0 ou antérieure

Un flou doux et uniforme.

Intensité est la taille du flou : 0 est net, et des valeurs plus élevées adoucissent davantage le calque. Il fonctionne sur les photos, les vidéos, les formes, les textes et les groupes.

  • Animez Force d’une valeur élevée jusqu’à 0 pour faire la mise au point sur un titre ou une photo.
  • Pour flouter tout ce qui se trouve derrière un calque, ajoutez d’abord Copy Background, puis Blur après lui.
  • Pour flouter selon le mouvement, utilisez Motion Blur. Pour garder le contour net, utilisez Inner Blur.
