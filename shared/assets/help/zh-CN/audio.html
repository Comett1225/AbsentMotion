把声音添加到项目中

AbsentMotion 没有内置的音乐或音效库：你可以使用手机中的音频文件、视频的声音，以及由文字生成的语音。

  • 添加、音频 标签：手机中保存的音乐和声音。点按格子即可试听，点按其 + 条即可将其添加到播放头位置。查看全部 会打开文件选择器。首次使用时，应用会请求读取音频文件的权限。
  • 文本转语音（同一标签）：见下文。
  • 视频片段的声音会随片段一起播放。图层菜单中的 提取音频 可将其分离为独立的音频图层。
  • 使用应用内相机录制的视频，如果你允许，也会包含麦克风的声音。
  • 文本闪烁特效会为文本图层逐字输入的每个字符添加一个短促的提示音：参见文本和字体。

音频图层以文件名命名，从播放头位置开始。项目的长度始终跟随最后一个图层的结束位置，因此较长的声音会让项目和导出内容也变长。

在时间轴上，音频图层是一条带有波形的紫色条。可用工具有 速度、修剪和分割、音量、预设、特效、标记节拍 和 AI。人声滤镜位于 特效 中。AI 中包含所选片段的 降噪 和 自动字幕。

音量

音量（扬声器图标）会为声音片段和视频打开音量面板。滑块范围为 0 % 至 150 %（默认 100 %），并带有数值框。可以使用关键帧和缓动按钮为其添加动画，从而实现淡入和淡出效果。没有关键帧且为 0 % 的片段会被静音，扬声器图标会显示这一状态。

面板的第一个按钮 音频特效 会打开该片段的特效。

片段的声音会跟随其速度变化（参见照片、视频和速度）。声道数超过两个的音源会混合为立体声。

电平表

项目播放时，整个项目的电平会显示在一个电平表上。在手机上，它是播放栏下方的细线：左半部分随左声道从中间向外增长，右半部分随右声道增长；削波时对应一侧会变红。横持的平板还会在预览左上角显示一个细长的电平表，电脑则把它显示在窗口左侧、按钮右边、项目名称下方：一个 L 条和一个 R 条，下方以 dB 显示整个项目的电平。

音频特效

对于声音片段，特效 会直接打开已位于 音频 分类中的特效库。对于视频片段，正常的特效库中会有一个 音频 分类。在音量面板中，音频特效 按钮会打开列表。在列表中：

  • 顶部的预设标签会替换整个效果链：收音机、电话、小房间、大厅、体育场、水下、回声、低音增强、人声清晰 和 噪声门。
  • 每一行都有名称、一个眼睛图标（旁通该特效）和一个抓手（调整顺序：顺序即处理顺序）。
  • 添加音频特效 提供下面列出的十种特效。一个片段最多可以容纳 16 个单位：每种特效占 1 个单位，人声滤镜 占 7 个单位。
  • 左侧一列中的 旁通 按钮可同时旁通所有特效，全部删除 则可一次删除全部特效。

每个特效都有一个 混合 滑块（0 至 100 %）以及各自的滑块。点按数值即可手动输入。

特效设置（范围，默认值）
均衡器一个低频搁架、三个中频段和一个高频搁架。低频 20 到 1000 Hz（120）、低频增益、中频 1 到 3 的频率（400、1500、5000 Hz）、增益和 Q（0.1 到 10）、高频 1000 到 20000 Hz（10000）、高频增益。增益范围为 -24 到 24 dB。
低通截止频率 20 到 20000 Hz（5000）、共振 0.1 到 10（0.71）、斜率 12 或 24 dB/oct
高通截止频率（200）、共振、斜率，同上
混响房间大小、阻尼、湿声、干声、宽度（0 至 100 %）、预延迟 0 至 200 毫秒
回声时间 1 到 2000 毫秒（250）、反馈 0 至 95 %、回声电平、乒乓、低切 20 到 2000 Hz
压缩器阈值 -60 至 0 dB（-18）、比率 1 到 20（4）、起音、释音、拐点 0 至 24 dB、补偿增益 0 至 24 dB
噪声门阈值 -100 至 0 dB（-50）、起音、保持、释音、衰减量 0 至 100 dB
高音调数量 0 到 12 个半音（5），向上移调
低音调数量 0 到 12 个半音（5），向下移调
人声滤镜音调 -12 到 12 个半音、低音、高音、闷响、单薄、丰满、回声、混响、乒乓

混响和回声会在片段结束后继续延续，最长可达十秒，并逐渐淡出。效果链末端的限幅器始终开启且无法编辑，它能防止总声音削波（上限为 -1 dB）。

人声滤镜

打开 特效 > 人声滤镜 即可查看十种声音：氦气声、低沉、低音增强、饱满人声、人声清晰、回声、空灵、水下、廉价麦克风 和 电话。选择其中一种会为该片段设置一个 人声滤镜 特效，之后你可以在音频特效中进行微调。选择另一种声音会替换它。

降噪

音频片段的 AI 工具可在手机上降低背景噪声：参见AI工具。

标记节拍

标记节拍 是音频图层工具中的一个格子，也是任何带声音片段的图层菜单中的一个条目。它只会分析该片段，并在找到的每一个节拍处添加一个书签（速度可在每分钟 60 到 180 个节拍之间，且节拍必须遵循稳定的节奏网格）。然后，你可以按书签剪辑视频：它们是时间轴上的吸附点。节拍特效（节拍缩放、节拍抖动、节拍闪烁等）以及设为 按节拍 的 粒子 会依据这些书签运行；若没有书签，它们则依据其 BPM 设置运行。应用会提示“已标记 N 个节拍”、“未找到新的节拍”或“无法找到节拍”。

文本转语音

依次点按 添加、音频、文本转语音，即可使用手机上 Android 已有的语音，将文字转换为语音。它可以离线运行，不使用任何在线服务。

  • 一个文本框（“输入语音要朗读的内容”）。
  • 语言 和 声音（每种语言的声音分别命名为“声音 1”、“声音 2”等）。列表中只显示已安装在手机上的声音，需要联网的声音会被隐藏。如果没有可用的声音，应用会提示“此设备没有离线声音”。你可以在手机自身的文本转语音设置中添加声音。
  • 速度 和 音调，范围为 50 % 至 200 %（默认 100 %）。
  • 预览 会朗读文本，但不会添加任何内容。添加 会在播放头位置创建一个音频图层，以文本开头的几个字命名。

导出中的声音

导出视频时，所有可听片段的混音（包括音量、关键帧、速度和特效）都会被渲染；你也可以只导出声音：参见导出。若要在不打开项目的情况下保存视频文件中的声音，请在 工具 标签中使用 提取音频：参见主屏幕。隐藏的图层不会发出声音。如果某个文件的声音无法读取，应用会在导出后告知你，并且该片段将是无声的。
