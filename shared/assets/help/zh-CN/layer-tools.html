图层工具

选中图层时出现的工具网格，以及其背后的每个面板。

点按一个图层后，底部会打开一组工具。第一行有五个小按钮（速度、修剪和分割、音量），在时间轴中有介绍。无法在播放头所在位置使用的修剪或延伸按钮根本不会显示。它们下方是大按钮，其组合取决于图层的类型。

大按钮分为两页。左右滑动工具网格即可切换页面；其下方的两个圆点表示你所在的页面。只有一页的图层不显示圆点。在大屏平板上，工具位于预览旁边的一列中，全部在同一页，分为两到四列，以便全部显示。

照片或视频是带有图片填充的矩形，因此它与形状拥有相同的工具。

该表列出的是第一页。第二页为除 3D 模型以外、你能看到的每个图层提供 裁剪：形状、文本、绘画、组、照片和视频。视频片段在那里还有四个按钮：AI、自动字幕、倒放和截图；照片在那里也有 AI。当项目的 深度顺序 开启时，第二页的开头还会加入 3D图层（适用于形状、照片、视频、文本、绘画和组）：参见相机图层和 3D。音频、相机、灯光、空对象和 3D 模型图层只有一页。

所有面板

大多数面板在左侧共享一列窄按钮：返回、添加关键帧或移除关键帧、缓动，以及仅在变换和特效中出现的 更多。灰色的关键帧按钮表示该设置无法设置动画。参见关键帧和缓动。

点按任何数字框即可打开数字键盘。第一次点按会选中整个数值，因此输入会替换它。点击对勾即可应用；点按外部则关闭键盘。标尺（带刻度和中心指针的条）在你左右拖动时会改变数字。

变换

右侧的标签：移动、旋转、大小、倾斜、斜切、锚点。对于相机，只有移动、旋转和大小可用，深度顺序开启时还可用倾斜；其他标签显示为灰色。在工具中长按 变换，或打开 更多，即可在 基础控制（移动、旋转、大小和斜切，默认）与 高级控制（全部六个标签）之间切换。

  • 移动。 一个触控板（“拖动此处以移动图层”）以及 X 和 Y 数字框。点按 Z 可沿深度轴移动图层。当图层与画布或另一个图层对齐时，会显示细红色参考线。
  • 旋转。 一个旋钮：拖动旋钮即可旋转，或点按度数即可输入。当图层在 3D 中倾斜时，此标签会变为 3D 触控板：单指倾斜，双指扭转。
  • 大小。 宽度和高度数字框，以及一个保持比例的 链接 按钮（默认开启）。对于相机，此标签会改变视角。链接设置会为每个图层记住并随项目保存；轻扫后标尺会继续滑动。
  • 倾斜。 以度为单位的 X轴旋转 和 Y轴旋转，用于 3D 倾斜。参见相机图层和 3D。
  • 斜切。 以度为单位的 X倾斜 和 Y倾斜。
  • 锚点。 图层旋转和缩放所围绕的点，以像素为单位，从图层中心算起。输入 X 和 Y，拖动触控板，点按九个方格之一以选择角、边或中心，或拖动画布上的标记。图层及其子图层会保持原位。
  • 更多 包含 重置位置、重置旋转、重置缩放、重置3D旋转、重置斜切、重置锚点和 重置变换（全部六项）。

移动即位置，其中 X、Y 和 Z 会一起设置动画。旋转、大小、倾斜、斜切和锚点各自拥有关键帧；宽度和高度共享大小的关键帧。

裁剪

照片、视频以及其他可见图层在工具网格的第二页有 裁剪 按钮。它会使将被裁掉的部分变暗，并显示一个带有八个把手的框：拖动角或边即可裁剪，拖动框内即可移动它。双指仍可缩放画布。自由、1:1、4:5、3:4、16:9 和 9:16 会适配该形状下最大的居中裁剪区域，并在拖动时保持该形状。点按一条边即可输入其数值，重置 会移除裁剪，完成 会关闭面板。关键帧按钮会同时为四条边设置关键帧。裁剪即 裁剪 特效，因此你也可以在 特效 中通过圆角和羽化进行更改；图层位置保持不变。

填充和颜色

顶部标签：无、颜色、渐变、媒体。

  • 颜色。 所选调色板的颜色（默认 调色板有十四种），然后是你保存的颜色。顶部的条显示调色板名称（点按可打开你的调色板），以及 #RRGGBB 格式的颜色及其不透明度；其上的 + 会保存当前颜色。三个按钮：吸管（触摸预览即可取样颜色）、颜色滑块 和 完整取色器（色轮，或 HSV 和 RGB 滑块以及十六进制输入框）。
  • 渐变。 选择线性、径向或扫描，然后选择起始颜色和结束颜色。预览上的两个把手可移动渐变。渐变恰好有两种颜色。
  • 媒体。 用照片或视频填充形状，或填充文本图层的文字。点按后会打开选择器。

只有“颜色”标签中的颜色可以设置关键帧。

调色板

调色板是一组可在每个项目中使用的颜色。填充和颜色 中的颜色条、完整取色器 以及特效设置中的颜色弹窗都会显示所选调色板的颜色。在那里点按调色板名称即可打开 调色板。

  • 点按调色板即可使用它。点按铅笔可进行编辑。
  • 新建 会用你当前所选的颜色创建调色板。从图片 会从照片的 8 种主色中创建调色板；从 AbsentMotion 导出的调色板图片会还原为每种颜色。从文件 会读取调色板文件：GIMP .gpl、Adobe .ase 或 .act、.pal，或十六进制颜色列表，例如你可以从 Lospec 下载的调色板。
  • 在打开的调色板中，点按名称即可重命名，点按 使用 即可选择它。点按颜色即可选中它：添加 会添加你当前所选的颜色，复制 会复制所选颜色，删除 会将其移除。排序 可按 色相、明度 或 饱和度 排列颜色。
  • 导出 会将调色板保存为 Pictures/AbsentMotion 中的 图片（PNG），或 Documents/AbsentMotion 中的 GIMP调色板（.gpl） 或 Adobe色板（.ase）。创建副本 会制作一个可编辑的副本，删除调色板 会在询问后将其移除。
  • 锁定 可防止添加、复制或删除颜色，直到你将其关闭为止。

内置了八种调色板：默认、柔和、霓虹、大地色、肤色、灰色、PICO-8 和 Game Boy。它们是永久锁定的：如需更改，请使用 创建副本。选择内置调色板时，你保存的颜色会显示在它的颜色之后，+ 会保存到这些颜色中。选择你自己的调色板时，+ 会将颜色添加到该调色板中，除非它已被锁定。

在电脑上，将 .gpl、.ase、.act 或 .pal 文件拖到窗口上即可：它会加入你的调色板，并成为所选调色板。你的调色板会保存在备份中：参见项目、备份和导入。

边框和阴影

三个标签：描边、边框 和 阴影。

  • 描边 是形状的轮廓。它有一个开关、颜色、粗细、线帽和连接方式，以及开放线条两端各自的样式（箭头、圆形、菱形等）。
  • 边框 可让你叠加任意数量的边框。每个边框都有粗细、颜色和位置（内部、居中、外部）。拖动把手可更改它们的顺序。添加边框 会添加一个。
  • 阴影 有一个开关，以及 颜色、大小、Alpha 和 位置（X 和 Y）。

不透明度

一个不透明度滑块，带有百分比输入框，以及七组共 28 种混合模式：正常；变暗（正片叠底、变暗、更深的颜色、颜色加深、线性加深）；变亮（滤色、变亮、更浅的颜色、颜色减淡、线性减淡）；对比（叠加、柔光、强光、柔和叠加、亮光、线性光、点光）；差值（差值、排除、减去、划分）；颜色（色相、饱和度、颜色、明度）；以及蒙版（蒙版、排除）。点按一组即可打开它，点按一种模式即可应用。蒙版 仅在此图层所在的位置保留下方的内容；排除 则会移除此图层所在位置下方的内容。

形状选项

定义形状的设置，每行一项，带有标尺和数值框。例如：圆形有大小；圆角矩形有大小和半径；多边形有边数、半径和角度；星形有顶点数、外半径、内半径和角度；箭头有起点、终点、尾部宽度、头部宽度和头部长度。所选行即为关键帧按钮设置动画的那一行。照片和视频在此处使用大小。

编辑点、编辑绘画、编辑文本

这些会打开全屏编辑器：参见形状、绘制和蒙版和文本和字体。

编辑组

打开该组，使时间轴和预览只显示其中的图层，以便你进行更改。参见形状、绘制和蒙版。

相机选项、灯光选项和模型选项

参见相机图层和 3D。

标记节拍

在音频图层上，标记节拍 会在声音的每个节拍处添加一个书签。它的作用与图层菜单中的 标记节拍 相同：参见音频。

音量

适用于声音和视频。参见音频。

AI、自动字幕、倒放和截图

这四个按钮位于视频片段工具网格的第二页（GIF 也算视频）。AI 会打开特效库中的 AI 类别；照片的第二页也有它（用于移除背景），音频图层的唯一一页上也有同样的按钮。自动字幕 仅为此片段生成字幕：参见AI 工具。倒放 会让片段倒着播放：参见媒体。

截图 会将播放头下的片段画面按片段自身的完整尺寸保存为图片。它是原始素材画面：不包括特效、裁剪、边框和图层位置，但修剪、速度更改和倒放都会生效。图片会保存到手机相册（Pictures/AbsentMotion），并作为新图层添加在该片段上方。如果你在 10 秒内删除该新图层，图片也会从相册中删除。播放头必须位于该片段上。
