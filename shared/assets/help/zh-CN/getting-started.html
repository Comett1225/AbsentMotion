安装

AbsentMotion 已安装在这部手机上。本页将带你完成第一个项目。其他页面会介绍每个屏幕。

首次启动

首次打开应用时，它会在主屏幕之前显示两个屏幕。

  1. 选择语言。 应用共提供 25 种语言：英语、印度尼西亚语、印地语、葡萄牙语（巴西）、西班牙语（拉丁美洲）、西班牙语（西班牙）、菲律宾语、越南语、泰语、马来语、阿拉伯语、波斯语、乌尔都语、土耳其语、俄语、孟加拉语、日语、韩语、繁体中文、简体中文、法语、德语、意大利语、波兰语和乌克兰语。若应用提供你手机的语言，则该语言会排在最前面。之后你可以在设置中更改。
  2. 检查本设备的能力。 快速测试会显示你的手机能导出哪些视频格式和尺寸，以及其速度（快速、良好或基础）。测试只运行一次，耗时几秒，所有数据都保留在手机上。你可以点按“跳过”。同一屏幕还有一个开关，允许应用每次打开时向 GitHub 询问一次最新版本号。它默认开启，且不会发送其他任何内容。

应用在启动时不会请求任何权限。首次使用需要它们的功能时，才会请求照片、视频、音频、相机和麦克风的访问权限。

制作第一个项目

  1. 在主屏幕底部点按圆形的 + 按钮。这就是 新建项目。
  2. 选择一种画面比例（16:9、9:16、4:5、1:1 或 4:3）、一种分辨率（1080p 是个不错的起点）和一种背景。如果不确定，就保持帧率不变。点按 创建项目。编辑器会打开一个空项目。详情：创建项目。
  3. 点按时间轴区域右下角的圆形 +，选择要添加的内容：形状、来自 媒体 选项卡的照片或视频，或 文本。
  4. 在预览上拖动以移动图层。双指捏合可放大或缩小。
  5. 在时间轴上左右拖动可在时间中移动。要移动图层的时间位置，请按住其条形后拖动。要修剪它，请先选中它，然后拖动其两端的圆形把手。
  6. 点按播放按钮观看效果。

没有保存按钮。每次更改后片刻，项目就会自动保存。

为对象添加动画

AbsentMotion 中的动画由关键帧组成：关键帧会在某一时刻存储一个值（位置、大小或不透明度），应用则会填充关键帧之间的运动。

  1. 在预览或时间轴上点按一个图层。底部会出现一组工具。
  2. 点按 变换。此时 移动 选项卡已打开。
  3. 将播放头移到动作应开始的位置，然后点按左侧一列中的关键帧按钮（菱形）。
  4. 将播放头移到稍后的时间，并将图层拖到新位置。由于该属性已有关键帧，系统会自动为你创建第二个关键帧。
  5. 点击播放。点按缓动按钮（曲线）可让运动加速、减速或弹跳。参见关键帧和缓动。

如需快速获得效果，请选中一个图层，然后点按预览右下角圆形的 添加动画 按钮，选择入场、出场或循环动画；或打开 特效，尝试其中一个“移动”特效。

导出

  1. 点按顶部栏中的分享图标（名为 导出并分享）。
  2. 已选中 视频 卡片。点按 导出。
  3. 等待进度条完成。在此期间你可以切换到其他应用：通知会显示进度。
  4. 点按 分享视频，或在 Movies/AbsentMotion 中找到该文件。

所有选项（格式、分辨率、帧率、GIF、仅音频）都在导出页面中。
