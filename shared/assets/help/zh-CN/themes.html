主题

在应用中或通过文件创建自己的主题，分享主题，并了解每种主题颜色的用途。

主题会改变整个应用的配色，包括编辑器、时间轴、主屏幕和菜单。你可以选择内置主题，在应用中自行制作，也可以加载别人分享的主题文件。

选择主题

打开 设置，在 选择主题 中选择 跟随系统、浅色、深色、日光、浅绿 或 自定义（制作或导入自己的主题后可用）。下方的 主题颜色 只会更改当前主题的强调色。见设置。

在应用中制作主题

打开 设置，点按 选择主题，然后选择 创建主题…。页面会分组列出所有主题颜色，并显示使用位置和颜色代码。

  • 导入主题文件… 位于顶部，可把主题文件（例如别人分享的）载入页面，方便你在保存前修改。
  • 以此为起点 会用内置主题（或自己的自定义主题）填充所有颜色，你只需改动想改的颜色。
  • 点按某个颜色即可打开取色器。编辑时整个应用会实时更新，你可以直接看到颜色用在各处的效果。
  • 为主题填写 名称，再点按 保存主题。它会成为你的 自定义 主题并立即生效。保存时 主题颜色 会恢复为 默认，以显示主题自带的强调色。
  • 导出 会将主题保存为 .json 文件，方便分享或留存。
  • 直接关闭页面，应用会恢复原来的主题。

应用只保留一个自定义主题。保存或导入新主题会替换原有主题。

制作主题文件

主题文件是一个小型 JSON 文本文件，只需列出你想修改的颜色。将以下内容保存为 mint.json。

{
  "name": "Mint",
  "Accent": "#5BD6A4",
  "HomeAccent": "#1B7A4A"
}

通过 设置 > 选择主题 > 导入主题文件… 加载。应用外观大体保持原样，强调色会变成薄荷绿。

  • 使用 UTF-8 编码的 JSON 纯文本，文件扩展名为 .json，大小不超过 64 KB。
  • name 可省略，超过 40 个字符会被截断。
  • 其他每一行都由下表中的颜色名、一个冒号和用引号括起的颜色值组成。名称的大小写必须与表中完全一致。除最后一行外，每行末尾加逗号。
  • 颜色写为 "#RRGGBB"（红、绿、蓝）或 "#AARRGGBB"（最前面为 Alpha）。应用不支持 #RGB 简写。
  • Alpha（不透明度） 决定颜色有多实。FF 完全不透明，80 半透明，00 完全透明。大多数颜色应当不透明。Alpha 用于遮罩和按压高亮，即 Scrim、MenuScrim、PressEditor 和 PressHome。
  • 未列出的颜色保留 AbsentMotion 的配色。如果设置了 Gold 而省略 Favorite，收藏星标会使用 Gold 的颜色。 SelectionBorder 和 SelectionHandle 也以同样方式分别跟随 Accent 和 OnDark。
  • 不在表中的名称会被忽略。文件至少要包含一种颜色。如果颜色格式有误，应用会拒绝加载文件，并指出有问题的颜色。

提示

  • 编辑器与主屏幕独立配色。AbsentMotion 默认外观使用深色编辑器和浅色主屏幕，你可以分别将它们调成浅色或深色。
  • 确保文字易读。文字颜色（OnDark、HomeInk 及其他以 On 开头的颜色）应与背景有足够的对比度。
  • 有些颜色只在少数位置显示，例如数字键盘、导出预览或已开启的开关。编辑时可以打开相应界面检查效果。
  • 要分享主题，请在 创建主题… 中导出并发送 .json 文件。收到文件的人可以用 导入主题文件… 加载。

所有颜色

颜色按用途分组。第二列列出各颜色主要出现的位置，有些颜色还会用在其他地方。

编辑器

名称使用位置
TopBar编辑器的主要背景，包括顶栏、面板后方的页面，以及预设等全屏工具界面。
PreviewBg视频预览后方、面板内的深色区域（滑块、选择器），以及时间轴末尾之后的空白区域。
TimelineBg时间轴背景、预览下方的播放栏和图层标签所在行的背景。
Panel从底部弹出的面板、工具面板（语音、字幕、拉伸）、电脑端媒体库和电平表。
PanelInset面板上的区块，例如元素库中的卡片、字体浏览器、未按下的数字键和未选中的选项。
Button编辑器中的按钮、卡片、效果行，以及时间轴上图层名称与图层条之间的分隔线。
Field编辑器中的对话框、文本框、列表行和菜单背景。
FieldHi选中或凸起的元素，例如切换控件中选中的标签、滑块轨道的未填充部分、项目安全确认框的边缘，以及电脑端主屏幕上的部分按钮。
Chosen缓动面板的曲线图背景、边框和阴影中选中的项目，以及渐变预览的深色端。
Well深色凹槽，例如媒体和音频标签页中的卡片、滑块轨道（混合和开关），以及数字键盘上的完成键。
Deepest最深色的区域，例如顶栏下划线、取色器网格、电平表背景和文本编辑器顶端的色条。
Line细分隔线，例如时间轴刻度和标题栏边缘、菜单列表的分隔线，以及教程卡片和字体浏览器的边框。
MenuLine编辑器菜单和缓动面板菜单内的分隔线。
PressEditor电脑端编辑器中按压或鼠标悬停时的高亮。

时间轴

这些颜色用于时间轴上的图层条和标记。

名称使用位置
LayerBar时间轴上普通图层（视频、图片、形状等）的图层条。
LayerBarStripe图层条上的条纹。
TextBar时间轴上的文本图层条。
TextBarStripe文本图层条上的条纹。
AudioBar时间轴上的音频图层条。
AudioWave音频条内的波形。
OnBar普通图层条和文本图层条上显示的图层名称。
OnAudioBar音频图层条上显示的图层名称。
Bookmark时间轴上的书签标记。
Gold时间轴上的变速标记、预览中未选中的点、字体浏览器中的搜索文字和进度环、滑块的微调线，以及数字键盘上超出范围的数字。
SelectionBorder电脑上时间轴中所选片段的边框。省略时跟随 Accent。
SelectionHandle电脑上时间轴中所选片段两端的修剪手柄。省略时跟随 OnDark。

数字键盘和菜单

这些颜色用于图层工具中的数字键盘，以及预览后方的深色区域。

名称使用位置
KeyDigit图层工具数字键盘上的 0 到 9 键。
KeySymbol同一数字键盘上的正负号、小数点和退格键。
Cool数字键盘上按键的蓝色标签，以及运动面板中入场侧的轮廓线。
CoolDeep数字键盘按键上选中数字的背景。
Scrim预览后方的深色区块，包括主屏幕上的工具预览（范围、压缩、工具箱）、导出预览和导出完成页，以及社区中没有图片的缩略图。
OnScrim深色区块上的文字和图标，例如导出预览按钮、页数、播放按钮和社区内容的占位图标。

强调色

名称使用位置
Accent主色，用于选中项、活动滑块、编辑器顶栏上的导出按钮、时间轴吸附线和选区、播放标记及主要按钮。这是用途最广的颜色之一。
AccentLit较亮的强调色，用于音量和混合滑块、编辑器开关的圆钮，以及电脑端编辑器的文件夹图标。
AccentGlow面板中用于高亮的浅强调色，例如数字键盘上当前按键的边框和标签。
AccentDeep深强调色，用于编辑器中开启的开关轨道、预览手柄和所选颜色的圆环。
OnAccent强调色上的文字和图标，例如导出图标、强调色按钮和选中的标签按钮。
Warning警告与错误，例如预览过期、文件缺失、片段超出限制，以及项目安全确认框上的删除按钮或危险操作按钮。
Favorite文本编辑器和效果浏览器中代表收藏的实心星标。

深色背景上的文字

这些颜色用于编辑器中的文字和图标。

名称使用位置
OnDark编辑器的主要文字和图标。这是最常用的颜色。
OnDarkDim较淡的文字和图标，例如计数、提示、空列表提示以及电脑端编辑器中的小图标。
Caption面板中的小号提示文字和箭头，以及点编辑器中的引导线。
Faint低对比度的图标和线条，例如点编辑器中未选中的图标、混合及边框和阴影的图标、刻度和取色器的闲置状态。
Inactive关闭或闲置的元素，例如时间轴标尺的刻度和手柄、关闭的开关轨道，以及移动面板中的链接和相机区块。

主屏幕

这些颜色用于主屏幕、设置抽屉、新建项目面板、导出页面和初次使用时的引导页面。

名称使用位置
HomeBg主屏幕背景和其中配色柔和的区块，例如更新内容的标题栏及对话框中的文本框。
Card主屏幕上的卡片与列表行，包括工具、模板、设置抽屉中的行、菜单、导出页面顶栏和教程卡片。
SheetBg面板和页面的背景，包括新建项目面板、导出页面、初次使用时的引导页面和关于页面。
HomeDrawer设置抽屉背景（手机和平板）。
HomePanel主屏幕上低对比度的区块，例如设置抽屉中分组显示的列表行、没有图片的社区内容和安全确认框的按钮。
Navy主屏幕的主深色，用于标题、图标、选中的标签页和标签按钮、选中的按钮和复选框，以及进度条。虽然名为 Navy，实际可设为任意颜色。
OnNavyNavy 底色上的文字和图标，例如选中的标签或按钮上的文字和图标。
OnNavyAccentNavy 底色上的强调文字和图标，包括所选选项和导出按钮的标签，以及主屏幕为浅色时导出页面进度区域的温度文字。
NavyHi设置抽屉列表中选中的行。
NavyLine设置抽屉列表、新建项目面板列表及模板页标签按钮上的线条和边框。
HomeAccent主屏幕的强调色，用于开启的开关、单选按钮、菜单勾选标记、导出页面的提醒文字，以及主屏幕安全确认框中的危险操作按钮。
HomeInk主屏幕的主要文字。
HomeMid主屏幕的次要文字和图标，例如版本信息、箭头、手柄和标签。
HomeDim主屏幕的辅助文字，例如提示、工具说明和小箭头。
HomeFaint主屏幕最淡的元素，例如未选中的分页圆点和新建项目面板中的链接图标。
HomeLine主屏幕上的细线和边框、进度条轨道，以及工具中选中的范围按钮。
MenuScrim在手机或平板上打开菜单时覆盖主屏幕的遮罩。
PressHome主屏幕上按压或鼠标悬停时的高亮。

开关和其他元素

名称使用位置
SwitchOff设置抽屉和导出页面中关闭的开关轨道。
Thumb导出页面和编辑器中关闭的开关圆钮，以及编辑器滑块上的标记。
