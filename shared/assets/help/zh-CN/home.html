主屏幕

你的项目、素材和模板，“工具”选项卡中的工具（压缩、修剪、提取音频、制作GIF 和视频下载器），以及它们周围的按钮。

首次启动后，主屏幕是你最先看到的界面。它会列出你的项目，并提供用于新建项目、搜索和更改设置的按钮。在屏幕足够宽的平板上，顶部栏会变为宽幅标题栏，项目和模板会以网格形式显示，无论竖屏还是横屏。

顶部栏

  • 菜单按钮（左上角，三条横线）。会打开设置抽屉。
  • 中间的 AbsentMotion。
  • 搜索（右侧的放大镜）。会打开搜索框。搜索时，同一位置会显示一个 X 用于关闭搜索框，返回按钮也可以关闭它。

底部栏

  • 项目、模板和工具用于在主屏幕的三个页面之间切换。
  • 它们中间的圆形 + 按钮用于新建项目：参见创建项目。

项目和素材

“项目”页面顶部有两个标签，项目和素材。

  • 项目是你的视频和动画。点按卡片即可在编辑器中打开它。
  • 素材是可重复使用的片段，可以从项目中保存，也可以通过新建项目面板中的 素材 选项创建。你可以在编辑器中将它们添加到其他项目中。参见素材、模板和预设。

项目和素材的存储方式相同；只是在列表中分开显示。

卡片显示的内容

每张卡片都有一个缩略图，角落处显示项目时长；卡片上还有名称，以及两行信息：画面比例（如 16:9）和分辨率（如 1080p），然后是文件大小和帧率。文件大小是项目文件本身的大小，不包括项目所使用的照片、视频和音频，因此一个包含数小时视频的项目仍可能只显示几 KB。

缩略图是在你关闭编辑器时截取的静态画面，位置为播放头所在处。从未在编辑器中打开过的项目可能显示空白缩略图。

卡片菜单

卡片上的三点按钮（名为 更多）包含以下选项。

  • 导出会直接从列表中打开导出屏幕。“当前帧”选项使用第一帧。这也是唯一提供 XML 导出的地方。参见导出。
  • 复制（素材则为 复制素材）会创建一个名为“名称 Copy”的副本，并包含其媒体。
  • 将媒体收集到项目会把项目使用的、位于其自身文件夹之外的每个文件复制到项目中，使其不再依赖你的相册。参见项目、备份和导入。
  • 版本历史会显示项目的早期版本，并让你恢复到其中某一个版本。
  • 删除（素材则为 删除素材）会先请求确认，然后删除项目、其版本以及其他项目未使用的媒体副本。没有回收站：已删除的项目无法恢复，因此如果不确定，请先备份。

如果项目文件已损坏，卡片会显示 已损坏，恢复历史版本，而不是其常规信息。点按它即可恢复较早的版本，或将其删除。

搜索

一个搜索框适用于整个主屏幕。在“项目”页面，它会搜索项目和素材的名称（“搜索项目和素材”）；在“模板”页面，它会搜索模板和预设。搜索不区分大小写和重音符号，你输入的每个词都必须出现在名称中，顺序不限。

排序

在“项目”和“素材”列表中，标题栏会显示 按日期排序 或 按名称排序。点按即可切换。按日期排序会将最新的项目放在最前，并按日期标题分组。按名称排序会按 A 到 Z 排列。应用会记住你的选择。

模板

模板页面有两个标签，我的模板和我的预设。它们在素材、模板和预设中有详细介绍。

工具

工具页面有五张卡片，它们处理文件，且不属于任何项目：压缩、修剪、提取音频、制作GIF和视频下载器。点按卡片即可打开。在平板上，卡片会并排显示，工具会全屏打开；横屏时，其设置会显示在文件旁边的第二列中。

压缩

压缩会为视频或图片制作一个更小的副本，例如用于在聊天中发送。原始文件绝不会被更改。

  1. 点按 选择视频或图片，然后在照片选择器中选择文件。点按 更换 可选择另一个文件。
  2. 在 压缩程度 下，选择 低（明显更小，画质几乎不变）、中等（默认：足够小，适合聊天和社交应用）、高（尽可能小，同时保持良好画质）、Discord 或 自定义。Discord 会适配 Discord 的上传限制，并会询问具体档位：自由（20 MB）、Nitro Basic（50 MB）或 Nitro（1 GB）。
  3. 按钮上方的一行会显示预计大小，例如“约 12 MB（当前为 80 MB）”。如果文件已经很小，或时长过长而无法适配大小限制，它也会提示。
  4. 点按 压缩。进度条会显示进度，点按 取消 可停止。工作期间屏幕会保持常亮。

自定义允许你自行选择所有设置：

设置选项
大小视频：原始、1080p、720p 或 480p。图片：原始、2048、1280 或 800 px
质量最佳、良好、较小或最小；或 指定文件大小，然后输入 MB 数
帧率仅视频：原始、60、30 或 24
声音仅视频：关闭、较小、良好或最佳
格式仅图片：JPEG 或 WebP

完成后，按钮上方的一行会显示压缩前和压缩后的大小，以及文件缩小了多少，例如“17MB → 5.5MB（缩小 66%）”。如果文件没有变小，它会明确告知，并建议保留原始文件。在 结果 下，压缩后 和 压缩前 标签可在新文件与原始文件之间切换预览；预览右上角的按钮会打开 全屏 视图，其中同样有这两个标签。点按 保存到相册 即可保留新文件（视频保存到 Movies/AbsentMotion，图片保存到 Pictures/AbsentMotion），或点按 分享 将其发送到其他应用。

修剪

修剪会保留你选择的视频片段，并将其保存为新的 MP4 视频。原始文件绝不会被更改。

  1. 点按 选择视频。
  2. 在 保留的片段 下，拖动图片条上的两端。上方的大图会显示你正在移动的那一端所在的帧。开始和终点旁边有箭头，可将该端稍微提前或推后，时长会显示所保留片段的长度。
  3. 在 方式 下，选择 快（默认：不重新编码，因此速度快且保持画质；开始点会吸附到最近的视频切点）或 精确（在你选择的位置精确剪切，但耗时更长）。使用“快”时，“开始”箭头会在各个切点之间跳动。
  4. 按钮上方的一行会显示预计大小。点按 修剪。

如果视频几乎没有切点，“快”只能从开头开始，屏幕会说明这一点：请选择“精确”，以便从任意位置开始。

提取音频

提取音频会将视频的声音保存为音频文件。

  1. 点按 选择视频。没有声音的视频会显示“此视频没有声音。”
  2. 格式：M4A（默认）或 MP3。
  3. 质量：较小、良好或最佳。对于 M4A，还有 原始，在视频的声音允许的情况下，它会原样复制声音，不损失任何质量。应用会自动为你选择它。
  4. 按钮上方的一行会显示预计大小和时长。点按 提取。

若要改为从项目中的视频提取声音，请使用图层菜单中的 提取音频：参见音频。

制作GIF

制作GIF会将视频的一部分转换为动画 GIF。

  1. 点按 选择视频。
  2. 在 保留的片段 下，像在修剪中一样选择片段。GIF 最长可达 30 秒。
  3. 大小是 GIF 的长边：320、480（默认）或 720 px。帧率：10、15（默认）或 24。循环：无限循环（默认）或一次。
  4. 按钮上方的一行会显示预计大小和帧数，这些数值是根据几个样本帧测得的。如果 GIF 会超过 25 MB，它会显示“此 GIF 会很大。请尝试更小的大小或更短的片段。”点按 制作GIF。

修剪、提取音频和制作GIF的结果

进度条会显示进度，点按 取消 可停止。完成后，按钮上方的一行会显示新文件的大小，结果区域会显示该文件（声音会显示其名称）。点按 保存 即可保留它，或点按 分享 将其发送到其他应用。视频保存到 Movies/AbsentMotion，GIF 保存到 Pictures/AbsentMotion，声音保存到 Music/AbsentMotion。如果出现问题，该行会说明具体情况，例如“此文件对该手机来说太大。请尝试更小的大小或更短的片段。”

视频下载器

视频下载器可以将链接中的视频保存到你的手机。它需要一个免费的附加组件，这是一次性下载，屏幕上会显示其大小（约 25 MB）。该附加组件包含开源工具 Python 和 yt-dlp，你可以随时在设置中点按 删除视频下载器附加组件 将其移除。它适用于 64 位处理器的手机。

  1. 首次使用时，点按提示“下载需要附加组件”的卡片上的 获取附加组件。
  2. 在其他应用中复制视频的链接，然后点按 粘贴（或在输入框中输入链接；点击 X 可清空）。应用会检查链接，并显示标题、一张小图片及其类型，例如“YouTube · Video · 10:35”。
  3. 在 保存内容 下，选择 视频和音频、仅视频或仅音频。
  4. 在 质量 下，选择该视频提供的某个画质。每个选项都会显示其大小，例如“1080p60 · 约 255MB”。仅含图片的帖子没有可选项：其图片会按原样保存。
  5. 点按 下载。完成后，消息会显示文件的位置，例如“已保存到 Movies/AbsentMotion”，并出现两个按钮：新建项目会打开一个包含该视频的新项目，压缩会打开压缩工具并载入该文件。

按钮下方，支持列出了可用的网站，部分支持列出了有限制条件的网站。点按其中的名称即可阅读限制说明，例如 Instagram 的限时动态和私密帖子需要登录账号，因此无法下载。无法下载的链接会显示原因：视频为私密或已被删除、帖子需要登录账号、这是播放列表、网站阻止了下载，或者没有网络连接。

请只下载你有权使用的内容：屏幕在按钮下方也会重申这一点。

视频下载器暂时不在电脑版中，也不在用于 Chromebook 的 Intel 或 AMD 版本文件中。

导入项目文件

默认情况下，主屏幕没有导入按钮。你可以通过其他应用（文件管理器、消息）使用“分享”或“打开方式”打开项目文件，应用会接收该文件。如果你更喜欢按钮，请在设置中开启 在项目列表中显示导入卡片；此时“项目”列表顶部会出现一张带有 选择文件 的卡片。参见项目、备份和导入。

出现问题时

  • 如果应用意外关闭，下次启动时会显示 AbsentMotion意外关闭，并附上原因；如果有未保存的编辑，还会提供恢复选项。
  • 崩溃日志位于设置中的 崩溃日志 下。
  • 如果版本过旧，应用可以提示你有较新的版本：参见设置。
