点按主屏幕底部的圆形 + 按钮。一个面板会从底部滑出。它会以你上次使用的值打开（画面比例、分辨率、帧率和背景；名称总是新的）。点按“返回”可在不创建任何内容的情况下关闭它。

项目还是素材

顶部的开关有两个选项：项目（默认）和素材。素材是一个具有透明背景的可重复使用的片段：其背景设置锁定为“透明”。参见素材、模板和预设。

名称

名称默认为“新项目 1”“新项目 2”，依此类推（素材默认为“新素材”）。点按输入框中的 X 即可清空。空白名称会回退为默认名称。

画面比例

16:9、9:16、4:5、1:1 和 4:3 按钮，以及一个用于自定义画面比例的铅笔按钮。默认为 1:1。手机视频选择 9:16，横屏视频选择 16:9。

分辨率

分辨率 一行显示画布尺寸，例如 1920 x 1080。对于五种画面比例，它是一个短边列表：

选项短边
2160p（4k）2160
1440p（QHD）1440
1080p（FHD），默认1080
720p（HD）720
540p（SD）、360p、270p、180p与名称一致

长边随画面比例而定。16:9 的 1080p 项目为 1920 x 1080，4:5 的项目为 1080 x 1350，4:3 的项目为 1440 x 1080。

选择自定义画面比例后，列表会变为宽度和高度两个数字输入框，中间有一个圆形的链接按钮。开启链接后，更改一边会保持开启链接时两个输入框所具有的比例。每边可在 32 到 4096 像素之间；离开输入框时，应用会修正数值。

若要保存尺寸以便日后使用，请点按输入框下方的 + 保存尺寸，并为其命名（例如“横幅”）。已保存的尺寸会显示为其旁边的按钮；点按其中一个即可填入其宽度和高度。长按已保存的尺寸（电脑上为右键单击）即可重命名或删除。在编辑器中，选择自定义比例时，项目设置也会提供相同的已保存尺寸。

更大的画布画面更清晰，但需要更多内存，导出也更慢。1080p 适合大多数项目。你之后可以在编辑器的项目设置中更改分辨率，这不会缩放你的图层。

帧率

可选择 12、15、18、20、24、25、30、48、50、60、90 或 120 fps（每秒帧数）。默认为 60。若想要电影般的质感和更小的文件，请使用 24 或 30；快速运动流畅时使用 60。90 和 120 适用于高刷新率屏幕上非常流畅的运动；并非每部手机都能以如此快的速度导出视频，导出屏幕会告诉你你的手机是否无法做到。此设置决定编辑器和导出绘制画面的频率。视频片段保留其自身的帧率；参见导出页面中的帧插值选项。

背景

图层后方的颜色：黑色、白色、浅灰色、绿色、蓝色 或 透明（以棋盘格显示）。新安装时默认为透明。导出的视频中透明区域会显示为黑色；GIF 和图片导出可以让你选择透明区域变为何种颜色，而 PNG 会保留透明。

底部按钮

  • 创建项目（素材则为 创建素材）会创建项目，并在编辑器中打开它。
  • 其下方的 X 会关闭面板。

如果存储空间不足，应用会提示，并且不会创建项目。
