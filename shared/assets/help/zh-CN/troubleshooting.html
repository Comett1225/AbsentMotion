应用自行关闭

Android会关闭占用内存过多的应用。这种情况最可能出现在 4K 视频、大量复杂特效，或同时打开其他应用时。

  1. 重新打开 AbsentMotion。如果它显示 AbsentMotion意外关闭，请点按恢复，找回你最近的编辑。
  2. 关闭其他应用，然后重新尝试该项目。
  3. 在预览条或设置中，将预览画质降低到一半或四分之一。
  4. 在设置中开启使用大型视频的预览副本（默认已开启）。
  5. 以较低的分辨率导出，或将很长的项目拆分开。

在设置的崩溃日志中，每次崩溃都会用一句话说明发生了什么。点按复制即可复制内容，然后将其附在 GitHub 的错误报告中发送。不会自动发送任何内容。

此手机无法运行编辑器

AbsentMotion 通过 Vulkan 1.1 使用图形芯片绘制预览和导出画面；如果手机不支持 Vulkan，则改用 OpenGL ES 3.0。如果两者都无法启动，应用会显示 此手机无法运行编辑器，并附带 Android 版本和图形芯片信息，而不是直接关闭。你的项目、设置、备份和崩溃日志仍然可以打开。点按复制详情可复制这些信息，以便添加到 GitHub 的错误报告中。参见系统要求和版本。如果编辑器能打开，但预览或导出画面看起来不对，请前往设置中的图形，选择 OpenGL。

如果 AbsentMotion 在图形启动过程中自行关闭，它会记住这一点。当图形设为自动时，下次启动会改用另一种图形接口，例如用 OpenGL 代替 Vulkan，从而让应用能够再次打开。这一设置会针对此手机上的此版本应用保留。

媒体缺失

图层为空，或导出时显示媒体缺失：项目使用的某个照片、视频或音频文件已不在手机上。

  • 选择该图层，在图层菜单中打开媒体信息，然后点按替换媒体文件，重新选择文件。
  • 在文件仍然存在时，使用项目卡片菜单中的将媒体收集到项目，让项目保存自己的副本。
  • 在设置中保持在项目中保留导入媒体的副本开启。

如果仍然导出，使用缺失文件的图层将不会包含在内。

导出问题

提示信息处理方法
存储空间不足释放手机空间，或选择较小的分辨率。预计大小显示在导出界面上。
此手机不支持手机的编码器无法生成该尺寸或编解码器。点按建议中的使用，或选择 H.264 和较小的尺寸。
导出缓慢只有软件编码器可用，或者在这些设置下硬件编码器速度较慢。可以继续，或选择建议的设置。
导出变慢手机温度较高，它会刻意降速以便降温。让手机冷却，或将手机从保护壳中取出。
导出失败，无法绘制画面帧请重试。如果问题反复出现，请降低分辨率，或关闭帧插值。
导出失败，视频编码器忙碌或无法生成该尺寸关闭其他正在播放或录制视频的应用，然后重试。如果问题反复出现，请选择较低的分辨率或帧率。
导出失败，视频解码器或编码器已停止工作另一个应用正在占用手机的视频硬件。请关闭正在播放或录制视频的应用，然后重试。
"手机的视频编码器正忙，因此本次导出将使用较慢的软件编码器"这不是错误：导出会耗时更长。关闭其他视频应用，下次即可恢复使用较快的硬件编码器。
导出的视频显示为静止画面并带有播放按钮手机无法立即播放该视频。点按播放按钮可再次尝试；文件本身已保存。
导出的视频没有声音隐藏的图层或音量为 0% 的片段是静音的。已保存到存储空间界面中的"已检查：..."一行会报告缺少音轨。

切换到其他应用时，导出会继续进行，并通过通知显示进度。从最近使用的应用列表中关闭 AbsentMotion，导出便会停止。

存储空间已满

  • 从主屏幕删除不用的项目，并从 Movies/AbsentMotion 中删除旧的导出文件。
  • 在设置中点按清除预览副本，最多可释放 2 GB 空间。
  • Documents/AbsentMotion 中的备份可能很大：将它们复制到电脑上，然后从手机中删除。
  • 如果保存失败，应用会提示。请释放空间后继续。

运行缓慢

  • 降低预览画质。
  • 使用预览条中的快速模糊选项。
  • 大型照片和视频很占资源。对视频使用预览副本，并在添加之前缩小非常大的照片。
  • 大量带特效的图层会累积负担。隐藏暂时不编辑的图层（点按眼睛图标）。

三星手机无法安装更新

在三星手机上，自动阻止程序可能会阻止 AbsentMotion 下载的更新。如果可能是此原因，更新已停止会显示："三星的自动阻止程序可能正在阻止此更新。"这会在 Android 报告安装被阻止时立即显示，或在同一更新连续两次安装失败后显示。

  1. 打开手机的设置，进入安全和隐私，选择自动阻止程序，然后将其关闭。
  2. 返回 AbsentMotion，点按重试以安装更新。你的项目不会受影响。
  3. 如果需要，请重新开启自动阻止程序。

文本使用了错误的字体

项目使用了此手机上没有的字体。请打开项目，在此手机没有这些字体中点按下载。字体下载需要联网一次。

常见问题

真的免费吗？ 是的。没有订阅、没有账号、没有水印，也没有广告。它是开源软件，采用 GNU General Public License v3.0 许可。

需要联网吗？ 不需要。只有一些可选功能会使用网络：下载 Google 字体、下载一次字幕模型，以及可选的更新检查。参见隐私。

我的项目在哪里？ 保存在应用的私有存储中，包括你添加的所有媒体文件。可以在设置中备份。导出的文件位于 Movies、Pictures、Music 和 Documents 下的 AbsentMotion 文件夹中。

可以把项目移到另一部手机上吗？ 可以：导出项目包，将 .absproj 文件复制到另一部手机上，然后在那里打开。

可以打开其他编辑器的项目吗？ 部分可以。参见项目、备份和导入。

有电脑版吗？ 有，从 5.0 版开始提供，适用于 Mac、Windows 和 Linux 电脑。手机版仍然是优先开发的版本。参见在电脑上使用 AbsentMotion。

有哪些语言？ 英语、印度尼西亚语、印地语、葡萄牙语（巴西）、西班牙语（拉丁美洲）、西班牙语（西班牙）、菲律宾语、越南语、泰语、马来语、阿拉伯语、波斯语、乌尔都语、土耳其语、俄语、孟加拉语和日语。可以在设置中更改。

如何报告问题或提出功能建议？ 请在 GitHub 上提交 issue。请不要在其中包含私人信息。

源代码在哪里？ 位于 GitHub上的项目页面。
