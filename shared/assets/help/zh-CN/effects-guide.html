使用特效

添加、叠加、重新排序、隐藏、复制和为特效设置动画，并在特效库中找到合适的特效。

特效会改变图层的外观或运动方式：例如模糊、发光、变色或抖动。一个图层可以拥有任意数量的特效。AbsentMotion 共有 216 种特效，分为十二个类别。本网站上的特效库列出了每种特效及其全部设置。

添加特效

  1. 选择一个图层。
  2. 在工具网格中点按 特效。
  3. 点按列表末尾的 添加特效。特效库 会打开。
  4. 点按一种特效。它会以标准设置添加，并立即打开其设置。

要先了解某个特效，请长按其格子。页面会打开，显示动画预览、说明、一个用于将其标记为收藏的星标、+ 标准设置，以及部分特效提供的现成预设。

特效库

  • 顶部有一个搜索框（“搜索”），会先匹配名称，再匹配说明，同时还能找到AI工具和预设。
  • 顶部是推荐特效条（色度抠像、模糊和发光），然后是你的 最近使用 或 收藏 特效网格，再往下是各个分类。要在“最近使用”和“收藏”之间切换，请点按两个小图标、在网格上左右滑动，或长按图标直到手机振动，然后滑动手指（向右为“收藏”，向左为“最近使用”）。
  • 分类： 颜色、模糊、扭曲、风格化、噪点、重复、抠像、移动、节拍、3D、文本和其他。新建 分类会列出最新大版本（5.x）中新增的特效。对于有声音的图层会出现 音频 分类，AI 分类则包含AI工具。
  • 手机无法运行的特效会显示为灰色。
  • 在某个分类内，向左滑动可切换到下一个分类，向右滑动则切换到上一个分类。

特效设置

点按列表中的某个特效即可打开它。其标题栏包含特效名称、一个三点菜单和一个垃圾桶图标。

  • 每个数值都带有一个刻度尺和一个数值框。点按某个设置的名称，可将其设为关键帧按钮的目标。位置类设置可以通过在预览上拖动来移动。
  • 颜色设置会打开一排快速色块和一个用于输入精确颜色的输入框。弹出框还会显示所选调色板的名称和颜色；点按名称即可打开你的调色板。
  • 开关用于开启或关闭某个选项。选项类设置会打开一个列表。
  • 调色板设置（在调色板映射和复古抖动中）会显示其全部颜色。预设 会列出复古主机和电脑的调色板，例如 PICO-8、Game Boy 和 Commodore 64。导入 可读取调色板文件：最多 256 种颜色的图片（较大的图片会缩减为 256 色），或 Photoshop 的 .ase 或 .act、GIMP 的 .gpl、.pal、.hex 或 Paint.NET 的 .txt 文件，就像你可以从 Lospec 下载的调色板一样。
  • 复古抖动（抖动）和调色板映射（抖动图案）的抖动图案会打开一个面板，其中显示每种图案的小样图，方便你根据效果进行选择。所选图案带有橙色边框。向上滑动网格可查看其余图案。
  • 三点菜单中有 特效信息、恢复默认值、复制、复制特效 和 粘贴特效数值（仅当你复制过同类特效时才会出现）。
  • 垃圾桶图标会删除该特效。点按标题栏即可将其收起。

如果该图层是其他图层的父级，特效顶部会出现一个 应用于子图层 开关（移动特效和重复特效除外）。

特效列表

  • 顺序很重要：位于顶部的特效会先应用。按住某一行的抓手（调整顺序）并拖动即可改变顺序。轻点抓手会打开该特效，与轻点该行的其他位置相同。
  • 眼睛图标（可见性）可在不删除特效的情况下将其隐藏。
  • 向左滑动某一行即可删除该特效。撤销即可将其恢复。
  • 左侧一列中的 更多 包含 复制特效（你可以勾选要复制的特效）以及 粘贴特效，它们会将已复制的特效添加到所选图层列表的末尾。

同时为多个图层添加特效

选中多个图层（参见图层菜单和多选），然后点按底部栏中的 特效。为全部添加特效 会打开特效库，并将你选择的特效添加到所有选中的图层上。粘贴所有特效 会将你在某个图层上复制的特效粘贴到所有选中的图层上。声音图层、相机图层和空对象图层会被跳过。

为特效设置动画

特效中的每个数值、颜色和位置都可以设置关键帧。打开特效，点按设置的名称，将播放头移动到所需位置，然后点按关键帧按钮。缓动按钮可以调整关键帧之间的运动方式。参见关键帧和缓动。

特效中的预设

有八种特效自带现成的预设：文本进度（打字机、逐词淡入、逐字上滑、弹出）、文本变换（波浪、旋转级联）、文本随机化（扰乱）、计数增减（计数增加）、文本抖动（紧张、害怕、不安、飘浮、波动、眩晕、摇晃）、文本闪烁（英雄、怪物、机器人、快嘴、打字机）、ASCII（终端、二进制雨、琥珀显示器、报纸、方块、线稿）以及粒子（雪、火花、彩纸、气泡、尘埃、爱心、闪烁、花瓣、图层喷泉、节拍彩纸）。

  • 在已打开的特效上，点按其标题栏中的 预设。列表会显示每个预设及其小图；点按某个即可使用。
  • 在特效库中，长按某个特效，其页面会在 预设 下列出预设，并附有图片。
  • 预设旁边的星标可将其标记为收藏。收藏的预设会排在特效库 收藏 条的前面。
  • 搜索预设的名称即可找到其所属的特效。

这些与图层的 预设 工具不同，后者保存的是你自己的外观：参见素材、模板和预设。

特殊类型的特效

  • 移动特效（自动抖动、摆动、摇摆、旋转、随机位移、随机抖动、脉冲、回声、偏移、沿路径移动、真实运动模糊）会自行为图层制作动画。父级助手 和 缩放辅助 也在这里：见下文。
  • 重复特效会将图层复制成一排、一圈、一个网格、沿路径排列或随机分散。请参见下文的 重复：每个副本的延迟和随机。
  • 3D特效会将图层变为立方体、球体、圆环和其他立体图形。此时“旋转”标签会控制该特效的旋转。
  • 节拍特效（节拍模糊、节拍闪烁、节拍故障、节拍发光、节拍脉冲、节拍RGB分离、节拍旋转、节拍抖动和节拍缩放）会在音乐的每个节拍上触发。请先选中音乐片段，然后点按其工具或图层菜单中的 标记节拍；若没有节拍标记，它们则依据 BPM 设置运行。参见音频。
  • 抠像特效（色度抠像、亮度抠像）可移除某种颜色，或图层中的暗部和亮部，例如绿幕。
  • 文本特效（文本进度、文本变换、文本随机化、文本抖动、文本闪烁、字重、计数增减、时间码、沿路径排列文本）会逐字为文本制作动画。参见文本和字体。
  • 音频特效作用于声音：参见音频。
  • AI工具（移除背景、降噪）在手机上运行：参见AI工具。
  • 其他中包含 复制背景，即调整图层：见下文。

裁剪属于抠像类特效，可裁掉图层的边缘。图层还带有一个 裁剪 按钮，位于工具网格的第 2 页，可在画布上显示裁剪效果：参见图层工具。

粒子

粒子（位于风格化中）会让粒子从图层中飞散出来。粒子类型 决定粒子的形态：雪、火花、彩纸、气泡、尘埃、爱心、星星、花瓣，或图层本身的小副本。发射器 决定粒子的起始位置：一个点、一条线、一个区域，或图层的轮廓。发射方式 决定发射的时机：持续（每秒 速率）、爆发（在你选择的时刻发射 数量 个粒子），或按节拍（在音乐的每个节拍上爆发，需要前面所述的节拍标记）。再往下是粒子的 寿命、速度 和 方向，以及 重力、风 和 漩涡 等作用力，还有它们的 大小 和 颜色。更多设置 会打开精细的控制项。其中提供十种预设，可作为起点（参见上文的特效中的预设）。

打开 深度 后，粒子还会飞向或远离相机：Z速度 使它们在深度上移动，Z散布 让它们的起始深度各不相同，透视 则设置远处粒子变小的程度。此时粒子也会跟随图层的3D旋转；若 排序 设为 按分块，则每个粒子都会与其他3D图层的分块按深度排序：参见相机图层与3D。

3D散布、3D碎裂和视频反馈

3D散布（位于3D中）会将图层变为一个由小立方体、球体、方块或圆形组成的网格，这些小块采用图层的颜色。网格间距 和 分块大小 用于设置网格，网格深度 会在其后方添加行，散开 会将分块在3D中向外抛散，扭转角度 会围绕扭转轴旋转网格。光照设置会为分块添加明暗效果。

3D碎裂（位于3D中）会将图层打碎成玻璃碎片。为 进度 设置动画，从 0（完整）到 1（破碎）；冲击点、力度、重力、旋转 和 深度推进 决定碎片如何飞散。

两者都会跟随图层自身的3D旋转、其父级的旋转以及相机，并会在图层倾斜或环绕时一同转动。它们的分块会相互前后穿插。开启 深度顺序 后，整个特效也会根据其深度位于其他图层的前方或后方。当 排序 设为 按分块 时，其分块也会穿插在其他图层的分块之间；特效卡片上的 将分块与其他图层混合 可为单个图层关闭此功能。灯光图层会为分块添加明暗效果。参见相机图层与3D。

视频反馈（位于重复中）会让图层不断地在自身内部重新绘制，就像摄像机对着自己的屏幕拍摄一样。缩放、旋转 和 偏移 用于设置每一步；开启 使用图层变换 后，移动、缩放或转动图层都会控制这条“隧道”的走向。淡化 和 色相偏移 会改变每个副本，延迟 则会让内部副本比图层的动画晚一会儿再跟随。

复制背景

复制背景（位于其他中）会将图层变为调整图层。它会复制该图层下方绘制的所有内容，你在其后添加的特效会作用于这份副本，因此一组特效就能同时改变其下方的所有图层。请将该图层放在你希望改变的图层之上。蒙版至图层 会将改变限制在图层自身的形状之内，混合 会恢复图层自身的填充，特效超出边界 则允许后续特效将副本延伸到图层边缘之外。它以前叫作“调整图层”，搜索“调整图层”仍然能找到它。使用了它的项目会继续正常工作。

ASCII

ASCII（位于风格化中）会将任何图层变为由字母和符号组成的文字艺术。大小 以图层为单位进行测量，因此字符会随图层一起移动、转动和缩放。选择 字符（或输入你自己的字符），保留图片的颜色或使用单一颜色，并可添加 边缘线 以生成轮廓。参见ASCII。

重复：每个副本的延迟和随机

线性重复、径向重复、网格重复 和 沿路径重复 各有五个设置，可使每个副本各不相同：

  • 每个副本的延迟（-60 到 60 秒）会让每个副本的动画比前一个副本晚播放这么多，使运动在副本之间依次传递。负值则会让它们更早播放。仅当图层设置了动画（例如使用关键帧或移动特效）时才会显示此项。
  • 随机位置、随机旋转、随机缩放 和 随机不透明度 会让每个副本随机地移动、旋转、缩放和淡化，幅度不超过你设置的值。种子 可以选择另一种随机图案。

当使用其中任何一项时，重复最多只会生成 256 个副本。

父级助手和缩放辅助

两者都位于 移动 中。父级助手 用于改变子图层跟随父图层的方式：其缩放和旋转可以完全跟随、保持 已锁定，或按你设置的 权重 跟随；自动旋转 会在图层移动时让它转动，就像滚动的车轮。缩放辅助 会沿 X、Y、两者，或 X 与 Y 反向方向增加额外的缩放（挤压和拉伸效果），并且图层的子图层会跟随新的尺寸。参见父级助手和缩放辅助。

小贴士

  • 如果在有许多特效时预览变慢，请将 预览画质 切换为二分之一或四分之一。导出不受影响。
