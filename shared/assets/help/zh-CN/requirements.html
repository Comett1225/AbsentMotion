两个版本

AbsentMotion 提供两个版本，以便更多手机可以使用。

版本Android说明
最新版13 或更高版本全部功能。
兼容版8 至 12部分功能被省略。参见 兼容版。

Android 7 及更早版本无法运行 AbsentMotion。要查看你的 Android 版本，请打开设置，依次选择“关于手机”和“Android 版本”。

手机需要满足的条件

  • ARM 芯片。 通常为 64 位（也称为 arm64）：过去几年发布的几乎所有手机和平板都有这种芯片。以 Android Go 版销售的廉价手机通常运行 32 位系统：它们需要 兼容版 32 位 文件，并且需要 Android 8 或更高版本。
  • Vulkan 1.1 或 OpenGL ES 3.0。 AbsentMotion 使用手机的图形芯片绘制预览和导出：手机支持时通过 Vulkan 1.1，不支持时通过 OpenGL ES 3.0。使用 OpenGL 时预览会更慢，并且 AI 平滑、AI 增强、AI 背景移除 2.0 和 光流法高档 将不可用。在 设置、图形 中可以切换这两种方式。
  • 内存。 建议 4 GB 或以上 RAM。内存较少的手机也能处理较小的 1080p 项目，但当项目包含 4K 视频或大量高负载特效时，Android 可能会关闭应用。如果应用被关闭，请参见 故障排除。
  • 可用存储空间，用于保存项目、所用的媒体以及导出文件。导出界面会在开始前检查可用空间。
  • 竖屏。 应用是为竖向持握的手机设计的。平板会获得为大屏幕设计的布局，支持竖屏和横屏：参见 编辑器界面。

使用应用无需账户、Google 账户或网络连接。只有少数可选功能使用网络，隐私 页面列出了所有这些功能。

Chromebook

AbsentMotion 可在能够安装 Android 应用的 Chromebook 上运行。

  • 使用 ARM 芯片的 Chromebook 与手机使用相同的文件。
  • 使用 Intel 或 AMD 芯片的 Chromebook 有专用文件，为 x86_64 构建：最新版 Intel 或 AMD（-foss-x86_64.apk，需要 Android 13 或更高版本）和 兼容版 Intel 或 AMD（-compatible-x86_64.apk，Android 9 至 12）。它们位于 下载页面 和 发布页面 的所有下载列表中。
  • 如果你在 Intel 或 AMD 的 Chromebook 上安装了手机版文件，请在其上安装 Intel 或 AMD 文件。你的项目会保留。
  • 在这些 Chromebook 上，设置 中的 检查更新 会自行下载 Intel 或 AMD 文件。
  • 视频下载器 在 Intel 或 AMD 文件中无法使用。
  • 在 Chromebook 上，应用会以大窗口打开。

速度

运行速度取决于手机的芯片。在大多数中端或更高级芯片的手机上，播放和编辑都很流畅。导出 4K 视频以及 AI 工具（字幕、视频背景移除）在较旧或较廉价的芯片上会花费更长时间；导出界面会在开始前显示预计时间，首次启动时的检测会将你的手机评为“快速”、“良好”或“基础”。

测试设备

已在运行 Android 16 和 17 的手机，以及 Android 13 及以上版本的模拟器上测试。其他手机只要符合上述要求应该也能正常工作，但没有人能测试所有机型。

你电脑上的 AbsentMotion

从 5.0 版本起，也提供电脑版。它与手机版是同一个应用，具有相同的特效、项目和导出功能，但界面针对鼠标和键盘进行了布局。手机版仍然优先。

  • Mac： 搭载 Apple 芯片（M1 或更新）或 Intel 芯片的电脑，系统为 macOS 11 或更新版本。请从 发布页面 下载适合你芯片的 Mac 文件：Apple 芯片选 -macos-arm64.dmg，Intel 选 -macos-x64.dmg。首次打开时，macOS 会提示无法检查该应用：点按 完成，然后打开 系统设置 > 隐私与安全性，点按 仍要打开。
  • Linux： 64 位电脑，芯片为 ARM（arm64）或 Intel 或 AMD（x86_64），运行 Ubuntu 22.04、Debian 12 或更新版本，或 glibc 2.35 或更高版本的其他 Linux。从 发布页面 下载：.deb 软件包，会将 AbsentMotion 添加到 Ubuntu、Debian 及类似系统的应用菜单中；.AppImage，无需安装即可运行：将其标记为可执行，然后打开；或 .tar.gz，可为你的用户在任何发行版（Arch、Fedora、openSUSE 等）上安装：解压后运行 install.sh。选择文件名中带有 arm64 或 x86_64 的文件。README 中为每种 Linux 提供了逐步安装说明。
  • Windows： 搭载 Intel 或 AMD 芯片的 64 位 Windows 10 或 11。请从 发布页面 下载安装程序（-windows-x64.msi）。它会为你的用户安装，并将 AbsentMotion 添加到开始菜单和桌面。如果 Windows 提示已保护你的电脑，请点击 更多信息，然后点击 仍要运行。

在 Linux 上，AbsentMotion 通过 Vulkan 使用图形芯片绘制。如果没有 Vulkan 驱动（在 Ubuntu 和 Debian 上为软件包 mesa-vulkan-drivers），它会改用处理器绘制，速度较慢，并且帧混合、光流法和运动模糊平滑以及 Datamosh 将无法使用。

电脑版的不同之处：

  • 媒体、声音和对象的素材库位于左侧，预览位于中间，检查器位于右侧，用于编辑所选图层。下方的时间轴为每个图层分配单独的一行。
  • 将文件从文件管理器拖入窗口，或链接一个文件夹，使其媒体显示在素材库中。将素材库中的图块拖到时间轴或预览上即可添加。
  • 在预览中拖动图层可以移动，拖动角点可以调整大小。按住 Alt 并滚动可缩放；加上 Shift 可旋转。使用鼠标中键拖动，可移动预览或时间轴的视图。
  • 在时间轴上右键点击片段，可打开菜单，其中包含剪切、拷贝、粘贴、复制、分割、删除、组合等选项。双击组可以打开它。
  • 键盘快捷键在 Mac 上使用 Cmd（在 Windows 和 Linux 上为 Ctrl）：空格键播放和暂停，方向键每次移动一帧（按住 Shift 时为十帧），Cmd+Z 撤销，Cmd+Shift+Z 重做，Cmd+C、Cmd+X 和 Cmd+V 分别拷贝、剪切和粘贴图层，Cmd+D 复制，Cmd+B 在播放头处分割，Option+左 和 Option+右（在 Windows 和 Linux 上为 Alt）跳转到上一个或下一个书签，然后跳转到开头或结尾；逗号键和句号键可将所选片段微调一帧（按住 Shift 时为十帧），Delete 删除所选图层，Cmd+E 打开导出。
  • 顶部的栏是应用的一部分，带有系统自带的窗口按钮（Mac 上在左侧，Windows 和 Linux 上在右侧）。退出按钮旁的 ☰ 按钮会打开“文件”、“编辑”、“视图”、“播放”和“帮助”菜单。如果该栏造成问题，请进入 设置 > 编辑器 > 使用系统标题栏，即可恢复普通标题栏。
  • 每个项目只显示你在其中选择或链接的媒体。在素材库中右键点击文件夹，然后选择 固定到所有项目，即可在每个项目中看到它。搜索时会先列出该文件夹，然后再列出其中匹配的文件。
  • 未选择任何内容时，检查器会显示项目：名称、尺寸、帧率、背景、时长、历史版本和图层列表。整个项目的电平表位于左侧按钮的右边。
  • 效果上的 ? 会在应用内的小窗口中打开其帮助；用 X 或 Esc 关闭。
  • 拍照或拍摄视频会使用电脑的网络摄像头。
  • 视频下载器尚未在电脑版上提供。

要在手机和电脑之间移动项目，请将其导出为 项目包（.absproj），并在另一台设备上打开该文件。参见 项目、备份与导入。
