目錄特效

需求與版本

AbsentMotion 可在哪些 Android 版本、手機與 Chromebook 上執行、最新版與相容版的差異，以及電腦版本。

兩種版本

AbsentMotion 提供兩種版本，讓更多手機都能使用。

版本Android說明
最新版13 或更新版本所有功能。
相容版8 至 12部分功能不會包含在內。請參閱相容版本。

Android 7 及更舊版本無法執行 AbsentMotion。若要查看您的 Android 版本，請開啟「設定」>「關於手機」>「Android 版本」。

手機需求

  • ARM 晶片。 通常為 64 位元（也稱為 arm64）：過去幾年推出的幾乎所有手機與平板都採用此晶片。以 Android Go 版販售的廉價手機通常執行 32 位元系統：它們需要 Android 8 或更新版本的 相容版 32 位元 檔案。
  • Vulkan 1.1 或 OpenGL ES 3.0。 AbsentMotion 會使用手機的圖形晶片繪製預覽與匯出內容：手機支援時使用 Vulkan 1.1，不支援時則使用 OpenGL ES 3.0。使用 OpenGL 時，預覽會較慢，而且不包含 AI平滑、AI增強、AI背景移除2.0 與 光流：高。在 設定 的 圖形 中可以切換這兩者。
  • 記憶體。 建議使用 4 GB 以上的 RAM。RAM 較少的手機可用於較小的 1080p 專案，但當專案包含 4K 影片或大量繁重的特效時，Android 可能會關閉應用程式。若應用程式關閉，請參閱疑難排解。
  • 可用儲存空間，用於您的專案、其使用的媒體與匯出檔案。匯出畫面會在開始前檢查可用空間。
  • 直向螢幕。 本應用程式專為直向握持的手機設計。平板會使用為大螢幕設計的版面，支援直向與橫向：請參閱編輯器畫面。

使用本應用程式不需要帳號、Google 帳號或網路連線。只有少數選用功能會使用網路，隱私權頁面列出了所有這些功能。

Chromebook

AbsentMotion 可在能安裝 Android 應用程式的 Chromebook 上執行。

  • 採用 ARM 晶片的 Chromebook 使用與手機相同的檔案。
  • 採用 Intel 或 AMD 晶片的 Chromebook 有各自的檔案，為 x86_64 所建置：最新版，Intel 或 AMD（-foss-x86_64.apk，Android 13 或更新版本）與 相容版，Intel 或 AMD（-compatible-x86_64.apk，Android 9 至 12）。這些檔案列於下載頁面及發行版頁面的所有下載項目中。
  • 如果您在 Intel 或 AMD Chromebook 上安裝了手機版檔案，請在其上方安裝 Intel 或 AMD 版檔案。您的專案會保留。
  • 在這些 Chromebook 上，設定中的 檢查更新 會自動下載 Intel 或 AMD 版檔案。
  • 影片下載器 無法在 Intel 或 AMD 版檔案中使用。
  • 在 Chromebook 上，應用程式會以大型視窗開啟。

速度

運作速度取決於手機的晶片。大多數搭載中階或更高階晶片的手機，播放與編輯都很順暢。在較舊或較便宜的晶片上，匯出 4K 影片以及 AI 工具（字幕、影片去背）會花費較長時間；匯出畫面會在您開始前顯示預估時間，而首次啟動時的檢查會將您的手機評為「快速」、「良好」或「基本」。

測試環境

已在執行 Android 16 與 17 的手機，以及 Android 13 及更新版本的模擬器上測試。其他手機若符合上述需求應可運作，但沒有人能測試每一款機型。

在電腦上使用 AbsentMotion

從 5.0 版起，也會提供電腦版本。它與手機版是同一個應用程式，具有相同的特效、專案與匯出功能，但版面為滑鼠與鍵盤而設計。手機版仍然優先。

  • Mac： 搭載 Apple 晶片（M1 或更新版本）或 Intel 晶片的電腦，需 macOS 11 或更新版本。請從發行版頁面下載適合你晶片的 Mac 檔案：Apple 晶片請用 -macos-arm64.dmg，Intel 請用 -macos-x64.dmg。第一次開啟時，macOS 會顯示無法檢查此應用程式：請點選完成，然後開啟系統設定 > 隱私權與安全性，再點選強制打開。
  • Linux： 64 位元電腦，採用 ARM（arm64）或 Intel 或 AMD（x86_64）晶片，執行 Ubuntu 22.04、Debian 12 或更新版本，或其他 glibc 2.35 或更新版本的 Linux。請從發行版頁面下載：.deb 套件，會將 AbsentMotion 加入 Ubuntu、Debian 及類似系統的應用程式選單；.AppImage，無需安裝即可執行：將其設為可執行後開啟；或 .tar.gz，可在任何發行版（Arch、Fedora、openSUSE 等）上為您的使用者安裝：解壓縮後執行 install.sh。請選擇檔名中含有 arm64 或 x86_64 的檔案。各種 Linux 的逐步安裝說明，請參閱 README。
  • Windows： 搭載 Intel 或 AMD 晶片的 64 位元 Windows 10 或 11。請從發行版頁面下載安裝程式（-windows-x64.msi）。它會為你的使用者帳戶安裝，並將 AbsentMotion 加入開始功能表和桌面。如果 Windows 顯示已保護你的電腦，請點選其他資訊，再點選仍要執行。

在 Linux 上，AbsentMotion 會透過 Vulkan 使用圖形晶片繪製。若沒有 Vulkan 驅動程式（在 Ubuntu 與 Debian 上為 mesa-vulkan-drivers 套件），則會改用處理器繪製，速度較慢，且影格混合、光流與動態模糊平滑，以及 Datamosh 都無法使用。

電腦版的不同之處：

  • 媒體、音效與物件的媒體庫位於左側，預覽位於中間，右側為屬性面板，用於編輯所選的圖層。下方的時間軸會為每個圖層提供各自的列。
  • 將檔案從檔案管理員拖曳到視窗中，或連結一個資料夾，使其媒體顯示在媒體庫中。從媒體庫將項目拖曳到時間軸或預覽上即可新增。
  • 在預覽中拖曳圖層即可移動，拖曳角落即可調整大小。按住 Alt 並捲動滾輪可縮放；再加上 Shift 則可旋轉。使用滑鼠中鍵拖曳，可移動預覽或時間軸的檢視範圍。
  • 在時間軸上的片段按右鍵，即可開啟包含剪下、拷貝、貼上、複製、分割、刪除、群組等功能的選單。按兩下群組即可開啟。
  • 鍵盤快速鍵在 Mac 上使用 Cmd（在 Windows 與 Linux 上為 Ctrl）：空白鍵可播放與暫停；方向鍵逐影格移動（按住 Shift 則移動十個影格）；Cmd+Z 復原，Cmd+Shift+Z 重做；Cmd+C、Cmd+X 與 Cmd+V 分別拷貝、剪下與貼上圖層；Cmd+D 複製；Cmd+B 在播放頭處分割；Option+左鍵與 Option+右鍵（在 Windows 與 Linux 上為 Alt）會跳到上一個或下一個書籤，然後跳到開頭或結尾；逗號鍵與句點鍵會將所選片段逐影格微調（按住 Shift 則十個影格）；Delete 會刪除所選圖層；Cmd+E 會開啟匯出。
  • 頂端的列是應用程式的一部分，並包含系統自己的視窗按鈕（Mac 上位於左側，Windows 與 Linux 上位於右側）。關閉按鈕旁的 ☰ 按鈕會開啟檔案、編輯、檢視、播放與說明選單。如果頂端列造成問題，請前往 設定 > 編輯器 > 使用系統標題列，即可恢復一般標題列。
  • 每個專案只會顯示您在其中選取或連結的媒體。在媒體庫中的資料夾上按右鍵，並選擇 釘選至所有專案，即可在每個專案中看到該資料夾。搜尋時，會先列出資料夾，然後列出其中符合的檔案。
  • 未選取任何項目時，屬性面板會顯示專案：名稱、大小、影格速率、背景、長度、較早的版本和圖層清單。整個專案的音量計位於左側按鈕的右邊。
  • 特效上的 ? 會在應用程式內的小視窗中開啟其說明；可按 X 或 Esc 關閉。
  • 拍攝相片或影片時會使用電腦的網路攝影機。
  • 影片下載器目前尚未提供於電腦版。

若要在手機與電腦之間移動專案，請將其匯出為 專案套件（.absproj），然後在另一台裝置上開啟該檔案。請參閱專案、備份與匯入。
