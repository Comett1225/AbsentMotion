AbsentMotion 不會收集、儲存或分享個人資料。沒有帳號、沒有廣告、沒有分析工具，也沒有追蹤。本頁為隱私權政策的摘要；完整內容請見原始碼中的 PRIVACY.md 檔案。

您的專案與媒體

專案、匯入的圖片、影片與音訊，以及您匯出的所有內容，都只會留在您的手機上。相片、影片與音訊權限只是讓應用程式在手機上顯示您的媒體庫，並使用您選取的檔案。不會上傳任何內容。

相機與麥克風權限只會在應用程式內建的相機開啟時使用。錄製的內容會儲存在手機上。備份會寫入手機上的 Documents/AbsentMotion，並且只留在手機中。

匯出進行時，應用程式會在通知中顯示進度，因此切換到其他應用程式時，匯出仍會繼續。在 Android 13 及更新版本上，首次匯出時會要求通知權限；如果您拒絕，匯出功能仍然相同。

如果應用程式意外關閉，它會在自己的儲存空間中保留當機記錄：發生時間、一句話的原因、應用程式與 Android 版本、手機型號、您當時正在做的事，以及技術錯誤訊息。只保留最近 20 筆，這些記錄不會包含在手機備份中，而且絕不會傳送到任何地方。您可以在設定中閱讀、複製或刪除它們。

應用程式何時會使用網路

應用程式只會在以下情況要求網路權限：

  • 字型。 當您選擇其中一種可下載的字型時，應用程式會從 Google Fonts 下載該字型。與任何網頁請求一樣，Google 會收到該字型的請求以及您的 IP 位址。
  • 自動字幕。 首次產生字幕時，應用程式會告知語音模型的大小（約 57 MB），並從 Hugging Face 下載。語音辨識在手機上執行。
  • AI增強與AI平滑。 第一次使用其中一項功能時，應用程式會告知所需模型的大小（約 1 到 11 MB），並從 GitHub 下載。AI 運算本身在手機上執行。
  • AI背景移除2.0。 只有在您選擇使用 AI 背景移除 2.0 來移除背景時，應用程式才會從 GitHub 下載其模型一次（約 62 MB）。去背運算本身在手機上執行。
  • 影片下載器。 只有在您使用「工具 > 影片下載器」時才會：首次使用時，應用程式會下載其附加元件（約 25 MB）：Python 來自 python.org，yt-dlp 來自 GitHub（github.com，由 objects.githubusercontent.com 或 release-assets.githubusercontent.com 提供）。附加元件安裝後，它每天最多會向 GitHub 詢問一次是否有較新的 yt-dlp，若有則下載。當您貼上連結時，附加元件會連線到該網站（例如 YouTube、Instagram 或 TikTok），讀取影片資訊並下載您選擇的部分，其方式與網頁瀏覽器相同；檔案會儲存在裝置上。
  • 檢查更新。 若您允許（應用程式只會詢問一次；開關位於設定中），應用程式每次開啟時都會向 GitHub 發出一次一般的 HTTPS 請求，以讀取最新版本號碼。不會傳送其他任何內容。與任何網頁請求一樣，GitHub 會看到您的 IP 位址。

除此之外，不會傳送任何內容。文字轉語音會使用手機上已有的語音，並可離線運作。
