點選首頁左上角的選單按鈕即可開啟設定抽屜。其中有四個預設為收合的群組（點選群組即可展開），下方還有幾個列。

編輯器

  • 主題。 AbsentMotion（預設：深色編輯器與溫暖的淺色首頁）、日光（全部為淺色）或自訂。匯入主題檔案... 會從一個小型檔案載入主題（見下文）。
  • 新圖層長度。 新圖層的持續時間：1 到 10、15、20、25、30、45 或 60 秒。預設為 2 秒。
  • 震動。 在時間軸上吸附、長按與重新排序時的輕微震動。預設為開啟。
  • 預覽中的轉場按鈕。 預設為關閉。新增轉場的圓形按鈕通常位於時間軸區域的右下角。開啟此選項後，它會改為位於預覽的左下角。請參閱轉場與動畫。
  • 表情符號樣式。 系統（手機的表情符號，為預設值）或 ANDROID（隨應用程式附帶的表情符號字型，在每支手機上都相同）。

自訂主題

主題檔案是小型的 JSON 格式文字檔，大小上限為 64 KB，可選擇性地包含 name，以及您想要更改的任何顏色（以 #RRGGBB 或 #AARRGGBB 格式書寫）。未填寫的顏色會保留 AbsentMotion 的外觀。例如：

{"name": "Mint", "Accent": "#5BD6A4", "HomeAccent": "#1B7A4A"}

顏色名稱為編輯器與首頁的顏色：TopBar、PreviewBg、TimelineBg、Panel、PanelInset、Button、Field、FieldHi、Chosen、Well、Deepest、Line、MenuLine、KeyDigit、KeySymbol、Scrim、PressEditor、OnDark、OnDarkDim、Caption、Faint、Inactive、OnScrim、Accent、AccentLit、AccentGlow、AccentDeep、OnAccent、Cool、CoolDeep、Gold、Warning、Bookmark、LayerBar、LayerBarStripe、TextBar、TextBarStripe、AudioBar、AudioWave、OnBar、OnAudioBar、HomeBg、Card、SheetBg、Navy、HomeAccent、OnNavy、OnNavyAccent、NavyHi、NavyLine、HomeInk、HomeMid、HomeDim、HomeFaint、HomeLine、HomePanel、HomeDrawer、SwitchOff、Thumb、MenuScrim 與 PressHome。同一時間只會保留一個自訂主題；匯入新檔案會取代舊的，並立即套用。

播放與預覽

  • 預覽品質。 FULL、HALF 或 QUARTER（預設為 FULL）：編輯器預覽的清晰度。數值較低時，在較慢的手機上會較快，且不會影響匯出。同一個切換鈕也位於編輯器的預覽列中。
  • 圖形。 AUTOMATIC 或 OPENGL（預設為 AUTOMATIC）：應用程式繪製預覽與匯出內容的方式。AUTOMATIC 會使用 Vulkan，並在 Vulkan 無法啟動時切換為 OpenGL。若應用程式在圖形啟動期間自行關閉，下次啟動時會改用另一種。若此手機上的預覽或匯出畫面看起來不正確，請選擇 OPENGL。切換鈕下方的文字會顯示目前使用的是哪一種。使用 OpenGL 時，部分 AI 工具不會包含在內；請參閱需求與版本。
  • 播放重新取樣。 LOW、HIGH 或 ULTRA（預設為 ULTRA）：編輯器播放時，以及為匯出混音時，聲音重新取樣的品質。
  • 大型影片使用預覽副本。 預設為開啟。對於大於 1920 x 1080 或關鍵影格較少的影片，應用程式會在背景建立一個小型、輕量的副本，並用於預覽。匯出時一律使用原始檔案。副本會保存在最多 2 GB 的快取中。
  • 清除預覽副本會刪除這些副本。此列會顯示它們所佔用的空間。
  • 閒置時預先算圖預覽。 預設為開啟。當你停下片刻，應用程式會在背景為播放頭附近的畫面算圖，直到為此預留的記憶體用滿。時間尺規底部的一條細綠線會標出已準備好的畫面，這些畫面可以順暢播放。變更只會捨棄受影響的畫面。關閉它可節省電力或記憶體。

專案與媒體

  • 在專案清單中顯示匯入卡片。 預設為關閉。會在專案清單頂端加入一張附有 選擇檔案 的卡片。
  • 將匯入的媒體保留副本於專案中。 預設為開啟。您新增的相片、影片或音訊會複製到專案內，因此即使原始檔案被移動或刪除，仍可繼續使用。如果您從不移動檔案，可以關閉此選項以節省儲存空間。
  • 去背品質。 標準 或 AI背景移除2.0：移除相片背景時所得到的去背類型。請參閱 AI 工具。
  • 移除字幕模型。 只有在字幕用的語音模型已下載後才會顯示。此列會顯示檔案大小，並刪除該檔案；若您之後使用字幕，應用程式會重新下載。
  • 刪除 AI……模型。 每個已下載的 AI增強或 AI平滑模型各有一列，並顯示其大小。點選後會刪除該模型；下次需要時，應用程式會再次下載。
  • 刪除影片下載器附加元件。 只有在附加元件已下載後才會顯示。此列會顯示附加元件所佔用的空間，並將其移除；下次使用影片下載器時，它會再次要求下載。請參閱首頁。
  • 使用圖形晶片執行 AI。 僅對已知可安全用於 AI平滑與 AI增強的較新圖形晶片預設為開啟；其他手機則由處理器執行這些功能。若要在其他晶片上開啟，系統會先詢問，因為這可能導致部分手機凍結。請參閱 AI 工具。

備份

  • 備份所有專案、從備份還原與每週自動備份（僅限專案）（預設為關閉）。請參閱專案、備份與匯入。

語言

語言列會顯示目前的語言，並開啟 25 種語言的清單：英文、印尼文、印地文、葡萄牙文（巴西）、西班牙文（拉丁美洲）、西班牙文（西班牙）、菲律賓文、越南文、泰文、馬來文、阿拉伯文、波斯文、烏爾都文、土耳其文、俄文、孟加拉文、日文、韓文、中文（繁體）、中文（簡體）、法文、德文、義大利文、波蘭文與烏克蘭文。選取後會立即套用。

關於、說明與其他列

  • 說明會在應用程式內開啟本指南，無需網路連線。
  • 開始教學會開始一段 5 分鐘的導覽。您會在練習專案中製作一段短動畫，因此您自己的專案不會受到影響。若您中途離開導覽，此列會變為繼續教學，並會出現第二列重新開始教學。首頁也會持續提供導覽，直到您選擇不再詢問。
  • 關於會顯示版本、授權條款（GNU 通用公眾授權條款第 3 版）、AbsentMotion 為獨立專案的說明、開放原始碼授權（本應用程式所使用之每個程式庫的完整授權條款），以及兩個會在網頁瀏覽器中開啟的連結：專案首頁（GitHub 儲存庫）與網站與指南（含本指南的 AbsentMotion 網站）。
  • 回報問題（位於關於下方、帶底線的連結）會在網頁瀏覽器中開啟錯誤回報表單。
  • 當機記錄會列出應用程式記錄的當機事件。點選其中一筆即可閱讀，並使用複製將其複製，例如附在錯誤回報中一併傳送。請參閱疑難排解。
  • 每次開啟應用程式時檢查新版本。 應用程式會詢問您一次是否允許此功能。若開啟，應用程式會在啟動時向 GitHub 發出一次請求，以取得最新版本號碼。除此之外不會傳送任何內容，也絕不會自行下載或安裝任何東西。
  • 檢查更新會立即執行一次相同的檢查。若有較新的版本，對話框會顯示其版本與下載大小。更新紀錄會開啟其版本說明，下載更新則會在應用程式內下載相符的應用程式檔案（最新版或相容版，以及搭載 Intel 或 AMD 晶片之 Chromebook 所需的 Intel 或 AMD 檔案），並顯示進度列與取消按鈕。在下載任何內容之前，若 Android 尚未允許，應用程式會要求您為 AbsentMotion 開啟允許來自此來源。應用程式會以發行版本的校驗碼與簽署金鑰檢查檔案，接著 Android 會要求您確認安裝。若找不到相符的檔案，下載會開啟發行版頁面。在三星手機上，Auto Blocker 可能會阻擋安裝：請參閱疑難排解。
