安裝

AbsentMotion已安裝在這支手機上。本頁將帶你完成第一個專案。其他頁面則說明每個畫面。

首次開啟

第一次開啟應用程式時，首頁出現之前會先顯示兩個畫面。

  1. 選擇語言。 應用程式共有25種語言：英文、印尼文、印地文、葡萄牙文（巴西）、西班牙文（拉丁美洲）、西班牙文（西班牙）、菲律賓語、越南文、泰文、馬來文、阿拉伯文、波斯文、烏爾都文、土耳其文、俄文、孟加拉文、日文、韓文、中文（繁體）、中文（簡體）、法文、德文、義大利文、波蘭文和烏克蘭文。若應用程式支援你手機的語言，該語言會列在最前面。之後你可以在設定中變更。
  2. 檢查此裝置的能力。 快速測試會顯示你的手機能匯出哪些影片格式與尺寸，以及速度如何（快速、良好或基本）。測試只需執行一次，約幾秒鐘，所有資料都留在手機上。你可以點選「略過」。同一個畫面有一個開關，可讓應用程式在每次開啟時，向GitHub詢問一次最新的版本號碼。此開關預設為開啟，且不會傳送其他任何資料。

應用程式在開始時不要求任何權限。第一次使用需要照片、影片、音訊、相機與麥克風的功能時，才會要求相關存取權限。

製作第一個專案

  1. 在首頁底部點選圓形的+按鈕。這就是新增專案。
  2. 選擇一種比例（16:9、9:16、4:5、1:1 或 4:3）、一種解析度（1080p是不錯的起點）以及一種背景。若不確定，請不要更動影格速率。點選建立專案。編輯器會開啟一個空白專案。詳細說明：建立專案。
  3. 在時間軸區域右下角點選圓形的+，然後選擇要新增的項目：形狀、來自媒體分頁的照片或影片，或是文字。
  4. 在預覽畫面上拖曳即可移動圖層。以雙指捏合可放大或縮小。
  5. 在時間軸上向左或向右拖曳，即可在時間中前後移動。若要在時間上移動圖層，請按住它的色條後拖曳。若要修剪，請先選取它，再拖曳兩端的圓形把手。
  6. 按下播放按鈕即可觀看。

沒有「儲存」按鈕。每次變更後，專案都會在片刻之後自動儲存。

為物件加上動畫

AbsentMotion的動畫是由關鍵影格組成：關鍵影格會在某個時間點儲存一個數值（位置、大小或不透明度），應用程式則會自動補上關鍵影格之間的移動。

  1. 在預覽或時間軸上點選一個圖層。底部會出現一組工具格。
  2. 點選變形。移動分頁會開啟。
  3. 將播放頭移到動作應該開始的位置，然後點選左欄的關鍵影格按鈕（菱形）。
  4. 將播放頭移到較晚的時間，再把圖層拖曳到新的位置。由於此屬性已有關鍵影格，系統會自動為你新增第二個關鍵影格。
  5. 播放。點選緩動按鈕（曲線），即可讓動作加速、減速或彈跳。參見關鍵影格與緩動。

想快速得到結果時，請選取圖層，點選預覽右下角圓形的製作動畫按鈕，然後選擇「In」、「Out」或「Loop」動畫；或開啟特效，試用其中一個移動特效。

匯出

  1. 點選頂部列中的分享圖示（名為匯出與分享）。
  2. 影片卡片已被選取。點選匯出。
  3. 等待進度列完成。期間你可以切換到其他應用程式：通知會顯示進度。
  4. 點選分享影片，或到Movies/AbsentMotion找到檔案。

所有選項（格式、解析度、影格速率、GIF、僅音訊）都在匯出頁面中。
