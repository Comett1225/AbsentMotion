首頁是首次啟動後你第一個看到的畫面。它會列出你的專案，並提供建立專案、搜尋與變更設定的按鈕。在螢幕夠寬的平板電腦上，頂部列會變成寬版標題列，專案與範本會以格狀顯示，直向與橫向都是如此。

頂部列

  • 選單按鈕（左上角，三條線）。會開啟設定抽屜。
  • 中間的 AbsentMotion。
  • 搜尋（右側的放大鏡）。會開啟搜尋欄位。搜尋時，同一位置會顯示一個 X 來關閉它，返回鍵也能關閉它。

底部列

  • 專案、範本和工具可在首頁的三個頁面之間切換。
  • 位於它們中間的圓形 + 按鈕會建立新專案：參見建立專案。

專案與素材

專案頁面頂部有兩個標籤：專案與素材。

  • 專案是你的影片與動畫。點選卡片即可在編輯器中開啟它。
  • 素材是你從專案儲存的可重複使用元件，或使用新專案面板中的 素材 選項建立的元件。你可以在編輯器中把它們加入其他專案。參見素材、範本與預設集。

專案與素材的儲存方式相同，只是在清單中分開列出。

卡片顯示的內容

每張卡片都有一張縮圖，角落會顯示專案長度；卡片上還有名稱，以及兩行資訊：長寬比（例如16:9）與解析度（例如1080p），然後是檔案大小與影格速率。檔案大小指的是專案檔本身的大小，不包含專案所使用的照片、影片與音訊，因此一個含有數小時影片的專案，仍可能只顯示幾 KB。

縮圖是你關閉編輯器時所拍下的靜態畫面，位置為播放頭所在處。從未在編輯器中開啟過的專案，可能會顯示空白縮圖。

卡片選單

卡片上的三點按鈕（名為更多）包含以下項目。

  • 匯出會直接從清單開啟匯出畫面。「目前影格」選項會使用第一個影格。這也是唯一提供 XML 匯出的地方。參見匯出。
  • 複製（素材則為複製素材）會建立一份名為「名稱 Copy」的副本，連同其媒體一起複製。
  • 將媒體收集至專案會把專案使用、位於其資料夾之外的每個檔案複製進專案中，因此它不再依賴你的相簿。參見專案、備份與匯入。
  • 版本紀錄會顯示專案的舊版本，並讓你還原到其中一個版本。
  • 刪除（素材則為刪除素材）會要求確認，然後刪除該專案、它的各個版本，以及沒有其他專案使用的媒體副本。沒有垃圾桶：被刪除的專案無法復原，如果不確定，請先做好備份。

若專案檔案損毀，卡片會顯示已損毀，請還原版本，取代原本的資訊。點選它即可還原較早的版本，或將其刪除。

搜尋

同一個搜尋框適用於整個首頁。在專案頁面中，它會搜尋專案與素材的名稱（「搜尋專案與素材」）；在範本頁面中，它會搜尋範本與預設集。搜尋時會忽略大小寫與重音符號，你輸入的每個字都必須出現在名稱中，順序不限。

排序

在專案與素材清單中，標題列會顯示依日期排序或依名稱排序。點選即可切換。依日期排序會將最新的項目放在最前面，並依日期標題分組；依名稱排序則是由 A 到 Z。應用程式會記住你的選擇。

範本

範本頁面有兩個標籤：我的範本與我的預設集。它們的說明請見素材、範本與預設集。

工具

工具頁面有五張卡片，都是用來處理檔案的，與任何專案無關：壓縮、修剪、擷取音訊、製作GIF和影片下載器。點選卡片即可開啟。在平板電腦上，卡片會並排顯示，而工具會以全螢幕開啟；橫向持握時，它的設定會顯示在檔案旁的第二欄。

壓縮

壓縮會為影片或圖片製作一份較小的副本，例如用來在聊天中傳送。原始檔案永遠不會被更改。

  1. 點選選擇影片或圖片，然後在相片選擇器中選取檔案。變更會改選另一個檔案。
  2. 在壓縮程度下方，選擇低（明顯較小，外觀幾乎相同）、中等（預設：小到足以用於聊天與社群應用程式）、高（盡可能小，且看起來仍然不錯）、Discord或自訂。Discord會配合 Discord 的上傳上限，並會詢問你的方案：自由（20 MB）、Nitro Basic（50 MB）或 Nitro（1 GB）。
  3. 按鈕上方的那一行會顯示預計的大小，例如「約12 MB（目前為80 MB）」。若檔案已經夠小，或長度太長而無法符合大小上限，它也會說明。
  4. 點選壓縮。進度列會顯示進度，點選取消即可停止。工作期間螢幕會保持亮起。

自訂可讓你自行選擇所有設定：

設定選項
大小影片：原始、1080p、720p 或 480p。圖片：原始、2048、1280 或 800 px
品質最佳、良好、小或最小；或是指定檔案大小，然後輸入以 MB 為單位的大小
影格速率僅影片：原始、60、30 或 24
聲音僅影片：關閉、小、良好或最佳
格式僅圖片：JPEG或WebP

完成後，按鈕上方那一行會顯示原本與新的大小，以及檔案縮小了多少，例如「17MB → 5.5MB（縮小66%）」。若檔案沒有變小，它會直接說明，並建議保留原始檔案。在結果下方，壓縮後與壓縮前標籤可以切換預覽，顯示新檔案或原始檔案；預覽右上角的按鈕會開啟全螢幕檢視，其中同樣有這兩個標籤。點選儲存至相簿即可保留新檔案（影片會存到Movies/AbsentMotion，圖片會存到Pictures/AbsentMotion），或點選分享將它傳送到其他應用程式。

修剪

修剪會保留你所選的影片部分，並將它儲存為新的 MP4 影片。原始檔案永遠不會被更改。

  1. 點選選擇影片。
  2. 在保留的片段下方，拖曳影格條上的兩端。上方的大圖會顯示你正在移動的那一端所在的影格。開始與終點旁各有箭頭，可讓該端稍微提前或延後，而時長會顯示所保留片段的長度。
  3. 在修剪方式下方，選擇快速（預設：不重新編碼，因此很快，也能保留畫質；開始點會對齊到影片最近的切點）或精確（會在你選擇的位置精確切割，但耗時較長）。使用快速時，開始的箭頭會從一個切點跳到下一個切點。
  4. 按鈕上方那一行會顯示預計的大小。點選修剪。

如果影片幾乎沒有切點，快速只能從開頭開始，畫面也會說明這一點：選擇精確即可從任何位置開始。

擷取音訊

擷取音訊會把影片的聲音儲存為音訊檔案。

  1. 點選選擇影片。沒有聲音的影片會顯示「此影片沒有聲音。」
  2. 格式：M4A（預設）或 MP3。
  3. 品質：小、良好或最佳。若是 M4A，還有原始選項，在影片的聲音允許的情況下，它會不經任何損失地原樣複製聲音。應用程式會替你自動選擇它。
  4. 按鈕上方那一行會顯示預計的大小與長度。點選擷取。

若要改為取出專案內某個影片的聲音，請使用圖層選單中的擷取音訊：參見音訊。

製作GIF

製作GIF會將影片的一部分轉為動態 GIF。

  1. 點選選擇影片。
  2. 在保留的片段下方，依照修剪的方式選擇片段。GIF 最長可達30秒。
  3. 大小是 GIF 的長邊：320、480（預設）或 720 px。影格速率：10、15（預設）或 24。循環：無限循環（預設）或一次。
  4. 按鈕上方那一行會顯示預計的大小與影格數，這是以幾個樣本影格測得的。若 GIF 會超過25 MB，它會顯示「此 GIF 會很大。請嘗試較小的大小或較短的片段。」點選製作GIF。

修剪、擷取音訊與製作GIF的結果

進度列會顯示進度，點選取消即可停止。完成後，按鈕上方那一行會顯示新檔案的大小，結果會顯示該檔案（聲音會顯示其名稱）。點選儲存即可保留它，或點選分享將它傳送到其他應用程式。影片會存到Movies/AbsentMotion，GIF 會存到Pictures/AbsentMotion，聲音則存到Music/AbsentMotion。若發生錯誤，該行會說明原因，例如「此檔案對這支手機來說太大。請嘗試較小的大小或較短的片段。」

影片下載器

影片下載器可將連結中的影片儲存到你的手機。它需要一個免費的附加元件，這是一次性的下載，畫面會顯示其大小（約25 MB）。此附加元件包含開放原始碼工具 Python 與 yt-dlp，你之後可以在設定中以刪除影片下載器附加元件將它移除。它適用於具備64位元處理器的手機。

  1. 第一次使用時，在寫著「下載需要附加元件」的卡片上點選取得附加元件。
  2. 在其他應用程式中複製影片的連結，然後點選貼上（或直接在欄位中輸入連結；X 會清除它）。應用程式會檢查連結，並顯示影片的標題、一張小圖，以及它的類型，例如「YouTube · 影片 · 10:35」。
  3. 在儲存內容下方，選擇影片和音訊、僅影片或僅音訊。
  4. 在品質下方，選擇該影片提供的其中一種畫質。每個選項都會顯示其大小，例如「1080p60 · 約255MB」。只含圖片的貼文沒有可選的項目：其圖片會以原樣儲存。
  5. 點選下載。完成後，訊息會說明檔案的位置，例如「已儲存至Movies/AbsentMotion」，並出現兩個按鈕：新增專案會開啟一個含有該影片的新專案，壓縮則會以該檔案開啟壓縮工具。

按鈕下方的支援會列出可正常使用的網站，部分支援則列出有限制的網站。點選其中的名稱即可閱讀其限制，例如 Instagram 的限時動態與私人貼文需要登入帳號，因此無法下載。無法下載的連結會顯示原因：影片為私人或已被移除、貼文需要登入帳號、清單式播放、網站封鎖了下載，或是無法連線。

請只下載你有權使用的內容：按鈕下方的畫面也會再次提醒這一點。

影片下載器尚未提供電腦版，也不提供給 Chromebook 的 Intel 或 AMD 版本。

匯入專案檔

預設情況下，首頁沒有匯入按鈕。你可以從其他應用程式（檔案管理員、訊息）使用分享或開啟方式來開啟專案檔，應用程式會接收它。若你希望有按鈕，請在設定中開啟在專案清單中顯示匯入卡片；之後專案清單頂部就會出現一張附有選擇檔案的卡片。參見專案、備份與匯入。

發生問題時

  • 若應用程式意外關閉，下次啟動時會顯示AbsentMotion意外關閉，並附上原因；若有尚未儲存的編輯，還會提供還原的選項。
  • 當機記錄位於設定中的當機記錄。
  • 若版本過舊，應用程式可以告訴你有較新的版本：參見設定。
