點選首頁底部的圓形 +。面板會從底部滑出。它會以你上次使用的數值開啟（形狀、解析度、影格速率與背景；名稱則一律是新的）。點選「返回」即可關閉它，不會建立任何內容。

專案或素材

頂部的切換有兩個選項：專案（預設）與素材。素材是具有透明背景的可重複使用元件：其背景設定會鎖定為透明。參見素材、範本與預設集。

名稱

名稱一開始為「新專案 1」、「新專案 2」，依此類推（素材則一開始為「新素材」）。點選欄位中的 X 即可清除它。空白的名稱會退回預設值。

畫面形狀（長寬比）

提供 16:9、9:16、4:5、1:1 與 4:3 按鈕，以及一個用來設定自訂長寬比的鉛筆按鈕。預設為 1:1。手機直式影片請選 9:16，橫向影片請選 16:9。

解析度

解析度列會顯示畫布尺寸，例如 1920 x 1080。對於五種形狀，它是一份短邊的清單：

選項短邊
2160p (4k)2160
1440p (QHD)1440
1080p (FHD)，預設1080
720p (HD)720
540p (SD)、360p、270p、180p依所列名稱

長邊依形狀而定。1080p 的 16:9 專案為 1920 x 1080，4:5 專案為 1080 x 1350，4:3 專案則為 1440 x 1080。

使用自訂長寬比時，清單會變成兩個數字欄位，分別為寬度與高度，中間有一個圓形的連結按鈕。連結開啟時，變更其中一邊會保持你開啟連結時兩個欄位所具有的比例。每一邊可介於 32 至 4096 像素之間；離開欄位時，應用程式會修正數值。

若要保留一個尺寸供日後使用，請點選欄位下方的 ＋儲存大小，並為它取一個名稱（例如「Banner」）。已儲存的尺寸會以按鈕形式出現在旁邊；點選其中一個即可填入其寬度與高度。長按已儲存的尺寸（在電腦上則為按右鍵）即可重新命名或刪除它。在編輯器中，當你選擇自訂比例時，專案設定也會提供相同的已儲存尺寸。

較大的畫布看起來較清晰，但需要更多記憶體，匯出也較久。1080p 適用於大多數專案。之後你可以在編輯器的專案設定中變更解析度，且這不會縮放你的圖層。

影格速率

可選擇每秒 12、15、18、20、24、25、30、48、50、60、90 或 120 個影格。預設為 60。想要電影般的質感與較小的檔案，請使用 24 或 30；想要快速動作的流暢感，請使用 60。90 與 120 適用於高更新率螢幕上的極致流暢動作；並非每支手機都能匯出這麼快的影片，匯出畫面會告訴你你的手機是否做不到。這會設定編輯器與匯出繪製畫面的頻率。影片片段會保留它們自己的影格速率；請參見匯出頁面中的影格插補選項。

背景

圖層後方的顏色：黑色、白色、淺灰色、綠色、藍色或透明（以棋盤格顯示）。全新安裝時預設為透明。匯出影片的透明區域會變成黑色；GIF 與圖片匯出可以選擇透明區域要變成什麼，PNG 則會保留透明。

底部按鈕

  • 建立專案（素材則為建立素材）會建立專案，並在編輯器中開啟它。
  • 其下方的 X 會關閉面板。

若儲存空間不足，應用程式會說明並且不建立專案。
