目錄特效

圖層工具

選取圖層時出現的工具格，以及其後的每個面板。

點選一個圖層，底部會開啟一組工具格。第一列有五個小按鈕（速度、修剪與分割、音量），說明見時間軸。無法在播放頭所在位置使用的修剪或延伸按鈕，根本不會顯示。在它們下方是大型按鈕，其組合會依圖層類型而不同。

大型按鈕分為兩頁。在工具格上左右滑動即可切換頁面；其下方的兩個點會顯示你目前位於哪一頁。只有一頁的圖層不會顯示這些點。在大型平板電腦上，工具會排列在預覽旁的欄位中，全部位於同一頁，以兩到四欄排列，以便容納。

照片與影片是以圖片填滿的矩形，因此與形狀使用相同的工具。

表格列出的是第一頁。第二頁提供裁切，適用於除3D模型外所有可見的圖層：形狀、文字、繪圖、群組、照片與影片。影片片段在那裡另有四個按鈕：AI、自動字幕、倒放與截圖；照片那裡也有 AI。在專案開啟深度順序時，第二頁的開頭還會為形狀、照片、影片、文字、繪圖與群組加上3D圖層：參見攝影機圖層與3D。音訊、攝影機、燈光、空物件與3D模型圖層只有單一頁。

每個面板

大多數面板左側都有一欄窄欄，其中有這些按鈕：返回、新增關鍵影格或移除關鍵影格、緩動，以及僅在變形與特效中才有的更多。呈灰色的關鍵影格按鈕表示該設定無法加上動畫。參見關鍵影格與緩動。

點選任何數字框即可開啟數字鍵盤。第一次點選會選取整個數值，因此輸入時會直接取代它。按下勾號會套用；點選外部則會關閉鍵盤。標尺（一條帶有刻度與中央指針的長條）在左右拖曳時會變更數字。

變形

右側的標籤：移動、旋轉、大小、傾斜、歪斜、錨點。對攝影機而言，只有移動、旋轉與大小可用；在深度順序開啟時，傾斜也可用；其他標籤呈灰色。在工具格中長按變形，或開啟更多，即可在基本控制（移動、旋轉、大小與歪斜，為預設）與進階控制（全部六個標籤）之間切換。

  • 移動。 一個觸控板（「拖曳此處以移動圖層」）以及 X 與 Y 數字框。點選 Z 即可沿深度軸移動圖層。當圖層與畫布或其他圖層對齊時，會顯示細紅色的參考線。
  • 旋轉。 一個旋鈕：拖曳旋鈕即可旋轉，或點選角度數字以輸入。當圖層以3D傾斜時，此標籤會變成3D觸控板：單指傾斜，雙指扭轉。
  • 大小。 寬度與高度數字框，以及一個連結按鈕（預設開啟），用來保持比例。對攝影機而言，此標籤會改變視角。連結設定會記住每個圖層，並隨專案一起儲存；標尺在輕撥後會持續滑動。
  • 傾斜。 以度數為單位的 X軸旋轉 與 Y軸旋轉，用於3D傾斜。參見攝影機圖層與3D。
  • 歪斜。 以度數為單位的 X軸傾斜 與 Y軸傾斜。
  • 錨點。 圖層旋轉與縮放所依據的點，以距離圖層中心的像素為單位。輸入 X 與 Y、拖曳觸控板、點選九個方格之一（代表角落、邊緣或中央），或拖曳畫布上的標記。圖層及其子圖層會留在原處。
  • 更多中有重設位置、重設旋轉、重設縮放、重設3D旋轉、重設傾斜、重設錨點，以及重設變形（全部六項）。

移動即位置，X、Y 與 Z 會一起加上動畫。旋轉、大小、傾斜、歪斜與錨點各自有自己的關鍵影格；寬度與高度共用大小的關鍵影格。

裁切

照片、影片與其他可見圖層，在工具格的第二頁都有裁切按鈕。它會將即將被裁掉的部分調暗，並顯示一個附有八個把手的框：拖曳角落或邊緣即可裁切，拖曳框內則可移動它。雙指仍可縮放畫布。自由、1:1、4:5、3:4、16:9與9:16會套用該比例下最大的置中裁切，並在拖曳時保持該比例。點選某一邊即可輸入其數值；重設會移除裁切，完成則會關閉面板。關鍵影格按鈕會同時為四邊加上關鍵影格。裁切本身就是裁切特效，因此你也可以在特效中變更它，並調整圓角與羽化；圖層則留在原處。

填色與顏色

頂部的標籤：無、顏色、漸層、媒體。

  • 顏色。 所選調色盤的顏色（預設調色盤有十四種），之後是你儲存的顏色。頂部的列會顯示調色盤名稱，點選它即可開啟你的調色盤；並以 #RRGGBB 格式顯示顏色及其不透明度；列上的 + 會儲存目前的顏色。共有三個按鈕：滴管（觸碰預覽即可取樣顏色）、顏色滑桿，以及完整顏色選擇器（色輪，或附有十六進位欄位的 HSV 與 RGB 滑桿）。
  • 漸層。 選擇線性、放射或掃描，然後選擇起始與結束顏色。預覽上的兩個把手可以移動漸層。漸層只有兩種顏色。
  • 媒體。 以照片或影片填滿形狀，或文字圖層的文字。點選它會開啟選擇器。

只有「顏色」標籤中的顏色可以加上關鍵影格。

調色盤

調色盤是一組可在每個專案中使用的顏色。填色與顏色中的顏色列、完整顏色選擇器，以及特效設定的顏色彈出視窗，都會顯示所選調色盤的顏色。在那裡點選調色盤的名稱，即可開啟調色盤。

  • 點選調色盤即可使用它。鉛筆圖示會開啟它以進行編輯。
  • 新增會以你目前使用的顏色建立一個調色盤。從圖片會從照片的8種主要顏色建立一個調色盤；從AbsentMotion匯出的調色盤圖片，則會帶回所有顏色。從檔案會讀取調色盤檔案：GIMP .gpl、Adobe .ase或 .act、.pal，或是一列十六進位顏色，例如你可以從Lospec下載的調色盤。
  • 在開啟的調色盤中，點選名稱即可重新命名，點選使用即可選取它。點選一個顏色即可選取它：新增會加入你目前使用的顏色，複製會複製所選的顏色，刪除則會移除它。排序會依色相、明度或飽和度排列顏色。
  • 匯出會將調色盤儲存為 Pictures/AbsentMotion 中的 圖片（PNG），或 Documents/AbsentMotion 中的 GIMP調色盤（.gpl）或 Adobe色票（.ase）。建立副本會建立一份可編輯的副本，而刪除調色盤會在詢問後將它移除。
  • 鎖定會阻止新增、複製或刪除顏色，直到你將它關閉為止。

內建八種調色盤：預設、粉彩、霓虹、大地色、膚色、灰階、PICO-8與Game Boy。它們永久鎖定：若要修改其中一個，請使用建立副本。選取內建調色盤時，你儲存的顏色會排在它自己的顏色之後，而+會儲存到那裡。選取你自己的調色盤時，+會將顏色加入該調色盤，除非它已被鎖定。

在電腦上，將 .gpl、.ase、.act 或 .pal 檔案拖放到視窗上，它就會加入你的調色盤，並成為所選的調色盤。你的調色盤會保存在備份中：參見專案、備份與匯入。

邊框與陰影

三個標籤：描邊、邊框與陰影。

  • 描邊是形狀的輪廓。它有一個開關、顏色、大小、線端與轉角樣式，以及開放線段兩端各自的樣式（箭頭、圓形、菱形等）。
  • 邊框可讓你疊加任意數量的邊框。每個邊框都有大小、顏色與位置（內側、置中、外側）。拖曳把手即可變更它們的順序。新增邊框會加入一個。
  • 陰影有一個開關、顏色、大小、透明度與位置（X 與 Y）。

不透明度

不透明度滑桿附有百分比數字框，另有 28 種混合模式，分為七組：正常；變暗（正片疊底、變暗、較深的顏色、加深顏色、線性加深）；變亮（濾色、變亮、較淺的顏色、減淡顏色、線性減淡）；對比（覆蓋、柔光、強光、柔和覆蓋、亮光、線性光、點光）；差異（差值、排除、減去、除）；顏色（色相、飽和度、顏色、亮度）；以及遮罩（遮罩、排除）。點選一組即可展開，點選一種模式即可套用。遮罩會讓下方內容只保留在此圖層範圍內；排除則會移除此圖層範圍內的下方內容。

形狀選項

定義形狀的設定，每列一項，附有標尺與數值框。例如：圓形有大小；圓角矩形有大小與圓角半徑；多邊形有邊數、半徑與角度；星形有頂點數、外半徑、內半徑與角度；箭頭有起點、終點、尾端寬度、頭部寬度與頭部長度。被選取的那一列，就是關鍵影格按鈕會加上動畫的那一列。照片與影片在這裡使用的是大小。

編輯節點、編輯繪圖、編輯文字

它們會開啟全螢幕編輯器：參見形狀、繪圖與遮罩與文字與字型。

編輯群組

開啟群組，使時間軸與預覽只顯示其中的圖層，讓你可以加以變更。參見形狀、繪圖與遮罩。

攝影機選項、燈光選項與模型選項

參見攝影機圖層與3D。

標記節拍

在音訊圖層上，標記節拍會在聲音的每一拍加入一個書籤。它與圖層選單中的標記節拍作用相同：參見音訊。

音量

用於聲音與影片。參見音訊。

AI、自動字幕、倒放與截圖

這四個按鈕位於影片片段工具格的第二頁（GIF 也算影片）。AI會開啟特效庫中的 AI 類別；照片的第二頁也有它（用於移除背景），而音訊圖層則在其唯一的一頁上有同樣的按鈕。自動字幕只會為這個片段製作字幕：參見AI工具。倒放會讓片段倒著播放：參見媒體。

截圖會將播放頭下方片段的影格，以片段本身的完整尺寸儲存為圖片。它是原始的素材畫面：特效、裁切、邊框與圖層的位置都不會包含在內，但修剪、速度變更與倒放都會被保留。圖片會存入手機相簿（Pictures/AbsentMotion），並以新圖層的形式加入專案，位於片段上方。若你在10秒內刪除該新圖層，圖片也會從相簿中移除。播放頭必須位於該片段上。
