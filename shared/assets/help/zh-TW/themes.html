主題

在應用程式中或透過檔案製作自己的主題、分享主題，並了解每種主題色彩的用途。

本頁內容

主題會改變整個應用程式的配色，包括編輯器、時間軸、首頁和選單。你可以選擇內建主題、在應用程式中自行製作，或載入別人分享的主題檔案。

選擇主題

開啟 設定，在 選擇主題 中選擇 系統預設、淺色、深色、日光、淺綠 或 自訂（有自己的主題後即可使用）。下方的 主題顏色 只會變更目前主題的強調色。請參閱設定。

在應用程式中製作主題

開啟 設定，點選 選擇主題，再選擇 建立主題…。頁面會分組列出所有主題色彩，並附上顯示位置和色碼。

  • 匯入主題檔案… 位於最上方，可把主題檔案（例如別人分享的）載入頁面，方便你在儲存前修改。
  • 起始主題 會帶入內建主題或自訂主題的所有色彩，你只要調整想變更的色彩。
  • 點一下色彩即可開啟色彩選擇器。編輯時整個應用程式會即時更新，你可以直接看到配色效果。
  • 輸入主題的 名稱，再點選 儲存主題。主題會儲存為 自訂 並立即套用。儲存時會將 主題顏色 重設為 預設，以顯示主題本身的強調色。
  • 匯出 會將主題儲存成 .json 檔案，方便分享或保留。
  • 關閉頁面且未儲存時，會恢復原本的主題。

應用程式一次只保留一個自訂主題。儲存或匯入新主題後會取代原有主題。

製作主題檔案

主題檔案是小型的 JSON 文字檔，只需列出想變更的色彩。將以下內容儲存為 mint.json。

{
  "name": "Mint",
  "Accent": "#5BD6A4",
  "HomeAccent": "#1B7A4A"
}

透過 設定 > 選擇主題 > 匯入主題檔案… 載入。強調色會變成薄荷綠，其餘外觀維持原樣。

  • 檔案使用 UTF-8 編碼的 JSON 純文字格式，副檔名為 .json，大小上限為 64 KB。
  • name 可省略，超過 40 個字元會被截斷。
  • 其他每一行依序寫下表中的色彩名稱、冒號，以及用引號括住的色碼。名稱的大小寫須與表格完全相同。除了最後一行，其餘各行末尾都要加上逗號。
  • 色碼格式為 "#RRGGBB"（紅、綠、藍）或 "#AARRGGBB"（Alpha 放在最前面）。不支援 #RGB 簡寫。
  • Alpha（不透明度） 決定色彩的透明程度。FF 完全不透明，80 半透明，00 完全透明。大多數色彩應保持不透明。Alpha 適用於遮罩和按壓醒目效果：Scrim、MenuScrim、PressEditor 和 PressHome。
  • 未指定的色彩會沿用 AbsentMotion 的配色。如果指定了 Gold 而省略 Favorite，收藏星號會使用 Gold 的色彩。 SelectionBorder 和 SelectionHandle 也以相同方式分別跟隨 Accent 和 OnDark。
  • 表中未列出的名稱會被忽略。檔案至少要有一種色彩，若色碼格式錯誤，應用程式會拒絕開啟檔案，並指出有問題的色彩。

提示

  • 編輯器和首頁的配色彼此獨立。AbsentMotion 的預設外觀採用深色編輯器和淺色首頁，你可以各自將它們設為淺色或深色。
  • 讓文字保持清晰易讀。文字色彩（OnDark、HomeInk 和其他以 On 開頭的色彩）應與背景有足夠的對比。
  • 有些色彩只出現在少數位置，例如數字鍵盤、匯出預覽或已開啟的開關。編輯時可開啟這些畫面確認效果。
  • 如要分享主題，請從 建立主題… 匯出並傳送 .json 檔案。收到檔案的人可用 匯入主題檔案… 載入。

所有色彩

色彩依用途分組。第二欄列出各色彩主要的顯示位置，有些色彩也會出現在其他地方。

編輯器

名稱顯示位置
TopBar編輯器的主要背景，包括頂端列、面板後方的畫面，以及預設集等全螢幕工具畫面。
PreviewBg影片預覽後方、面板內的深色區塊（滑桿和選擇器），以及時間軸末端後的空白處。
TimelineBg時間軸、預覽下方的播放列，以及圖層分頁所在列的背景。
Panel底部面板、工具面板（語音、字幕、延展）、電腦版媒體庫和音量電平表。
PanelInset面板內的區塊，例如元素庫的圖塊、字型瀏覽器、未按下的數字鍵和未選取的選項。
Button編輯器中的按鈕、圖塊、效果列，以及時間軸上圖層名稱與圖層列之間的分隔線。
Field編輯器中的對話框、文字欄位、清單列和選單背景。
FieldHi已選取或凸起的項目，例如切換控制中選取的分頁、滑桿軌道未填滿的部分、專案安全確認對話框的邊緣，以及電腦版首頁的部分按鈕。
Chosen緩動面板的曲線圖背景、邊框與陰影中選取的項目，以及漸層預覽的深色端。
Well深色凹槽，例如媒體與音訊分頁中的圖塊、滑桿軌道（混合和開關），以及數字鍵盤上的完成鍵。
Deepest最深色的區域，包括頂端列底線、色彩選擇器的格線、電平表背景和文字編輯器的頂端色條。
Line細分隔線，例如時間軸刻度和標題列邊緣、選單清單分隔線，以及教學卡片和字型瀏覽器的邊框。
MenuLine編輯器選單與緩動面板選單內的分隔線。
PressEditor電腦版編輯器中，按壓或將游標移到項目上時的醒目效果。

時間軸

這些色彩用於時間軸上的圖層列和標記。

名稱顯示位置
LayerBar時間軸上一般圖層（影片、圖片、形狀等）的圖層列。
LayerBarStripe圖層列上的條紋。
TextBar時間軸上的文字圖層列。
TextBarStripe文字圖層列上的條紋。
AudioBar時間軸上的音訊圖層列。
AudioWave音訊圖層列內的波形。
OnBar一般圖層列和文字圖層列上顯示的圖層名稱。
OnAudioBar音訊圖層列上顯示的圖層名稱。
Bookmark時間軸上的書籤標記。
Gold時間軸上的變速標記、預覽中未選取的點、字型瀏覽器的搜尋文字和進度環、滑桿上的微調線，以及數字鍵盤上超出範圍的數字。
SelectionBorder電腦上時間軸中所選片段的邊框。省略時會跟隨 Accent。
SelectionHandle電腦上時間軸中所選片段兩端的修剪控制點。省略時會跟隨 OnDark。

數字鍵盤與選單

這些色彩用於圖層工具的數字鍵盤，以及預覽後方的深色區塊。

名稱顯示位置
KeyDigit圖層工具數字鍵盤上的 0 到 9 鍵。
KeySymbol同一個數字鍵盤上的正負號、小數點和退格鍵。
Cool數字鍵盤上按鍵的藍色標籤，以及動態面板中進場側的外框。
CoolDeep數字鍵盤按鍵上所選數字的背景。
Scrim預覽後方的深色區塊，包括首頁上的工具預覽（範圍、壓縮、工具組）、匯出預覽和匯出完成畫面，以及社群中沒有圖片的縮圖。
OnScrim深色區塊上的文字與圖示，例如匯出預覽按鈕、頁數、播放按鈕與社群項目的預留圖示。

強調色

名稱顯示位置
Accent主色，用於選取的項目、使用中的滑桿、編輯器頂端列的匯出按鈕、時間軸貼齊線和選取範圍、播放標記及主要按鈕。這是用途最廣的色彩之一。
AccentLit較亮的強調色，用於音量與混合滑桿、編輯器開關的圓鈕，以及電腦版編輯器中的資料夾圖示。
AccentGlow用於面板內醒目效果的淺強調色，例如使用中的數字鍵邊框和標籤。
AccentDeep深強調色，用於編輯器中已開啟的開關軌道、預覽控制點及所選色彩的圓環。
OnAccent強調色上的文字與圖示，例如匯出圖示、強調色按鈕和選取的標籤按鈕。
Warning警告和錯誤，包括預覽過期、檔案遺失、片段超出限制，以及專案安全確認對話框中的刪除按鈕或危險操作按鈕。
Favorite文字編輯器和效果瀏覽器中代表收藏的實心星號。

深色背景上的文字

這些色彩用於編輯器中的文字和圖示。

名稱顯示位置
OnDark編輯器中的主要文字與圖示。這是最常使用的色彩。
OnDarkDim較淡的文字和圖示，包括計數、提示、空清單訊息和電腦版編輯器中的小圖示。
Caption面板內的小字提示與箭頭，以及點編輯器中的輔助線。
Faint淡色圖示與線條，例如點編輯器中未選取的圖示、混合及邊框與陰影圖示、刻度和色彩選擇器閒置時的顏色。
Inactive關閉或閒置的元素，例如時間軸尺規刻度和握把、關閉的開關軌道，以及移動面板中的連結與攝影機區塊。

首頁

這些色彩用於首頁、設定側欄、新增專案面板、匯出畫面和初次使用的導覽畫面。

名稱顯示位置
HomeBg首頁背景與淺淡色塊，例如最新消息的標題列和對話框的文字欄位。
Card首頁上的卡片和清單列：工具、範本、設定側欄的清單列、選單、匯出畫面的頂端列，以及教學卡片。
SheetBg面板和畫面的背景，包括新增專案面板、匯出畫面、初次使用的導覽畫面和關於畫面。
HomeDrawer設定側欄背景（手機和平板）。
HomePanel首頁上較不醒目的面板，包括設定側欄中分組的清單列、沒有圖片的社群項目，以及安全確認對話框中的按鈕。
Navy首頁的主要深色，用於標題、圖示、所選分頁和標籤按鈕、選取的按鈕和核取方塊，以及進度列。名稱雖是 Navy，仍可設為任何色彩。
OnNavyNavy 底色上的文字和圖示，例如所選分頁或按鈕上的內容。
OnNavyAccentNavy 底色上的強調文字和圖示，包括所選選項的標籤、匯出按鈕標籤，以及首頁為淺色時匯出畫面中進度區域的溫度文字。
NavyHi設定側欄清單中選取的列。
NavyLine設定側欄清單、新增專案面板清單，以及範本分頁標籤按鈕的線條和邊框。
HomeAccent首頁的強調色，用於已開啟的開關、選項按鈕、選單中的勾選記號、匯出畫面的提醒文字，以及首頁安全確認對話框的危險操作按鈕。
HomeInk首頁的主要文字。
HomeMid首頁的次要文字和圖示，包括版本資訊、箭頭、控制點和標籤。
HomeDim首頁的第三層文字與圖示，包括提示文字、工具說明和小箭號。
HomeFaint首頁上最淺淡的元素，例如未選取的分頁圓點和新增專案面板的連結圖示。
HomeLine首頁的細線和邊框、進度列的軌道，以及工具中選取的範圍按鈕。
MenuScrim在手機或平板上開啟選單時覆蓋首頁的遮罩。
PressHome在首頁按壓或將游標移到項目上時的醒目效果。

開關與其他元素

名稱顯示位置
SwitchOff設定側欄與匯出畫面上關閉的開關軌道。
Thumb匯出畫面和編輯器中關閉的開關圓鈕，以及編輯器滑桿上的標記。
