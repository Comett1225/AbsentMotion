應用程式自行關閉了

Android 會關閉使用過多記憶體的應用程式。這種情況最常發生在 4K 影片、大量高負載特效，或同時開啟其他應用程式時。

  1. 再次開啟 AbsentMotion。如果它顯示 AbsentMotion意外關閉，請點選還原，取回你最後的編輯內容。
  2. 關閉其他應用程式，然後再試一次這個專案。
  3. 在預覽列或設定中，將預覽品質調低為一半或四分之一。
  4. 在設定中開啟使用大型影片的預覽副本（預設即為開啟）。
  5. 以較低的解析度匯出，或將非常長的專案分割。

在設定的當機記錄中，每次當機都會以一句話說明發生了什麼。點選複製即可複製內容，然後附在 GitHub 的錯誤回報中。不會自動傳送任何資料。

這支手機無法執行編輯器

AbsentMotion 會透過 Vulkan 1.1 使用圖形晶片繪製預覽與匯出畫面；若手機沒有 Vulkan，則改用 OpenGL ES 3.0。如果兩者都無法啟動，應用程式會顯示 這支手機無法執行編輯器，並列出 Android 版本與圖形晶片資訊，而不會直接關閉。你的專案、設定、備份與當機記錄仍可開啟。點選複製詳細資料即可複製這些資訊，並附在 GitHub 的錯誤回報中。見系統需求與版本。如果編輯器可以開啟，但預覽或匯出畫面看起來不對，請在設定的圖形中選擇 OpenGL。

如果 AbsentMotion 在圖形啟動期間自行關閉，它會記住這件事。當圖形設為自動時，下次啟動會改用另一種方式（例如以 OpenGL 取代 Vulkan），讓應用程式能夠再次開啟。此記錄會針對這支手機上的這個版本保留。

遺失的媒體

圖層是空的，或匯出時顯示媒體遺失：專案使用的照片、影片或音訊檔案已不在手機上。

  • 選取圖層，在圖層選單中開啟媒體資訊，然後點選替換媒體檔案，重新選擇該檔案。
  • 趁檔案仍在時，在專案卡片的選單中使用將媒體收集至專案，讓專案保有自己的副本。
  • 在設定中保持開啟在專案中保留匯入媒體的副本。

如果仍然要匯出，使用遺失檔案的圖層會被排除在外。

匯出問題

訊息處理方式
儲存空間不足釋放手機上的空間，或選擇較小的解析度。預估大小顯示在匯出畫面上。
此手機不支援手機的編碼器無法製作該尺寸或編碼格式。點選建議項目中的使用，或選擇 H.264 與較小的尺寸。
匯出速度慢只能使用軟體編碼器，或在這些設定下硬體編碼器速度較慢。可以繼續，或改選建議的設定。
匯出速度變慢手機溫度較高，系統會刻意降速以降溫。讓手機冷卻，或將手機從保護殼中取出。
匯出失敗，無法繪製影格再試一次。如果仍然發生，請降低解析度，或將影格插補關閉。
匯出失敗，影片編碼器忙碌中或無法製作此尺寸關閉其他正在播放或錄製影片的應用程式，然後再試一次。如果仍然發生，請選擇較低的解析度或影格速率。
匯出失敗，影片解碼器或編碼器停止運作其他應用程式正在使用手機的影片硬體。請關閉正在播放或錄製影片的應用程式，然後再試一次。
「手機的影片編碼器忙碌中，因此這次匯出會使用較慢的軟體編碼器」沒有問題：匯出會花比較久的時間。下次請關閉其他影片應用程式，讓系統恢復使用較快的硬體編碼器。
完成的影片顯示靜態畫面與播放按鈕手機無法立即播放該影片。點選播放按鈕即可再試一次；檔案本身已經儲存。
匯出的影片沒有聲音隱藏的圖層或音量為 0% 的片段會是無聲的。已儲存至裝置畫面上的「已檢查：...」會回報遺失的音軌。

切換到其他應用程式時，匯出會繼續進行，並以通知顯示進度。從最近使用的應用程式清單關閉 AbsentMotion 會停止匯出。

儲存空間已滿

  • 從首頁刪除不需要的專案，並從 Movies/AbsentMotion 刪除舊的匯出檔案。
  • 在設定中點選清除預覽副本，可釋放最多 2 GB 的空間。
  • Documents/AbsentMotion 中的備份可能很大：請將它們複製到電腦，然後從手機刪除。
  • 如果儲存失敗，應用程式會告知你。請釋放空間後繼續。

速度很慢

  • 調低預覽品質。
  • 使用預覽列中的快速模糊選項。
  • 大型照片與影片很吃資源。影片請使用預覽副本，並在加入前縮小非常大的照片。
  • 大量套用特效的圖層會累積負擔。隱藏你目前沒有在編輯的圖層（點選眼睛圖示）。

三星手機無法安裝更新

在三星手機上，自動封鎖程式可能會阻擋 AbsentMotion 下載的更新。當它可能是原因時，更新已停止會顯示：「三星的自動封鎖程式可能正在阻擋此更新。」如果 Android 回報安裝遭到封鎖，會立即顯示此訊息；如果同一更新連續兩次安裝失敗，也會顯示。

  1. 開啟手機的設定，前往安全性與隱私權，點選自動封鎖程式，然後將它關閉。
  2. 回到 AbsentMotion，點選再試一次以安裝更新。你的專案會保留。
  3. 如果你想要，可以再將自動封鎖程式開啟。

文字使用了錯誤的字型

專案使用的字型不在這支手機上。開啟專案，然後在此手機缺少字型中點選下載。字型只需要連線網路一次。

問題與解答

真的免費嗎？ 是的。沒有訂閱、不需要帳號、沒有浮水印，也沒有廣告。它是開放原始碼軟體，採用 GNU 通用公共授權條款第 3.0 版。

需要網路嗎？ 不需要。只有某些選用功能會使用網路：下載 Google 字型、下載一次字幕模型，以及選用的更新檢查。見隱私權。

我的專案在哪裡？ 在應用程式的私有儲存空間中，包含你加入的所有媒體檔案。你可以從設定備份它們。匯出檔案位於 Movies、Pictures、Music 和 Documents 下的 AbsentMotion 資料夾中。

可以把專案搬到另一支手機嗎？ 可以：匯出專案套件，將 .absproj 檔案複製到另一支手機，然後在那裡開啟。

可以開啟其他編輯器的專案嗎？ 部分可以。見專案、備份與匯入。

有電腦版嗎？ 有，從 5.0 版開始提供，適用於 Mac、Windows 與 Linux 電腦。手機版仍然優先。見在電腦上使用 AbsentMotion。

有哪些語言？ 英文、印尼文、印地文、葡萄牙文（巴西）、西班牙文（拉丁美洲）、西班牙文（西班牙）、菲律賓文、越南文、泰文、馬來文、阿拉伯文、波斯文、烏爾都文、土耳其文、俄文、孟加拉文和日文。你可以在設定中切換。

如何回報問題或要求新功能？ 請在 GitHub 上開一個 issue。請不要在其中包含私人資訊。

原始碼在哪裡？ 在 GitHub 上的專案頁面。
