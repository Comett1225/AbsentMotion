Mapa de paleta

Cor · Adicionado na versão 3.0.0

Troca cada pixel pela cor mais próxima de uma paleta: até oito cores que você escolhe, ou uma paleta de até 512 cores de uma predefinição ou de um arquivo importado. Os padrões de dither misturam cores vizinhas da paleta para mostrar mais tons. Alfa mistura as cores mapeadas com a camada original.
