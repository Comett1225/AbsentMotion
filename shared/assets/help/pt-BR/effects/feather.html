Suavizar bordas

Chave · Adicionado na versão 3.0.0

Suaviza as bordas alfa da camada. Para dentro aplica o esmaecimento dentro do contorno existente; Desfoque alfa também espalha a borda suavizada para fora.

Feather suaviza a borda da camada. Força é a largura da borda suave. Bordas é Para dentro (a borda se dissolve na camada) ou Desfoque Alfa (a borda suave também se espalha para fora do contorno original). Use após Chroma Key para um recorte mais limpo.
