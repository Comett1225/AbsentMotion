Virar página

Distorção · Adicionado na versão 5.1.0

Vira a camada como uma página: um canto se levanta e se enrola, mostrando o verso. Anime o Progresso para virar a página. Com Seguir a forma ativado, a página vira a partir das bordas do que está visível, então uma imagem redonda ou um modelo 3D se curva a partir da própria borda em vez de uma caixa invisível.
