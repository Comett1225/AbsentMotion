Desfoque

Desfoque · Adicionado na versão 2.1.0 ou anterior

Um desfoque suave e uniforme.

Intensidade é o tamanho do desfoque: 0 é nítido, e números maiores suavizam mais a camada. Funciona em fotos, vídeo, formas, texto e grupos.

  • Anime a Intensidade de um número alto até 0 para trazer um título ou foto para o foco.
  • Para desfocar tudo o que está atrás de uma camada, adicione primeiro uma Camada de Ajuste e depois Desfoque.
  • Para desfocar ao longo do movimento, use Desfoque de Movimento. Para manter o contorno nítido, use Desfoque Interno.
