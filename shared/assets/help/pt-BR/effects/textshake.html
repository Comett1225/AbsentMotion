Tremor de texto

Texto · Adicionado na versão 5.0.0

Sacode cada letra por conta própria, como um diálogo nervoso em um jogo. Tremor desliza entre posições, Vibração salta para uma nova posição a cada passo, Onda balança as letras para cima e para baixo, Círculo as move em pequenos laços e Oscilar as inclina de um lado para o outro. Diminua Letras tremendo para sacudir só algumas letras, escolhidas ao acaso de novo a cada poucos instantes.

Tremor de texto move cada letra por conta própria, como um diálogo nervoso em um jogo. Escolha um Estilo:

  • Tremor desliza cada letra entre posições aleatórias e Vibração salta para uma nova posição a cada passo. Quantidade é a distância em pixels, Velocidade é quantas posições novas por segundo, e Rotação deixa as letras girarem também.
  • Onda balança as letras para cima e para baixo, Círculo as move em pequenos laços e Oscilar as inclina de um lado para o outro pelo ângulo de Inclinação. Para esses, Velocidade é em ondas por segundo (Hz) e Dispersão desloca a onda de uma letra para a seguinte.

Letras tremendo abaixo de 100 % sacode só algumas das letras, e Novas letras a cada escolhe um novo conjunto ao acaso a cada tantos segundos. Baseado em sacode cada caractere, cada palavra ou cada linha. Início e Fim limitam o tremor a uma parte do texto, e Semente dá outro padrão aleatório. Para começar rápido, experimente uma predefinição: Nervoso, Assustado, Inquieto, Flutuante, Ondulado, Tonto ou Bambo.
