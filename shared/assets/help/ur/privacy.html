آپ کے پروجیکٹ اور میڈیا

پروجیکٹ، امپورٹ شدہ تصاویر، ویڈیوز اور آڈیو، اور آپ جو کچھ بھی ایکسپورٹ کرتے ہیں سب آپ کے فون پر ہی رہتا ہے۔ فوٹو، ویڈیو اور آڈیو کی اجازتیں ایپ کو آپ کی لائبریری دکھانے اور آپ کی منتخب کردہ فائلیں فون پر استعمال کرنے دیتی ہیں۔ کچھ بھی اپ لوڈ نہیں ہوتا۔

کیمرہ اور مائیکروفون کی اجازتیں صرف ایپ کے اندرونی کیمرے کے کھلے رہنے کے دوران استعمال ہوتی ہیں۔ ریکارڈنگز فون پر محفوظ ہوتی ہیں۔ بیک اپ فون پر Documents/AbsentMotion میں لکھے جاتے ہیں اور وہیں رہتے ہیں۔

ایکسپورٹ کے دوران ایپ نوٹیفکیشن میں اس کی پیش رفت دکھاتی ہے، تاکہ آپ دوسری ایپ پر جانے پر بھی ایکسپورٹ جاری رہ سکے۔ Android 13 اور اس سے نئے ورژن پر پہلی ایکسپورٹ کے وقت نوٹیفکیشن کی اجازت مانگی جاتی ہے؛ اگر آپ انکار کریں تو بھی ایکسپورٹ ویسے ہی کام کرتا ہے۔

اگر ایپ اچانک بند ہو جائے تو یہ اپنی اسٹوریج میں کریش لاگ رکھتی ہے: یہ کب ہوا، ایک جملے میں وجہ، ایپ اور Android کے ورژن، فون ماڈل، آپ کیا کر رہے تھے اور تکنیکی خرابی۔ صرف آخری 20 رکھے جاتے ہیں، وہ فون بیک اپ میں شامل نہیں ہوتے اور کبھی کہیں بھیجے نہیں جاتے۔ آپ انہیں سیٹنگز میں پڑھ، کاپی یا ڈیلیٹ کر سکتے ہیں۔

ایپ کب انٹرنیٹ استعمال کرتی ہے

ایپ صرف ان چیزوں کے لیے انٹرنیٹ کی اجازت مانگتی ہے:

  • فونٹس۔ جب آپ ڈاؤن لوڈ کے قابل فونٹس میں سے کوئی منتخب کرتے ہیں تو ایپ اسے Google Fonts سے ڈاؤن لوڈ کرتی ہے۔ Google کو اس فونٹ کی درخواست اور آپ کا IP ایڈریس ملتا ہے، جیسے کسی بھی ویب درخواست پر ملتا ہے۔
  • آٹو کیپشنز۔ جب آپ پہلی بار کیپشنز بناتے ہیں تو ایپ آپ کو اسپیچ ماڈل کا سائز بتاتی ہے (تقریباً 57 MB) اور اسے Hugging Face سے ڈاؤن لوڈ کرتی ہے۔ اسپیچ کی پہچان فون پر ہی چلتی ہے۔
  • AI Enhance اور AI Smooth۔ جب آپ ان میں سے کوئی پہلی بار استعمال کرتے ہیں تو ایپ آپ کو مطلوبہ ماڈل کا سائز بتاتی ہے (تقریباً 1 سے 11 MB) اور اسے GitHub سے ڈاؤن لوڈ کرتی ہے۔ AI کا اصل کام فون پر ہی چلتا ہے۔
  • AI بیک گراؤنڈ ریموول 2.0۔ صرف اس صورت میں جب آپ بیک گراؤنڈز ہٹانے کے لیے AI بیک گراؤنڈ ریموول 2.0 منتخب کرتے ہیں، ایپ اس کا ماڈل ایک بار (تقریباً 62 MB) GitHub سے ڈاؤن لوڈ کرتی ہے۔ کٹ آؤٹ خود فون پر چلتا ہے۔
  • ویڈیو ڈاؤن لوڈر۔ صرف اگر آپ ٹولز > ویڈیو ڈاؤن لوڈر استعمال کریں: پہلی بار ایپ اس کا ایڈ آن (تقریباً 25 MB) ڈاؤن لوڈ کرتی ہے: Python python.org سے اور yt-dlp GitHub سے (github.com، جو objects.githubusercontent.com یا release-assets.githubusercontent.com سے آتا ہے)۔ جب تک ایڈ آن انسٹال ہے، یہ دن میں زیادہ سے زیادہ ایک بار GitHub سے پوچھتا ہے کہ کیا yt-dlp کا نیا ورژن ہے، اور ہو تو اسے ڈاؤن لوڈ کر لیتا ہے۔ جب آپ لنک پیسٹ کرتے ہیں تو ایڈ آن اس ویب سائٹ (مثلاً YouTube، Instagram یا TikTok) سے رابطہ کرتا ہے تاکہ ویڈیو کی تفصیل پڑھے اور آپ کے چنے ہوئے حصے ڈاؤن لوڈ کرے، بالکل ویب براؤزر کی طرح؛ فائلیں ڈیوائس پر محفوظ ہوتی ہیں۔
  • اپ ڈیٹ چیک۔ اگر آپ اجازت دیں (ایپ ایک بار پوچھتی ہے؛ سوئچ سیٹنگز میں ہے)، تو ایپ ہر بار کھلنے پر GitHub کو ایک عام HTTPS درخواست بھیجتی ہے تاکہ تازہ ترین ورژن نمبر پڑھ سکے۔ اس کے علاوہ کچھ نہیں بھیجا جاتا۔ GitHub آپ کا IP ایڈریس دیکھتا ہے، جیسے کسی بھی ویب درخواست پر۔

اور کچھ بھی کہیں نہیں بھیجا جاتا۔ ٹیکسٹ ٹو اسپیچ فون میں پہلے سے موجود آوازیں استعمال کرتا ہے اور آف لائن کام کرتا ہے۔
