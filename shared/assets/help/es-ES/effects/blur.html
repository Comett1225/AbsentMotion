Desenfoque

Desenfoque · Añadido en la versión 2.1.0 o anterior

Un desenfoque suave y uniforme.

Intensidad es el tamaño del desenfoque: 0 mantiene la nitidez y, cuanto más alto sea el número, más se suaviza la capa. Funciona con fotos, vídeos, formas, texto y grupos.

  • Anima Intensidad desde un valor alto hasta 0 para enfocar un título o una foto.
  • Para desenfocar todo lo que hay detrás de una capa, añade primero Copiar fondo y después Desenfoque.
  • Para desenfocar siguiendo el movimiento, usa Desenfoque de movimiento. Para mantener nítido el contorno, usa Desenfoque interior.
