AbsentMotion tidak mengumpulkan, menyimpan, atau membagikan data pribadi. Tidak ada akun, tidak ada iklan, tidak ada analitik, dan tidak ada pelacakan. Halaman ini merangkum kebijakan privasi; teks lengkapnya ada di file PRIVACY.md pada kode sumber.

Proyek dan media Anda

Proyek, gambar, video, dan audio yang diimpor, serta semua yang Anda ekspor tetap tersimpan di ponsel Anda. Izin foto, video, dan audio memungkinkan aplikasi menampilkan pustaka Anda dan menggunakan file yang Anda pilih, di ponsel. Tidak ada yang diunggah.

Izin kamera dan mikrofon hanya digunakan oleh kamera dalam aplikasi, selama kamera tersebut terbuka. Rekaman disimpan di ponsel. Cadangan ditulis ke Documents/AbsentMotion di ponsel dan tetap di sana.

Saat ekspor berjalan, aplikasi menampilkan progresnya di notifikasi, sehingga ekspor dapat berlanjut saat Anda beralih ke aplikasi lain. Di Android 13 dan yang lebih baru, aplikasi meminta izin notifikasi saat ekspor pertama; ekspor tetap berjalan sama jika Anda menolaknya.

Jika aplikasi tertutup secara tak terduga, aplikasi menyimpan log crash di penyimpanannya sendiri: kapan terjadinya, alasan dalam satu kalimat, versi aplikasi dan Android, model ponsel, apa yang sedang Anda lakukan, dan kesalahan teknisnya. Hanya 20 log terakhir yang disimpan, tidak disertakan dalam cadangan ponsel, dan tidak pernah dikirim ke mana pun. Anda dapat membaca, menyalin, atau menghapusnya di Pengaturan.

Kapan aplikasi menggunakan internet

Aplikasi meminta izin internet hanya untuk hal-hal berikut:

  • Font. Saat Anda memilih salah satu font yang dapat diunduh, aplikasi mengunduhnya dari Google Fonts. Google menerima permintaan font tersebut dan alamat IP Anda, seperti pada permintaan web pada umumnya.
  • Takarir otomatis. Saat pertama kali membuat takarir, aplikasi memberi tahu ukuran model ucapan (sekitar 57 MB) dan mengunduhnya dari Hugging Face. Pengenalan ucapan berjalan di ponsel.
  • AI Enhance dan AI Smooth. Saat pertama kali menggunakan salah satunya, aplikasi memberi tahu ukuran model yang dibutuhkan (sekitar 1 hingga 11 MB) dan mengunduhnya dari GitHub. Pekerjaan AI itu sendiri berjalan di ponsel.
  • Penghapusan latar belakang AI 2.0. Hanya jika Anda memilih penghapusan latar belakang AI 2.0 untuk menghapus latar belakang, aplikasi mengunduh modelnya satu kali (sekitar 62 MB) dari GitHub. Proses pemotongan itu sendiri berjalan di ponsel.
  • Pengunduh Video. Hanya jika Anda memakai Alat > Pengunduh Video: pertama kali, aplikasi mengunduh add-on-nya (sekitar 25 MB): Python dari python.org dan yt-dlp dari GitHub (github.com, disajikan dari objects.githubusercontent.com atau release-assets.githubusercontent.com). Selama add-on terpasang, aplikasi bertanya ke GitHub paling banyak sekali sehari apakah ada yt-dlp yang lebih baru dan mengunduhnya jika ada. Saat Anda menempel tautan, add-on menghubungi situs web itu (misalnya YouTube, Instagram, atau TikTok) untuk membaca detail video dan mengunduh bagian yang Anda pilih, sama seperti peramban web; file disimpan di perangkat.
  • Pemeriksaan pembaruan. Jika Anda mengizinkannya (aplikasi meminta sekali; tombolnya ada di Pengaturan), aplikasi membuat satu permintaan HTTPS normal ke GitHub setiap kali dibuka, untuk membaca nomor versi terbaru. Tidak ada hal lain yang dikirim. GitHub melihat alamat IP Anda, seperti pada permintaan web pada umumnya.

Tidak ada hal lain yang dikirim ke mana pun. Text to speech menggunakan suara yang sudah ada di ponsel dan berfungsi offline.

Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak dan tidak mengumpulkan apa pun dari siapa pun.

Lisensi dan sumber

AbsentMotion gratis dan open source, dirilis di bawah GNU General Public License v3.0. Kode sumbernya ada di halaman proyek di GitHub. Perangkat lunak pihak ketiga yang digunakan (Skia, whisper.cpp, RNNoise, LAME, AndroidX Compose, dan lainnya) beserta lisensinya tercantum di THIRD_PARTY_NOTICES.md dan di aplikasi: Pengaturan, Tentang, Lisensi open source.

AbsentMotion adalah proyek independen. Proyek ini tidak berafiliasi dengan, didukung oleh, atau disponsori oleh pembuat aplikasi lain mana pun; nama produk lain milik pemiliknya masing-masing.
