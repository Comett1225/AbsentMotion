Dissolve

Noise · Added in version 2.1.0 or earlier

Removes random pixels or blocks from the layer. Animate Strength for a dissolve transition; Seed chooses the pattern and Size sets the size of each speck.

Dissolve removes random specks from the layer. Animate Strength from 0 to 1 for a dissolve transition. Size is the size of each speck and Seed picks the pattern.
