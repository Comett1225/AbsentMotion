Text Shake

Text · Added in version 5.0.0

Shakes each letter on its own, like nervous dialogue in a game. Shake drifts between spots, Jitter jumps to a new spot at each step, Wave bobs the letters up and down, Circle moves them in small loops and Wobble tilts them back and forth. Lower Letters Shaking to shake only some letters, picked at random again every few moments.

Text Shake moves each letter on its own, like nervous dialogue in a game. Pick a Style:

  • Shake glides each letter between random spots and Jitter jumps to a new spot at each step. Amount is how far in pixels, Speed how many new spots per second, and Rotation lets the letters turn as well.
  • Wave bobs the letters up and down, Circle moves them in small loops and Wobble tilts them back and forth by the Tilt angle. For these, Speed is in waves per second (Hz) and Spread shifts the wave from one letter to the next.

Letters Shaking below 100 % shakes only some of the letters, and New Letters Every picks a new set at random every so many seconds. Based On shakes each character, each word or each line. Start and End limit the shake to a part of the text, and Seed gives another random pattern. To start quickly, try a preset: Nervous, Scared, Uneasy, Floaty, Wavy, Dizzy or Wobbly.
