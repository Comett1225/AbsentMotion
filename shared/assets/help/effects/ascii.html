ASCII turns a layer into text art made of letters and symbols: brighter parts get fuller characters. It works on videos, photos, text and shapes.

  • Size is how wide each character is, measured on the layer, so the characters move, turn and scale with it. Smaller sizes keep more detail.
  • Characters picks the set: Detailed, Simple, Blocks, Binary, or Custom, where you type your own characters.
  • Color keeps the picture's own colors (Original) or draws every character in one Text Color. Background is None, so the layer shows through between the characters, or a Background Color.
  • Contrast, Brightness and Invert change which character each part gets. Edge Lines draws outlines with the characters |, -, / and \.

The presets are Terminal, Binary Rain, Amber Monitor, Newspaper, Blocks and Line Art.
