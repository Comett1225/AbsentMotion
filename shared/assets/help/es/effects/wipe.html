Clave · Añadido en la versión 3.0.0

Oculta la capa desde dos lados opuestos. Anima Inicio o Fin para lograr una transición de barrido.

Wipe oculta la capa desde dos lados opuestos. Anima Start o End para revelar o quitar la capa con un borde recto; Angle es la dirección del borde y Feather lo suaviza. Para un barrido como la aguja de un reloj, usa Radial Wipe.
