テーマ

アプリ内やファイルで自分のテーマを作って共有し、各色がどこに反映されるか確認できます。

テーマを変えると、エディター、タイムライン、ホーム画面、メニューなど、アプリ全体の色が変わります。内蔵テーマを選ぶほか、自分でテーマを作ったり、共有されたテーマファイルを読み込んだりできます。

テーマを選ぶ

設定を開き、テーマを選択でシステムのデフォルト、ライト、ダーク、デイライト、ライトグリーン、または自分のテーマを作成済みならカスタムを選びます。その下のテーマカラーでは、テーマのアクセントカラーだけを変更できます。設定を参照してください。

アプリでテーマを作る

設定を開き、テーマを選択をタップしてテーマを作成…を選びます。ページにはテーマの色がグループ別に並び、それぞれのカラーコードと使用場所が表示されます。

  • テーマファイルを読み込む…を一番上で選ぶと、誰かが共有したものなどのテーマファイルがページに読み込まれ、保存前に変更できます。
  • 元にするテーマを選ぶと、内蔵テーマや自分のカスタムテーマからすべての色が読み込まれます。変えたい色だけを調整できます。
  • 色をタップするとカラーピッカーが開きます。変更はアプリ全体にその場で反映されるので、実際の画面で色を確認できます。
  • テーマに名前を付けてテーマを保存をタップします。カスタムテーマとして保存され、すぐに適用されます。保存するとテーマカラーがデフォルトに戻り、そのテーマ本来のアクセントカラーが使われます。
  • 書き出しを選ぶと、テーマを .json ファイルとして保存できます。共有したり保管したりできます。
  • 保存せずにページを閉じると、前のテーマに戻ります。

保存できるカスタムテーマは1つです。新しいテーマを保存または読み込むと、前のテーマが置き換わります。

テーマファイルを作る

テーマファイルは、変えたい色をリストにした小さな JSON 形式のテキストファイルです。この例を mint.json として保存します。

{
  "name": "Mint",
  "Accent": "#5BD6A4",
  "HomeAccent": "#1B7A4A"
}

設定 > テーマを選択 > テーマファイルを読み込む…で読み込みます。これまでの外観のまま、アクセントカラーだけがミントグリーンになります。

  • ファイルは JSON 形式のプレーンテキストです。拡張子は .json、文字コードは UTF-8、サイズは 64 KB 以下にします。
  • name は省略できます。40文字を超える部分は切り詰められます。
  • ほかの行は、下の表にある色名、コロン、引用符で囲んだ色の順に書きます。大文字と小文字も表と同じにしてください。最後の行を除き、各行の末尾にカンマを付けます。
  • 色は "#RRGGBB"（赤、緑、青）または "#AARRGGBB"（アルファ値が先頭）で書きます。#RGB は使えません。
  • アルファ値は色の不透明度です。FF は不透明、80 は半透明、00 は透明です。通常は不透明な色を使います。アルファ値は、画面を暗くする幕や押したときの強調色（Scrim、MenuScrim、PressEditor、PressHome）に使います。
  • 省略した色は AbsentMotion の標準のままです。Gold を指定して Favorite を省略すると、お気に入りの星に Gold の色が使われます。 SelectionBorder と SelectionHandle も同様に、それぞれ Accent と OnDark に従います。
  • 表にない名前は無視されます。ファイルには色が少なくとも1つ必要です。色の書き方が正しくない場合、アプリはファイルを読み込まず、該当する色名を表示します。

ヒント

  • エディターとホーム画面の色は別々です。AbsentMotion の標準ではエディターが暗く、ホーム画面が明るくなっています。それぞれ明るくも暗くもできます。
  • 文字が読みやすいように、文字色（OnDark、HomeInk、そのほか On で始まるもの）と背景色の差を十分に付けてください。
  • テンキーや書き出しプレビュー、オンのスイッチなど、一部の場所にだけ表示される色もあります。編集中に該当する画面を開いて確認してください。
  • テーマを共有するには、テーマを作成…から書き出して .json ファイルを送ります。受け取った人はテーマファイルを読み込む…で読み込めます。

色の一覧

色はグループに分かれています。2列目は主な使用場所です。ほかの場所にも使われる色があります。

エディター

名前使われる場所
TopBarエディターの主な背景色です。上部バー、パネルの背後、プリセットなどの全画面ツールに使われます。
PreviewBg動画プレビューの背景、パネル内の暗い枠（スライダーやピッカー）、タイムラインの終端より後ろの空き部分。
TimelineBgタイムラインの背景、プレビュー下の再生バー、レイヤータブの背後の行。
Panel下から開くシート、ツールパネル（音声、キャプション、ストレッチ）、パソコンのメディアライブラリ、レベルメーター。
PanelInsetパネル上の枠。素材ライブラリのタイル、フォントブラウザー、数字キーの通常時の色、選択していない項目など。
Buttonエディターのボタンやタイル、エフェクトの行、タイムラインのレイヤー名とバーの間の線。
Fieldエディターのダイアログ、テキスト入力欄、リストの行、メニューの背景。
FieldHi選択中または浮き出た項目。切り替えで選んだタブ、スライダーの空き部分、プロジェクトの安全確認ダイアログの縁、パソコンのホーム画面の一部のボタンなど。
Chosenイージングパネルのグラフ背景、「枠線と影」の選択項目、グラデーションプレビューの暗い端。
Well暗いくぼみ。メディアとオーディオのタブのタイル、ブレンドのスライダーやスイッチの溝、テンキーの「完了」キーなど。
Deepest最も暗い部分。上部バーの下線、カラーピッカーのグリッド、レベルメーターの背景、テキストエディターの上部帯。
Line細い区切り線。タイムラインの目盛りとヘッダーの縁、メニュー内のリストの線、チュートリアルカードとフォントブラウザーの枠など。
MenuLineエディターのメニュー内と、イージングパネルのメニュー内の区切り線。
PressEditorパソコンのエディターで押したときやポインターを重ねたときの強調色。

タイムライン

タイムライン上のレイヤーバーや目印に使われる色です。

名前使われる場所
LayerBarタイムライン上の通常レイヤー（動画、画像、図形など）のバー。
LayerBarStripeレイヤーバーに重ねる縞模様。
TextBarタイムライン上のテキストレイヤーのバー。
TextBarStripeテキストレイヤーのバーに重ねる縞模様。
AudioBarタイムライン上の音声レイヤーのバー。
AudioWave音声バー内に描かれる波形。
OnBarレイヤーバーとテキストバー上のレイヤー名。
OnAudioBar音声バー上のレイヤー名。
Bookmarkタイムラインに表示されるブックマークの目印。
Goldタイムラインの速度変更マーク、プレビューの未選択の点、フォントブラウザーの検索文字と進捗リング、スライダーの微調整線、テンキーの範囲外の数値。
SelectionBorderパソコンのタイムラインで、選択したクリップを囲む枠線の色です。省略すると Accent と同じ色になります。
SelectionHandleパソコンのタイムラインで、選択したクリップの両端にあるトリムハンドルの色です。省略すると OnDark と同じ色になります。

テンキーとメニュー

レイヤーツールのテンキーや、プレビューの背後の暗い枠に使われる色です。

名前使われる場所
KeyDigitレイヤーツールのテンキーにある0〜9の数字キー。
KeySymbol同じテンキーの符号、小数点、削除のキー。
Coolテンキーの青いラベルと、モーションシートの入り側の輪郭。
CoolDeepテンキーで選択中の数字の背後。
Scrimプレビューの背後にある暗い枠。ホーム画面のツールプレビュー（範囲、圧縮、ツールキット）、書き出しプレビューと書き出し完了画面、コミュニティの画像がないサムネイルなど。
OnScrimScrim の上の文字やアイコン。書き出しプレビューのボタン、ページ数、再生ボタン、コミュニティの画像がない項目に出る仮のアイコン。

アクセント

名前使われる場所
Accent主なアクセントカラーです。選択項目、操作中のスライダー、エディター上部の書き出しボタン、タイムラインのスナップ線や選択範囲、再生位置マーカー、主要ボタンなど、特に多くの場所で使われます。
AccentLitより明るいアクセント。音量やブレンドのスライダー、エディターのスイッチのつまみ、パソコンのエディターのフォルダーアイコン。
AccentGlowパネル内を強調する明るいアクセント。操作中のテンキーの枠やラベルなど。
AccentDeep暗いアクセント。エディターのオンのスイッチの溝、プレビューのハンドル、選択色の周りのリングなど。
OnAccentアクセントカラーの上の文字とアイコン。書き出しアイコン、アクセント色のボタン、選択中のチップなど。
Warning古いプレビュー、見つからないファイル、クリップが制限を超えた場合などの警告とエラー。プロジェクトの安全確認ダイアログの削除や危険な操作のボタンにも使われます。
Favoriteテキストエディターとエフェクトブラウザーのお気に入りを示す塗りつぶしの星。

暗い背景の文字

エディターの文字やアイコンに使われる色です。

名前使われる場所
OnDarkエディターの主な文字とアイコン。使用頻度が最も高い色です。
OnDarkDim控えめな文字とアイコン。件数、ヒント、リストが空のときのメッセージ、パソコンのエディターの小さなアイコンなど。
Captionパネル内の小さなヘルプ文と矢印、点のエディターのガイド線。
Faint控えめなアイコンや線。点のエディターの未選択アイコン、ブレンドや「枠線と影」のアイコン、目盛り、カラーピッカーの通常時など。
Inactiveオフや未操作の項目。タイムラインの定規の目盛りとつまみ、オフのスイッチの溝、移動パネルのリンクとカメラの枠など。

名前使われる場所
HomeBgホーム画面の背景と、新着情報の見出しやダイアログの入力欄などの淡い枠。

Navyホーム画面の主な暗色。見出し、アイコン、選択中のタブやチップ、選択済みのボタンやチェックボックス、進捗バーに使われます。名前に関係なく、どんな色でも指定できます。
OnNavyNavy の上の文字とアイコン。選択中のタブやボタンなど。
OnNavyAccentNavy の上のアクセント色の文字とアイコン。選択中の項目や書き出しボタンのラベル、ホーム画面が明るいときに書き出し画面に出る温度の表示。

NavyLine設定パネルや新規プロジェクトシートのリスト、テンプレートタブのチップの線と枠。
HomeAccentホーム画面のアクセント。オンのスイッチ、ラジオボタン、メニューのチェックマーク、書き出しの警告文、安全確認ダイアログで危険な操作を行うボタンなど。
HomeInkホーム画面の主な文字。
HomeMidホーム画面の補助的な文字とアイコン。バージョン表記、矢印、ハンドル、ラベルなど。
HomeDimホーム画面でさらに控えめな文字。ヘルプ文、ツールの説明、小さな山形の矢印など。
HomeFaintホーム画面の最も控えめな項目。未選択のページを表す点と、新規プロジェクトシートのリンクアイコン。
HomeLineホーム画面の細い線と枠、進捗バーの溝、ツールで選択中の範囲ボタン。
MenuScrimメニューを開いたときにホーム画面を覆う幕（スマートフォンとタブレット）。
PressHomeホーム画面で押したときやポインターを重ねたときの強調色。
