インストール

このスマートフォンにはAbsentMotionがすでにインストールされています。このページでは最初のプロジェクトの流れを説明します。ほかのページでは各画面について説明しています。

初回起動

アプリを初めて開くと、ホーム画面の前に2つの画面が表示されます。

  1. 言語を選びます。 アプリは25言語に対応しています。英語、インドネシア語、ヒンディー語、ポルトガル語（ブラジル）、スペイン語（中南米）、スペイン語（スペイン）、フィリピン語、ベトナム語、タイ語、マレー語、アラビア語、ペルシア語、ウルドゥー語、トルコ語、ロシア語、ベンガル語、日本語、韓国語、中国語（繁体字）、中国語（簡体字）、フランス語、ドイツ語、イタリア語、ポーランド語、ウクライナ語です。スマートフォンの言語がアプリに対応していれば、最初に表示されます。あとから設定で変更できます。
  2. この端末でできることを確認します。 簡単なテストで、スマートフォンが書き出せる動画の形式とサイズ、処理速度（高速、良好、基本）がわかります。テストは1回だけ実行され、数秒で終わります。データはすべてスマートフォン内に留まります。スキップをタップしてもかまいません。同じ画面には、アプリを開くたびに1回、GitHubへ最新のバージョン番号を問い合わせるスイッチがあります。初期状態はオンで、ほかの情報は送信しません。

アプリは起動時に権限を求めません。写真、動画、音声、カメラ、マイクへのアクセスは、それらが必要な機能を初めて使うときに求められます。

最初のプロジェクトを作る

  1. ホーム画面で、下部にある丸い+ボタンをタップします。これが新規プロジェクトです。
  2. 画面の形（16:9、9:16、4:5、1:1、4:3）、解像度（最初は1080pがおすすめ）、背景を選びます。フレームレートがわからない場合はそのままにしておきます。プロジェクトを作成をタップします。空のプロジェクトでエディターが開きます。詳細：プロジェクトの作成。
  3. タイムライン領域の右下にある丸い+をタップし、追加するものを選びます。図形、メディアタブの写真や動画、テキストなどです。
  4. プレビュー上でドラッグするとレイヤーを移動できます。ピンチで拡大・縮小できます。
  5. タイムラインを左右にドラッグすると時間を移動できます。レイヤーを時間方向に移動するには、そのバーを長押ししてからドラッグします。トリムするには、レイヤーを選択して両端の丸いつまみをドラッグします。
  6. 再生ボタンを押すと確認できます。

保存ボタンはありません。変更するたびに、少ししてからプロジェクトが保存されます。

アニメーションしてみる

AbsentMotionのアニメーションはキーフレームで作ります。キーフレームは、ある時点の値（位置、サイズ、不透明度）を記録し、アプリがキーフレーム間の動きを補間します。

  1. プレビューまたはタイムラインでレイヤーをタップします。下部にツールの一覧が表示されます。
  2. トランスフォームをタップします。移動タブが開きます。
  3. 動きを始めたい位置に再生ヘッドを置き、左の列にあるキーフレームボタン（ひし形）をタップします。
  4. 再生ヘッドを後ろの時間に移動し、レイヤーを新しい場所へドラッグします。プロパティにすでにキーフレームがあるので、2つ目のキーフレームが自動で作成されます。
  5. 再生します。イージングボタン（曲線）をタップすると、動きを加速、減速、バウンドさせられます。キーフレームとイージングをご覧ください。

手早く仕上げるには、レイヤーを選択し、プレビュー右下の丸いアニメーションボタンをタップしてイン、アウト、ループのアニメーションを選ぶか、エフェクトを開いて移動系のエフェクトを試してみましょう。

書き出し

  1. 上部バーの共有アイコン（書き出しと共有）をタップします。
  2. 動画カードが選択されています。書き出しをタップします。
  3. 進行状況バーが終わるまで待ちます。途中でほかのアプリに切り替えてもかまいません。通知に進行状況が表示されます。
  4. 動画を共有をタップするか、Movies/AbsentMotion内のファイルを探します。

すべてのオプション（形式、解像度、フレームレート、GIF、音声のみ）は書き出しページにあります。
