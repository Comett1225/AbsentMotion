테마

앱이나 파일에서 나만의 테마를 만들어 공유하고, 각 테마 색상이 어디에 쓰이는지 알아보세요.

테마를 바꾸면 편집기, 타임라인, 홈 화면, 메뉴 등 앱 전체의 색상이 달라집니다. 기본 제공 테마를 고르거나 앱에서 직접 만들거나 다른 사람이 공유한 테마 파일을 불러올 수 있습니다.

테마 선택하기

설정의 테마 선택에서 시스템 기본값, 라이트, 다크, 데이라이트, 라이트 그린 또는 사용자 지정을 고릅니다. 사용자 지정은 나만의 테마가 있을 때 선택할 수 있습니다. 아래의 테마 색상는 선택한 테마의 강조색만 바꿉니다. 설정을 참고하세요.

앱에서 테마 만들기

설정에서 테마 선택을 누른 다음 테마 만들기…를 고릅니다. 화면에는 테마의 모든 색상이 그룹별로 표시되며, 각 색상의 사용 위치와 색상 코드가 함께 나옵니다.

  • 테마 파일 가져오기…를 맨 위에서 선택하면 다른 사람이 공유한 파일 같은 테마 파일이 페이지에 불러와져, 저장하기 전에 수정할 수 있습니다.
  • 기준 테마를 선택하면 기본 제공 테마나 기존 사용자 지정 테마의 모든 색상이 채워집니다. 바꾸고 싶은 색상만 수정하세요.
  • 색상을 누르면 색상 선택기가 열립니다. 수정하는 동안 앱 전체에 변경 사항이 반영되어 색상이 쓰이는 곳에서 효과를 볼 수 있습니다.
  • 테마 이름을 입력하고 테마 저장을 누릅니다. 저장한 테마는 사용자 지정으로 등록되어 바로 적용됩니다. 저장 시 테마 색상은 기본으로 돌아가 테마 자체의 강조색이 표시됩니다.
  • 내보내기는 테마를 .json 파일로 저장합니다. 이 파일을 공유하거나 보관할 수 있습니다.
  • 저장하지 않고 화면을 닫으면 이전 테마로 돌아갑니다.

사용자 지정 테마는 하나만 보관됩니다. 새 테마를 저장하거나 가져오면 기존 테마를 대체합니다.

테마 파일 만들기

테마 파일은 바꾸고 싶은 색상을 나열한 작은 JSON 텍스트 파일입니다. 다음 내용을 mint.json으로 저장하세요.

{
  "name": "Mint",
  "Accent": "#5BD6A4",
  "HomeAccent": "#1B7A4A"
}

설정 > 테마 선택 > 테마 파일 가져오기…에서 파일을 불러오세요. 앱의 다른 색상은 그대로이고 강조색만 민트 그린으로 바뀝니다.

  • 파일은 UTF-8로 인코딩한 JSON 일반 텍스트여야 하며, 확장자는 .json, 크기는 최대 64 KB입니다.
  • name은 생략할 수 있으며, 40자를 넘으면 잘립니다.
  • 그 밖의 각 줄에는 아래 표의 색상 이름, 콜론, 따옴표로 감싼 색상 값을 차례로 적습니다. 이름은 대소문자까지 표와 똑같이 쓰세요. 마지막 줄을 제외한 모든 줄 끝에 쉼표를 붙입니다.
  • 색상은 "#RRGGBB"(빨강, 초록, 파랑) 또는 "#AARRGGBB"(알파가 맨 앞)로 적습니다. #RGB는 지원하지 않습니다.
  • 알파는 색상의 불투명도를 나타냅니다. FF는 완전 불투명, 80은 반투명, 00은 완전 투명입니다. 대부분의 색상은 불투명하게 두는 것이 좋습니다. 알파는 가림막과 누름 강조색에 쓰입니다. 해당 색상은 Scrim, MenuScrim, PressEditor, PressHome입니다.
  • 지정하지 않은 색상은 AbsentMotion의 기본 색상을 유지합니다. Gold를 지정하고 Favorite를 생략하면 즐겨찾기 별에 Gold 색상이 적용됩니다. SelectionBorder와 SelectionHandle도 같은 방식으로 각각 Accent와 OnDark를 따릅니다.
  • 표에 없는 이름은 무시됩니다. 파일에는 색상이 하나 이상 있어야 합니다. 색상 형식이 잘못되면 앱이 파일을 불러오지 않고 해당 색상 이름을 알려 줍니다.

팁

  • 편집기와 홈 화면은 별도로 설정할 수 있습니다. AbsentMotion 기본 테마는 편집기가 어둡고 홈 화면이 밝지만, 각각 밝거나 어둡게 바꿀 수 있습니다.
  • 텍스트가 읽기 쉬워야 합니다. 글자 색상(OnDark, HomeInk 및 그 밖에 On으로 시작하는 색상)은 배경색과 충분히 대비되어야 합니다.
  • 숫자 키패드, 내보내기 미리보기, 켜진 스위치처럼 일부 위치에만 표시되는 색상도 있습니다. 편집하면서 해당 화면을 열어 확인하세요.
  • 테마를 공유하려면 테마 만들기…에서 내보낸 .json 파일을 보내세요. 받은 사람은 테마 파일 가져오기…로 불러올 수 있습니다.

모든 색상

색상은 그룹별로 정리되어 있습니다. 두 번째 열에는 각 색상이 주로 쓰이는 위치가 나옵니다. 다른 곳에 쓰이는 색상도 있습니다.

편집기

이름사용 위치
TopBar상단 바와 패널 뒤 화면 등 편집기의 기본 배경입니다. 프리셋 같은 전체 화면 도구에도 쓰입니다.
PreviewBg영상 미리보기 뒤, 패널의 어두운 상자 안쪽(슬라이더, 선택기)과 타임라인 끝 뒤의 빈 공간입니다.
TimelineBg타임라인, 미리보기 아래 재생 바, 레이어 탭이 있는 행의 배경입니다.
Panel하단 시트, 음성·자막·늘리기 도구 패널, 컴퓨터의 미디어 라이브러리와 레벨 미터입니다.
PanelInset패널 위의 상자입니다. 요소 라이브러리 타일, 글꼴 탐색기, 누르지 않은 숫자 키와 선택하지 않은 옵션에 쓰입니다.
Button편집기의 버튼, 타일, 효과 목록 행과 타임라인에서 레이어 이름과 막대 사이의 선입니다.
Field편집기의 대화상자, 텍스트 입력란, 목록 행, 메뉴 배경입니다.
FieldHi선택했거나 도드라진 항목에 쓰입니다. 전환 컨트롤의 선택된 탭, 슬라이더 트랙의 빈 부분, 프로젝트 안전 확인 대화상자의 테두리와 컴퓨터 홈 화면의 일부 버튼입니다.
Chosen이징 패널의 그래프 배경, 테두리 및 그림자에서 선택한 항목, 그라데이션 미리보기의 어두운 쪽입니다.
Well미디어 및 오디오 탭의 타일, 슬라이더 트랙(블렌딩, 스위치), 숫자 키패드의 완료 키 등 어두운 영역에 쓰입니다.
Deepest상단 바의 밑줄, 색상 선택기 그리드, 레벨 미터 배경, 텍스트 편집기의 상단 띠처럼 가장 어두운 영역에 쓰입니다.
Line타임라인 눈금과 헤더 가장자리, 메뉴 목록의 구분선, 튜토리얼 카드와 글꼴 탐색기의 테두리 등 얇은 선에 쓰입니다.
MenuLine편집기 메뉴와 이징 패널 메뉴 안의 구분선입니다.
PressEditor컴퓨터 편집기에서 항목을 누르거나 마우스를 올릴 때 나타나는 강조 표시입니다.

타임라인

타임라인의 레이어 막대와 표시 등에 쓰이는 색상입니다.

이름사용 위치
LayerBar타임라인에서 영상, 이미지, 도형 등 일반 레이어의 막대입니다.
LayerBarStripe레이어 막대 위의 줄무늬.
TextBar타임라인의 텍스트 레이어 막대입니다.
TextBarStripe텍스트 레이어 막대 위의 줄무늬.
AudioBar타임라인의 오디오 레이어 막대입니다.
AudioWave오디오 막대 안의 파형.
OnBar일반 레이어와 텍스트 레이어의 막대에 표시되는 레이어 이름입니다.
OnAudioBar오디오 막대에 표시되는 레이어 이름입니다.
Bookmark타임라인의 북마크 표시.
Gold타임라인의 속도 조절 표시, 미리보기에서 선택하지 않은 점, 글꼴 탐색기의 검색 텍스트와 진행률 링, 슬라이더의 미세 조정선, 키패드에서 범위를 벗어난 숫자입니다.
SelectionBorder컴퓨터의 타임라인에서 선택한 클립을 둘러싼 테두리입니다. 생략하면 Accent를 따릅니다.
SelectionHandle컴퓨터의 타임라인에서 선택한 클립 양쪽 끝의 트림 핸들입니다. 생략하면 OnDark를 따릅니다.

키패드와 메뉴

레이어 도구의 숫자 키패드와 미리보기 뒤의 어두운 상자에 쓰이는 색상입니다.

이름사용 위치
KeyDigit레이어 도구 숫자 키패드의 0부터 9까지의 키입니다.
KeySymbol같은 키패드의 부호, 소수점, 지우기 키입니다.
Cool숫자 키패드에서 키에 붙은 파란 라벨과 모션 시트에서 들어오는 쪽의 윤곽선입니다.
CoolDeep키패드에서 선택한 숫자의 배경.
Scrim홈 화면 도구(범위, 압축, 도구 모음) 및 내보내기 미리보기 뒤, 내보내기 완료 화면, 이미지가 없는 커뮤니티 썸네일에 쓰이는 어두운 상자입니다.
OnScrim어두운 상자의 텍스트와 아이콘입니다. 내보내기 미리보기 버튼, 페이지 수, 재생 버튼, 커뮤니티 항목의 자리 표시 아이콘에 쓰입니다.

강조색

이름사용 위치
Accent선택한 항목, 활성 슬라이더, 편집기 상단 바의 내보내기 버튼, 타임라인의 스냅 선과 선택 영역, 재생 표시, 주요 버튼에 쓰이는 기본 색상입니다. 사용 범위가 가장 넓은 색상입니다.
AccentLit볼륨과 블렌딩 슬라이더, 편집기 스위치의 손잡이, 컴퓨터 편집기의 폴더 아이콘에 쓰이는 더 밝은 강조색입니다.
AccentGlow패널 안에서 강조하는 데 쓰이는 밝은 색입니다. 활성 숫자 키의 테두리와 라벨이 한 예입니다.
AccentDeep편집기에서 켜진 스위치의 트랙, 미리보기 핸들, 선택한 색상을 둘러싼 링에 쓰이는 어두운 강조색입니다.
OnAccent강조색 위의 텍스트와 아이콘입니다. 내보내기 아이콘, 강조색 버튼, 선택한 칩 등에 쓰입니다.
Warning오래된 미리보기, 누락된 파일, 제한을 벗어난 클립과 같은 경고 및 오류와 프로젝트 안전 확인 대화상자의 삭제 버튼 또는 위험한 작업 버튼에 쓰입니다.
Favorite텍스트 편집기와 효과 탐색기의 채워진 즐겨찾기 별입니다.

어두운 배경의 텍스트

편집기의 텍스트와 아이콘에 쓰이는 색상입니다.

이름사용 위치
OnDark편집기의 주요 텍스트와 아이콘에 쓰이며, 가장 많이 사용되는 색상입니다.
OnDarkDim힌트, 개수, 빈 목록 메시지 및 컴퓨터 편집기의 작은 아이콘 등 눈에 덜 띄는 텍스트와 아이콘입니다.
Caption패널의 작은 도움말 텍스트와 화살표, 점 편집기의 안내선입니다.
Faint점 편집기에서 선택하지 않은 아이콘, 블렌딩과 테두리 및 그림자 아이콘, 눈금과 대기 상태의 색상 선택기 등 눈에 덜 띄는 아이콘과 선입니다.
Inactive타임라인 자의 눈금과 손잡이, 꺼진 스위치 트랙, 이동 패널의 연결 및 카메라 상자 등입니다.

홈 화면

홈 화면, 설정 서랍, 새 프로젝트 시트, 내보내기 화면과 처음 사용 안내 화면에 쓰이는 색상입니다.

이름사용 위치
HomeBg홈 화면 배경과 홈 화면의 옅은 상자입니다. 새로운 기능 헤더와 대화상자의 입력란이 포함됩니다.
Card도구, 템플릿, 설정 서랍의 행, 메뉴, 내보내기 화면 상단 바, 튜토리얼 카드 등 홈 화면의 카드와 행입니다.
SheetBg새 프로젝트 시트, 내보내기 화면, 처음 사용 안내 화면, 정보 화면의 배경입니다.
HomeDrawer설정 서랍 배경(휴대폰 및 태블릿).
HomePanel홈 화면의 눈에 덜 띄는 패널에 쓰입니다. 설정 서랍의 그룹화된 행, 이미지가 없는 커뮤니티 항목, 안전 확인 대화상자 버튼이 포함됩니다.

OnNavyNavy 위의 텍스트와 아이콘입니다. 선택한 탭이나 버튼 위의 텍스트와 아이콘 등이 포함됩니다.
OnNavyAccentNavy 위의 강조 텍스트와 아이콘입니다. 선택한 옵션의 라벨, 내보내기 버튼 라벨, 홈 화면이 밝을 때 내보내기 화면의 진행 영역에 표시되는 온도 텍스트에 쓰입니다.

NavyLine설정 서랍 목록과 새 프로젝트 시트 목록, 템플릿 탭의 칩에 쓰이는 선과 테두리입니다.
HomeAccent홈 화면의 강조색입니다. 켜진 스위치, 라디오 버튼, 메뉴의 체크 표시, 내보내기 화면의 알림 텍스트와 홈의 안전 확인 대화상자에서 위험한 작업 버튼에 쓰입니다.
HomeInk홈 화면의 주요 텍스트.
HomeMid버전 표기, 화살표, 손잡이와 라벨 등 홈 화면의 보조 텍스트와 아이콘입니다.
HomeDim도움말, 도구 설명, 작은 꺾쇠 등 홈 화면의 세 번째 단계 텍스트와 아이콘입니다.
HomeFaint선택하지 않은 페이지 점과 새 프로젝트 시트의 연결 아이콘 등 홈 화면에서 가장 옅은 요소에 쓰입니다.
HomeLine홈 화면의 얇은 선과 테두리, 진행률 표시줄 트랙, 도구에서 선택한 범위 버튼입니다.
MenuScrim휴대폰과 태블릿에서 메뉴가 열려 있을 때 홈 화면을 덮는 가림막입니다.
PressHome홈 화면에서 항목을 누르거나 마우스를 올릴 때 나타나는 강조 표시입니다.
