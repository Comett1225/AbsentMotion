목차이펙트

추가 메뉴

도형, 사진, 동영상, 소리, 텍스트, 드로잉, 카메라, 조명, 3D 모델 등을 추가하는 방법입니다.

이 페이지
  • 빠른 버튼
  • 도형
  • 미디어
  • 오디오
  • 오브젝트 / 에셋
  • 템플릿

타임라인 영역 오른쪽 아래의 둥근 + 버튼을 누르면 추가 메뉴가 열립니다. 아무것도 선택하지 않았을 때만 보이며, 레이어를 선택하면 도구 격자로 바뀝니다.

새 레이어는 재생 헤드 위치에서 시작하며, 새 레이어 길이 설정(기본값 2초)만큼 유지됩니다. 사진과 도형은 이 길이를 사용하고, 동영상과 소리는 자체 길이를 사용합니다. 카메라 레이어와 조명 레이어는 프로젝트 전체 길이 동안 유지됩니다.

메뉴 상단에는 탭 다섯 개(도형, 미디어, 오디오, 오브젝트 / 에셋, 템플릿)가 있고, 오른쪽에는 빠른 버튼 네 개가 있습니다. X를 누르면 메뉴가 닫힙니다.

빠른 버튼

  • 자유형 브러시는 드로잉 레이어를 만들고 드로잉 편집기를 엽니다. 도형, 드로잉 및 마스크를 참고하세요.
  • 펜 도구는 도형 레이어를 만들고 포인트 편집기를 엽니다. 포인트를 하나씩 찍어 도형을 그릴 수 있습니다.
  • 텍스트는 텍스트 레이어를 추가하고 바로 텍스트 편집기를 엽니다. 텍스트와 글꼴을 참고하세요.
  • 자막은 자동 자막 시트를 엽니다. AI 도구를 참고하세요.

도형

기본 제공 도형 54개가 한 줄에 여섯 개씩 페이지로 나뉘어 있습니다. 도형을 누르면 화면 가운데에 무작위로 고른 보기 좋은 색상으로 추가됩니다.

도형 19개는 매개변수 방식이며 도형 옵션으로 편집합니다. 원, 둥근 사각형, 플러스, 호, 삼각형, 콜아웃, 파이, 다각형, 멀티포일, 화살표, 쿼드, 달, 직사각형, 별, 선, 넓은 선, 불규칙 오각형, 스탬프, 물방울형입니다. 나머지 35개는 포인트로 그린 도형이며 포인트 편집으로 편집합니다. 하트, 구름, 번개, 체크 표시, X 표시, 고리, 말풍선, 방패, 집, 책갈피, 깃발, 초승달과 별, 해, 잎, 폭발 씰, 육각형 윤곽선, 별 윤곽선, 쉐브론, 양방향 화살표, 곡선 화살표, 평행사변형, 사다리꼴, 티켓, 태그, 왕관, 눈, 우산, 음표, 물방울 한 쌍, 열쇠, 위치 핀, 둥근 재생, 일시정지, 녹화, 톱니바퀴입니다.

미디어

사진과 동영상이 최신순으로 격자에 표시됩니다. 하나를 누르면 화면에 맞는 크기로 추가됩니다.

  • 모두 보기를 누르면 안드로이드의 사진 선택기가 열립니다. 별도 권한은 필요하지 않습니다.
  • 격자의 첫 번째 타일인 파일에서 가져오기를 누르면 안드로이드의 파일 선택기가 열려 어느 폴더에서든 사진이나 동영상을 가져올 수 있습니다. 이 기능도 별도 권한은 필요하지 않습니다.
  • 위쪽의 앨범 목록으로 격자를 좁힐 수 있습니다(기본값은 전체).
  • 카메라를 누르면 앱 내 카메라가 열립니다. 카메라 조작 방법은 프로젝트 만들기를 참고하세요.
  • 검색으로 격자에서 찾을 수 있습니다("사진 및 동영상 검색").
  • 갤러리의 SVG 파일도 여기에 표시됩니다.

처음 사용할 때 안드로이드가 사진과 동영상을 볼 수 있는 권한을 요청합니다. 안드로이드 14 이상에서는 선택한 항목에만 접근하도록 허용할 수 있습니다. 기본적으로 앱은 추가한 미디어의 사본을 프로젝트 안에 보관하므로, 나중에 원본을 삭제해도 프로젝트는 계속 작동합니다.

오디오

휴대폰에 저장된 음악과 소리입니다. 처음 사용할 때 앱이 오디오 파일을 읽을 수 있는 권한을 요청합니다.

  • 모두 보기를 누르면 오디오 파일용 파일 선택기가 열립니다.
  • 파일에서 가져오기를 누르면 안드로이드의 파일 선택기가 열려 어느 폴더에서든 오디오 파일을 가져올 수 있습니다. 별도 권한은 필요하지 않습니다.
  • 텍스트 음성 변환은 입력한 텍스트를 음성으로 바꿉니다. 오디오를 참고하세요.
  • 소리 타일을 누르면 소리가 재생되고, 다시 누르면 멈춥니다. 타일 아래쪽의 + 띠를 누르면 재생 헤드 위치에 프로젝트로 추가됩니다.
  • 음악 및 소리 검색은 제목, 파일 이름, 앨범, 아티스트와 일치하는 항목을 찾습니다.

오브젝트 / 에셋

그 밖의 레이어 종류를 위한 타일 일곱 개입니다.

  • 카메라는 프로젝트 전체 길이 동안 유지되는 카메라 레이어를 추가합니다. 카메라 레이어와 3D를 참고하세요.
  • 조명은 3D 모델과 3D 이펙트의 조각에 그림자를 드리우는 조명을 추가합니다. 카메라 레이어와 3D를 참고하세요.
  • 널 오브젝트는 보이지 않는 보조 레이어를 추가합니다. 다른 레이어의 부모로 쓰거나 모션 트래킹의 대상으로 사용할 수 있습니다.
  • 빈 그룹은 빈 그룹을 추가합니다.
  • 에셋 / 프로젝트는 저장한 에셋과 다른 프로젝트를 나열합니다. 하나를 누르면 재생 헤드 위치에 그룹으로 삽입됩니다. 에셋은 원본과 계속 연결되어 있고, 프로젝트는 독립된 사본으로 삽입됩니다. 에셋, 템플릿, 프리셋을 참고하세요.
  • SVG 가져오기는 .svg 파일(최대 16 MB)을 고르는 파일 선택기를 엽니다. 도형 하나는 도형 레이어가 되고, 여러 개면 그룹이 됩니다. 가져오지 못한 요소는 메시지로 알려 줍니다. 텍스트, 이미지, 내장 콘텐츠, 애니메이션, 클리핑 경로, 마스크, 필터, 마커, 점선 또는 그라데이션 선, 패턴 채우기가 여기에 해당합니다. 그라데이션은 첫 번째 색과 마지막 색만 유지됩니다.
  • 3D 모델은 .obj, .glb, .gltf 파일을 고르는 파일 선택기를 엽니다. 모델에 재질 파일과 이미지 파일이 있다면 함께 선택하세요. 파일 전체 크기는 최대 256 MB이며, 삼각형이 50,000개를 넘는 모델은 간소화된 형태로 표시됩니다.

템플릿

모두 보기를 누르면 저장한 템플릿이 전체 화면 격자로 표시됩니다. 각 템플릿은 아래에 타일로도 표시됩니다. 하나를 누르면 내 미디어를 넣을 수 있는 화면이 열립니다. 아직 템플릿이 없으면 페이지에 "여기에는 아무것도 없습니다. 템플릿으로 저장한 프로젝트가 여기에 표시됩니다."라고 나타납니다. 에셋, 템플릿, 프리셋을 참고하세요.
