설치

이 휴대전화에는 AbsentMotion이 이미 설치되어 있습니다. 이 페이지는 첫 프로젝트를 만드는 과정을 안내합니다. 다른 페이지에서는 모든 화면을 설명합니다.

처음 실행

처음 앱을 열면 홈 화면 전에 두 개의 화면이 나옵니다.

  1. 언어를 고르세요. 앱은 25개 언어를 지원합니다: 영어, 인도네시아어, 힌디어, 포르투갈어(브라질), 스페인어(라틴 아메리카), 스페인어(스페인), 필리핀어, 베트남어, 태국어, 말레이어, 아랍어, 페르시아어, 우르두어, 터키어, 러시아어, 벵골어, 일본어, 한국어, 중국어(번체), 중국어(간체), 프랑스어, 독일어, 이탈리아어, 폴란드어, 우크라이나어. 앱이 지원하면 휴대전화의 언어가 맨 앞에 표시됩니다. 나중에 설정에서 바꿀 수 있습니다.
  2. 이 기기의 성능을 확인하세요. 간단한 테스트로 휴대전화가 내보낼 수 있는 동영상 형식과 크기, 그리고 속도(빠름, 좋음, 기본)를 확인합니다. 몇 초 정도 걸리는 테스트는 한 번만 실행되며, 모든 것은 휴대전화 안에서만 처리됩니다. 건너뛰어도 됩니다. 같은 화면의 스위치를 켜 두면 앱을 열 때마다 한 번씩 GitHub에 최신 버전 번호를 물어볼 수 있습니다. 기본으로 켜져 있으며, 이 기능 외에는 아무것도 보내지 않습니다.

이 앱은 시작할 때 아무 권한도 요청하지 않습니다. 사진, 동영상, 오디오, 카메라, 마이크 접근은 해당 기능을 처음 사용할 때 요청합니다.

첫 프로젝트 만들기

  1. 홈 화면 아래의 둥근 + 버튼을 누르세요. 이것이 새 프로젝트입니다.
  2. 화면 비율(16:9, 9:16, 4:5, 1:1 또는 4:3), 해상도(1080p가 좋은 시작점입니다), 배경을 고르세요. 잘 모르겠다면 프레임 레이트는 그대로 두세요. 프로젝트 만들기를 누르세요. 편집기가 빈 프로젝트로 열립니다. 자세한 내용은 프로젝트 만들기를 참고하세요.
  3. 타임라인 영역 오른쪽 아래의 둥근 +를 누른 뒤 추가할 항목을 고르세요. 도형, 미디어 탭의 사진이나 동영상, 또는 텍스트입니다.
  4. 미리보기에서 드래그하면 레이어가 움직입니다. 두 손가락으로 벌리거나 모으면 크기가 커지거나 작아집니다.
  5. 타임라인에서 좌우로 드래그하면 시간이 이동합니다. 레이어를 시간상 옮기려면 막대를 길게 누른 채 드래그하세요. 길이를 자르려면 레이어를 선택한 뒤 양 끝의 둥근 손잡이를 드래그하세요.
  6. 재생 버튼을 눌러 확인하세요.

저장 버튼은 없습니다. 모든 변경 후 잠시 뒤에 프로젝트가 자동으로 저장됩니다.

무언가에 애니메이션 적용하기

AbsentMotion의 애니메이션은 키프레임으로 이루어집니다. 키프레임은 특정 시점의 값(위치, 크기, 불투명도)을 저장하고, 앱이 키프레임 사이의 움직임을 채웁니다.

  1. 미리보기나 타임라인에서 레이어를 누르세요. 하단에 도구 격자가 나타납니다.
  2. 변형을 누르세요. 이동 탭이 열려 있습니다.
  3. 재생 헤드를 움직임이 시작될 위치에 두고, 왼쪽 열의 키프레임 버튼(다이아몬드)을 누르세요.
  4. 재생 헤드를 나중 시간으로 옮기고 레이어를 새 위치로 드래그하세요. 해당 속성에 이미 키프레임이 있으므로 두 번째 키프레임이 자동으로 만들어집니다.
  5. 재생하세요. 이징 버튼(곡선)을 누르면 움직임이 빨라지거나, 느려지거나, 튕기도록 만들 수 있습니다. 키프레임과 이징을 참고하세요.

빠르게 결과를 내려면 레이어를 선택한 뒤 미리보기 오른쪽 아래의 둥근 애니메이션 적용 버튼을 눌러 In, Out 또는 Loop 애니메이션을 고르거나, 이펙트를 열어 이동 이펙트 중 하나를 써 보세요.

내보내기

  1. 상단 바의 공유 아이콘(내보내기 및 공유)을 누르세요.
  2. 동영상 카드가 선택되어 있습니다. 내보내기를 누르세요.
  3. 진행 막대가 끝날 때까지 기다리세요. 그사이 다른 앱으로 전환해도 됩니다. 알림에 진행 상황이 표시됩니다.
  4. 동영상 공유를 누르거나, Movies/AbsentMotion에서 파일을 찾으세요.

모든 옵션(형식, 해상도, 프레임 레이트, GIF, 오디오만)은 내보내기 페이지에 있습니다.
