경로를 따르는 텍스트

텍스트 · 버전 4.2.0에서 추가됨

텍스트를 호, 원, 또는 바로 아래 레이어의 윤곽을 따라 한 글자씩 배치합니다. 텍스트의 서식, 글꼴, 이모지는 그대로 유지됩니다.

경로를 고르세요. 텍스트 레이어 주변의 호나 원(캔버스에서 점을 끌거나 값을 직접 입력), 또는 레이어 목록에서 텍스트 바로 아래에 있는 것을 따라가는 아래 레이어(펜 패스, 도형, 드로잉의 선, 다른 텍스트의 글자)를 고를 수 있습니다. 원이나 닫힌 윤곽선에서 위치 50 %는 텍스트를 위쪽 가운데에 두고 왼쪽에서 오른쪽으로 읽히게 하며, 0 %는 아래쪽에 둡니다. 경로 반전를 켜면 0 %가 텍스트를 아래쪽에 두며 여전히 왼쪽에서 오른쪽으로 읽힙니다. 여러 부분으로 된 패스는 한 부분씩 차례로 따라갑니다. 패스 위의 텍스트는 텍스트 상자에 맞춰 줄바꿈되지 않으므로, 두 번째 줄은 직접 줄을 바꾸세요.
