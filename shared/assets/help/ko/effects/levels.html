목차이펙트

레벨

색상 · 버전 2.1.0 이하에서 추가됨

입력 검정점과 흰점, 감마, 출력 검정점과 흰점으로 이미지의 레벨을 조정합니다.

레벨은 어떤 밝기가 순수한 검정과 순수한 흰색이 될지 정합니다. 입력 검정을 올리면 그림자가 어두워지고, 입력 흰색을 낮추면 하이라이트가 밝아집니다. 감마는 검정과 흰색은 건드리지 않고 중간 톤만 바꿉니다. 출력 검정과 출력 흰색은 최종 범위를 제한하여 빛바랜 느낌을 줍니다.

설정

설정유형범위기본값
입력 검정숫자0~10.1
입력 흰색숫자0~10.85
감마숫자0.2~51
출력 검정숫자0~10
출력 흰색숫자0~11
