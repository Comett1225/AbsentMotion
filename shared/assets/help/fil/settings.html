Mga Setting

I-tap ang menu button sa itaas na kaliwa ng home screen para buksan ang drawer ng Mga setting. Sa itaas ay may card na may bersyon at mga button ng update. Sa ilalim nito ay apat na grupong nagsisimulang nakasara (i-tap ang isang grupo para buksan ito) at ilang row pa.

Bersyon at mga update

Ipinapakita ng card sa itaas ang bersyon na gamit mo at tatlong button.

  • Isang beses, ngayon, sinusuri ng Maghanap ng Update kung may mas bagong bersyon. Kung mayroon, ipinapakita ng dialog ang bersyon at laki ng download nito. Binubuksan ng Talaan ng mga pagbabago ang release notes nito, at dina-download ng I-download ang update ang tugmang app file (Latest o Compatible na bersyon, at ang Intel o AMD file sa mga Chromebook na may ganoong chip) sa loob ng app, may progress bar at Kanselahin. Bago may ma-download, hihilingin ng app na i-on mo ang Payagan mula sa source na ito para sa AbsentMotion kung hindi pa ito pinapayagan ng Android. Sinusuri ng app ang file gamit ang checksum at signing key ng release, saka ini-install ito ng Android; sa Android 12 at mas bago, nangyayari ito nang walang confirmation dialog kapag pinapayagan ng system, at pagkatapos ay nagbubukas ng app ang isang notification (hihilingin ng mas lumang Android na kumpirmahin mo). Sa Windows, Mac at Linux, sine-save ng I-install at i-restart ang proyekto mo, isinasara ang app, ini-install ang update at binubuksan ulit ang app. Kung hindi mahanap ang tugmang file, binubuksan ng I-download ang release page. Sa Samsung na phone, puwedeng pigilan ng Auto Blocker ang pag-install: tingnan ang Pag-troubleshoot at mga tanong.
  • Binubuksan ng Ano ang bago ang mga tala ng bersyon na gamit mo: ang mga bagong feature at bawat ayos, sa mga grupo. Tingnan ang Ano ang bago.
  • Ipinapakita ng Auto-check: Naka-on o Auto-check: Naka-off kung naghahanap ang app ng bagong bersyon sa tuwing bubukas ito. I-tap ito para magpalit. Nagtatanong ang app nang isang beses kung maaari itong gawin. Kung naka-on, ang app ay gumagawa ng isang request sa GitHub para sa numero ng pinakabagong bersyon kapag binuksan ito. Wala itong ibang ipinapadala at hindi kailanman nagda-download o nag-i-install ng kahit ano nang mag-isa.

Sa computer, ang Mga setting ay isang window na nakalista sa kaliwa ang mga page nito. Doon, ang page na Mga update ay may switch na Maghanap ng bagong version sa tuwing bubukas ang app, Maghanap ng Update at ang bersyon, at ang mga tala ng bersyon ay bumubukas mula sa page na Tungkol.

Editor

  • Tema. Default ng system (ang default sa bagong install: Maliwanag o Madilim, ayon sa dark mode ng iyong telepono o computer), Maliwanag (madilim na editor at maliwanag na home screen), Madilim (madilim sa lahat ng lugar, pati Home), Daylight (maliwanag sa lahat ng lugar) o Pasadya. Sa unang pagbukas ay ipinapakita ang Piliin ang iyong tema, at gayundin sa unang pagbukas pagkatapos mag-update sa 5.1 kung hindi ka pa pumili ng tema. Naglo-load ang Mag-import ng file ng tema… ng tema mula sa maliit na file (tingnan sa ibaba). Sa ilalim nito, itinatakda ng Kulay ng tema ang accent color ng mga button, switch at iba pang highlight: Default (ang sariling kulay ng tema), Asul, Berde, Lila, Rosas o Pasadya…, na nagbubukas ng color picker. Itinatakda ng Font ng app ang font ng mga menu at label ng app, hindi ang teksto sa iyong mga proyekto: Default o isa sa mga font na kasama ng app o na in-import mo.
  • Tagal ng bagong layer. Gaano katagal tumatagal ang mga bagong layer: 1 hanggang 10, 15, 20, 25, 30, 45 o 60 segundo. Ang default ay 2.
  • Vibration. Maliliit na vibration sa timeline para sa pag-snap, matagal na pagpindot at pag-reorder. Naka-on bilang default.
  • Transition button sa preview. Naka-off bilang default. Ang bilog na button na nagdadagdag ng transition ay karaniwang nasa kanang ibaba ng timeline area. I-on ito para mapunta ito sa kaliwang ibaba ng preview. Tingnan ang Mga transition at animation.
  • Estilo ng emoji. SISTEMA (emoji ng iyong phone, ang default) o ANDROID (ang emoji font na kasama ng app, pareho sa bawat phone).

Mga pasadyang tema

Ang file ng tema ay isang maliit na text file sa JSON format na hanggang 64 KB na may opsyonal na name at alinman sa mga kulay na gusto mong baguhin, na isinusulat bilang #RRGGBB o #AARRGGBB. Ang mga kulay na hindi mo ilalagay ay mananatili sa itsura ng AbsentMotion. Halimbawa:

{"name": "Mint", "Accent": "#5BD6A4", "HomeAccent": "#1B7A4A"}

Ang mga pangalan ng kulay ay ang mga kulay ng editor at home screen: TopBar, PreviewBg, TimelineBg, Panel, PanelInset, Button, Field, FieldHi, Chosen, Well, Deepest, Line, MenuLine, KeyDigit, KeySymbol, Scrim, PressEditor, OnDark, OnDarkDim, Caption, Faint, Inactive, OnScrim, Accent, AccentLit, AccentGlow, AccentDeep, OnAccent, Cool, CoolDeep, Gold, Favorite, Warning, Bookmark, LayerBar, LayerBarStripe, TextBar, TextBarStripe, AudioBar, AudioWave, OnBar, OnAudioBar, HomeBg, Card, SheetBg, Navy, HomeAccent, OnNavy, OnNavyAccent, NavyHi, NavyLine, HomeInk, HomeMid, HomeDim, HomeFaint, HomeLine, HomePanel, HomeDrawer, SwitchOff, Thumb, MenuScrim at PressHome. Isang pasadyang tema lang ang itinatabi sa isang pagkakataon; kapag nag-import ka ng bagong file, papalitan nito ang dati at agad itong ilalapat.

Pag-playback at preview

  • Kalidad ng preview. BUO, KALAHATI o SANGKAAPAT (default Buo): gaano kalinaw ang editor preview. Ang mas mababa ay mas mabilis sa mabagal na phone at hindi binabago ang mga export. Ang parehong switch ay nasa preview strip ng editor.
  • Graphics. AWTOMATIKO o OPENGL (default Awtomatiko): kung paano iginuguhit ng app ang preview at ang export. Gumagamit ng Vulkan ang Awtomatiko at lumilipat sa OpenGL kapag hindi nagsimula ang Vulkan. Kung kusang nagsasara ang app habang nagsisimula ang graphics, ang susunod na pagbukas ay gagamit ng isa pa. Piliin ang OpenGL kung mali ang itsura ng preview o ng mga export sa phone na ito. Sinasabi ng linya sa ilalim ng switch kung alin ang ginagamit. Sa OpenGL, may ilang AI tool na wala; tingnan ang Mga kinakailangan at bersyon.
  • Resampling ng playback. MABABA, MATAAS o ULTRA (default Ultra): ang kalidad ng sound resampling, kapag nagpe-play ang editor at kapag hinahalo ang tunog para sa isang export.
  • Gamitin ang preview copies ng malalaking bidyo. Naka-on bilang default. Para sa mga bidyo na mas malaki sa 1920 x 1080, o may kaunting keyframe, gumagawa ang app ng maliit at magaan na kopya sa background at ginagamit ito para sa preview. Ang mga export ay laging gumagamit ng orihinal na file. Ang mga kopya ay pinapanatili sa cache na hanggang 2 GB.
  • Binubura ng Burahin ang preview copies ang mga ito. Ipinapakita ng row ang espasyong ginagamit nila.
  • I-pre-render ang preview habang nakatigil. Naka-on bilang default. Kapag huminto ka sandali, nire-render ng app sa background ang mga frame sa paligid ng playhead hanggang mapuno ang memory na nakalaan para dito. Isang manipis na berdeng linya sa ibaba ng time ruler ang nagmamarka sa mga frame na handa na, at maayos ang takbo ng mga ito. Mga frame lang na apektado ng pagbabago ang itinatapon. I-off ito para makatipid sa baterya o memory.

Mga proyekto at media

  • Ipakita ang import card sa listahan ng proyekto. Naka-off bilang default. Nagdadagdag ng card na may Pumili ng file sa itaas ng listahan ng proyekto.
  • Folder ng mga bundle. Dito sine-save ang mga bundle ng proyekto (.absproj). I-tap ito para pumili ng folder nang isang beses; pagkatapos nito, diretsong mapupunta roon ang bawat bundle. Ang Gamitin ang default na folder ng mga bundle ay bumabalik sa Documents/AbsentMotion. Maaari mo rin itong baguhin sa I-save sa sa pahinang Bundle ng proyekto sa I-export. Kung hindi na ma-access ang folder, may paalala sa ilalim nito; i-tap ito para pumili muli ng folder.
  • Magtabi ng kopya ng na-import na media sa proyekto. Naka-on bilang default. Ang larawan, bidyo o audio na idinagdag mo ay kinokopya sa loob ng proyekto, kaya patuloy itong gumagana kahit ilipat o burahin ang orihinal. I-off ito para makatipid sa storage kung hindi mo kailanman inililipat ang iyong mga file.
  • Kalidad ng cut-out. Standard o AI pagtanggal ng background 2.0: ang uri ng cut-out na makukuha mo kapag inalis mo ang background ng isang larawan. Tingnan ang Mga AI tool.
  • Alisin ang modelo ng kapsyon. Ipinapakita lang pagkatapos ma-download ang speech model para sa mga kapsyon. Ipinapakita nito ang laki ng file at binubura ito; muli itong dina-download ng app kung gagamit ka ng mga kapsyon sa hinaharap.
  • I-delete ang AI ... model. Isang row para sa bawat na-download na AI Enhance o AI Smooth model, kasama ang laki nito. Binubura ang model kapag tinap mo ito; muli itong dina-download ng app sa susunod na kailanganin.
  • I-delete ang Add-on para sa pag-download ng bidyo. Ipinapakita lang pagkatapos ma-download ang add-on. Ipinapakita nito ang espasyong ginagamit ng add-on at inaalis ito; hihingin muli ng Downloader ng bidyo ang add-on sa susunod mong paggamit. Tingnan ang Ang home screen.
  • Gamitin ang graphics chip para sa AI. Naka-on bilang default para lang sa mas bagong graphics chip na alam na ligtas para sa AI Smooth at AI Enhance; sa ibang phone, tumatakbo ang mga ito sa processor. Kapag in-on mo ito para sa ibang chip, magtatanong muna ang app, dahil maaari nitong i-freeze ang ilang phone. Tingnan ang Mga AI tool.

Backup

  • I-backup ang lahat ng proyekto, I-restore mula sa backup at Lingguhang awtomatikong backup (mga proyekto lang) (naka-off bilang default). Tingnan ang Mga Proyekto, backup at import.

Mga tool

Binubuksan ng Mga tool ang I-customize ang mga tool: lagyan ng tsek ang mga tool na ipapakita at i-drag ang mga ito sa pagkakasunod-sunod, nang hiwalay para sa Pahina ng Mga tool at Sa loob ng proyekto. Ibinabalik ng I-reset ang bawat tool sa karaniwang pagkakasunod-sunod.

Wika

Ang row na Wika ay nagpapakita ng kasalukuyang wika at binubuksan ang listahan ng 26 na wika: English, Indonesian, Hindi, Portuguese (Brazil), Spanish (Latin America), Spanish (Spain), Filipino, Vietnamese, Thai, Malay, Arabic, Persian, Urdu, Turkish, Russian, Bengali, Japanese, Korean, Chinese (Traditional), Chinese (Simplified), French, German, Italian, Polish, Dutch at Ukrainian. Agad itong inilalapat kapag pumili ka ng isa. Sa Windows, Mac at Linux, magagamit ang bagong wika pagkatapos mong i-restart ang app.

Tungkol, Tulong at iba pang row

  • Binubuksan ng Tulong ang gabay na ito sa loob ng app, kahit walang koneksyon.
  • Ang Simulan ang tutorial ay nagsisimula ng 5-minutong tour. Gagawa ka ng maikling animation sa practice project, kaya hindi nagagalaw ang sarili mong mga proyekto. Kung titigil ka sa kalagitnaan ng tour, magiging Ituloy ang tutorial ang row at lilitaw ang pangalawang row, ang Simulan muli ang tutorial. Iniaalok din ng home screen ang tour hanggang piliin mo ang Huwag nang itanong muli.
  • Ipinapakita ng Tungkol ang bersyon, ang button na nagbubukas ng mga tala ng bersyong ito, lisensya (GNU General Public License v3.0), paalalang independiyenteng proyekto ang AbsentMotion, Mga lisensya ng open source (buong teksto ng lisensya ng bawat library na ginagamit ng app) at dalawang link na bumubukas sa browser: Home page ng proyekto (ang GitHub repository) at Website at gabay (ang website ng AbsentMotion na may gabay na ito).
  • Ang Mag-ulat ng problema at Magmungkahi ng feature, ang dalawang button sa ilalim ng Tungkol, ay nagbubukas ng bug report form at ng form para sa mga ideya sa iyong web browser. Ang Sumali sa Discord sa ilalim ng mga ito ay nagbubukas ng imbitasyon sa Discord server ng AbsentMotion.
  • Inililista ng Mga crash log ang mga crash na naitala ng app. I-tap ang isa para basahin ito at gamitin ang Kopyahin para kopyahin ito, halimbawa para ipadala kasama ng bug report. Tingnan ang Pag-troubleshoot at mga tanong.
