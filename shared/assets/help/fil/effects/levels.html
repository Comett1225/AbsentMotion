Mga antas

Kulay · Idinagdag sa bersyon 2.1.0 o mas nauna

Inaayos ang mga antas ng larawan gamit ang input na itim/puti, gamma, at output na itim/puti.

Itinatakda ng Mga antas kung aling liwanag ang magiging purong itim at purong puti. Taasan ang Itim na input para dumilim ang mga anino at babaan ang Puting input para lumiwanag ang mga highlight. Binabago ng Gamma ang mga midtone nang hindi ginagalaw ang itim at puti. Nililimitahan ng Itim na output at Puting output ang huling range, para sa kupas na itsura.
