Mga antas

Kulay · Idinagdag sa bersyon 2.1.0 o mas nauna

Inaayos ang mga antas ng larawan gamit ang input na itim/puti, gamma, at output na itim/puti.

Ang Levels ay nagtatakda kung aling brightness ang magiging pure black at pure white. Itaas ang Input Black para gawing mas madilim ang mga shadow at ibaba ang Input White para gawing mas maliwanag ang mga highlight. Binabago ng Gamma ang mga midtone nang hindi ginagalaw ang black at white. Nililimitahan ng Output Black at Output White ang huling range, para sa faded na itsura.
