Tunay na motion blur

Galaw · Idinagdag sa bersyon 3.0.0

Hinihidyo ang layer sa aktwal na paraan ng paggalaw, pag-ikot at paglaki nito, gaya ng shutter ng kamera. Mas malawak ang shutter angle, mas mahaba ang bakas; mas maraming sample, mas makinis. Mas mabilis ang preview blur maliban kung naka-on ang Full Blur.

Ang True Motion Blur ay gumagana tulad ng shutter ng kamera. Ang Shutter Angle ay kung gaano katagal nakabukas ang shutter: ang 180 degrees ang karaniwang film look at ang 360 ang nagbibigay ng pinakamahabang trails. Ang Samples ay kung ilang kopya ang pinagsasama: mas marami ay mas smooth pero mas mabagal.

Sinusundan nito ang totoong galaw ng layer, kasama ang mga motion effect. Ang preview ay nagpapakita ng mabilis na approximation maliban kung naka-on ang Full Blur sa preview strip.
