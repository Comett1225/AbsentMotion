Bigat ng Font

Teksto · Idinagdag sa bersyon 5.0.0

Itinatakda kung gaano kakapal ang mga letra, mula manipis hanggang makapal, at puwedeng i-animate gamit ang mga keyframe. Gumagana sa mga variable font, na nasa iisang file ang lahat ng bigat: Raleway, Quicksand, Comfortaa, Lora, Bitter, Orbitron, Playfair Display at Dancing Script sa listahan ng font, o isang variable font na ii-import mo. Pinapanatili ng mga font na may nakapirming bigat ang sarili nilang hitsura.

Ang Bigat ng Font ay ginagawang mas manipis o mas bold ang mga letra ng isang text layer. Ang Bigat ay mula 1 hanggang 1000: 100 ang manipis, 400 ang regular, 700 ang bold at 900 ang black. I-animate ito gamit ang mga keyframe at unti-unting lumalapot o numinipis ang mga letra.

Kailangan nito ng variable font, isang font na naglalaman ng lahat ng bigat sa isang file. Sa listahan ng font, ang mga ito ay Raleway, Quicksand, Comfortaa, Lora, Bitter, Orbitron, Playfair Display at Dancing Script, at gumagana rin ito sa isang variable font na ii-import mo. Pinananatili ng mga font na may nakapirming bigat ang sarili nilang hitsura.
