Luma key

Key · Idinagdag sa bersyon 2.1.0 o mas nauna

Tinatanggal ang madidilim na bahagi ng layer (o ang maliliwanag).

Ginagawang transparent ng Luma Key ang madidilim na bahagi ng isang layer (ang maliliwanag na bahagi kapag naka-Invert). Ang Threshold ay ang liwanag kung saan nito pinuputol at ang Softness ay kung gaano kalumanay ang pagputol. Kapaki-pakinabang ito para sa footage ng apoy, usok o sparks na kinunan sa itim, o para sa puting background kapag naka-Invert.
