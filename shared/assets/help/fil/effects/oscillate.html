Oscillate

Galaw · Idinagdag sa bersyon 3.0.0

Ginagalaw ang layer pabalik-balik sa isang anggulo, sa lalim o paikot sa isang orbit.

Kusang ginagalaw ng Oscillate ang layer pabalik-balik. Pinipili ng Direksyon ang galaw sa isang Anggulo, sa Lalim, o paikot sa isang Orbit. Ang Dalas ay ang bilang ng indayog bawat segundo, ang Laki ay kung gaano ito kalayo gumagalaw, at ang Alon ay Sine (makinis) o Tatsulok (pantay ang bilis). Gamitin ang Phase para pag-iba-ibahin ang tiyempo ng ilang layer para hindi sila gumalaw nang sabay.
