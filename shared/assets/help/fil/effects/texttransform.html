Transform ng Teksto

Teksto · Idinagdag sa bersyon 3.0.0

Ginagalaw, pinalalaki, pinapaikot, pinapakupas at kinukulayan ang mga letra, salita o linya sa loob ng isang range. Itinatakda ng Anchor kung bawat component o ang gitna ng layer ang gagamitin sa scaling at rotation. Ilipat ang range gamit ang Offset para gumalaw ang pagbabago sa buong teksto.

Ang Text Transform ay naglilipat, nag-s-scale, nagpapaikot, nagpapa-fade at nagti-tint ng mga letra, salita o linya. Itakda kung ano ang dapat mangyari sa mga apektadong piraso (Position, Scale, Rotation, Opacity, Tint), pagkatapos i-animate ang Offset para dumaan ang pagbabago sa teksto mula simula hanggang dulo. Ang mga preset na Wave at Spin Cascade ay magandang simula.
