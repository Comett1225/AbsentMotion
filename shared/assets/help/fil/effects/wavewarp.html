Wave Warp

Distort · Idinagdag sa bersyon 2.1.0 o mas nauna

Binabaluktot ang layer gamit ang sine wave: Itinatakda ng Spacing kung ilang wave ang tumatawid, ng Magnitude kung gaano kalayo ang pagtulak, ng Anggulo ang direksyon ng pagtakbo ng waves at ng Warp Angle ang direksyon ng pagtulak.

Binabaluktot ng Wave Warp ang layer gamit ang alon. Ang Spacing ay ang distansya sa pagitan ng mga alon, ang Magnitude ay kung gaano kalayo nila itinutulak ang larawan, ang Angle ay ang direksyon na tinatahak ng mga alon, at ang Warp Angle ay ang direksyon ng kanilang pagtulak. I-animate ang Phase para gumalaw ang mga alon, o itakda ang Speed para kusang gumalaw ang mga ito.
