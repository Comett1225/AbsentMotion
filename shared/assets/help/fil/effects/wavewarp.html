Wave Warp

Distort · Idinagdag sa bersyon 2.1.0 o mas nauna

Binabaluktot ang layer gamit ang sine wave: itinatakda ng Spacing kung ilang alon ang tumatawid dito, ng Magnitude kung gaano kalayo ang tulak, ng Anggulo ang direksyon ng takbo ng mga alon, at ng Warp Angle ang direksyon ng tulak. Iniaangkop ng Screen Space ang laki ng mga alon sa screen sa halip na sa layer. Nagdadagdag ang Cross Magnitude ng ikalawang alon, na ang laki ay itinatakda ng Cross Spacing, na tumatakbo ayon sa Warp Angle at tumutulak ayon sa Anggulo. Kapag Kaliwang ibaba ng screen ang Origin, sinusukat ang mga alon mula sa sulok na iyon ng screen batay sa maikling gilid nito, at saka sila inuusog ng Phase. Pinapahina ng Damping ang mga alon papunta sa Damping Anchor, isang puwesto sa layer mula 0 hanggang 1 sa kahabaan ng Anggulo; binabatak ng Damping Spacing ang mga alon malapit sa anchor kapag lampas sa 0 at palayo rito kapag mas mababa sa 0.

Binabaluktot ng Wave Warp ang layer gamit ang alon. Ang Spacing ay ang layo sa pagitan ng mga alon, ang Magnitude ay kung gaano kalayo nila itinutulak ang larawan, ang Anggulo ang direksyong tinatakbo ng mga alon, at ang Warp Angle ang direksyon ng pagtulak nila. I-animate ang Phase para gumalaw ang mga alon, o itakda ang Bilis para kusa silang gumalaw.
