ASCII

I-istilo · Idinagdag sa bersyon 5.0.0

Ginagawang text art ang layer, gawa sa mga letra at simbolo: mas buong character ang inilalagay sa mas maliliwanag na bahagi. Itinatakda ng Laki kung gaano kalapad ang bawat character sa layer, kaya gumagalaw, umiikot at nagsi-scale ang mga character kasama nito. Pinapanatili ng Kulay ang sariling kulay ng larawan o gumagamit ng isang kulay lang, at gumuguhit ang Mga linya ng gilid ng mga outline gamit ang mga character na | - / at \.

Ang ASCII ay ginagawang text art na gawa sa mga letra at simbolo ang isang layer: ang mas maliliwanag na bahagi ay nakakakuha ng mas punong mga character. Gumagana ito sa mga bidyo, larawan, teksto at hugis.

  • Ang Laki ay kung gaano kalapad ang bawat character, sinusukat sa layer, kaya gumagalaw, umiikot at nag-i-scale ang mga character kasama nito. Mas maraming detalye ang napapanatili ng mas maliliit na laki.
  • Pinipili ng Mga character ang set: Detalyado, Simple, Mga block, Binary, o Custom, kung saan tina-type mo ang sarili mong mga character.
  • Pinananatili ng Kulay ang sariling mga kulay ng larawan (Orihinal) o iginuguhit ang bawat character sa iisang Kulay ng teksto. Ang Background ay Wala, kaya nakikita ang layer sa pagitan ng mga character, o isang Kulay ng background.
  • Binabago ng Kontrast, Liwanag at I-invert kung aling character ang nakukuha ng bawat bahagi. Gumuguhit ang Mga linya ng gilid ng mga outline gamit ang mga character na |, -, / at \.

Ang mga preset ay Terminal, Ulan ng Binary, Amber Monitor, Diyaryo, Mga block at Line Art.
