Pinaiikot ang layer pabalik-balik sa pagitan ng dalawang anggulo.

Ang Swing ay pinapagpag ang isang layer pabalik-balik sa pagitan ng Angle 1 at Angle 2, Frequency beses kada segundo. Gamitin ang Wave para piliin ang Sine (makinis) o Triangle (tuloy-tuloy ang bilis), at ang Phase para i-offset ang mga layer sa isa't isa.
