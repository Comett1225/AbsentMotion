Teksto sa Path

Teksto · Idinagdag sa bersyon 4.2.0

Inilalagay ang teksto sa kahabaan ng arko, bilog, o outline ng layer na nasa ilalim mismo nito, titik por titik, habang napapanatili ang hugis ng mga titik, font, at emoji ng teksto.

Piliin ang Path: isang arko o bilog sa paligid ng text layer (i-drag ang mga punto nito sa canvas o i-type ang mga ito), o Layer sa Ilalim para sundan ang nasa mismong ilalim ng teksto sa listahan ng layer: isang pen path, isang hugis, ang mga stroke ng isang drawing o ang mga letra ng ibang teksto. Sa bilog o anumang saradong outline, inilalagay ng Posisyon na 50 % ang teksto sa gitna sa itaas, binabasa mula kaliwa pakanan, at nasa ibaba ang 0 %; kapag naka-on ang Baligtarin ang Path, inilalagay ng 0 % ang teksto sa ibaba, binabasa pa rin mula kaliwa pakanan. Sinusundan nang isa-isa ang mga bahagi ng path na may ilang bahagi. Hindi nagwa-wrap ang teksto sa path ayon sa text box nito: ikaw mismo ang magsimula ng bagong linya para sa ikalawang hanay.
