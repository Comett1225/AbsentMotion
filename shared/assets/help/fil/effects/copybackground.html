Kopyahin ang Background

Iba pa · Idinagdag sa bersyon 2.1.0 o mas nauna

Dati itong tinatawag na Adjustment layer. Isang adjustment layer: kinokopya ang iginuguhit sa ilalim ng layer para ang mga epektong kasunod nito ang magbago sa kopyang iyon. Nililimitahan ng Mask sa layer ang kopya sa mga opaque na bahagi ng layer. Ibinabalik ng Halo ang fill ng layer. Pinapayagan ng Umaabot sa labas ang mga epekto ang mga susunod na epekto, gaya ng Stretch, na dalhin ang kopya lampas sa gilid ng layer.

Ginagawang adjustment layer ng Kopyahin ang Background ang isang layer. Kinokopya nito ang lahat ng iginuhit sa ilalim ng layer, kaya binabago ng mga epektong inilagay pagkatapos nito ang lahat ng layer na iyon nang sabay. Ilagay ang layer sa itaas ng mga layer na gustong baguhin, idagdag ang epektong ito, pagkatapos ay magdagdag ng mga epektong tulad ng Hue & Saturation o Blur pagkatapos nito. Nililimitahan ng Mask sa layer ang pagbabago sa sariling hugis ng layer, na nagbibigay-daan upang i-blur o kulayan lamang ang isang bahagi ng larawan. Ibinabalik ng Halo ang sariling fill ng layer. Hinahayaan ng Umaabot sa labas ang mga epekto ang mga susunod na epekto, tulad ng Stretch, na dalhin ang kopya lampas sa mga gilid ng layer. Dating tinatawag na Adjustment Layer ang epektong ito.
