Chroma key

Key · Idinagdag sa bersyon 2.1.0 o mas nauna

Tinatanggal ang isang kulay, tulad ng green screen.

Ginagawang transparent ng Chroma key ang isang kulay, halimbawa ang green screen. Piliin ang kulay gamit ang Kulay ng key (berde bilang default). Ang Toleransya ay kung gaano kalawak ang hanay ng mga kulay sa paligid nito na tinatanggal, at ang Kalambutan ay kung gaano kalambot ang gilid ng cut-out.

  1. Ilagay ang clip na kini-key sa itaas ng background na gusto mong ipakita.
  2. Magdagdag ng Chroma key at itakda ang Kulay ng key sa kulay ng screen.
  3. Taasan ang Toleransya hanggang mawala ang screen. Kung nagsisimulang mawala ang ilang bahagi ng tao, ibaba ito ulit.
  4. Linisin ang gilid gamit ang Kalambutan, Feather o Matte Choker.

Ilawan nang pantay ang screen kapag nagfi-film ka: ang patag at maliwanag na kulay ang nagbibigay ng pinakamalinis na resulta.
