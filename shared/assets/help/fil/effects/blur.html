Pag-blur

Blur · Idinagdag sa bersyon 2.1.0 o mas nauna

Makinis at pantay na pag-blur.

Ang Strength ay ang laki ng blur: 0 ay matalas, at mas mataas na numero ay mas pinapalambot ang layer. Gumagana ito sa mga larawan, bidyo, hugis, teksto at grupo.

  • I-animate ang Strength mula sa mataas na numero pababa sa 0 para maging malinaw ang isang titulo o larawan.
  • Para i-blur ang lahat ng nasa likod ng isang layer, magdagdag muna ng Adjustment Layer at Blur pagkatapos nito.
  • Para mag-blur kasabay ng paggalaw, gamitin ang Motion Blur. Para manatiling matalas ang outline, gamitin ang Inner Blur.
