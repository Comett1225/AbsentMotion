Pag-blur

Blur · Idinagdag sa bersyon 2.1.0 o mas nauna

Makinis at pantay na pag-blur. Kapag Kahon ang Hugis, ina-average naman ang pantay na parisukat sa paligid ng bawat punto.

Ang Lakas ay ang laki ng blur: matalas ang 0, at lalong pinalalambot ng mas mataas na numero ang layer. Gumagana ito sa mga larawan, bidyo, hugis, teksto at grupo.

  • I-animate ang Lakas mula sa mataas na numero pababa sa 0 para luminaw ang isang pamagat o larawan.
  • Para i-blur ang lahat ng nasa likod ng isang layer, magdagdag muna ng Kopyahin ang Background at Pag-blur pagkatapos nito.
  • Para mag-blur kasabay ng paggalaw, gamitin ang Motion blur. Para manatiling matalas ang outline, gamitin ang Blur sa loob.
