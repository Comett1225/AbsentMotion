Mga tema

Gumawa ng sarili mong tema sa app o bilang file, ibahagi ito, at alamin kung ano ang binabago ng bawat kulay.

Binabago ng tema ang kulay ng buong app, kasama ang editor, timeline, home screen at mga menu. Puwede kang pumili ng kasamang tema, gumawa ng sarili sa app, o mag-load ng file ng tema na ibinahagi ng iba.

Pumili ng tema

Buksan ang Mga setting at gamitin ang Piliin ang iyong tema para pumili ng Default ng system, Maliwanag, Madilim, Daylight, Maliwanag na berde o Pasadya (sarili mong tema kapag nakagawa ka na). Ang Kulay ng tema sa ibaba nito ay para lang sa kulay ng accent ng tema. Tingnan ang Mga setting.

Gumawa ng tema sa app

Buksan ang Mga setting, i-tap ang Piliin ang iyong tema at piliin ang Gumawa ng tema…. Nakapangkat sa page ang lahat ng kulay ng tema, kasama ang code ng kulay at maikling paliwanag kung saan ito lumalabas.

  • Mag-import ng file ng tema… sa itaas ay naglo-load ng file ng tema sa page, halimbawa ang ibinahagi ng iba, para mabago mo ito bago i-save.
  • Kinukuha ng Magsimula sa ang lahat ng kulay mula sa kasamang tema o sa pasadya mong tema. Baguhin lang ang mga kulay na gusto mo.
  • I-tap ang isang kulay para buksan ang color picker. Agad nakikita ang pagbabago sa buong app, kaya makikita mo ang kulay kung saan talaga ito ginagamit.
  • Bigyan ng Pangalan ang tema, saka i-tap ang I-save ang tema. Magiging tema mo itong Pasadya at agad itong ilalapat. Sa pag-save, babalik ang Kulay ng tema sa Default para lumabas ang sariling accent ng tema.
  • Sine-save ng I-export ang tema bilang .json file na puwede mong ibahagi o itago.
  • Kapag isinara mo ang page nang hindi nagse-save, babalik ang dati mong tema.

Iisang pasadyang tema lang ang naka-save. Papalitan ito kapag nag-save o nag-import ka ng bago.

Gumawa ng file ng tema

Ang file ng tema ay maliit na text file na nasa format na JSON at naglilista ng mga kulay na gusto mong baguhin. I-save ang halimbawang ito bilang mint.json:

{
  "name": "Mint",
  "Accent": "#5BD6A4",
  "HomeAccent": "#1B7A4A"
}

I-load ito gamit ang Mga setting > Piliin ang iyong tema > Mag-import ng file ng tema…. Pareho pa rin ang hitsura ng app, pero mint green na ang accent.

  • Plain text ang file, nasa format na JSON, may hulaping .json at naka-encode sa UTF-8. Hanggang 64 KB ang laki nito.
  • Opsyonal ang name at hanggang 40 character lang ang ititira.
  • Sa bawat iba pang linya, isulat ang pangalan ng kulay mula sa mga talahanayan sa ibaba, kasunod ang tutuldok at ang kulay na nakapanipi. Kopyahin ang mga pangalan ayon sa nakasulat sa talahanayan, pati ang malalaking titik. Lagyan ng kuwit sa dulo ang bawat linya maliban sa huli.
  • Isulat ang mga kulay bilang "#RRGGBB" (pula, berde, asul) o "#AARRGGBB" (nauuna ang alpha). Hindi tinatanggap ang #RGB.
  • Ipinapakita ng Alpha kung gaano ka-opaque ang kulay. Ang FF ay ganap na opaque, ang 80 ay kalahating transparent, at ang 00 ay hindi nakikita. Karamihan ng kulay ay dapat opaque. Para ang alpha sa mga sapin at highlight kapag pinipindot: Scrim, MenuScrim, PressEditor at PressHome.
  • Mananatili sa hitsura ng AbsentMotion ang mga kulay na hindi mo nilista. Kung itatakda mo ang Gold pero iiwan ang Favorite, gagamitin ng bituin ng paborito ang kulay ng Gold. Sinusundan din ng SelectionBorder at SelectionHandle ang Accent at OnDark sa parehong paraan.
  • Nilalaktawan ang mga pangalang wala sa talahanayan. Kailangang may kahit isang kulay sa file. Kapag mali ang pagkakasulat ng kulay, tatanggihan ng app ang file at tutukuyin ang kulay.

Mga tip

  • Magkahiwalay ang mga kulay ng editor at home screen. Madilim ang editor at maliwanag ang home screen sa hitsura ng AbsentMotion. Puwede mong gawing maliwanag o madilim ang bawat isa.
  • Tiyaking madaling basahin ang teksto. Dapat litaw sa background ang mga kulay ng teksto (OnDark, HomeInk at ang iba pang nagsisimula sa On).
  • Sa iilang lugar lang lumalabas ang ilang kulay, gaya ng keypad, preview ng export o naka-on na switch. Buksan ang mga bahaging iyon habang nag-e-edit para masuri ang mga kulay.
  • Para ibahagi ang tema, i-export ito mula sa Gumawa ng tema… at ipadala ang .json file. Puwede itong i-load ng tatanggap gamit ang Mag-import ng file ng tema….

Lahat ng kulay

Nakapangkat ang mga kulay. Nasa pangalawang column ang mga pangunahing lugar kung saan lumalabas ang bawat kulay. May ilang ginagamit din sa ibang bahagi ng app.

Editor

PangalanSaan ito lumalabas
TopBarPangunahing background ng editor, kasama ang top bar at page sa likod ng mga panel. Ginagamit din sa mga full-screen na tool gaya ng mga preset.
PreviewBgLugar sa likod ng preview ng video, loob ng madidilim na kahon sa mga panel (mga slider at picker), at bakanteng espasyo sa dulo ng timeline.
TimelineBgBackground ng timeline at ng playback bar sa ilalim ng preview, pati ang row sa likod ng mga tab ng layer.
PanelMga panel sa ibaba at panel ng tool (boses, mga kapsyon, pag-stretch), media library sa computer, at mga level meter.
PanelInsetMga kahon sa panel, gaya ng tile sa library ng mga elemento, font browser, karaniwang kulay ng mga number key at mga opsyong hindi napili.
ButtonMga button at tile sa editor, row ng mga effect, at linya sa pagitan ng mga pangalan ng layer at mga bar sa timeline.
FieldMga dialog, text field, row ng listahan at background ng menu sa editor.
FieldHiMga napili o nakaangat na item, gaya ng napiling tab sa isang selector, bakanteng track ng mga slider, gilid ng mga dialog na pangkaligtasan ng proyekto, at ilang button sa home screen ng computer.
ChosenBackground ng graph sa panel ng Easing, napiling item sa Frame at Anino, at madilim na dulo ng preview ng gradient.
WellMadidilim na kahon, gaya ng mga tile sa tab na Media at Audio, track ng mga slider at switch (gaya sa Blending), at key na Tapos sa keypad.
DeepestPinakamadidilim na bahagi, gaya ng linya sa ilalim ng top bar, grid sa color picker, background ng mga level meter at strip sa itaas ng text editor.
LineManinipis na linya, gaya ng mga marka at gilid ng header ng timeline, linya ng mga listahan sa menu, at border ng tutorial card at font browser.
MenuLineMga linyang naghihiwalay sa mga item sa menu ng editor at sa menu ng panel ng Easing.
PressEditorHighlight kapag pinipindot o tinatapatan ng pointer sa editor sa computer.

PangalanSaan ito lumalabas
LayerBarBar ng karaniwang layer sa timeline, gaya ng video, larawan o hugis.
LayerBarStripeMga guhit na nakapatong sa bar ng layer.
TextBarBar ng text layer sa timeline.
TextBarStripeMga guhit na nakapatong sa bar ng text layer.
AudioBarBar ng audio layer sa timeline.

SelectionBorderAng border sa paligid ng napiling clip sa timeline sa computer. Kung hindi mo ito isasama, susundan nito ang Accent.
SelectionHandleAng mga hawakan sa pag-trim sa magkabilang dulo ng napiling clip sa timeline sa computer. Kung hindi mo isasama, susundan nila ang OnDark.

PangalanSaan ito lumalabas
KeyDigitMga key mula 0 hanggang 9 sa keypad ng mga tool ng layer.
KeySymbolMga key ng sign, decimal point at backspace sa parehong keypad.
CoolAsul na label sa key ng keypad, at outline ng papasok na bahagi sa mga panel ng galaw.
CoolDeepBackground sa likod ng napiling numero sa isang key ng keypad.
ScrimMadidilim na kahon sa likod ng preview ng mga tool sa home screen (saklaw, pag-compress, tool kit), preview ng export at screen ng natapos na export, at mga thumbnail sa Komunidad na walang larawan.
OnScrimTeksto at mga icon sa ibabaw ng Scrim, gaya ng mga button sa preview ng export, bilang ng page, play button at pansamantalang icon sa mga item sa Komunidad.

Accent

PangalanSaan ito lumalabas
AccentPangunahing kulay ng mga napiling item, aktibong slider, button ng pag-export sa top bar ng editor, snap line at seleksyon sa timeline, marker ng playback at mga pangunahing button. Lumalabas ito sa maraming lugar.
AccentLitMas matingkad na accent sa mga slider ng volume at blending, hawakan ng mga switch sa editor at icon ng folder sa editor sa computer.
AccentGlowMaliwanag na accent bilang highlight sa loob ng mga panel, gaya ng border at label ng aktibong key ng keypad.
AccentDeepMadilim na accent sa track ng naka-on na switch sa editor, mga hawakan sa preview, at singsing sa paligid ng napiling kulay.
OnAccentTeksto at mga icon sa ibabaw ng accent, gaya ng icon ng pag-export, mga button na may accent at mga napiling chip.
WarningMga babala at error, gaya ng lumang preview, nawawalang file, mga limitasyong nilalampasan ng clip, at button para mag-delete o gumawa ng mapanganib na aksyon sa mga dialog na pangkaligtasan ng proyekto.
FavoriteMay kulay na bituin ng paborito sa text editor at browser ng mga effect.

OnDarkDimMas mapusyaw na teksto at icon, gaya ng bilang, hint, mensahe kapag walang laman ang listahan at maliliit na icon sa editor sa computer.
CaptionMaliliit na teksto ng tulong at arrow sa mga panel, at mga gabay na linya sa editor ng mga point.
FaintMapupusyaw na icon at linya, gaya ng mga hindi napiling icon sa editor ng mga point, icon ng Blending at Frame at Anino, mga marka sa scale, at color picker kapag hindi ginagamit.
InactiveMga nakapatay o hindi aktibong item, gaya ng marka at hawakan sa ruler ng timeline, track ng naka-off na switch, at mga kahon ng Link at Kamera sa mga panel ng paggalaw.

HomeMidPangalawang teksto at mga icon sa home screen, gaya ng linya ng bersyon, mga arrow, hawakan at label.
HomeDimTeksto sa ikatlong antas sa home screen, gaya ng teksto ng tulong, mga paglalarawan ng tool at maliliit na palaso.
HomeFaintPinakamapupusyaw na bahagi ng home screen, gaya ng mga tuldok ng mga hindi napiling page at icon ng link sa panel ng Bagong proyekto.

MenuScrimSapin na nagpapadilim sa home screen kapag bukas ang menu sa telepono o tablet.
