Ang home screen

Ang iyong mga proyekto, asset at template, ang mga tool sa tab na Mga tool (I-compress, I-trim, I-extract ang audio, Gumawa ng GIF at Downloader ng bidyo) at ang mga button sa paligid ng mga ito.

Sa pahinang ito
  • Ang top bar
  • Ang bottom bar
  • Projects at Assets
  • Search
  • Pag-sort
  • Templates
  • Mga tool
  • Pag-import ng project file
  • Kapag may mali

Ang home screen ang unang makikita mo pagkatapos ng unang pag-start. Inililista nito ang iyong mga proyekto at may mga button para sa paggawa ng bago, paghahanap at pagbabago ng mga setting. Sa isang tablet na sapat ang lapad ng screen, nagiging malapad na header ang itaas na bar at ipinapakita bilang grid ang mga proyekto at template, sa portrait at sa landscape.

Ang top bar

  • Menu button (sa taas kaliwa, tatlong linya). Binubuksan ang Settings drawer.
  • AbsentMotion sa gitna.
  • Search (ang magnifier sa kanan). Binubuksan ang isang search field. Habang naghahanap, ipinapakita sa parehong lugar ang isang X para isara ito, at isinasara rin ito ng Back button.

Ang bottom bar

  • Ang Mga proyekto, Mga template at Mga tool ang nagpapalit sa tatlong pahina ng home screen.
  • Ang bilog na + button sa pagitan ng mga ito ay gumagawa ng bagong proyekto: tingnan ang Paggawa ng proyekto.

Projects at Assets

Ang Projects page ay may dalawang chip sa taas, Projects at Assets.

  • Ang Projects ay ang iyong mga bidyo at animation. I-tap ang isang card para buksan ito sa editor.
  • Ang Assets ay mga magagamit muli na bahagi na na-save mo mula sa isang proyekto o ginawa gamit ang ASSET option ng new project sheet. Idinaragdag mo ang mga ito sa ibang mga proyekto mula sa editor. Tingnan ang Assets, templates at presets.

Ang isang proyekto at isang asset ay iniimbak sa parehong paraan; magkahiwalay lamang silang naililista.

Ano ang ipinapakita ng isang card

Bawat card ay may thumbnail na may tagal ng proyekto sa sulok, ang pangalan, at dalawang linya ng mga detalye: ang aspect ratio (tulad ng 16:9) at ang resolusyon (tulad ng 1080p), pagkatapos ang file size at ang frame rate. Ang file size ay ang laki ng mismong project file. Hindi kasama dito ang mga larawan, bidyo at audio na ginagamit ng proyekto, kaya ang isang proyektong may oras-oras na bidyo ay maaaring magpakita pa rin ng ilang kilobyte.

Ang thumbnail ay isang still na kinuha kapag isinara mo ang editor, sa lugar kung saan naroon ang playhead. Ang isang proyektong hindi mo pa nabuksan sa editor ay maaaring magpakita ng walang laman na thumbnail.

Ang card menu

Ang three-dot button sa isang card (pinangalanang More) ay may mga entry na ito.

  • Ang Export ay direktang binubuksan ang export screen mula sa listahan. Ang mga "Current Frame" na opsyon ay gumagamit ng unang frame. Ito rin ang tanging lugar na nag-aalok ng XML export. Tingnan ang Export.
  • Ang Duplicate (Duplicate Asset para sa isang asset) ay gumagawa ng kopya na pinangalanang "name Copy", kasama ang media nito.
  • Ang Collect media into project ay kinokopya ang bawat file na ginagamit ng proyekto mula sa labas ng sarili nitong folder papunta sa proyekto, para hindi na ito umaasa sa iyong gallery. Tingnan ang Projects, backup at import.
  • Ang Version history ay nagpapakita ng mga naunang version ng proyekto at hinahayaan kang bumalik sa isa sa mga ito.
  • Ang Delete (Delete Asset) ay humihingi ng kumpirmasyon at pagkatapos ay tinatanggal ang proyekto, ang mga version nito at ang mga kopya ng media na walang ibang gumagamit. Walang trash: ang isang na-delete na proyekto ay hindi na maibabalik, kaya gumawa muna ng backup kung hindi ka sigurado.

Ang isang proyektong nasira ang file ay nagpapakita ng Damaged — restore a version sa halip na ang mga detalye nito. I-tap ito para i-restore ang isang naunang version, o i-delete ito.

Search

Isang search box ang nagsisilbi sa buong home screen. Sa Projects page, hinahanap nito ang mga pangalan ng proyekto at asset ("Search projects and assets"); sa Templates page, hinahanap nito ang mga template at preset. Hindi nito pinapansin ang malalaki at maliliit na letra at mga accent, at ang bawat salitang iyong itina-type ay dapat lumitaw sa pangalan, sa anumang pagkakasunod-sunod.

Pag-sort

Sa Projects at Assets na listahan, ipinapakita ng header ang Sort by Date o Sort by Name. I-tap ito para magpalit. Ang Date ay inilalagay ang pinakabago sa unahan, na nakagrupo sa ilalim ng mga date heading. Ang Name ay nagso-sort mula A hanggang Z. Tandaan ng app ang iyong pinili.

Templates

Ang Templates page ay may dalawang chip, My Templates at My Presets. Inilalarawan ang mga ito sa Assets, templates at presets.

Mga tool

Ang page na Mga tool ay may limang card na gumagana sa mga file, sa labas ng anumang proyekto: I-compress, I-trim, I-extract ang audio, Gumawa ng GIF at Downloader ng bidyo. I-tap ang isang card para buksan ito. Sa isang tablet, magkakatabi ang mga card, at bumubukas nang full screen ang isang tool; kapag nakahiga ang tablet, nasa pangalawang column sa tabi ng file ang mga setting nito.

I-compress

Gumagawa ang I-compress ng mas maliit na kopya ng isang bidyo o larawan, halimbawa para ipadala sa chat. Hindi kailanman nababago ang orihinal mo.

  1. I-tap ang Pumili ng bidyo o larawan at piliin ang file sa photo picker. Pumipili ng iba ang Palitan.
  2. Sa ilalim ng Gaano kaliit? piliin ang Mababa (malinaw na mas maliit, halos pareho pa rin ang hitsura), Katamtaman (ang default: sapat na liit para sa mga chat at social app), Mataas (pinakamaliit na posible pero maayos pa rin ang hitsura), Discord o Custom. Kasya ang Discord sa limit ng pag-upload ng Discord at itatanong kung alin: Libre (20 MB), Nitro Basic (50 MB) o Nitro (1 GB).
  3. Ipinapakita ng linya sa ibabaw ng button ang inaasahang laki, halimbawa "Mga 12 MB (ngayon 80 MB)". Sinasabi rin nito kapag maliit na ang file o masyadong mahaba para magkasya sa limit ng laki.
  4. I-tap ang I-compress. Ipinapakita ng bar ang progress at itinitigil ito ng Kanselahin. Nananatiling bukas ang screen habang gumagana ito.

Hinahayaan kang pumili ng lahat ang Custom:

SettingMga pagpipilian
LakiBidyo: Orihinal, 1080p, 720p o 480p. Larawan: Orihinal, 2048, 1280 o 800 px
KalidadPinakamahusay, Maganda, Maliit o Pinakamaliit; o Mag-target ng laki ng file, tapos i-type ang laki sa MB
Frame rateBidyo lang: Orihinal, 60, 30 o 24
TunogBidyo lang: Naka-off, Maliit, Maganda o Pinakamahusay
FormatLarawan lang: JPEG o WebP

Kapag tapos na, ipinapakita ng linya sa ibabaw ng mga button ang luma at bagong laki at kung gaano lumiit ang file, halimbawa "17MB → 5.5MB (66% mas maliit)". Kung hindi lumiit, sasabihin nito iyon at imumungkahing panatilihin ang orihinal mo. Sa ilalim ng Resulta, ang mga chip na Pagkatapos at Bago ay nagpapalit ng preview sa pagitan ng bagong file at ng orihinal, at ang button sa kanang itaas ng preview ay nagbubukas ng Buong screen na view na may parehong dalawang chip. I-tap ang I-save sa gallery para itago ang bagong file (ang mga bidyo ay napupunta sa Movies/AbsentMotion, ang mga larawan sa Pictures/AbsentMotion) o I-share para ipadala ito sa ibang app.

I-trim

Pinananatili ng I-trim ang bahagi ng bidyo na pipiliin mo at sine-save ito bilang bagong MP4 na bidyo. Hindi kailanman nababago ang orihinal mo.

  1. I-tap ang Pumili ng bidyo.
  2. Sa ilalim ng Bahaging itatabi, i-drag ang dalawang dulo sa strip ng mga larawan. Ipinapakita ng malaking larawan sa itaas ang frame sa dulong inililipat mo. May mga arrow ang Simula at Wakas na naglilipat sa dulong iyon nang bahagyang mas maaga o mas huli, at ipinapakita ng Tagal kung gaano katagal ang bahagi.
  3. Sa ilalim ng Paano? piliin ang Mabilis (ang default: walang re-encoding, kaya mabilis ito at napapanatili ang kalidad; kumakapit ang simula sa pinakamalapit na cut point ng bidyo) o Eksakto (eksaktong pumuputol kung saan mo pipiliin, pero mas matagal). Sa Mabilis, tumatalon ang mga arrow ng Simula mula sa isang cut point papunta sa susunod.
  4. Ipinapakita ng linya sa itaas ng button ang inaasahang laki. I-tap ang I-trim.

Kung halos walang cut point ang isang bidyo, sa simula lang makakapagsimula ang Mabilis, at sinasabi ito ng screen: piliin ang Eksakto para magsimula kahit saan.

I-extract ang audio

Sine-save ng I-extract ang audio ang tunog ng isang bidyo bilang audio file.

  1. I-tap ang Pumili ng bidyo. Kapag walang tunog ang bidyo, sinasabi nitong "Walang tunog ang bidyong ito."
  2. Format: M4A (ang default) o MP3.
  3. Kalidad: Maliit, Maganda o Pinakamahusay. Para sa M4A, mayroon ding Orihinal, na kinokopya ang tunog nang buo, walang nawawala, kapag pinapayagan ito ng tunog ng bidyo. Ang app na ang pipili nito para sa iyo.
  4. Ipinapakita ng linya sa itaas ng button ang inaasahang laki at tagal. I-tap ang I-extract.

Para kunin ang tunog ng isang bidyo sa loob ng isang proyekto, gamitin ang I-extract ang audio sa layer menu: tingnan ang Audio.

Gumawa ng GIF

Ginagawang animated na GIF ng Gumawa ng GIF ang bahagi ng isang bidyo.

  1. I-tap ang Pumili ng bidyo.
  2. Sa ilalim ng Bahaging itatabi, piliin ang bahagi tulad ng sa I-trim. Hanggang 30 segundo ang haba ng isang GIF.
  3. Ang Laki ay ang mahabang gilid ng GIF: 320, 480 (ang default) o 720 px. Frame rate: 10, 15 (ang default) o 24. Loop: Walang hanggan (ang default) o Isang beses.
  4. Ipinapakita ng linya sa itaas ng button ang inaasahang laki at ang bilang ng mga frame, na sinusukat sa ilang sample frame. Kung lalampas sa 25 MB ang GIF, sinasabi nitong "Malaki ang magiging GIF na ito. Subukan ang mas maliit na size o mas maikling bahagi." I-tap ang Gumawa ng GIF.

Ang resulta ng I-trim, I-extract ang audio at Gumawa ng GIF

Ipinapakita ng isang bar ang progreso, at pinahihinto ito ng Kanselahin. Kapag tapos na, ipinapakita ng linya sa itaas ng mga button ang laki ng bagong file, at ipinapakita ito ng Resulta (ipinapakita ng tunog ang pangalan nito). I-tap ang I-save para itago ito, o ang I-share para ipadala ito sa ibang app. Ang mga bidyo ay napupunta sa Movies/AbsentMotion, ang mga GIF sa Pictures/AbsentMotion at ang mga tunog sa Music/AbsentMotion. Kapag may nagkamali, sinasabi ng linya kung ano ang nangyari, halimbawa "Masyadong malaki ito para sa phone na ito. Subukan ang mas maliit na size o mas maikling bahagi."

Downloader ng bidyo

Sine-save ng Downloader ng bidyo ang isang bidyo mula sa link papunta sa phone mo. Kailangan nito ng libreng add-on, isang beses na download na ipinapakita ng screen ang laki (mga 25 MB). Dala ng add-on ang mga open source na tool na Python at yt-dlp, at puwede mo itong alisin muli sa Mga Setting gamit ang Burahin ang add-on para sa pag-download ng bidyo. Gumagana ito sa mga phone na may 64-bit na processor.

  1. Sa unang beses, i-tap ang Kunin ang add-on sa card na may nakasulat na "Kailangan ng add-on ang download".
  2. Kopyahin ang link ng isang bidyo sa ibang app, tapos i-tap ang I-paste (o i-type ang link sa field; nililinis ito ng X). Sinusuri ng app ang link at ipinapakita ang pamagat nito, isang maliit na larawan at kung ano ito, halimbawa "YouTube · Bidyo · 10:35".
  3. Sa ilalim ng Ano ang ise-save piliin ang Bidyo at audio, Bidyo lang o Audio lang.
  4. Sa ilalim ng Kalidad pumili ng isa sa mga kalidad na meron ang bidyo. Ipinapakita ng bawat isa ang laki nito, halimbawa "1080p60 · mga 255MB". Walang pipiliin sa isang post na larawan lang ang laman: sine-save ang mga larawan nang kung ano sila.
  5. I-tap ang I-download. Kapag tapos na, sinasabi ng mensahe kung nasaan ang file, halimbawa "Na-save sa Movies/AbsentMotion", at may lalabas na dalawang button: ang Bagong proyekto ay nagbubukas ng bagong proyekto na may bidyo, at ang I-compress ay nagbubukas ng Compress tool kasama ang file.

Sa ibaba ng button, inililista ng Sinusuportahan ang mga site na gumagana, at ng Bahagyang sinusuportahan ang mga gumagana na may limitasyon. I-tap ang isang pangalan doon para basahin ang limitasyon, halimbawa na ang mga story ng Instagram at pribadong post ay nangangailangan ng naka-sign in na account, kaya hindi ma-download ang mga ito. Ipinapakita ng link na hindi ma-download ang dahilan: pribado o inalis na bidyo, post na nangangailangan ng naka-sign in na account, playlist, site na humarang sa download o walang koneksyon.

Mag-download lang ng may karapatan kang gamitin: inuulit ito ng screen sa ilalim ng button.

Wala pa sa bersyon para sa computer ang Downloader ng bidyo, ni sa mga Intel o AMD file para sa mga Chromebook.

Pag-import ng project file

Bilang default, ang home screen ay walang import button. Maaari mong buksan ang isang project file mula sa ibang app (isang file manager, isang mensahe) gamit ang Share o Open with, at tatanggapin ito ng app. Kung mas gusto mo ng button, i-on ang Show the import card in the project list sa Settings; may card na may Choose file na lilitaw sa taas ng Projects list. Tingnan ang Projects, backup at import.

Kapag may mali

  • Kung biglang nagsara ang app, ipapakita ng susunod na pag-start ang AbsentMotion closed unexpectedly kasama ang dahilan at, kung may mga hindi na-save na edit, isang alok na i-restore ang mga ito.
  • Ang mga crash log ay nasa Settings sa ilalim ng Crash logs.
  • Para sa isang lumang version, maaaring sabihan ka ng app tungkol sa mas bagong version: tingnan ang Settings.
