Privacy at lisensya

Ano ang iniimbak ng app, ano ang ipinapadala nito, at ang lisensyang ginagamit nito.

Hindi nangongolekta, nag-iimbak o nagbabahagi ang AbsentMotion ng personal na data. Walang account, walang advertising, walang analytics at walang tracking. Ang pahinang ito ay nagbubuod ng privacy policy; ang buong teksto ay nasa file na PRIVACY.md ng source code.

Ang iyong mga proyekto at media

Ang mga proyekto, na-import na larawan, bidyo at audio, at lahat ng ini-export mo ay nananatili sa iyong telepono. Ang mga pahintulot sa photo, video at audio ay nagbibigay-daan sa app na ipakita ang iyong library at gamitin ang mga file na pinili mo, sa telepono. Walang ina-upload.

Ang mga pahintulot sa kamera at mikropono ay ginagamit lamang ng in-app na kamera, habang bukas ito. Ang mga recording ay naka-save sa telepono. Ang mga backup ay isinusulat sa Documents/AbsentMotion sa telepono at nananatili doon.

Habang tumatakbo ang isang export, ipinapakita ng app ang progreso nito sa isang notification, para magpatuloy ang export kapag lumipat ka sa ibang app. Sa Android 13 at mas bago, hinihiling nito ang pahintulot sa notification sa unang export; gumagana pa rin ang mga export nang pareho kung tumanggi ka.

Kung biglang magsara ang app, nagtatala ito ng crash log sa sarili nitong storage: kung kailan nangyari, ang dahilan sa isang pangungusap, ang mga bersyon ng app at Android, ang modelo ng telepono, ang ginagawa mo at ang teknikal na error. Ang huling 20 lang ang itinatabi, hindi sila kasama sa mga backup ng telepono at hindi sila kailanman ipinapadala kahit saan. Mababasa, makokopya o mabubura mo sila sa Mga setting.

Kailan gumagamit ng internet ang app

Hinihiling ng app ang pahintulot sa internet para sa mga bagay na ito lamang:

  • Mga font. Kapag pumili ka ng isa sa mga nada-download na font, dina-download ito ng app mula sa Google Fonts. Natatanggap ng Google ang kahilingan para sa font na iyon at ang iyong IP address, tulad ng anumang web request. Kapag naghanap ka ng font, minsan sa isang linggo nilo-load ang listahan ng mga pamilya ng Google Fonts mula sa fonts.google.com; ang paghahanap mismo ay tumatakbo sa device mo at walang ipinapadala sa anumang tina-type mo.
  • Awtomatikong kapsyon. Sa unang pagkakataong bumuo ka ng mga kapsyon, sinasabi ng app sa iyo ang laki ng speech model (mga 57 MB, o mga 82 MB para sa Mas mataas na precision) at dina-download ito mula sa Hugging Face. Tumatakbo sa telepono ang pagkilala sa pagsasalita.
  • Pag-alis ng background. Sa unang pagkakataong mag-alis ka ng background, dina-download ng app ang model nito nang isang beses (mga 3 MB) mula sa GitHub. Sa telepono mismo ginagawa ang cut-out.
  • AI Enhance at AI Smooth. Sa unang pagkakataong gamitin mo ang isa sa mga ito, sinasabi ng app sa iyo ang laki ng model na kailangan nito (mga 1 hanggang 11 MB) at dina-download ito mula sa GitHub. Tumatakbo sa telepono ang AI work mismo.
  • AI pagtanggal ng background 2.0. Tanging kapag pinili mo ang AI pagtanggal ng background 2.0 para sa pag-alis ng background, dina-download ng app ang model nito nang isang beses (mga 62 MB) mula sa GitHub. Tumatakbo sa telepono ang cut-out mismo.
  • Downloader ng bidyo. Tanging kapag ginamit mo ang Mga tool > Downloader ng bidyo: sa unang pagkakataon, dina-download ng app ang add-on nito (mga 25 MB): Python mula sa python.org at yt-dlp mula sa GitHub (github.com, inihahatid mula sa objects.githubusercontent.com o release-assets.githubusercontent.com). Habang naka-install ang add-on, nagtatanong ito sa GitHub nang hindi hihigit sa isang beses kada araw kung may mas bagong yt-dlp at dina-download ito kung mayroon. Kapag nag-paste ka ng link, kinokontak ng add-on ang website na iyon (halimbawa YouTube, Instagram o TikTok) para basahin ang detalye ng bidyo at i-download ang mga bahaging pipiliin mo, tulad ng gagawin ng web browser; sine-save ang mga file sa device.
  • Pagsuri ng update. Kung papayagan mo ito (isang beses lang magtatanong ang app; ang switch ay nasa Mga setting), tuwing bubukas ito, gumagawa ang app ng isang normal na HTTPS request sa GitHub para basahin ang numero ng pinakabagong bersyon, at binabasa roon ang README ng proyekto para laging napapanahon ang mga link ng Discord at feedback. Wala nang ibang ipinapadala. Nakikita ng GitHub ang iyong IP address, tulad ng anumang web request.

Kapag binuksan ang tab na Komunidad, nilo-load mula sa GitHub ang listahan ng mga shared preset at bundle at ang mga larawan nila, ang larawan ng isang preset ay iginuguhit mula sa file ng preset na iyon, at dina-download ng Idagdag ang piniling item; walang ina-upload. Wala nang ibang ipinapadala kahit saan. Gumagamit ang Teksto sa boses ng mga boses na nasa telepono na, at gumagana ito offline.

Lisensya at source

Ang AbsentMotion ay libre at open source, na inilabas sa ilalim ng GNU General Public License v3.0. Ang source code nito ay nasa pahina ng proyekto sa GitHub. Ang third-party software na ginagamit nito (Skia, whisper.cpp, RNNoise, LAME, AndroidX Compose at iba pa) at ang kanilang mga lisensya ay nakalista sa THIRD_PARTY_NOTICES.md at sa app: Mga setting, Tungkol, Mga lisensya ng open source.

Ang AbsentMotion ay isang independent na proyekto. Hindi ito kaakibat, inendorso o inisponsor ng anumang ibang gumagawa ng app; ang mga pangalan ng ibang produkto ay pag-aari ng kanilang mga may-ari.
