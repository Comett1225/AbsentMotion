# What's new in 5.2.1

The **Community asks before it connects**, downloads **ask before using mobile data**, **layer locking**, **right-click to change shortcuts**, **live keyframes on any property** and a fix for a **crash with 3D models and Scatter Field**.

## New features
- **Layer locking** - a **padlock** beside the eye on every timeline row. **Tap** it to lock a layer so it **can't be selected or changed**, or **hold** it (right-click on a computer) for **Lock timing only**, which keeps the layer editable but stops it **moving or changing length**.
- **Community asks first** - the Community tab **asks before it connects** to the internet and loads nothing until you press **Connect**.
- **Mobile data** - downloads **ask before using mobile data** when you are not on Wi-Fi. Turn the question off in **Settings > Projects and media**.
- **Change shortcuts by right-clicking** - on a computer and in **Samsung DeX**, **right-click** a button or menu item that has a keyboard shortcut to **change**, **remove** or **reset** it. Samsung DeX uses the **same shortcuts** as the computer app, and a shortcut can be left empty.

## Improvements
- **Record keyframes while playing** - press **Play** and drag a layer or change a Transform value: the change is recorded as keyframes **even on a property that has none yet**.

## Bug fixes
- **3D models with Scatter Field** - a **3D model** with **Scatter Field** could **crash the app**. The copies are now drawn from one picture of the model, so memory stays low.
