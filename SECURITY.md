# Security

Report vulnerabilities privately through the repository's Security tab (*Report a vulnerability*). Please do not open a
public issue. Include the app version, the Android version, what you did and what happened.

AbsentMotion is a volunteer project, so there is no guaranteed deadline. Fixes go into the latest release.

Project files and packages can come from anywhere and are treated as untrusted: the importer limits their size and
refuses references to the app's private files.
