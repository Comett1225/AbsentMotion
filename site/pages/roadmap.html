4.2

  • Text Along Path: set text along an arc, a circle or the outline of the layer beneath it.
  • Puppet Pin: bend a layer with up to 32 pins that can be animated.
  • A Pivot tab in Transform, with a marker you can drag on the canvas. Moving the pivot keeps the layer where it is.
  • Transform tabs are now Move, Rotate, Size, Tilt, Skew and Pivot, and the Size ruler keeps gliding after a flick.
  • Width and height can be unlinked per layer, and the choice is saved with the project.
  • Bigger grab areas for the small dots around a picture or video, so they are easier to catch.
  • Updates download inside the app, with a progress bar, a check that the file is genuine and signed by the same key, and automatic retry if the connection drops.
  • An interrupted update download can be continued the next time the app opens, and the update dialog warns on metered connections.
  • A Crop tool for pictures and videos, with draggable edges and ratio presets.
  • The Rotate tab always shows the 360 degree dial, also on tilted layers.
  • The New tag in Effects only marks effects from the last five updates.
  • The Curl effect preview rolls up and back down smoothly.
  • Cut-outs drop faint haze and stray specks away from the subject.
  • Support for devices with 16 KB memory pages, and an emulator test matrix covering many Android versions.

4.3

  • Stronger compatibility with Alight Motion files imported into AbsentMotion.
  • More effects from CapCut.
  • Better image background remover model, with two versions.
  • Other feature requests.

5.0

  • PC support for Windows, Linux, macOS and Chromebook/ChromeOS.
  • Possibly an IPA file for sideloading on iPhones and iPads.
  • During 5.0 and after, there won't be many major patches or features; most updates will focus on stability for the PC version and the new iOS file.
