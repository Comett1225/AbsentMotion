---
title: Will it run on my phone?
kind: checker
site_only: true
summary: Type your phone model to see which version of AbsentMotion it should run.
---
The answer comes from a list of phones kept in this website. It says what should work, not what has been tried on every phone. Phones that are not in the list can still work: the rule is Android 13 or newer for the Latest version, Android 9 to 12 for the Compatible version, always with a 64-bit ARM chip and Vulkan 1.1.

You can find your Android version in Settings, About phone, Android version. The model code (for example SM-G998B) is also in About phone.
