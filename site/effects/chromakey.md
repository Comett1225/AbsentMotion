Chroma Key makes one color transparent, for example a green screen. Pick the color with **Key Color** (green by default). **Tolerance** is how wide a range of colors around it is removed, and **Softness** is how soft the edge of the cut-out is.

1. Put the keyed clip above the background you want to show.
2. Add Chroma Key and set Key Color to the color of the screen.
3. Raise Tolerance until the screen has gone. If parts of the person start to disappear, lower it again.
4. Clean the edge with Softness, [Feather](@effect/feather) or [Matte Choker](@effect/mattechoker).

Light the screen evenly when you film: a flat, well-lit color gives the cleanest result.
