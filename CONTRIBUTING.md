# Contributing to AbsentMotion

## Licence and originality

By submitting a contribution you agree that it is licensed under the Apache License 2.0, and that you wrote it or have the
right to submit it under that licence.

Do not contribute anything taken from another app: its code (decompiled or not), resources, assets, strings, icons, shaders,
data tables or screenshots. What is welcome:

- behaviour you observed by using an app as a black box, described in your own words and tested with your own files;
- public algorithms, cited in the pull request;
- icons from sets whose licence allows redistribution, listed in `docs/ICON_SOURCES.md` and `THIRD_PARTY_NOTICES.md`;
- interface text you wrote yourself.

New third-party code or data needs a compatible licence and an entry in `THIRD_PARTY_NOTICES.md`.

## Building and checking

Setup is in [`docs/BUILD.md`](docs/BUILD.md). Run `tools/check.sh` before a pull request: it compiles both flavours and runs
the unit tests. `tools/release.sh [patch|minor|major]` builds the release APKs.

## Code

- The app is in `app/src/main/kotlin`; flavour-specific files are in `app/src/play` and `app/src/foss` (`foss` must not use Google
  libraries). Panels go in `LayerPanel`, tools in `LayerTools`, layer actions in `editor/...Actions.kt`.
- Kotlin follows the official style. C++ (`app/src/main/cpp`) is C++20 without RTTI, in `namespace am`.
- The source has no code comments; put an explanation in `docs/` or in the pull request.
- Keep the project file format lossless: elements the app does not understand must survive a load and a save.
- Keep dependencies few. Tests use files under `testdata/` that were made with AbsentMotion or generated by a script.

## Pull requests

One change per pull request. Say how you checked it, and include before and after pictures for anything that draws
differently. Commit with a name and address you are happy to see in public: git history is permanent.
Bugs and ideas go in the issue tracker, or the [bug report form](https://forms.gle/6bY8KBPMKc2iUypV6) if you can't or don't want to use GitHub; security problems follow [`SECURITY.md`](SECURITY.md).
