1. ENGINE LIBRARIES
-------------------

AbsentMotion's renderer is C++ on top of Skia. Skia and the libraries it needs are built from source (see docs/BUILD.md) and linked statically into the engine library, libamengine.so. Speech recognition lives in a second library, libwhisper_jni.so, loaded only when captions are generated.

----

- Version: branch chrome/m156, commit 95ee33d7ec7791ab9c071675710a14fe6408ae4f, with one local patch, tools/skia-patches/vulkan-dst-read-copy.patch (a change to the Vulkan back end of Skia's Graphite renderer; it is applied to the checkout by tools/build_skia.sh).
- Licence: BSD-3-Clause (text in appendix A.1).
- Copyright: Copyright (c) 2011 Google Inc. All rights reserved.
- URL: https://skia.org/ and https://skia.googlesource.com/skia

5. FONTS, ICONS AND EFFECT THUMBNAILS
-------------------------------------

Google Fonts
------------

No font file is part of AbsentMotion. When a user picks a font from the font browser, the app downloads that family from Google's font servers (fonts.googleapis.com, fonts.gstatic.com) and stores it on the device. Each family keeps its own licence: the SIL Open Font License 1.1, the Apache License 2.0 or the Ubuntu Font Licence 1.0, as stated for that family at https://fonts.google.com/. Text a user sets in such a font belongs to the user.

Icons
-----

The icon sets used in the user interface, and their licences, are listed in docs/ICON_SOURCES.md.

attribution and endorsement protections to other entities.  Thus, it was
desirable to choose a license that granted us the same protections for new code
that were granted to the IJG for code derived from their software.

Every icon in AbsentMotion is either taken from an open icon set whose licence allows redistribution, or drawn for this project. Nothing is copied or traced from another app. This file is the single list of where each icon comes from; the third-party notices file is generated from it.

- Effect thumbnails are not icons: they are small renders of six CC0 photographs, listed in THIRD_PARTY_NOTICES.md (section 5, "Effect thumbnail photos").

How the Lucide shapes were used: the SVG shapes (path, circle, rect, line) were joined into one path-data string on the same 24 unit grid, written with absolute commands, and tinted and stroked by the app (round caps and joins, 1.2 to 2.5 dp strokes depending on the icon). Where the Notes column says "scaled" or "mirrored" the shape was scaled about the grid centre or flipped left to right; nothing else about the geometry was changed. "Moved" means shifted to sit inside the icon's own viewport (for example a 32 dp speaker). The path strings themselves live in the *Icons.kt files.
