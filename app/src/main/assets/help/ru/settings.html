Нажмите кнопку меню в левом верхнем углу главного экрана, чтобы открыть панель «Настройки». В ней четыре группы, которые изначально свёрнуты (нажмите на группу, чтобы развернуть её), и ещё несколько строк ниже.

Редактор

  • Тема. AbsentMotion (по умолчанию: тёмный редактор и тёплый светлый главный экран), Daylight (светлая везде) или Custom. Импорт файла темы... загружает тему из небольшого файла (см. ниже).
  • Длительность нового слоя. Как долго длятся новые слои: от 1 до 10, 15, 20, 25, 30, 45 или 60 секунд. По умолчанию — 2.
  • Вибрация. Короткие вибрации на таймлайне при привязках, долгих нажатиях и переупорядочивании. Включена по умолчанию.
  • Стиль эмодзи. SYSTEM (эмодзи вашего телефона, по умолчанию) или ANDROID (шрифт эмодзи, входящий в приложение, одинаковый на любом телефоне).

Пользовательские темы

Файл темы — это небольшой текстовый файл в формате JSON размером до 64 КБ с необязательным name и любыми цветами, которые вы хотите изменить, записанными как #RRGGBB или #AARRGGBB. Пропущенные цвета сохраняют вид AbsentMotion. Например:

{"name": "Mint", "Accent": "#5BD6A4", "HomeAccent": "#1B7A4A"}

Названия цветов — это цвета редактора и главного экрана: TopBar, PreviewBg, TimelineBg, Panel, PanelInset, Button, Field, FieldHi, Chosen, Well, Deepest, Line, MenuLine, KeyDigit, KeySymbol, Scrim, PressEditor, OnDark, OnDarkDim, Caption, Faint, Inactive, OnScrim, Accent, AccentLit, AccentGlow, AccentDeep, OnAccent, Cool, CoolDeep, Gold, Warning, Bookmark, LayerBar, LayerBarStripe, TextBar, TextBarStripe, AudioBar, AudioWave, OnBar, OnAudioBar, HomeBg, Card, SheetBg, Navy, HomeAccent, OnNavy, OnNavyAccent, NavyHi, NavyLine, HomeInk, HomeMid, HomeDim, HomeFaint, HomeLine, HomePanel, HomeDrawer, SwitchOff, Thumb, MenuScrim и PressHome. Одновременно хранится только одна пользовательская тема; импорт нового файла заменяет её и сразу применяет.

Воспроизведение и предпросмотр

  • Качество предпросмотра. FULL, HALF или QUARTER (по умолчанию Full): насколько чёткий предпросмотр в редакторе. Более низкое значение работает быстрее на медленном телефоне и не влияет на экспорт. Тот же переключатель есть в полосе предпросмотра редактора.
  • Ресемплинг при воспроизведении. LOW, HIGH или ULTRA (по умолчанию Ultra): качество ресемплирования звука при воспроизведении в редакторе и при микшировании звука для экспорта.
  • Использовать копии предпросмотра для больших видео. Включено по умолчанию. Для видео больше 1920 x 1080 или с малым числом ключевых кадров приложение создаёт в фоне небольшую лёгкую копию и использует её для предпросмотра. При экспорте всегда используется исходный файл. Копии хранятся в кэше размером до 2 ГБ.
  • Очистить копии предпросмотра удаляет их. Строка показывает занимаемое ими место.

Проекты и медиа

  • Показывать карточку импорта в списке проектов. Выключено по умолчанию. Добавляет карточку с Выбрать файл в верхнюю часть списка проектов.
  • Хранить копию импортированных медиа в проекте. Включено по умолчанию. Добавленные фото, видео или аудио копируются внутрь проекта, поэтому продолжают работать, если оригинал перемещён или удалён. Отключите, чтобы сэкономить место, если вы никогда не перемещаете свои файлы.
  • Удалить модель субтитров. Показывается только после загрузки речевой модели для субтитров. Показывает размер файла и удаляет его; приложение загрузит её снова, если вы позже воспользуетесь субтитрами.
  • Удалить модель AI ... Одна строка для каждой загруженной модели AI Enhance или AI Smooth с её размером. Нажатие удаляет модель; приложение загрузит её снова, когда она понадобится в следующий раз.
  • Использовать графический чип для AI. Включено по умолчанию только для новых графических чипов, известных как безопасные для AI Smooth и AI Enhance; на других телефонах они работают на процессоре. Включение для другого чипа сначала запрашивает подтверждение, так как это может заморозить некоторые телефоны. См. AI-инструменты.

Резервное копирование

  • Резервная копия всех проектов, Восстановить из резервной копии и Еженедельная автоматическая резервная копия (только проекты) (выключено по умолчанию). См. Проекты, резервное копирование и импорт.

Язык

Строка Язык показывает текущий язык и открывает список из 14 языков. Выбор применяется сразу.

О программе, справка и другие строки

  • Справка открывает это руководство внутри приложения, без подключения к сети.
  • О программе показывает версию, лицензию (Apache License 2.0), примечание о том, что AbsentMotion — независимый проект, Лицензии открытого исходного кода (полный текст лицензии каждой библиотеки, используемой приложением) и адрес Домашней страницы проекта.
  • Журналы сбоев перечисляет сбои, записанные приложением. Нажмите на один, чтобы прочитать, и используйте Копировать, чтобы скопировать его, например для отправки с отчётом об ошибке. См. Устранение неполадок.
  • Проверять новую версию при каждом открытии приложения. Приложение один раз спрашивает, можно ли это делать. Если включено, при открытии приложение отправляет один запрос на GitHub за номером последней версии. Больше ничего не отправляется, и приложение никогда не скачивает и не устанавливает что-либо само.
  • Проверить обновление выполняет ту же проверку один раз, прямо сейчас. Если существует более новая версия, Список изменений открывает её примечания к выпуску, а Скачать открывает в браузере загрузку соответствующего файла приложения (Latest, Play services или Compatible version); если этот файл не найден, открывается страница выпуска.
