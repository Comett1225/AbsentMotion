Текст по контуру

Текст · Добавлено в версии 4.2.0

Размещает текст вдоль дуги, окружности или контура слоя, лежащего прямо под ним, буква за буквой, сохраняя начертание, шрифты и эмодзи текста.

Выберите Path: дугу или круг вокруг текстового слоя (перетаскивайте точки на холсте или введите значения) либо Layer Below, чтобы текст шёл по тому, что лежит прямо под ним в списке слоёв: контуру пера, фигуре, штрихам рисунка или буквам другого текста. На круге или любом замкнутом контуре Position 50 % ставит текст по центру сверху, слева направо, а 0 % — это низ; при включённом Reverse Path значение 0 % ведёт текст по низу, тоже слева направо. Контур из нескольких частей проходится часть за частью. Текст на контуре не переносится по ширине текстового поля: для второго ряда начните новую строку сами.
