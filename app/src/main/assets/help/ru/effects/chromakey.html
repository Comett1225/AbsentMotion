Хромакей

Ключ · Добавлено в версии 2.1.0 или раньше

Удаляет один цвет, например зелёный фон.

Хромакей делает один цвет прозрачным, например зелёный экран. Выберите цвет с помощью Key Color (по умолчанию зелёный). Tolerance — это насколько широкий диапазон цветов вокруг него удаляется, а Softness — насколько мягкий край выреза.

  1. Поместите клип с хромакеем над фоном, который хотите показать.
  2. Добавьте Chroma Key и установите Key Color на цвет экрана.
  3. Повышайте Tolerance, пока экран не исчезнет. Если части человека начинают пропадать, снова уменьшите его.
  4. Очистите край с помощью Softness, Feather или Matte Choker.

Освещайте экран равномерно при съёмке: ровный, хорошо освещённый цвет даёт самый чистый результат.
