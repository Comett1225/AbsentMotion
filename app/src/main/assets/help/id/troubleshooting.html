Aplikasi tertutup sendiri

Android menutup aplikasi yang menggunakan terlalu banyak memori. Ini paling mungkin terjadi dengan video 4K, banyak efek berat, atau aplikasi lain yang terbuka pada saat bersamaan.

  1. Buka AbsentMotion lagi. Jika muncul AbsentMotion closed unexpectedly, ketuk Restore untuk mendapatkan kembali editan terakhir Anda.
  2. Tutup aplikasi lain, dan coba proyek lagi.
  3. Turunkan Preview Quality ke Half atau Quarter di strip pratinjau atau di Pengaturan.
  4. Aktifkan Use preview copies of large videos di Pengaturan (aktif secara default).
  5. Ekspor pada resolusi lebih rendah, atau pisahkan proyek yang sangat panjang.

Pengaturan, Crash logs menampilkan apa yang terjadi dalam satu kalimat untuk setiap crash. Copy menyalinnya sehingga Anda dapat mengirimkannya dengan laporan bug di GitHub. Tidak ada yang dikirim secara otomatis.

Ponsel ini tidak dapat menjalankan editor

AbsentMotion menggambar pratinjau dan ekspor dengan chip grafis melalui Vulkan 1.1. Jika driver grafis ponsel tidak menyediakannya, aplikasi menampilkan This phone cannot run the editor dengan versi Android dan chip grafis, bukan menutup. Proyek, pengaturan, cadangan, dan log crash Anda tetap terbuka. Copy details menyalin faktanya sehingga Anda dapat menambahkannya ke laporan bug di GitHub. Lihat Requirements and versions.

Media hilang

Sebuah lapisan kosong, atau ekspor menyatakan Media Missing: file foto, video, atau audio yang digunakan proyek tidak lagi ada di ponsel.

  • Pilih lapisan, buka Media Info di menu lapisan dan ketuk Swap media file untuk memilih file lagi.
  • Gunakan Collect media into project di menu kartu proyek selama file masih ada, sehingga proyek menyimpan salinannya sendiri.
  • Biarkan Keep a copy of imported media in the project aktif di Pengaturan.

Jika Anda tetap mengekspor, lapisan yang menggunakan file hilang akan dihilangkan.

Masalah ekspor

PesanYang harus dilakukan
Not enough storageKosongkan ruang di ponsel atau pilih resolusi lebih kecil. Perkiraan ukuran ada di layar ekspor.
Not supported on this phoneEncoder ponsel tidak dapat membuat ukuran atau codec tersebut. Ketuk Use pada saran, atau pilih H.264 dan ukuran lebih kecil.
Slow exportHanya encoder perangkat lunak yang tersedia atau encoder perangkat keras lambat untuk pengaturan ini. Lanjutkan, atau pilih pengaturan yang disarankan.
Ekspor melambatPonsel menjadi hangat. Ini melambat dengan sengaja untuk mendingin. Biarkan mendingin, atau lepaskan casing ponsel.
Export Failed, frame tidak dapat digambarCoba lagi. Jika berulang, turunkan resolusi atau matikan Frame Interpolation.
Export Failed, encoder video sibuk atau tidak dapat membuat ukuran iniTutup aplikasi lain yang memutar atau merekam video, lalu coba lagi. Jika berulang, pilih resolusi atau frame rate lebih rendah.
Export Failed, decoder atau encoder video berhenti bekerjaAplikasi lain sedang menggunakan perangkat keras video ponsel. Tutup aplikasi yang memutar atau merekam video dan coba lagi.
"The phone's video encoder is busy, so this export uses the slower software encoder"Tidak ada yang salah: ekspor memakan waktu lebih lama. Tutup aplikasi video lain agar encoder perangkat keras yang lebih cepat kembali digunakan lain kali.
Video yang selesai menampilkan gambar diam dengan tombol putarPonsel tidak dapat memutarnya saat itu. Ketuk tombol putar untuk mencoba lagi; file itu sendiri sudah tersimpan.
Video hasil ekspor tidak memiliki suaraLapisan tersembunyi, atau klip pada volume 0 %, tidak bersuara. Baris "Checked: ..." pada layar Saved to storage melaporkan trek suara yang hilang.

Ekspor tetap berjalan saat Anda beralih ke aplikasi lain, dan notifikasi menampilkan kemajuannya. Menutup AbsentMotion dari daftar aplikasi terbaru menghentikannya.

Penyimpanan penuh

  • Hapus proyek yang tidak terpakai dari layar utama dan ekspor lama dari Movies/AbsentMotion.
  • Clear preview copies di Pengaturan membebaskan hingga 2 GB.
  • Cadangan di Documents/AbsentMotion bisa besar: salin ke komputer dan hapus dari ponsel.
  • Jika penyimpanan gagal, aplikasi akan memberitahukannya. Kosongkan ruang dan lanjutkan.

Lambat

  • Turunkan Preview Quality.
  • Gunakan opsi Fast Blur di strip pratinjau.
  • Foto dan video besar itu berat. Gunakan salinan pratinjau untuk video, dan perkecil foto yang sangat besar sebelum menambahkannya.
  • Banyak lapisan dengan efek akan menumpuk. Sembunyikan lapisan yang tidak sedang Anda kerjakan (ketuk ikon mata).

Teks menggunakan font yang salah

Proyek menggunakan font yang tidak ada di ponsel ini. Buka proyek dan ketuk Download di Fonts not on this phone. Font memerlukan koneksi internet sekali.

Pertanyaan

Apakah benar-benar gratis? Ya. Tidak ada langganan, tidak ada akun, tidak ada watermark, dan tidak ada iklan. Ini open source di bawah Apache License 2.0.

Apakah memerlukan internet? Tidak. Hanya hal opsional yang menggunakannya: mengunduh Google Font, mengunduh model takarir sekali, dan pemeriksaan pembaruan opsional. Lihat Privacy.

Di mana proyek saya? Di penyimpanan privat aplikasi, dengan setiap file media yang Anda tambahkan. Cadangkan dari Pengaturan. Ekspor ada di Movies, Pictures, Music, dan Documents di bawah AbsentMotion.

Dapatkah saya memindahkan proyek ke ponsel lain? Ya: ekspor Project Bundle, salin file .absproj ke ponsel lain dan buka di sana.

Dapatkah saya membuka proyek dari editor lain? Sebagian. Lihat Projects, backup and import.

Apakah ada versi komputer? Tidak. AbsentMotion dibuat untuk ponsel Android.

Bahasa apa saja yang tersedia? Inggris, Indonesia, Hindi, Portugis (Brasil), Spanyol, Filipino, Vietnam, Thailand, Melayu, Arab, Turki, dan Rusia. Ubah di Pengaturan.

Bagaimana cara melaporkan masalah atau meminta fitur? Buka issue di GitHub. Jangan sertakan informasi privat di dalamnya.

Di mana kode sumbernya? Di halaman proyek di GitHub.
