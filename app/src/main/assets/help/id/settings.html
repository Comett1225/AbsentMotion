Ketuk tombol menu di kiri atas layar utama untuk membuka drawer Pengaturan. Drawer ini memiliki empat grup yang awalnya tertutup (ketuk grup untuk membukanya) dan beberapa baris lagi di bawahnya.

Editor

  • Tema. AbsentMotion (bawaan: editor gelap dan layar utama terang hangat), Daylight (terang di semua tempat) atau Custom. Impor file tema... memuat tema dari file kecil (lihat di bawah).
  • Panjang Lapisan Baru. Berapa lama lapisan baru bertahan: 1 hingga 10, 15, 20, 25, 30, 45 atau 60 detik. Bawaannya 2.
  • Getaran. Getaran kecil pada timeline untuk snap, tekan lama dan pengurutan ulang. Aktif secara bawaan.
  • Gaya Emoji. SYSTEM (emoji ponsel Anda, bawaan) atau ANDROID (font emoji yang disertakan aplikasi, sama di setiap ponsel).

Tema kustom

File tema adalah file teks kecil dalam format JSON hingga 64 KB dengan name opsional dan warna apa pun yang ingin Anda ubah, ditulis sebagai #RRGGBB atau #AARRGGBB. Warna yang tidak Anda sertakan tetap memakai tampilan AbsentMotion. Contoh:

{"name": "Mint", "Accent": "#5BD6A4", "HomeAccent": "#1B7A4A"}

Nama warna adalah warna editor dan layar utama: TopBar, PreviewBg, TimelineBg, Panel, PanelInset, Button, Field, FieldHi, Chosen, Well, Deepest, Line, MenuLine, KeyDigit, KeySymbol, Scrim, PressEditor, OnDark, OnDarkDim, Caption, Faint, Inactive, OnScrim, Accent, AccentLit, AccentGlow, AccentDeep, OnAccent, Cool, CoolDeep, Gold, Warning, Bookmark, LayerBar, LayerBarStripe, TextBar, TextBarStripe, AudioBar, AudioWave, OnBar, OnAudioBar, HomeBg, Card, SheetBg, Navy, HomeAccent, OnNavy, OnNavyAccent, NavyHi, NavyLine, HomeInk, HomeMid, HomeDim, HomeFaint, HomeLine, HomePanel, HomeDrawer, SwitchOff, Thumb, MenuScrim dan PressHome. Satu tema kustom disimpan dalam satu waktu; mengimpor file baru akan menggantikannya dan langsung menerapkannya.

Pemutaran dan pratinjau

  • Kualitas Pratinjau. FULL, HALF atau QUARTER (bawaan Full): seberapa tajam pratinjau editor. Lebih rendah lebih cepat di ponsel lambat dan tidak mengubah ekspor. Sakelar yang sama ada di strip pratinjau editor.
  • Resampling Pemutaran. LOW, HIGH atau ULTRA (bawaan Ultra): kualitas resampling suara, saat editor memutar dan saat suara dicampur untuk ekspor.
  • Gunakan salinan pratinjau untuk video besar. Aktif secara bawaan. Untuk video lebih besar dari 1920 x 1080, atau dengan sedikit keyframe, aplikasi membuat salinan kecil dan ringan di latar belakang dan menggunakannya untuk pratinjau. Ekspor selalu memakai file asli. Salinan disimpan di cache hingga 2 GB.
  • Hapus salinan pratinjau menghapusnya. Baris ini menampilkan ruang yang dipakainya.

Proyek dan media

  • Tampilkan kartu impor di daftar proyek. Nonaktif secara bawaan. Menambahkan kartu dengan Pilih file di bagian atas daftar proyek.
  • Simpan salinan media yang diimpor di proyek. Aktif secara bawaan. Foto, video atau audio yang Anda tambahkan disalin di dalam proyek, sehingga tetap berfungsi jika file asli dipindahkan atau dihapus. Nonaktifkan untuk menghemat penyimpanan jika Anda tidak pernah memindahkan file.
  • Hapus model takarir. Hanya ditampilkan setelah model ucapan untuk takarir telah diunduh. Baris ini menampilkan ukuran file dan menghapusnya; aplikasi akan mengunduhnya lagi jika Anda memakai takarir nanti.
  • Hapus model AI ... Satu baris untuk setiap model AI Enhance atau AI Smooth yang diunduh, beserta ukurannya. Ketuk untuk menghapus model; aplikasi akan mengunduhnya lagi saat diperlukan berikutnya.
  • Gunakan chip grafis untuk AI. Aktif secara bawaan hanya untuk chip grafis yang lebih baru yang diketahui aman untuk AI Smooth dan AI Enhance; di ponsel lain fitur ini berjalan di prosesor. Mengaktifkannya untuk chip lain akan meminta konfirmasi terlebih dahulu, karena dapat membuat sebagian ponsel macet. Lihat Alat AI.

Cadangan

  • Cadangkan semua proyek, Pulihkan dari cadangan dan Cadangan otomatis mingguan (hanya proyek) (nonaktif secara bawaan). Lihat Proyek, cadangan dan impor.

Bahasa

Baris Bahasa menampilkan bahasa saat ini dan membuka daftar 14 bahasa. Memilih salah satu langsung menerapkannya.

Tentang, Bantuan dan baris lainnya

  • Bantuan membuka panduan ini di dalam aplikasi, tanpa koneksi.
  • Tentang menampilkan versi, lisensi (Apache License 2.0), catatan bahwa AbsentMotion adalah proyek independen, Lisensi sumber terbuka (teks lisensi lengkap setiap pustaka yang dipakai aplikasi) dan alamat Halaman utama proyek.
  • Log crash menampilkan daftar crash yang dicatat aplikasi. Ketuk salah satunya untuk membacanya dan gunakan Salin untuk menyalinnya, misalnya untuk dikirim bersama laporan bug. Lihat Pemecahan masalah.
  • Periksa versi baru setiap kali aplikasi dibuka. Aplikasi menanyakan sekali apakah boleh melakukannya. Jika aktif, aplikasi membuat satu permintaan ke GitHub untuk nomor versi terbaru saat dibuka. Aplikasi tidak mengirim apa pun selain itu dan tidak pernah mengunduh atau memasang apa pun sendiri.
  • Periksa Pembaruan melakukan pemeriksaan yang sama sekali sekarang. Jika ada versi lebih baru, Changelog membuka catatan rilisnya dan Unduh membuka unduhan file aplikasi yang cocok (versi Latest, Play services atau Kompatibel) di browser Anda; jika file itu tidak ditemukan, halaman rilis akan dibuka.
