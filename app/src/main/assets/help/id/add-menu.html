Menu Tambah

Cara menambahkan bentuk, foto, video, suara, teks, gambar, kamera, model 3D, dan lainnya.

Tombol bundar + di kanan bawah area timeline membuka menu Tambah. Tombol ini hanya muncul saat tidak ada yang dipilih; memilih lapisan menggantinya dengan kisi alat.

Lapisan baru dimulai pada playhead dan berlangsung selama pengaturan Panjang Lapisan Baru (2 detik secara default). Foto dan bentuk memakai durasi tersebut; video dan suara memakai durasi masing-masing. Lapisan kamera berlangsung sepanjang proyek.

Menu ini memiliki lima tab di kiri dan empat tombol cepat di kanan. Tanda X menutupnya.

Tombol cepat

  • Kuas Bebas membuat lapisan gambar dan membuka editor gambar. Lihat Bentuk, gambar, dan masker.
  • Alat Pena membuat lapisan bentuk dan membuka editor titik sehingga Anda dapat menggambar bentuk titik demi titik.
  • Teks menambahkan lapisan teks dan langsung membuka editor teks. Lihat Teks dan font.
  • Takarir membuka lembar Takarir Otomatis. Lihat Alat AI.

Bentuk

Lima puluh empat bentuk siap pakai, enam per baris, dalam halaman yang dapat Anda geser. Ketuk salah satunya untuk menambahkannya di tengah kanvas dengan warna acak yang enak dilihat.

Sembilan belas bentuk bersifat parametrik dan diedit dengan Opsi Bentuk: Circle, Rounded Rectangle, Plus, Arc, Triangle, Callout, Pie, Polygon, Multifoil, Arrow, Quad, Moon, Rectangle, Star, Line, Wide Line, Irregular Pentagon, Stamp, dan Teardrop. Tiga puluh lima lainnya digambar dengan titik dan diedit dengan Edit Titik: Heart, Cloud, Lightning Bolt, Check Mark, X Mark, Ring, Speech Bubble, Shield, House, Bookmark, Flag, Crescent and Star, Sun, Leaf, Seal Burst, Hexagon Outline, Star Outline, Chevron, Double Arrow, Curved Arrow, Parallelogram, Trapezoid, Ticket, Tag, Crown, Eye, Umbrella, Music Note, Droplet Pair, Key, Location Pin, Rounded Play, Pause, Record, dan Gear.

Media

Foto dan video Anda, terbaru lebih dulu, dalam kisi. Ketuk salah satunya untuk menambahkannya, dengan ukuran menyesuaikan kanvas.

  • Lihat Semua membuka pemilih foto bawaan Android. Ini tidak memerlukan izin.
  • Daftar album di atas mempersempit kisi (default-nya Semua).
  • Kamera membuka kamera dalam aplikasi. Lihat Membuat proyek untuk kontrol kamera.
  • Cari menelusuri kisi ("Cari foto dan video").
  • File SVG dari galeri Anda juga muncul di sini.

Saat pertama kali, Android meminta izin untuk melihat foto dan video Anda. Di Android 14 dan yang lebih baru, Anda dapat mengizinkan hanya yang Anda pilih. Secara default aplikasi menyimpan salinan media yang ditambahkan di dalam proyek, sehingga proyek tetap berfungsi jika Anda menghapus aslinya nanti.

Audio

Musik dan suara yang tersimpan di ponsel Anda. Saat pertama kali, aplikasi meminta izin untuk membaca file audio.

  • Lihat semua membuka pemilih file untuk file audio.
  • Teks ke Ucapan mengubah teks yang diketik menjadi suara: lihat Audio.
  • Ketuk ubin suara untuk mendengarkannya, dan ketuk lagi untuk berhenti. Ketuk strip + di bagian bawah ubin untuk menambahkannya ke proyek pada playhead.
  • Cari musik dan suara mencocokkan judul, nama file, album, dan artis.

Objek / Aset

Enam ubin untuk jenis lapisan lainnya.

  • Kamera menambahkan lapisan kamera yang berlangsung sepanjang proyek. Lihat Lapisan kamera dan 3D.
  • Null menambahkan lapisan pembantu tak terlihat. Gunakan sebagai induk untuk lapisan lain atau sebagai target untuk pelacakan gerak.
  • Grup Kosong menambahkan grup kosong.
  • Aset / Proyek mencantumkan aset tersimpan Anda, lalu proyek Anda yang lain. Ketuk salah satunya untuk menyisipkannya sebagai grup pada playhead. Aset tetap tertaut ke sumbernya; proyek disisipkan sebagai salinan independen. Lihat Aset, template, dan preset.
  • Impor SVG membuka pemilih file untuk file .svg (hingga 16 MB). Satu bentuk menjadi lapisan bentuk; beberapa menjadi grup. Pesan mencantumkan apa yang tidak dapat diimpor: teks, gambar, konten tertanam, animasi, jalur kliping, masker, filter, penanda, stroke putus-putus atau gradien, dan isian pola. Gradien hanya mempertahankan warna pertama dan terakhirnya.
  • Model 3D membuka pemilih file untuk file .obj, .glb, dan .gltf. Pilih file material dan gambar model bersamanya jika ada. File dapat berjumlah hingga 256 MB, dan model dengan lebih dari 50.000 segitiga ditampilkan dalam bentuk yang disederhanakan.

Template

Lihat Semua menampilkan kisi layar penuh berisi template tersimpan Anda, dan di bawahnya setiap template memiliki ubin. Mengetuk salah satunya membuka layar tempat Anda menukar media Anda sendiri. Lihat Aset, template, dan preset.
