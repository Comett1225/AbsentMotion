অ্যাপ নিজে থেকেই বন্ধ হয়ে গেল

Android এমন অ্যাপ বন্ধ করে দেয় যেগুলো অতিরিক্ত মেমরি ব্যবহার করে। 4K ভিডিও, অনেক ভারী ইফেক্ট, বা একই সময়ে অন্য অ্যাপ খোলা থাকলে এটি হওয়ার সম্ভাবনা বেশি।

  1. আবার AbsentMotion খুলুন। যদি AbsentMotion closed unexpectedly দেখায়, আপনার সর্বশেষ এডিট ফিরে পেতে Restore ট্যাপ করুন।
  2. অন্য অ্যাপ বন্ধ করুন, এবং আবার প্রজেক্টটি চেষ্টা করুন।
  3. প্রিভিউ স্ট্রিপে বা সেটিংসে Preview Quality কমিয়ে Half বা Quarter করুন।
  4. সেটিংসে Use preview copies of large videos চালু করুন (এটি ডিফল্টভাবে চালু থাকে)।
  5. কম রেজোলিউশনে এক্সপোর্ট করুন, অথবা খুব দীর্ঘ প্রজেক্টকে ভাগ করুন।

সেটিংসে, Crash logs প্রতিটি ক্র্যাশের জন্য এক বাক্যে দেখায় কী ঘটেছে। Copy এটি কপি করে যাতে আপনি GitHub-এ বাগ রিপোর্টের সাথে পাঠাতে পারেন। কিছুই স্বয়ংক্রিয়ভাবে পাঠানো হয় না।

এই ফোনে এডিটর চালানো যাবে না

AbsentMotion Vulkan 1.1-এর মাধ্যমে, অথবা ফোনে তা না থাকলে OpenGL ES 3.0-এর মাধ্যমে, গ্রাফিক্স চিপ দিয়ে প্রিভিউ ও এক্সপোর্ট আঁকে। কোনোটিই চালু না হলে, অ্যাপটি বন্ধ হওয়ার পরিবর্তে Android সংস্করণ ও গ্রাফিক্স চিপসহ This phone cannot run the editor দেখায়। আপনার প্রজেক্ট, সেটিংস, ব্যাকআপ ও ক্র্যাশ লগ তবুও খোলে। Copy details তথ্যগুলো কপি করে যাতে আপনি GitHub-এ বাগ রিপোর্টে যোগ করতে পারেন। দেখুন Requirements and versions। এডিটর খুললেও প্রিভিউ বা এক্সপোর্ট ভুল দেখালে সেটিংস, গ্রাফিক্স-এ OpenGL বেছে নিন।

অনুপস্থিত মিডিয়া

একটি লেয়ার খালি, অথবা এক্সপোর্টে Media Missing দেখায়: প্রজেক্টে ব্যবহৃত একটি ছবি, ভিডিও বা অডিও ফাইল আর ফোনে নেই।

  • লেয়ারটি নির্বাচন করুন, লেয়ার মেনুতে Media Info খুলুন এবং আবার ফাইল বাছাই করতে Swap media file ট্যাপ করুন।
  • ফাইলগুলো এখনও থাকতে থাকতেই প্রজেক্ট কার্ডের মেনুতে Collect media into project ব্যবহার করুন, যাতে প্রজেক্ট নিজের কপি রাখে।
  • সেটিংসে Keep a copy of imported media in the project চালু রাখুন।

তবুও যদি এক্সপোর্ট করেন, অনুপস্থিত ফাইল ব্যবহার করা লেয়ারগুলো বাদ পড়বে।

এক্সপোর্ট সমস্যা

বার্তাকী করবেন
Not enough storageফোনে জায়গা খালি করুন বা ছোট রেজোলিউশন বাছাই করুন। আনুমানিক আকার এক্সপোর্ট স্ক্রিনে আছে।
Not supported on this phoneফোনের এনকোডার ওই আকার বা কোডেক তৈরি করতে পারে না। পরামর্শে Use ট্যাপ করুন, অথবা H.264 ও ছোট আকার বাছাই করুন।
Slow exportশুধু একটি সফটওয়্যার এনকোডার পাওয়া যাচ্ছে অথবা এই সেটিংসের জন্য হার্ডওয়্যার এনকোডার ধীর। চালিয়ে যান, অথবা পরামর্শকৃত সেটিংস বাছাই করুন।
এক্সপোর্ট ধীর হয়ে যায়ফোন গরম। ঠান্ডা হতে দেওয়ার জন্য এটি ইচ্ছাকৃতভাবে ধীর হয়। ঠান্ডা হতে দিন, অথবা ফোনটি কেস থেকে বের করুন।
Export Failed, ফ্রেম আঁকা যায়নিআবার চেষ্টা করুন। যদি পুনরাবৃত্তি হয়, রেজোলিউশন কম করুন বা Frame Interpolation বন্ধ করুন।
Export Failed, ভিডিও এনকোডার ব্যস্ত অথবা এই আকার তৈরি করতে পারে নাভিডিও প্লে বা রেকর্ড করে এমন অন্য অ্যাপ বন্ধ করুন, তারপর আবার চেষ্টা করুন। যদি পুনরাবৃত্তি হয়, কম রেজোলিউশন বা ফ্রেম রেট বাছাই করুন।
Export Failed, ভিডিও ডিকোডার বা এনকোডার কাজ করা বন্ধ করেছেঅন্য একটি অ্যাপ ফোনের ভিডিও হার্ডওয়্যার ব্যবহার করছে। ভিডিও প্লে বা রেকর্ড করে এমন অ্যাপ বন্ধ করুন এবং আবার চেষ্টা করুন।
"The phone's video encoder is busy, so this export uses the slower software encoder"কিছুই ভুল নয়: এক্সপোর্ট বেশি সময় নেয়। পরেরবার দ্রুততর হার্ডওয়্যার এনকোডার ফিরে পেতে অন্য ভিডিও অ্যাপ বন্ধ করুন।
শেষ হওয়া ভিডিওতে প্লে বাটনসহ একটি স্থির ছবি দেখায়ফোন এটি সাথে সাথে প্লে করতে পারেনি। আবার চেষ্টা করতে প্লে বাটন ট্যাপ করুন; ফাইলটি নিজেই সংরক্ষিত আছে।
এক্সপোর্ট করা ভিডিওতে শব্দ নেইএকটি লুকানো লেয়ার, বা 0 % ভলিউমের একটি ক্লিপ নীরব। Saved to storage স্ক্রিনে "Checked: ..." লাইনটি অনুপস্থিত সাউন্ড ট্র্যাক জানায়।

অন্য অ্যাপে গেলেও এক্সপোর্ট চলতে থাকে, এবং একটি নোটিফিকেশন এর অগ্রগতি দেখায়। সাম্প্রতিক অ্যাপ তালিকা থেকে AbsentMotion বন্ধ করলে এটি থেমে যায়।

  • সংরক্ষণ ব্যর্থ হলে, অ্যাপ তা জানায়। জায়গা খালি করুন এবং চালিয়ে যান।

এটি ধীর

  • Preview Quality কমান।
  • প্রিভিউ স্ট্রিপে Fast Blur অপশন ব্যবহার করুন।
  • বড় ছবি ও ভিডিও ভারী। ভিডিওর জন্য প্রিভিউ কপি ব্যবহার করুন, এবং যোগ করার আগে খুব বড় ছবি ছোট করুন।
  • ইফেক্টসহ অনেক লেয়ার যোগ হয়। যে লেয়ারগুলোতে কাজ করছেন না সেগুলো লুকান (চোখে ট্যাপ করুন)।

টেক্সট ভুল ফন্ট ব্যবহার করছে

প্রজেক্টটি এমন একটি ফন্ট ব্যবহার করছে যা এই ফোনে নেই। প্রজেক্ট খুলুন এবং Fonts not on this phone-এ Download ট্যাপ করুন। ফন্টের জন্য একবার ইন্টারনেট সংযোগ প্রয়োজন।

প্রশ্ন

এটি কি সত্যিই বিনামূল্যে? হ্যাঁ। কোনো সাবস্ক্রিপশন, অ্যাকাউন্ট, ওয়াটারমার্ক বা বিজ্ঞাপন নেই। এটি Apache License 2.0-এর অধীনে ওপেন সোর্স।

এটির কি ইন্টারনেট প্রয়োজন? না। শুধু ঐচ্ছিক জিনিসগুলো এটি ব্যবহার করে: একটি Google Font ডাউনলোড, একবার ক্যাপশন মডেল ডাউনলোড, এবং ঐচ্ছিক আপডেট চেক। দেখুন Privacy।

আমার প্রজেক্ট কোথায়? অ্যাপের প্রাইভেট স্টোরেজে, আপনার যোগ করা প্রতিটি মিডিয়া ফাইলসহ। সেটিংস থেকে সেগুলো ব্যাকআপ করুন। এক্সপোর্টগুলো Movies, Pictures, Music ও Documents-এ AbsentMotion-এর অধীনে থাকে।

আমি কি একটি প্রজেক্ট অন্য ফোনে নিতে পারি? হ্যাঁ: একটি Project Bundle এক্সপোর্ট করুন, .absproj ফাইলটি অন্য ফোনে কপি করুন এবং সেখানে খুলুন।

আমি কি অন্য এডিটরের প্রজেক্ট খুলতে পারি? কিছুটা। দেখুন Projects, backup and import।

কোনো কম্পিউটার সংস্করণ আছে? না। AbsentMotion Android ফোনের জন্য তৈরি।

কোন কোন ভাষা আছে? ইংরেজি, ইন্দোনেশীয়, হিন্দি, পর্তুগিজ (ব্রাজিল), স্প্যানিশ, ফিলিপিনো, ভিয়েতনামীয়, থাই, মালয়, আরবি, তুর্কি ও রুশ। সেটিংসে এটি পরিবর্তন করুন।

আমি কীভাবে একটি সমস্যা রিপোর্ট করব বা ফিচার চাইব? GitHub-এ একটি ইস্যু খুলুন। অনুগ্রহ করে এতে ব্যক্তিগত তথ্য অন্তর্ভুক্ত করবেন না।

সোর্স কোড কোথায়? GitHub-এ প্রজেক্ট পেজে।
