The Compatible version

A version of AbsentMotion for phones with Android 9 to 12, and what it leaves out.

On this page
  • Who it is for
  • What it leaves out
  • How to install it
  • Same requirements as the Latest version

Who it is for

The Compatible version is made for phones that run Android 9, 10, 11 or 12 and cannot be updated to Android 13. The Latest version needs Android 13 or newer. Phones with Android 8 or older cannot run either version.

You can find your Android version in Settings, About phone, Android version.

What it leaves out

This list is not final. The Compatible version is still being built. The complete list of what it leaves out will be written here before it is released. Everything that is not on the list is meant to work the same way as in the Latest version.

  • To be filled in when the Compatible version is finished.

In the app, a feature that the Compatible version leaves out is shown greyed out with a note that it needs Android 13.

How to install it

The Compatible version is a separate file from the Latest version. Download it from the releases page.

Same requirements as the Latest version

The phone still needs a 64-bit ARM chip and Vulkan 1.1. See Requirements and versions.
