Mga Hugis

Magdagdag ng ready-made na hugis mula sa Shape tab ng Add menu. May dalawang uri.

  • Parametric shapes (Circle, Rectangle, Star, Polygon at iba pa) ay ina-edit gamit ang Shape Options: size, radius, bilang ng points at iba pa. Maaaring i-animate ang mga setting na ito.
  • Path shapes (Heart, Cloud, Gear at iba pa) ay ina-edit gamit ang Edit Points.

Ang kulay at outline ay itinatakda gamit ang Fill & Color at Frame & Shadow. Tingnan ang Layer tools.

Ang pen tool at Edit Points

Ang Pen Tool sa Add menu ay gumagawa ng bagong shape layer at binubuksan ang point editor. Ang Edit Points sa tool grid ay binubuksan ito para sa umiiral na path shape. Sa preview, tapikin para maglagay ng point; pindutin at i-drag para hilahin ang curve handle. May ghost point na nagpapakita kung saan mapupunta ang susunod na point. Kapag umalis nang walang iginuhit, mabubura ang bagong layer.

Sa ibaba ng editor:

  • Close the path o Open the path (kailangan ng dalawa o higit pang points).
  • Make the point curved o Make the point sharp.
  • Add point at Delete point.
  • Isang trackpad na gumagalaw sa napiling point ("Drag to move the point"), at kapag ina-edit mo ang handle ng smooth point, ang mga toggle na Angle at Distance ay nagla-lock sa anggulo o haba nito.
  • Contour na may mga arrow na gumagalaw sa pagitan ng magkakahiwalay na sub-path ng isang hugis.
  • Isang listahan ng mga point sa kanan, na may maliliit na "+" na cell sa pagitan ng mga ito para magsingit ng point.

Sa itaas ay may Undo, Redo at Back.

Animated na hugis (shape keyframes)

Sa point editor, may time bar na may Previous shape keyframe, Next shape keyframe, Add shape keyframe at Remove shape keyframe. Ang shape keyframe ay nag-iimbak ng buong hugis sa playhead. Lumipat sa ibang oras, baguhin ang mga point, magdagdag ng isa pang keyframe, at mag-a-animate ang hugis sa pagitan ng mga ito. Ang nakaraang keyframe ay lumalabas bilang malabong dashed outline para makatulong sa pag-align. Ganito gumawa ng animated na mask para sa rotoscoping: i-trace ang outline sa paligid ng isang bagay sa bidyo at baguhin ito habang gumagalaw ang bidyo.

Freehand drawing

Ang Freehand Brush sa Add menu ay gumagawa ng drawing layer at binubuksan ang drawing editor.

  • Ang Pen ay gumuhit ng pantay na linya, ang Brush ay nagbabago ng lapad ng linya gamit ang pressure, ang Fill ay ginagawang filled shape ang isang loop na iginuhit mo, at ang Eraser ay nag-aalis ng mga bahagi.
  • Isang size slider (1 hanggang 300), at isang color picker na may hue strip at opacity strip.
  • Undo at Redo sa itaas. Bawat stroke ay pinapanatili kapag inangat mo ang daliri.
  • Ang tool, size at kulay ay natatandaan. Kapag umalis nang walang iginuhit, mabubura ang bagong layer.

Walang keyframe ang mga drawing. Para i-animate ang isang drawing, gumamit ng mga epekto tulad ng Drawing Progress; tingnan ang effects library.

Mga SVG file

Ang Import SVG sa Add menu ay ginagawang mga hugis ang isang vector na larawan. Tingnan ang The Add menu para sa kung ano ang pinapanatili.

Mga mask at clipping

  • Ang Create Clipping Mask (layer menu) ay nag-clip ng isang layer sa hugis ng layer na direkta sa ibaba nito. Ang Release Clipping Mask ay nag-aalis nito.
  • Ang Group & Mask at Group & Exclude (multi-select) ay nag-grupo ng mga layer at itinatakda ang blending mode ng top layer sa Mask o Exclude. Maaari ring itakda ang blending mode na Mask o Exclude sa anumang layer sa Opacity & Blend Mode. Ang Mask ay pinapanatili ang nilalaman sa ibaba lamang kung saan naroon ang layer; ang Exclude ay pinuputol ito.
  • Ang mga animated na mask ay nagmumula sa shape keyframes (sa itaas).
  • Ang Remove Background para sa mga larawan at bidyo ay inilarawan sa AI tools.

Mga grupo at parent

  • Ang Group (multi-select) ay naglalagay ng mga layer sa isang group layer. Gawing isa ang paggalaw, pag-scale, pag-fade at pagdagdag ng mga epekto sa grupo. Tingnan ang Layer menus and multi-select.
  • Ang parent (ang parent button sa top bar) ay gumagawa ng isang layer na sumusunod sa isa pa nang walang pag-grupo.
  • Ang Null layer (Add, Object / Asset) ay hindi nakikita. Gawin itong parent ng ibang mga layer para galawin silang lahat nang sabay, o hayaan ang motion tracking na galawin ito.
