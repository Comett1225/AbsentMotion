Paglikha ng proyekto

Bawat setting ng bagong proyekto sheet.

Sa pahinang ito
  • Proyekto o asset
  • Pangalan
  • Hugis ng larawan (aspect ratio)
  • Resolusyon
  • Frame rate
  • Background
  • Mga button sa ibaba

I-tap ang bilog na + sa ibaba ng home screen. May sheet na dadausdos pataas mula sa ibaba. Bubukas ito gamit ang mga value na ginamit mo noong huli (hugis, resolusyon, frame rate at background; ang pangalan ay laging bago). I-tap ang Back para isara ito nang walang magagawa.

Proyekto o asset

Ang switch sa itaas ay may dalawang pagpipilian, PROJECT (ang default) at ASSET. Ang asset ay reusable na piraso na may transparent na background: naka-lock ang background setting nito sa Transparent. Tingnan ang Assets, templates at presets.

Pangalan

Nagsisimula ang pangalan sa "New Project 1", "New Project 2" at iba pa (nagsisimula ang mga asset sa "New Asset"). I-tap ang X sa field para i-clear ito. Ang blangkong pangalan ay babalik sa default.

Hugis ng larawan (aspect ratio)

Mga button para sa 16:9, 9:16, 4:5, 1:1 at 4:3, at pencil button para sa Custom aspect ratio. Ang default ay 1:1. Piliin ang 9:16 para sa phone video, 16:9 para sa landscape na bidyo.

Resolusyon

Ang Resolution row ay nagpapakita ng canvas size, tulad ng 1920 x 1080. Para sa limang hugis ito ay listahan ng short side:

PagpipilianShort side
2160p (4k)2160
1440p (QHD)1440
1080p (FHD), ang default1080
720p (HD)720
540p (SD), 360p, 270p, 180payon sa pangalan

Ang long side ay sumusunod sa hugis. Ang 16:9 na proyekto sa 1080p ay 1920 x 1080, ang 4:5 na proyekto ay 1080 x 1350, at ang 4:3 na proyekto ay 1440 x 1080.

Sa Custom aspect ratio, ang listahan ay nagiging dalawang number field para sa width at height, na may bilog na Link button sa pagitan nila. Kapag naka-on ang Link, ang pagbabago sa isang side ay nagpapanatili ng hugis na mayroon ang dalawang field noong binuksan mo ang Link. Ang bawat side ay maaaring mula 32 hanggang 4096 pixels; itinatama ng app ang value kapag umalis ka sa field.

Mas mukhang matalas ang mas malaking canvas pero nangangailangan ito ng mas maraming memory at mas matagal i-export. Ang 1080p ay magandang pagpipilian para sa karamihan ng proyekto. Maaari mong baguhin ang resolusyon mamaya sa project settings ng editor, na hindi nag-rescale ng iyong mga layer.

Frame rate

Pumili ng 12, 15, 18, 20, 24, 25, 30, 48, 50 o 60 frames per second. Ang default ay 60. Gamitin ang 24 o 30 para sa film look at mas maliliit na file, at 60 para sa smooth na mabilis na galaw. Itinatakda nito kung gaano kadalas nagdo-draw ng larawan ang editor at ang export. Ang mga video clip ay may sariling frame rate; tingnan ang frame interpolation option sa Export page.

Background

Ang kulay sa likod ng iyong mga layer: Black, White, Light Gray, Green, Blue o Transparent (ipinapakita bilang checkerboard). Ang bagong install ay nagsisimula sa Transparent. Ang mga transparent na bahagi ng na-export na bidyo ay lumalabas na itim; sa GIF at image export maaari mong piliin kung ano ang nagiging transparent na bahagi, at pinapanatili ito ng PNG.

Mga button sa ibaba

  • Ang CREATE PROJECT (CREATE ASSET para sa asset) ay gumagawa ng proyekto at binubuksan ang editor dito.
  • Isinasara ng X sa ilalim nila ang sheet.

Kung walang sapat na storage, sinasabi ito ng app at hindi ito gumagawa ng proyekto.
