Ang timeline

Mga layer bilang mga bar sa oras: pag-scrub, pag-trim, paggalaw, muling pag-order, mga keyframe, bookmark at snapping.

Sa pahinang ito
  • Pagbasa sa timeline
  • Mga gesture
  • Snapping
  • Mga bookmark
  • Ang mga tool sa ilalim ng napiling layer

Ang timeline ay ang lugar sa ilalim ng play bar. Bawat layer ay isang row na may bar na nagpapakita kung kailan umiiral ang layer.

Pagbasa sa timeline

  • Ang playhead ay isang nakapirming patayong linya sa gitna. Ang nilalaman ay nag-scroll sa ilalim nito. Ang time pill sa ruler ay nagpapakita ng minuto, segundo at frame.
  • Ruler. Ang matataas na tick ay nagmamarka ng bawat segundo at ang mas maiikli ay ang kalahating segundo at frame, depende sa kung gaano kalayo ang iyong na-zoom in.
  • Mga row. Isang row bawat layer, na ang front layer ay nasa itaas. Sa kaliwa, ang mata ay nagpapakita o nagtatago ng layer (ang nakatagong layer ay hindi iginuguhit at tahimik ang tunog nito) at isang maliit na larawan ang kumikilala dito.
  • Mga kulay ng bar. Ang mga ordinaryong layer ay teal na may diagonal stripes, ang mga text layer ay amber, ang mga camera layer ay crimson at ang mga audio layer ay violet na may waveform. Ang mga larawan at bidyo ay nagpapakita ng strip ng mga larawan. Ang pangalan ng layer ay nakasulat sa bar.
  • Mga kulay ng label. Ang layer menu ay maaaring markahan ang isang layer ng isa sa labing-isang label na kulay, na ipinapakita bilang maliit na kulay na sulok sa bar.
  • Mga keyframe diamond. Ang maliliit na diamond sa bar ay mga keyframe. Mas malaki ang mga ito sa napiling layer. Habang bukas ang isang property o epekto, ang mga keyframe lamang nito ang ipinapakita. Tingnan ang Mga keyframe at easing.

BookmarkI-tap ang time pill sa ruler.

Ang simpleng swipe sa bar ay naglilipat lamang ng playhead. Ito ay sinasadya: upang ilipat ang clip kailangan mo munang pindutin at hawakan ito, upang hindi ito gumalaw nang aksidente.

Kapag ang isang bidyo o audio clip ay umabot sa dulo ng file nito, ang grip ay nagiging pula at may ticks: hindi ito maaaring gawing mas mahaba. Upang gawing mas mahaba ang clip, pabagalin ito gamit ang Speed tool (tingnan ang Mga larawan, bidyo at bilis).

Snapping

Ang mga trim, paglipat ng clip at paglipat ng keyframe ay nag-snap sa playhead, mga bookmark, simula at dulo ng iba pang layer at mga keyframe. Ang kulay na patayong linya at maliit na vibration ay nagsasabi kapag may snap na nangyari. Ang vibration ay maaaring patayin sa Mga setting.

Mga bookmark

I-tap ang time pill sa ruler upang magdagdag ng bookmark sa kasalukuyang frame. Ito ay lumalabas bilang pink na flag. I-tap muli ang pill sa parehong lugar upang alisin ito. Ang mga bookmark ay gumagana bilang stops para sa skip buttons at bilang snap points. Ang Mark Beats sa layer menu ay nagdadagdag ng mga bookmark sa mga beat ng kanta: tingnan ang Audio.

Ang mga tool sa ilalim ng napiling layer

Kapag napili ang isang layer, lumalabas ang grid ng mga tool sa ibaba. Ang unang row ay may limang maliit na button.

  • Speed ay nagbubukas ng Time Remapping para sa bidyo at audio clip.
  • Trim start ay pinuputol ang clip upang magsimula ito sa playhead.
  • Split ay pinuputol ang clip sa dalawa sa playhead. Ang ikalawang bahagi ay nagiging bagong layer sa itaas ng una.
  • Trim end ay pinuputol ang clip upang magtapos ito sa playhead.
  • Volume ay nagbubukas ng volume panel para sa tunog at para sa mga bidyo.

Kung ang playhead ay nasa labas ng clip, ang parehong mga button ay nagbabago ng kahulugan: Extend the start to the playhead, Extend the end to the playhead, o Move the clip to the playhead (ang simula o dulo ng clip ay tumalon sa playhead).

Ang malalaking button sa ibaba ay ang mga tool ng layer.
