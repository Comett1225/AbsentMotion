Mga asset, template at preset

Gamitin muli ang iyong pinakamagandang gawa: i-save ang mga layer bilang asset, magsimula sa mga template at itago ang paborito mong itsura bilang preset.

Sa pahinang ito
  • Mga asset
  • Mga template
  • Mga preset

May tatlong paraan ang AbsentMotion para magamit muli ang gawa. Nagkakaiba sila sa kung ano ang itinatago.

ItinatagoGinagamit mula sa
AssetIsang layer o buong animation, naka-link sa source nitoAdd menu, Object / Asset
TemplateIsang buong proyekto na may mga lugar kung saan ipapalit mo ang sarili mong mediaAdd menu, Template; home screen, Templates
PresetAng itsura at galaw ng isang layer (mga epekto, keyframe, border, blending mode at iba pa)Tool grid, Presets

Mga asset

Gumawa ng asset

  • Sa editor, piliin ang isang layer o grupo at piliin ang Save to My Assets sa layer menu. May mensahe na "Saved to My Assets".
  • Sa home screen, piliin ang ASSET sa new project sheet at buuin ang animation sa sarili nitong proyekto. Ang asset project ay may transparent na background.

Lumalabas ang mga asset sa ilalim ng Assets chip ng home screen.

Gumamit ng asset

Ang Add, Object / Asset, Asset / Project ay naglilista ng iyong mga asset (pinakabago muna), pagkatapos ang iba mong proyekto, na may search box. I-tap ang isa para i-insert ito bilang grupo sa playhead. Nananatiling naka-link ang asset sa source asset nito. Ang proyektong na-insert sa ganitong paraan ay plain independent copy na lang.

Ang naka-link na layer ay may tool na Asset Properties na may dalawang button.

  • Open original Asset ay binubuksan ang sariling proyekto ng asset para mabago mo ito. Kung na-delete na ang proyektong iyon, inaalok ng app ang Rebuild Source Project (gumawa ng proyekto mula sa layer na ito) o Unlink from Asset.
  • Unlink from Asset ay ginagawang ordinaryong grupo ang layer na malaya mong mai-edit.

Mga asset project

Sa loob ng asset project, may dalawa pang row ang project settings sheet.

  • Precompose ay pumipili ng Adaptive Resolution o Locked Resolution para sa asset.
  • Re-timing ay nagpapasya kung ano ang mangyayari kapag inilagay ang asset sa mas mahabang clip kaysa sa sarili nitong haba: Freeze (i-hold ang huling frame ng gitnang bahagi), Stretch, Loop, Repeat & Stretch o Blank (walang mangyayari pagkatapos ng sarili nitong haba).

May nadadagdag din sa copy and paste menu na Set intro end at Set outro start. Naglalagay sila ng gold flags sa ruler: ang bahagi bago ang intro end at pagkatapos ng outro start ay pinapanatili ang totoong bilis habang ang gitna ay ini-stretch, ini-loop o ini-freeze.

Mga template

Ang template ay isang tapos na proyekto kung saan ang bawat larawan o bidyo ay slot na maaari mong palitan.

Gumamit ng template

  1. Sa home screen, buksan ang Templates page at ang My Templates chip, at i-tap ang isang template. Mula sa loob ng editor, maaari mong gamitin ang Add, Template.
  2. Ipinapakita ng Use Template screen ang preview at isang row ng Media slots. I-tap ang isang slot para piliin ito (lumulundag ang playhead sa simula nito), pagkatapos i-tap muli para pumili ng sarili mong photo o bidyo.
  3. Binabago ng corner icon sa isang slot kung paano ini-scale ang media: fill, fit o stretch.
  4. Kung mas mahaba ang bidyo mo kaysa sa slot, may screen na Drag across to select para pumili kung aling bahagi ang gagamitin. Kung mas maikli, hinohold ang huling frame at sinasabi ito ng app sa iyo.
  5. I-tap ang Next, at pagkatapos ang Go to Timeline. May bagong proyektong magagawa. Hindi kailanman nababago ang template mismo.

Ang Open as project sa menu ng template ay lumalaktaw sa swap screen at agad na gumagawa ng bagong proyekto. Maaari ring pangalanan muli at i-delete ang mga template mula sa menu na iyon.

Gumawa ng template

  • I-on ang switch na Also keep a copy as a Template sa export screen bago ka mag-export. Itinatago nito ang proyekto kasama ang media nito sa Templates sa phone na ito, at tumatakbo pagkatapos ng matagumpay na export.
  • Ang mga package na ina-import mo mula sa ibang editors ay dumarating bilang templates: tingnan ang Projects, backup and import.

Mga preset

Ang preset ay nagtatago ng itsura ng isang layer para mailagay mo ito sa iba.

Mag-save ng preset

Piliin ang layer at piliin ang Save Preset sa copy and paste menu (ang ikaanim na button ng play bar). Magagamit lang ito kapag may itinatago ang layer: stroke, border o shadow, mga epekto, blending mode na hindi Normal, binagong opacity, animated na position o size, binagong volume o bilis, o binagong font. Pagkatapos mag-save, maaari mong Name it.

Gumamit ng preset

Piliin ang ibang layer at i-tap ang Presets sa tool grid. Ipinapakita ng Try a Preset screen ang layer nang mag-isa kasama ang inilapat na preset. I-tap ang isang preset para subukan ito, i-tap ang preview para i-play ito, at i-tap ang Apply para panatilihin ito. May Rename at Delete ang bawat preset sa menu nito.

Pinapalitan ng preset ang border, shadow, blending mode at opacity, animated transform, mga epekto, text style (teksto sa teksto), volume at audio effects (tunog sa tunog) at bilis (clip sa clip). Hindi nito binabago ang fill color, hugis, nilalaman o timing.

Walang built-in na preset: tanging ang mga sina-save mo lang. Nakalista sila sa home screen sa ilalim ng Templates, My Presets, kung saan maaari mong pangalanan muli at i-delete sila.
