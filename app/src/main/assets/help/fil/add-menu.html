Ang menu na Add

Paano magdagdag ng mga hugis, larawan, bidyo, tunog, teksto, guhit, kamera, 3D model at iba pa.

Sa pahinang ito
  • Mga quick button
  • Hugis
  • Media
  • Audio
  • Object / Asset
  • Template

Ang bilog na + button sa kanang ibaba ng timeline area ay nagbubukas ng Add menu. Lumalabas lang ito kapag walang seleksyon; kapag pumili ka ng layer, napapalitan ito ng tool grid.

Ang mga bagong layer ay nagsisimula sa playhead at tumatagal hangga't ang New Layer Length na setting (2 segundo bilang default). Ang mga larawan at hugis ay gumagamit ng tagal na iyon; ang mga bidyo at tunog ay gumagamit ng sarili nilang tagal. Ang camera layer ay tumatagal sa buong proyekto.

Ang menu ay may limang tab sa kaliwa at apat na quick button sa kanan. Isinasara ito ng X.

Mga quick button

  • Freehand Brush ay gumagawa ng drawing layer at nagbubukas ng drawing editor. Tingnan ang Mga hugis, pagguhit at mask.
  • Pen Tool ay gumagawa ng shape layer at nagbubukas ng point editor para makaguhit ka ng hugis punto por punto.
  • Text ay nagdadagdag ng text layer at agad na nagbubukas ng text editor. Tingnan ang Teksto at mga font.
  • Captions ay nagbubukas ng Auto Captions sheet. Tingnan ang Mga AI tool.

Hugis

Limampu't apat na ready-made na hugis, anim bawat row, sa mga page na ini-swipe mo. I-tap ang isa para idagdag ito sa gitna ng canvas na may random na magandang kulay.

Labinsiyam na hugis ang parametric at ini-edit gamit ang Shape Options: Circle, Rounded Rectangle, Plus, Arc, Triangle, Callout, Pie, Polygon, Multifoil, Arrow, Quad, Moon, Rectangle, Star, Line, Wide Line, Irregular Pentagon, Stamp at Teardrop. Ang iba pang tatlumpu't lima ay iginuhit gamit ang mga punto at ini-edit gamit ang Edit Points: Heart, Cloud, Lightning Bolt, Check Mark, X Mark, Ring, Speech Bubble, Shield, House, Bookmark, Flag, Crescent and Star, Sun, Leaf, Seal Burst, Hexagon Outline, Star Outline, Chevron, Double Arrow, Curved Arrow, Parallelogram, Trapezoid, Ticket, Tag, Crown, Eye, Umbrella, Music Note, Droplet Pair, Key, Location Pin, Rounded Play, Pause, Record at Gear.

Media

Ang iyong mga larawan at bidyo, pinakabago muna, sa isang grid. I-tap ang isa para idagdag ito, naka-size para magkasya sa canvas.

  • View All ay nagbubukas ng sariling photo picker ng Android. Hindi ito nangangailangan ng permiso.
  • Ang album list sa itaas ay nagpapaliit sa grid (ang default ay All).
  • Camera ay nagbubukas ng in-app na kamera. Tingnan ang Paglikha ng proyekto para sa mga kontrol ng kamera.
  • Search ay naghahanap sa grid ("Search photos and videos").
  • Ang mga SVG file mula sa iyong gallery ay lumalabas din dito.

Sa unang pagkakataon, humihingi ang Android ng permiso para makita ang iyong mga larawan at bidyo. Sa Android 14 at mas bago, maaari mong payagan lamang ang mga pinili mo. Bilang default, nagtatago ang app ng kopya ng idinagdag na media sa loob ng proyekto, kaya gumagana pa rin ang proyekto kung buburahin mo ang orihinal mamaya.

Audio

Musika at tunog na naka-store sa iyong telepono. Sa unang pagkakataon, humihingi ang app ng permiso para magbasa ng audio file.

  • View all ay nagbubukas ng file picker para sa mga audio file.
  • Text to Speech ay ginagawang boses ang nai-type na teksto: tingnan ang Audio.
  • I-tap ang sound tile para marinig ito, at i-tap muli para itigil. I-tap ang + strip sa ibaba ng tile para idagdag ito sa proyekto sa playhead.
  • Search music and sounds ay tumutugma sa title, file name, album at artist.

Object / Asset

Anim na tile para sa iba pang uri ng layer.

  • Camera ay nagdadagdag ng camera layer na tumatagal sa buong proyekto. Tingnan ang Mga camera layer at 3D.
  • Null ay nagdadagdag ng invisible helper layer. Gamitin ito bilang parent ng ibang layer o bilang target para sa motion tracking.
  • Empty Group ay nagdadagdag ng empty group.
  • Asset / Project ay naglilista ng iyong mga naka-save na asset, pagkatapos ang iba mong proyekto. I-tap ang isa para i-insert ito bilang group sa playhead. Ang asset ay nananatiling naka-link sa source nito; ang proyekto ay ini-insert bilang independent na kopya. Tingnan ang Mga asset, template at preset.
  • Import SVG ay nagbubukas ng file picker para sa mga .svg file (hanggang 16 MB). Ang isang hugis ay nagiging shape layer; ang marami ay nagiging group. Naglilista ang isang mensahe ng mga hindi ma-import: teksto, larawan, embedded na content, animation, clipping path, mask, filter, marker, dashed o gradient stroke at pattern fill. Ang mga gradient ay pinapanatili lamang ang una at huling kulay.
  • 3D Model ay nagbubukas ng file picker para sa mga .obj, .glb at .gltf file. Piliin kasama ang material at picture file ng modelo kung mayroon ito. Ang mga file ay maaaring umabot hanggang 256 MB sa kabuuan, at ang modelong may higit sa 50,000 triangles ay ipinapakita sa pinasimpleng anyo.

Template

View All ay nagpapakita ng full-screen grid ng iyong mga naka-save na template, at sa ibaba nito ay may tile ang bawat template. Ang pag-tap sa isa ay nagbubukas ng screen kung saan papalitan mo ng sarili mong media. Tingnan ang Mga asset, template at preset.
