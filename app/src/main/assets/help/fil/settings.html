Mga Setting

Bawat setting sa drawer sa home screen, kasama ang default.

Sa pahinang ito
  • Editor
  • Playback and preview
  • Projects and media
  • Backup
  • Language
  • About, Help and other rows

I-tap ang menu button sa itaas na kaliwa ng home screen para buksan ang Settings drawer. May apat itong grupo na nagsisimulang nakasara (i-tap ang isang grupo para buksan ito) at ilang row pa sa ibaba nila.

Editor

  • Theme. AbsentMotion (ang default: madilim na editor at maliwanag na home screen), Daylight (maliwanag sa lahat ng lugar) o Custom. Import theme file... naglo-load ng theme mula sa maliit na file (tingnan sa ibaba).
  • New Layer Length. Gaano katagal tumatagal ang mga bagong layer: 1 hanggang 10, 15, 20, 25, 30, 45 o 60 segundo. Ang default ay 2.
  • Vibration. Maliliit na vibration sa timeline para sa snaps, long presses at reordering. Naka-on bilang default.
  • Emoji Style. SYSTEM (emoji ng iyong phone, ang default) o ANDROID (ang emoji font na kasama ng app, pareho sa bawat phone).

Custom themes

Ang theme file ay isang maliit na text file sa JSON format na hanggang 64 KB na may opsyonal na name at alinman sa mga kulay na gusto mong baguhin, na isinusulat bilang #RRGGBB o #AARRGGBB. Ang mga kulay na hindi mo ilalagay ay mananatili sa AbsentMotion look. Halimbawa:

{"name": "Mint", "Accent": "#5BD6A4", "HomeAccent": "#1B7A4A"}

Ang mga pangalan ng kulay ay ang mga kulay ng editor at home screen: TopBar, PreviewBg, TimelineBg, Panel, PanelInset, Button, Field, FieldHi, Chosen, Well, Deepest, Line, MenuLine, KeyDigit, KeySymbol, Scrim, PressEditor, OnDark, OnDarkDim, Caption, Faint, Inactive, OnScrim, Accent, AccentLit, AccentGlow, AccentDeep, OnAccent, Cool, CoolDeep, Gold, Warning, Bookmark, LayerBar, LayerBarStripe, TextBar, TextBarStripe, AudioBar, AudioWave, OnBar, OnAudioBar, HomeBg, Card, SheetBg, Navy, HomeAccent, OnNavy, OnNavyAccent, NavyHi, NavyLine, HomeInk, HomeMid, HomeDim, HomeFaint, HomeLine, HomePanel, HomeDrawer, SwitchOff, Thumb, MenuScrim at PressHome. Isang custom theme lang ang pinapanatili sa isang pagkakataon; ang pag-import ng bagong file ay papalitan ito at ilalapat agad.

Playback and preview

  • Preview Quality. FULL, HALF o QUARTER (default Full): gaano kalinaw ang editor preview. Ang mas mababa ay mas mabilis sa mabagal na phone at hindi binabago ang mga export. Ang parehong switch ay nasa preview strip ng editor.
  • Playback Resampling. LOW, HIGH o ULTRA (default Ultra): ang kalidad ng sound resampling, kapag nagpe-play ang editor at kapag hinahalo ang tunog para sa isang export.
  • Use preview copies of large videos. Naka-on bilang default. Para sa mga bidyo na mas malaki sa 1920 x 1080, o may kaunting keyframe, gumagawa ang app ng maliit at magaan na kopya sa background at ginagamit ito para sa preview. Ang mga export ay laging gumagamit ng orihinal na file. Ang mga kopya ay pinapanatili sa cache na hanggang 2 GB.
  • Clear preview copies binubura ang mga ito. Ipinapakita ng row ang espasyong ginagamit nila.

Projects and media

  • Show the import card in the project list. Naka-off bilang default. Nagdadagdag ng card na may Choose file sa itaas ng project list.
  • Keep a copy of imported media in the project. Naka-on bilang default. Ang larawan, bidyo o audio na idinagdag mo ay kinokopya sa loob ng proyekto, kaya patuloy itong gumagana kahit ilipat o burahin ang orihinal. I-off ito para makatipid sa storage kung hindi mo kailanman inililipat ang iyong mga file.
  • Remove caption model. Ipinapakita lang pagkatapos ma-download ang speech model para sa mga kapsyon. Ipinapakita nito ang laki ng file at binubura ito; muling idinodownload ng app ito kung gagamit ka ng mga kapsyon sa hinaharap.
  • Delete AI ... model. Isang row para sa bawat na-download na AI Enhance o AI Smooth model, kasama ang laki nito. Ang pag-tap dito ay binubura ang model; muling idinodownload ng app ito sa susunod na kailanganin.
  • Use the graphics chip for AI. Naka-on bilang default para lang sa mas bagong graphics chip na alam na ligtas para sa AI Smooth at AI Enhance; sa ibang phone, tumatakbo ang mga ito sa processor. Ang pag-on nito para sa ibang chip ay nagtatanong muna, dahil maaari nitong i-freeze ang ilang phone. Tingnan ang AI tools.

Backup

  • Back up all projects, Restore from backup at Weekly automatic backup (projects only) (naka-off bilang default). Tingnan ang Projects, backup and import.

Language

Ang row na Language ay nagpapakita ng kasalukuyang wika at binubuksan ang listahan ng 14 na wika. Ang pagpili ng isa ay agad itong inilalapat.

About, Help and other rows

  • Help binubuksan ang gabay na ito sa loob ng app, walang koneksyon.
  • About ipinapakita ang version, ang lisensya (Apache License 2.0), isang paalala na ang AbsentMotion ay isang independiyenteng proyekto, Open source licenses (ang buong teksto ng lisensya ng bawat library na ginagamit ng app) at ang address ng Project home page.
  • Crash logs naglilista ng mga crash na naitala ng app. I-tap ang isa para basahin ito at gamitin ang Copy para kopyahin ito, halimbawa para ipadala kasama ng bug report. Tingnan ang Troubleshooting.
  • Check for a new version each time the app opens. Ang app ay nagtatanong sa iyo nang isang beses kung maaari itong gawin. Kung naka-on, ang app ay gumagawa ng isang request sa GitHub para sa pinakabagong version number kapag binuksan ito. Wala itong ibang ipinapadala at hindi kailanman nagda-download o nag-i-install ng kahit ano nang mag-isa.
  • Check for Update ginagawa ang parehong check nang isang beses, ngayon. Kung may mas bagong version, ang Changelog ay binubuksan ang release notes nito at ang Download ay binubuksan ang download ng tugmang app file (Latest, Play services o Compatible version) sa iyong browser; kung hindi mahanap ang file na iyon, binubuksan nito ang release page.
