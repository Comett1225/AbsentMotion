Ang home screen

Ang iyong mga proyekto, asset at template, at ang mga button sa paligid ng mga ito.

Sa pahinang ito
  • Ang top bar
  • Ang bottom bar
  • Projects at Assets
  • Search
  • Pag-sort
  • Templates
  • Pag-import ng project file
  • Kapag may mali

Ang home screen ang unang makikita mo pagkatapos ng unang pag-start. Inililista nito ang iyong mga proyekto at may mga button para sa paggawa ng bago, paghahanap at pagbabago ng mga setting.

Ang top bar

  • Menu button (sa taas kaliwa, tatlong linya). Binubuksan ang Settings drawer.
  • AbsentMotion sa gitna.
  • Search (ang magnifier sa kanan). Binubuksan ang isang search field. Habang naghahanap, ipinapakita sa parehong lugar ang isang X para isara ito, at isinasara rin ito ng Back button.

Ang bottom bar

  • Projects at Templates ang nagpapalit sa dalawang pahina ng home screen.
  • Ang bilog na + button sa pagitan ng mga ito ay gumagawa ng bagong proyekto: tingnan ang Paggawa ng proyekto.

Projects at Assets

Ang Projects page ay may dalawang chip sa taas, Projects at Assets.

  • Ang Projects ay ang iyong mga bidyo at animation. I-tap ang isang card para buksan ito sa editor.
  • Ang Assets ay mga magagamit muli na bahagi na na-save mo mula sa isang proyekto o ginawa gamit ang ASSET option ng new project sheet. Idinaragdag mo ang mga ito sa ibang mga proyekto mula sa editor. Tingnan ang Assets, templates at presets.

Ang isang proyekto at isang asset ay iniimbak sa parehong paraan; magkahiwalay lamang silang naililista.

Ano ang ipinapakita ng isang card

Bawat card ay may thumbnail na may tagal ng proyekto sa sulok, ang pangalan, at dalawang linya ng mga detalye: ang aspect ratio (tulad ng 16:9) at ang resolusyon (tulad ng 1080p), pagkatapos ang file size at ang frame rate. Ang file size ay ang laki ng mismong project file. Hindi kasama dito ang mga larawan, bidyo at audio na ginagamit ng proyekto, kaya ang isang proyektong may oras-oras na bidyo ay maaaring magpakita pa rin ng ilang kilobyte.

Ang thumbnail ay isang still na kinuha kapag isinara mo ang editor, sa lugar kung saan naroon ang playhead. Ang isang proyektong hindi mo pa nabuksan sa editor ay maaaring magpakita ng walang laman na thumbnail.

Ang card menu

Ang three-dot button sa isang card (pinangalanang More) ay may mga entry na ito.

  • Ang Export ay direktang binubuksan ang export screen mula sa listahan. Ang mga "Current Frame" na opsyon ay gumagamit ng unang frame. Ito rin ang tanging lugar na nag-aalok ng XML export. Tingnan ang Export.
  • Ang Duplicate (Duplicate Asset para sa isang asset) ay gumagawa ng kopya na pinangalanang "name Copy", kasama ang media nito.
  • Ang Collect media into project ay kinokopya ang bawat file na ginagamit ng proyekto mula sa labas ng sarili nitong folder papunta sa proyekto, para hindi na ito umaasa sa iyong gallery. Tingnan ang Projects, backup at import.
  • Ang Version history ay nagpapakita ng mga naunang version ng proyekto at hinahayaan kang bumalik sa isa sa mga ito.
  • Ang Delete (Delete Asset) ay humihingi ng kumpirmasyon at pagkatapos ay tinatanggal ang proyekto, ang mga version nito at ang mga kopya ng media na walang ibang gumagamit. Walang trash: ang isang na-delete na proyekto ay hindi na maibabalik, kaya gumawa muna ng backup kung hindi ka sigurado.

Ang isang proyektong nasira ang file ay nagpapakita ng Damaged — restore a version sa halip na ang mga detalye nito. I-tap ito para i-restore ang isang naunang version, o i-delete ito.

Search

Isang search box ang nagsisilbi sa buong home screen. Sa Projects page, hinahanap nito ang mga pangalan ng proyekto at asset ("Search projects and assets"); sa Templates page, hinahanap nito ang mga template at preset. Hindi nito pinapansin ang malalaki at maliliit na letra at mga accent, at ang bawat salitang iyong itina-type ay dapat lumitaw sa pangalan, sa anumang pagkakasunod-sunod.

Pag-sort

Sa Projects at Assets na listahan, ipinapakita ng header ang Sort by Date o Sort by Name. I-tap ito para magpalit. Ang Date ay inilalagay ang pinakabago sa unahan, na nakagrupo sa ilalim ng mga date heading. Ang Name ay nagso-sort mula A hanggang Z. Tandaan ng app ang iyong pinili.

Templates

Ang Templates page ay may dalawang chip, My Templates at My Presets. Inilalarawan ang mga ito sa Assets, templates at presets.

Pag-import ng project file

Bilang default, ang home screen ay walang import button. Maaari mong buksan ang isang project file mula sa ibang app (isang file manager, isang mensahe) gamit ang Share o Open with, at tatanggapin ito ng app. Kung mas gusto mo ng button, i-on ang Show the import card in the project list sa Settings; may card na may Choose file na lilitaw sa taas ng Projects list. Tingnan ang Projects, backup at import.

Kapag may mali

  • Kung biglang nagsara ang app, ipapakita ng susunod na pag-start ang AbsentMotion closed unexpectedly kasama ang dahilan at, kung may mga hindi na-save na edit, isang alok na i-restore ang mga ito.
  • Ang mga crash log ay nasa Settings sa ilalim ng Crash logs.
  • Para sa isang lumang version, maaaring sabihan ka ng app tungkol sa mas bagong version: tingnan ang Settings.
