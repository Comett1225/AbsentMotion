Kusang nagsara ang app

Sinisigil ng Android ang mga app na gumagamit ng masyadong maraming memory. Malamang mangyari ito sa 4K na bidyo, maraming mabibigat na epekto, o ibang app na bukas nang sabay.

  1. Buksan muli ang AbsentMotion. Kung lalabas ang Kusang nagsara ang AbsentMotion, i-tap ang I-restore para mabalik ang huling mga edit mo.
  2. Isara ang ibang app, at subukan ulit ang proyekto.
  3. Bawasan ang Kalidad ng Preview sa Kalahati o Sangkapat sa preview strip o sa Mga Setting.
  4. I-on ang Gumamit ng preview copies ng malalaking bidyo sa Mga Setting (naka-on ito bilang default).
  5. I-export sa mas mababang resolusyon, o hatiin ang napakahabang proyekto.

Sa Mga Setting, ipinapakita ng Crash logs ang nangyari sa isang pangungusap para sa bawat crash. Kinokopya ito ng Kopyahin para maipadala mo kasama ng bug report sa GitHub. Walang awtomatikong ipinapadala.

Hindi kayang patakbuhin ng phone na ito ang editor

Ginagamit ng AbsentMotion ang graphics chip sa pamamagitan ng Vulkan 1.1, o ng OpenGL ES 3.0 kung wala nito ang phone, para iguhit ang preview at ang export. Kung walang gumana sa dalawa, ipinapakita ng app ang Hindi kayang patakbuhin ng phone na ito ang editor kasama ang bersyon ng Android at ang graphics chip sa halip na magsara. Bukas pa rin ang mga proyekto, setting, backup at crash log mo. Kinokopya ng Kopyahin ang detalye ang mga katotohanan para maidagdag mo sa bug report sa GitHub. Tingnan ang Mga Kinakailangan at bersyon. Kung bumubukas ang editor pero mali ang itsura ng preview o ng mga export, piliin ang OpenGL sa Mga setting, Graphics.

Nawawalang media

Walang laman ang isang layer, o sinasabi ng export na Nawawalang Media: wala na sa phone ang larawan, bidyo o audio file na ginamit ng proyekto.

  • Piliin ang layer, buksan ang Media Info sa menu ng layer at i-tap ang Palitan ang media file para piliin muli ang file.
  • Gamitin ang Kolektahin ang media sa proyekto sa menu ng project card habang nandiyan pa ang mga file, para may sariling kopya ang proyekto.
  • Panatilihing naka-on ang Magtabi ng kopya ng na-import na media sa proyekto sa Mga Setting.

Kung mag-e-export ka pa rin, hindi isasama ang mga layer na gumagamit ng nawawalang file.

Mga problema sa export

Bumabagal ang exportMainit ang phone. Sinasadya nitong bumagal para lumamig. Hayaang lumamig, o tanggalin ang case ng phone.

Nabigo ang Export, tumigil sa paggana ang video decoder o encoderMay ibang app na gumagamit ng video hardware ng phone. Isara ang mga app na nagpapatugtog o nagre-record ng bidyo at subukan ulit.
"Abala ang video encoder ng phone, kaya mas mabagal na software encoder ang gamit ng export na ito"Walang problema: mas matagal ang export. Isara ang ibang video app para bumalik ang mas mabilis na hardware encoder sa susunod.

Walang tunog ang na-export na bidyoMay silent na nakatagong layer, o clip na 0 % ang volume. Ang linyang "Sinuri: ..." sa Na-save sa storage screen ay nag-uulat ng nawawalang sound track.

Tuloy-tuloy ang export kahit lumipat ka sa ibang app, at may notification na nagpapakita ng progreso nito. Ititigil ito kapag isinara mo ang AbsentMotion mula sa listahan ng recent apps.

Puno ang storage

  • Magbura ng hindi ginagamit na proyekto sa home screen at lumang export sa Movies/AbsentMotion.
  • Nakakapagbakante ng hanggang 2 GB ang I-clear ang preview copies sa Mga Setting.
  • Maaaring malaki ang mga backup sa Documents/AbsentMotion: kopyahin ang mga ito sa computer at burahin sa phone.
  • Kung mabigo ang pag-save, sinasabi ito ng app. Magbakante ng espasyo at magpatuloy.

Mabagal

  • Bawasan ang Kalidad ng Preview.
  • Gamitin ang Mabilis na Blur na opsyon sa preview strip.
  • Mabibigat ang malalaking larawan at bidyo. Gumamit ng preview copies para sa bidyo, at liitan ang napakalalaking larawan bago idagdag.
  • Dumarami ang bigat ng maraming layer na may epekto. Itago ang mga layer na hindi mo ginagawa (i-tap ang mata).

Mali ang font na ginagamit ng teksto

Gumagamit ang proyekto ng font na wala sa phone na ito. Buksan ang proyekto at i-tap ang I-download sa Mga font na wala sa phone na ito. Isang beses lang kailangan ng internet connection ang mga font.

Mga tanong

Libre ba talaga? Oo. Walang subscription, walang account, walang watermark at walang advertising. Open source ito sa ilalim ng Apache License 2.0.

Kailangan ba ng internet? Hindi. Mga opsyonal na bagay lang ang gumagamit nito: pag-download ng Google Font, isang beses na pag-download ng caption model, at ang opsyonal na update check. Tingnan ang Privacy.

Nasaan ang mga proyekto ko? Sa private storage ng app, kasama ang bawat media file na idinagdag mo. I-backup ang mga ito mula sa Mga Setting. Nasa Movies, Pictures, Music at Documents sa ilalim ng AbsentMotion ang mga export.

Mapapalipat ko ba ang proyekto sa ibang phone? Oo: mag-export ng Project Bundle, kopyahin ang .absproj file sa ibang phone at buksan ito doon.

Mabubuksan ko ba ang mga proyekto mula sa ibang editor? Ang ilan. Tingnan ang Mga Proyekto, backup at import.

May computer version ba? Wala. Ginawa ang AbsentMotion para sa mga Android phone.

Anong mga wika ang available? English, Indonesian, Hindi, Portuguese (Brazil), Spanish, Filipino, Vietnamese, Thai, Malay, Arabic, Turkish at Russian. Palitan ito sa Mga Setting.

Paano ako mag-uulat ng problema o hihingi ng feature? Magbukas ng issue sa GitHub. Huwag magsama ng pribadong impormasyon dito.

Nasaan ang source code? Sa pahina ng proyekto sa GitHub.
