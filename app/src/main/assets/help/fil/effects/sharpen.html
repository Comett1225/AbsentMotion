Pagpapatalas

I-istilo · Idinagdag sa bersyon 2.1.0 o mas nauna

Naglalapat ng unsharp mask gamit ang 3x3 neighborhood para pagbutihin ang maliliit na detalye.

Ang Sharpen ay naglalabas ng pinong detalye. Ang Strength ay kung gaano kalakas, at ang Radius ay kung gaano kalawak ang mga sharpened na gilid. Ang sobrang dami ay gumagawa ng mga halo sa paligid ng mga gilid. Para sa ibang paraan ng sharpening, subukan ang Unsharp Mask.
