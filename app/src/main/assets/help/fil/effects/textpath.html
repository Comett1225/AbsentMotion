Teksto sa Path

Teksto · Idinagdag sa bersyon 4.2.0

Inilalagay ang teksto sa kahabaan ng arko, bilog, o outline ng layer na nasa ilalim mismo nito, titik por titik, habang napapanatili ang hugis ng mga titik, font, at emoji ng teksto.

Piliin ang Path: isang arc o bilog sa paligid ng text layer (i-drag ang mga point nito sa canvas o i-type ang mga ito), o Layer Below para sundan ang nasa mismong ilalim ng text sa listahan ng layer: isang pen path, isang shape, ang mga stroke ng isang drawing o ang mga titik ng ibang text. Sa bilog o anumang saradong outline, ang Position na 50 % ay naglalagay ng text sa gitna sa itaas, binabasa mula kaliwa pakanan, at ang 0 % ay ang ibaba; kapag naka-on ang Reverse Path, inilalagay ng 0 % ang text sa ibaba, binabasa pa rin mula kaliwa pakanan. Ang path na may ilang bahagi ay sinusundan nang isa-isang bahagi. Hindi nagwa-wrap ang text sa path ayon sa text box nito: ikaw mismo ang magsimula ng bagong linya para sa ikalawang hanay.
