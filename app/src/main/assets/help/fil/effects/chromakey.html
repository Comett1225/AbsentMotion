Chroma key

Key · Idinagdag sa bersyon 2.1.0 o mas nauna

Tinatanggal ang isang kulay, tulad ng green screen.

Ginagawang transparent ng Chroma Key ang isang kulay, halimbawa ay green screen. Piliin ang kulay gamit ang Key Color (berde bilang default). Ang Tolerance ay kung gaano kalawak ang hanay ng mga kulay sa paligid nito na tinatanggal, at ang Softness ay kung gaano kalambot ang gilid ng cut-out.

  1. Ilagay ang keyed na clip sa itaas ng background na gusto mong ipakita.
  2. Magdagdag ng Chroma Key at itakda ang Key Color sa kulay ng screen.
  3. Taasan ang Tolerance hanggang mawala ang screen. Kung may mga bahagi ng tao na nagsisimulang mawala, ibaba ito muli.
  4. Linisin ang gilid gamit ang Softness, Feather o Matte Choker.

Pantay-pantay na ilawan ang screen kapag nagfi-film ka: ang patag at maayos na nailawang kulay ang nagbibigay ng pinakamalinis na resulta.
