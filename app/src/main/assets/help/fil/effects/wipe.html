Wipe

Key · Idinagdag sa bersyon 3.0.0

Itinatago ang layer mula sa dalawang magkasalungat na gilid. I-animate ang Simula o Wakas para sa wipe transition.

Ang Wipe ay nagtatago ng layer mula sa dalawang magkasalungat na gilid. I-animate ang Start o End para ihayag o alisin ang layer gamit ang tuwid na gilid; ang Angle ay ang direksyon ng gilid at pinapalambot ito ng Feather. Para sa wipe na parang kamay ng orasan, gamitin ang Radial Wipe.
