Echo na keyframe

Galaw · Idinagdag sa bersyon 3.0.0

Gumuguhit ng mga kopya ng layer gaya ng ilang sandali ang nakalipas, sumusunod sa animation nito.

Ang Echo Keyframes ay gumuguhit ng mga kopya ng layer tulad ng itsura nito ilang sandali ang nakalipas, kaya ang gumagalaw na layer ay nag-iiwan ng bakas. Ang Seconds ay kung gaano kalayo ang nakalipas ng mga kopya, ang Count ay kung ilan ang mga ito, ang Alpha ay kung gaano sila kahayag, at ang Composite ay kung nasa Behind o Atop sila ng layer.
