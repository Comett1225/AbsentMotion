Pag-uulit · Idinagdag sa bersyon 3.0.0

Dynamic na gumagawa ng maraming kopya ng layer.

Ang Repeat ay gumagawa ng mga kopya ng layer, isa-isa nang sunod-sunod. Ang Count ay ang bilang ng mga kopya, ang Offset ay kung gaano kalayo ang bawat kopya mula sa nauna, ang Angle at Scale ay kung paano lumiliko at lumalaki ang bawat isa, at ang Time ay nagpapaantala sa bawat kopya para sumunod sila sa layer na parang trail. Para sa iba pang kaayusan tingnan ang Linear Repeat, Radial Repeat at Grid Repeat.
