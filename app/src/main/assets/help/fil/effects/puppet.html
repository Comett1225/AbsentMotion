Puppet Pin

Distort · Idinagdag sa bersyon 4.2.0

Binabaluktot ang layer na parang puppet: maglagay ng mga pin dito, tapos i-drag o i-animate ang mga pin at susundan sila ng larawan nang maayos.

Binabaluktot ng Puppet Pin ang isang layer gamit ang mga pin. I-on ang Magdagdag ng Pin at i-tap ang layer kung saan ito dapat bumaluktot, hanggang 32 pin. Pagkatapos ay i-off ang Magdagdag ng Pin at i-drag ang isang pin sa preview, o i-tap ang X o Y nito sa listahan para mag-type ng posisyon. Sumasama ang larawan sa ilalim ng pin na dina-drag mo, pinapanatili sa puwesto ng mga pin na hindi mo ginagalaw ang larawan, at hindi binabago ng bagong pin sa layer na nakabaluktot na ang larawan.

  • Itinatakda ng Falloff kung paano kumakalat ang baluktot: pinapanatili ito ng mataas na value malapit sa mga pin na ginagalaw mo, at ikinakalat ito nang maayos ng mababang value sa buong layer.
  • Para i-animate ang isang pin, i-tap ang pangalan nito sa listahan at gamitin ang keyframe button gaya ng sa ibang setting. Tingnan ang Mga keyframe at easing.
  • Ibinabalik ng arrow sa tabi ng pin ito sa kung saan nagsimula ang bahagi nito ng larawan, kaya nawawala ang baluktot ng pin na iyon. Binubura ng basurahan ang pin at ang mga keyframe nito.
  • Binabaluktot din ng Ilapat sa mga anak ang mga child layer, na parang bahagi sila ng larawan ng layer na ito.
  • Maglagay ng mga pin sa mga bahaging dapat manatili, gaya ng katawan kapag gumagalaw ka ng braso.
