Mga Proyekto, backup at import

Pag-save

Walang Save button. Pagkatapos ng bawat pagbabago, isinusulat ng editor ang proyekto sa telepono pagkaraan ng ilang sandali, sa paraang hindi kayang mag-iwan ng kalahating naisulat na file. Habang nasa gitna ka ng pag-drag, may draft ding isinusulat. Kung mabibigo ang pag-save dahil puno ang telepono, sasabihin ng app na "Could not save the project. Free some storage space." at muling susubukan.

Kasaysayan ng version

Tinatago ng app ang mga naunang version ng bawat proyekto. Naka-save ang isang version kapag binuksan mo ang proyekto, kapag isinara mo ito, at pagkatapos ng pag-save kung ang pinakabagong version ay hindi bababa sa dalawang minuto ang tanda. Nagtatago rin ito ng isa bago ang isang restore at bago mo sagutin ang isang tanong sa crash-recovery. Tinatago ng app ang 20 pinakabagong version at ang pinakabago sa bawat isa sa huling pitong araw, at binubura ang mga mas luma.

Buksan ito mula sa menu ng project card (Version history) o sa project settings ng editor (Earlier versions). May thumbnail, oras ("Today at 14:05", "Yesterday at 09:30") at Restore ang bawat row. Bago mag-restore, may tanong muna: "The project goes back to how it was ... The current state is kept in Version history, so nothing is lost."

Crash recovery

Kung biglang huminto ang app habang bukas ang isang proyekto, sa susunod na pag-start ay ipapakita ang AbsentMotion closed unexpectedly kasama ang dahilan sa isang pangungusap, tulad ng "It ran out of memory while exporting." Kung may mga hindi na-save na pagbabago, magtatanong ito ng "Restore your last edits to ...?" kasama ang Restore at Discard. Ang itinapong draft ay nananatili sa kasaysayan ng version ng proyekto.

Naisusulat din ang bawat crash sa Crash logs sa Settings: oras, dahilan sa isang pangungusap, version ng app at Android, modelo ng telepono, ginagawa mo noon, at ang teknikal na detalye. Tinatago ang huling 20. Walang ipinapadala kahit saan; makokopya mo ang isa para ikaw mismo ang magpadala.

Sirang proyekto

Kung hindi mabasa ang isang project file, sasabihin ng card nito na Damaged — restore a version. I-tap ito para mag-restore ng naunang version, o i-delete ito.

Mga media file

Ang mga larawan, bidyo at audio na idinadagdag mo ay, bilang default, kinokopya sa proyekto, para hindi umasa ang proyekto sa iyong gallery. I-off ito gamit ang Keep a copy of imported media in the project sa Settings kung gusto mong makatipid sa storage.

  • Collect media into project (menu ng project card) ay kinokopya ang bawat file na binabasa pa ng proyekto mula sa labas ng sarili nitong folder papunta sa proyekto. Sinusubukan muna nitong hanapin ang mga file na nawala.
  • Nawawalang media. Kapag wala na sa telepono ang isang file, hinahanap ito ng app sa iyong photo, video at audio library ayon sa eksaktong pangalan at laki kapag binuksan ang proyekto, at ginagamit ito kung eksaktong isang file ang tumutugma. Para ayusin ito nang manu-mano, piliin ang layer, buksan ang Media Info sa menu ng layer at piliin ang Swap media file. Kung mag-e-export ka na may nawawalang file, magbababala ang app at iiwan nito ang mga layer na iyon.

Backup at restore

Sa Settings, grupo Backup:

  • Back up all projects ay gumagawa ng isang file, AbsentMotion-backup- na sinusundan ng petsa at oras, na nagtatapos sa .absbackup, sa Documents/AbsentMotion. Naglalaman ito ng lahat ng proyekto kasama ang kanilang kasaysayan ng version, mga template kasama ang kanilang media, mga preset, mga na-import na font, mga resulta ng AI at lahat ng itinagong media. Kailangan nito ng libreng espasyo na halos kasinlaki ng content dagdag ang 50 MB. Nananatili ang file sa telepono kahit i-uninstall mo ang AbsentMotion; kopyahin ito sa computer o cloud service para mapanatiling ligtas.
  • Weekly automatic backup (projects only) ay off bilang default. Kapag on, ilang segundo pagkatapos magbukas ng app, kung lumipas na ang pitong araw mula sa huling backup, isusulat nito ang AbsentMotion-weekly-...absbackup kasama lamang ang mga proyekto (walang media) at buburahin ang naunang weekly file. Ang mga manual na backup ay hindi kailanman binubura ng app.
  • Restore from backup ay hihilingin sa iyong pumili ng backup file. Ang proyektong narito na at pareho ay hindi gagalawin; ang proyektong pareho ang pangalan pero iba ang nilalaman ay ire-restore bilang hiwalay na kopya. Walang umiiral na maa-overwrite. Ang restore ay maaaring ihinto at patakbuhin muli mamaya.

Pag-import ng mga project file

Mabubuksan mo ang isang project file mula sa ibang app (halimbawa isang file manager) gamit ang Share o Open with. Para sa import button sa home screen, i-on ang Show the import card in the project list: lalabas ang Choose file card sa itaas ng iyong mga proyekto.

FileAno ang makukuha mo
.absproj na ginawa ng AbsentMotionIsang normal na proyekto kasama ang media nito
Isang project package mula sa ibang editor (.amproj)Nagiging template ang bawat scene, at ang anumang asset ay nananatiling asset
Isang plain scene XML fileIsang normal na proyekto. Hindi sinusundan ang mga media link para sa kaligtasan, kaya lalabas ang media bilang nawawala maliban kung mahahanap ito sa gallery.

Ang mga epektong mayroon ang AbsentMotion ay kino-convert. Ang mga epektong wala ito ay nananatili sa file pero hindi iginuguhit. Pagkatapos ng import, ang ulat ay naglilista lamang ng mga hindi nakarating: mga epektong hindi nito kayang patakbuhin, mga setting na hindi naipasa, media na hindi natagpuan at mga font na hindi naka-install. Kapag nakarating ang lahat, walang ipinapakitang ulat. Ang mga backup file (.absbackup) ay nire-restore mula sa Settings, hindi ini-import dito.

May mga limitasyon para protektahan ang telepono. Halimbawa, ang isang package ay maaaring may hindi hihigit sa 2000 file at 32 proyekto, hindi hihigit sa 2 GB kapag na-unpack, at ang isang scene ay kailangan ng sukat na hindi hihigit sa 16384 pixels at frame rate mula 1 hanggang 240. Sasabihin ng app kung aling rule ang nilabag ng isang file.

Mga file format at kung saan nakalagay ang mga bagay

  • Ang isang proyekto ay isang XML text file. Nakalagay ang media sa tabi nito sa private folder ng proyekto.
  • Ang isang .absproj ay ZIP: project.xml, isang manifest.json at ang mga media file sa ilalim ng media/. Ang mga 3D model ay nagtatalaga ng kanilang mga file sa isang folder.
  • Ang isang .absbackup ay ZIP na may bawat proyekto, preset, template, font at media file.
  • Private app storage (tinatanggal kapag nag-uninstall ka): mga proyekto at ang kanilang mga thumbnail, kasaysayan ng version, itinagong media, mga template, mga preset, crash drafts, crash logs, mga na-import na font, ang caption model, mga preview copy at mga resulta ng AI.
  • Shared storage (nananatili kapag nag-uninstall ka): Movies/AbsentMotion (mga bidyo), Pictures/AbsentMotion (mga GIF, still frame at image sequence), Music/AbsentMotion (mga audio export), Documents/AbsentMotion (.absproj, XML at mga backup) at DCIM/AbsentMotion (mga larawan at bidyo mula sa in-app na kamera).

Hindi ginagamit ng AbsentMotion ang malawak na "all files" permission: nagse-save ito sa pamamagitan ng media storage ng Android.
