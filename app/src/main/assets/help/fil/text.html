Teksto at mga font

Magdagdag ng teksto

I-tap ang + na button at pagkatapos ay Teksto. May naidagdag na text layer sa gitna ng canvas (kulay abo, Roboto Regular, 18 pt, naka-left align) at agad na bubukas ang full-screen na text editor.

Sa itaas ng editor:

  • Paulit-ulit na pinapalitan ng Alignment ang left, center, right at justify.
  • Binubuksan ng pangalan ng font (ipinapakita sa sarili nitong estilo) ang isang strip na may mga recent font mo, mga paborito mo at Show All Fonts.
  • Binubuksan ng size na button (tulad ng "18pt") ang isang slider na may 25 na sukat mula 5 hanggang 144 pt.
  • Binubuksan ng color na swatch ang color picker na may eyedropper.
  • Isinasara ng tick (Done) ang editor.

Sa ilalim ng mga ito ay ang preview at pagkatapos ay ang text box, na nagsasabing "Enter your text here." hanggang sa mag-type ka. I-drag ang round handle sa gilid ng text frame sa preview para baguhin ang lapad kung saan nagbabalot ang mga linya. Ang pangalan ng text layer ay ang teksto nito, hanggang sa palitan mo ang pangalan.

Para i-edit ang teksto mamaya, piliin ang layer at i-tap ang Edit Text.

I-style ang teksto

Gumagana ang ibang mga tool sa teksto tulad ng sa anumang layer.

  • Nagbibigay ang Fill & Color sa mga letra ng kulay, gradient o larawan o bidyo (Media).
  • Frame & Shadow: Ang Stroke ay ang outline ng mga letra. Nagdadagdag pa ang Border at Shadow.
  • Gumagana ang Opacity & Blend Mode, Transform at Effects tulad ng para sa mga hugis.
  • Ginagawang hugis ng Convert to Outline (layer menu) ang teksto na puwede mong i-edit point by point. Hindi na ito maibabalik sa teksto.

Sumusunod ang emoji sa Emoji Style na setting: ang emoji ng iyong telepono o ang set na kasama ng app. Tingnan ang Mga setting.

Mga font

May 150 font family ang catalog. 50 sa mga ito ay built-in sa app. Ang iba pang 100 ay dinodownload mula sa Google Fonts sa unang pagkakataong pumili ka ng isa (nagpapakita sila ng cloud icon at "Downloads when chosen"; kailangan ng internet connection ang download). Ang proyektong gumagamit ng mga font na wala ka ay nagpapakita ng Fonts not on this phone kapag binuksan mo ito, at gumagamit ang teksto ng ibang font hanggang sa i-download mo ang mga ito.

Ang font browser

Binubuksan ng Show All Fonts ang isang grid ng mga font, bawat isa ay may sample. Sa itaas ay may menu button na nagbubukas ng drawer na may mga filter na ito:

  • Mga kategorya: Serif, Sans Serif, Display, Handwriting, Monospace, Favorite at Imported.
  • Sorting: Popular o Alphabetical.
  • Languages: All Languages o isa sa labing-anim na script tulad ng Arabic, Cyrillic, Greek, Hebrew, Japanese, Korean, Chinese, Thai, Vietnamese at Latin.
  • Import Fonts.

Ang search field sa itaas ay may label na "Type here to search". Minamarkahan ng star sa isang font na paborito mo ito.

Sarili mong mga font

Hinahayaan ka ng Import Fonts na pumili ng mga font file mula sa iyong telepono. Kung may file na hindi magamit, may listahan na nagsasabi kung alin ang nabigo. Pindutin at hawakan ang isang imported na font para alisin ito.

I-animate ang teksto

Ina-animate ng mga epekto ng Teksto na kategorya ang teksto letra by letra.

  • Inilalantad ng Text Progress ang teksto by character, word o line (ang typewriter at fade in by word ay mga preset).
  • Ginagalaw, iniikot, ini-scale at pinapadilim ng Text Transform ang bawat letra nang isa-isa (mga preset: Wave at Spin Cascade).
  • Hinahalo ng Text Randomizer ang mga letra bago sila mag-settle (preset: Scramble).
  • Ginagawang counter o orasan ng Count Up/Down at Timecode ang teksto.

Tingnan ang Paggamit ng mga epekto para sa kung paano idagdag ang mga ito, at ang effects library para sa bawat setting.

Mga kapsyon

Nakikinig ang Auto Captions sa pagsasalita sa isang bidyo o tunog at gumagawa ng isang text layer bawat kapsyon, sa telepono at offline. Tingnan ang Mga AI tool.
