สารบัญเอฟเฟกต์

แอสเซท เทมเพลต และพรีเซ็ต

นำผลงานที่ดีที่สุดของคุณกลับมาใช้ซ้ำ: บันทึกเลเยอร์เป็นแอสเซท เริ่มต้นจากเทมเพลต และเก็บลุคที่คุณชอบไว้เป็นพรีเซ็ต

ในหน้านี้
  • แอสเซท
  • เทมเพลต
  • พรีเซ็ต

AbsentMotion มีสามวิธีในการนำงานกลับมาใช้ซ้ำ ซึ่งแตกต่างกันในสิ่งที่เก็บไว้

เก็บใช้จาก
แอสเซทเลเยอร์หรือแอนิเมชันทั้งหมด ที่เชื่อมโยงกับต้นฉบับเมนู Add, Object / Asset
เทมเพลตโปรเจกต์ทั้งหมดที่มีจุดให้คุณสลับสื่อของคุณเองเข้าไปเมนู Add, Template; หน้าจอหลัก, Templates
พรีเซ็ตลุคและการเคลื่อนไหวของเลเยอร์หนึ่ง (เอฟเฟกต์ คีย์เฟรม ขอบ โหมดผสม และอื่นๆ)ตารางเครื่องมือ, Presets

แอสเซท

สร้างแอสเซท

  • ในตัวแก้ไข เลือกเลเยอร์หรือกลุ่มแล้วเลือก Save to My Assets ในเมนูเลเยอร์ ข้อความจะแจ้งว่า "Saved to My Assets"
  • บนหน้าจอหลัก เลือก ASSET ในชีตโปรเจกต์ใหม่ แล้วสร้างแอนิเมชันในโปรเจกต์ของตัวเอง โปรเจกต์แอสเซทมีพื้นหลังโปร่งใส

แอสเซทจะปรากฏใต้ชิป Assets ของหน้าจอหลัก

ใช้แอสเซท

Add, Object / Asset, Asset / Project แสดงรายการแอสเซทของคุณ (ใหม่ที่สุดก่อน) ตามด้วยโปรเจกต์อื่นๆ พร้อมช่องค้นหา แตะหนึ่งรายการเพื่อแทรกเป็นกลุ่มที่หัวอ่าน แอสเซทยังคง เชื่อมโยง กับแอสเซทต้นฉบับ ส่วนโปรเจกต์ที่แทรกด้วยวิธีนี้จะเป็นสำเนาอิสระธรรมดาแทน

เลเยอร์ที่เชื่อมโยงมีเครื่องมือ Asset Properties พร้อมสองปุ่ม

  • Open original Asset เปิดโปรเจกต์ของแอสเซทนั้นเพื่อให้คุณแก้ไข หากโปรเจกต์นั้นถูกลบ แอปจะเสนอ Rebuild Source Project (สร้างโปรเจกต์จากเลเยอร์นี้) หรือ Unlink from Asset
  • Unlink from Asset เปลี่ยนเลเยอร์ให้เป็นกลุ่มธรรมดาที่คุณแก้ไขได้อย่างอิสระ

โปรเจกต์แอสเซท

ภายในโปรเจกต์แอสเซท ชีตการตั้งค่าโปรเจกต์มีแถวเพิ่มอีกสองแถว

  • Precompose เลือก Adaptive Resolution หรือ Locked Resolution สำหรับแอสเซท
  • Re-timing กำหนดสิ่งที่จะเกิดขึ้นเมื่อวางแอสเซทบนคลิปที่ยาวกว่าความยาวของมันเอง: Freeze (คงเฟรมสุดท้ายของส่วนตรงกลาง), Stretch, Loop, Repeat & Stretch หรือ Blank (ไม่มีอะไรหลังความยาวของมันเอง)

เมนูคัดลอกและวางยังมี Set intro end และ Set outro start เพิ่มขึ้น ซึ่งจะวางธงสีทองบนไม้บรรทัด: ส่วนก่อนจุดสิ้นสุดอินโทรและหลังจุดเริ่มเอาต์โทรจะคงความเร็วจริงไว้ ขณะที่ส่วนตรงกลางถูกยืด วนซ้ำ หรือหยุดนิ่ง

เทมเพลต

เทมเพลตคือโปรเจกต์ที่เสร็จสมบูรณ์ซึ่งทุกรูปภาพหรือวิดีโอเป็นช่องที่คุณแทนที่ได้

ใช้เทมเพลต

  1. บนหน้าจอหลัก เปิดหน้า Templates และชิป My Templates แล้วแตะเทมเพลต จากภายในตัวแก้ไขคุณสามารถใช้ Add, Template แทนได้
  2. หน้าจอ Use Template แสดงตัวอย่างและแถว Media slots แตะช่องเพื่อเลือก (หัวอ่านจะกระโดดไปยังจุดที่ช่องเริ่ม) แล้วแตะอีกครั้งเพื่อเลือกภาพถ่ายหรือวิดีโอของคุณเอง
  3. ไอคอนมุมของช่องเปลี่ยนวิธีการปรับขนาดสื่อ: fill, fit หรือ stretch
  4. หากวิดีโอของคุณยาวกว่าช่อง หน้าจอชื่อ Drag across to select จะให้คุณเลือกส่วนที่จะใช้ หากสั้นกว่า เฟรมสุดท้ายจะถูกคงไว้และแอปจะแจ้งให้คุณทราบ
  5. แตะ Next แล้วแตะ Go to Timeline จะสร้างโปรเจกต์ใหม่ ตัวเทมเพลตเองจะไม่ถูกเปลี่ยนแปลง

Open as project ในเมนูของเทมเพลตจะข้ามหน้าจอสลับสื่อและสร้างโปรเจกต์ใหม่ทันที เทมเพลตยังสามารถเปลี่ยนชื่อและลบได้จากเมนูนั้น

สร้างเทมเพลต

  • เปิดสวิตช์ Also keep a copy as a Template บนหน้าจอส่งออกก่อนที่คุณจะส่งออก ซึ่งจะเก็บโปรเจกต์พร้อมสื่อไว้ใน Templates บนโทรศัพท์เครื่องนี้ และทำงานหลังจากส่งออกสำเร็จ
  • แพ็กเกจที่คุณนำเข้าจากตัวแก้ไขอื่นจะมาถึงในรูปแบบเทมเพลต: ดู Projects, backup and import

พรีเซ็ต

พรีเซ็ตเก็บลุคของเลเยอร์ไว้เพื่อให้คุณนำไปใส่บนเลเยอร์อื่นได้

บันทึกพรีเซ็ต

เลือกเลเยอร์แล้วเลือก Save Preset ในเมนูคัดลอกและวาง (ปุ่มที่หกของแถบเล่น) ใช้ได้เฉพาะเมื่อเลเยอร์มีสิ่งที่จะเก็บ: เส้นขอบ ขอบ หรือเงา, เอฟเฟกต์, โหมดผสมอื่นที่ไม่ใช่ Normal, ความทึบที่เปลี่ยนแปลง, ตำแหน่งหรือขนาดที่เคลื่อนไหว, ระดับเสียงหรือความเร็วที่เปลี่ยนแปลง หรือฟอนต์ที่เปลี่ยนแปลง หลังจากบันทึกแล้ว คุณสามารถ Name it

ใช้พรีเซ็ต

เลือกเลเยอร์อื่นแล้วแตะ Presets ในตารางเครื่องมือ หน้าจอ Try a Preset แสดงเลเยอร์เดี่ยวพร้อมพรีเซ็ตของคุณที่ใช้แล้ว แตะพรีเซ็ตเพื่อลอง แตะตัวอย่างเพื่อเล่น และแตะ Apply เพื่อคงไว้ พรีเซ็ตแต่ละอันมี Rename และ Delete ในเมนู

พรีเซ็ตจะแทนที่ขอบ เงา โหมดผสม และความทึบ, การแปลงที่เคลื่อนไหว, เอฟเฟกต์, สไตล์ข้อความ (ข้อความเป็นข้อความ), ระดับเสียงและเอฟเฟกต์เสียง (เสียงเป็นเสียง) และความเร็ว (คลิปเป็นคลิป) แต่จะไม่เปลี่ยนสีเติม รูปร่าง เนื้อหา หรือการจับเวลา

ไม่มีพรีเซ็ตในตัว: มีเฉพาะที่คุณบันทึกเท่านั้น พรีเซ็ตจะแสดงบนหน้าจอหลักใต้ Templates, My Presets ซึ่งคุณสามารถเปลี่ยนชื่อและลบได้
