ข้อความตามเส้นทาง

ข้อความ · เพิ่มในเวอร์ชัน 4.2.0

วางข้อความไปตามส่วนโค้ง วงกลม หรือเส้นขอบของเลเยอร์ที่อยู่ด้านล่างทีละตัวอักษร โดยคงรูปตัวอักษร ฟอนต์ และอีโมจิของข้อความไว้

เลือก Path: ส่วนโค้งหรือวงกลมรอบเลเยอร์ข้อความ (ลากจุดบนแคนวาสหรือพิมพ์ค่า) หรือ Layer Below เพื่อให้ข้อความไหลตามสิ่งที่อยู่ใต้ข้อความโดยตรงในรายการเลเยอร์: เส้นทางปากกา รูปทรง เส้นของภาพวาด หรือตัวอักษรของข้อความอื่น บนวงกลมหรือเส้นขอบปิดใดๆ Position ที่ 50 % จะวางข้อความไว้ตรงกลางด้านบน อ่านจากซ้ายไปขวา และ 0 % คือด้านล่าง เมื่อเปิด Reverse Path ค่า 0 % จะวางข้อความไปตามด้านล่าง และยังอ่านจากซ้ายไปขวา เส้นทางที่มีหลายส่วนจะไหลตามทีละส่วน ข้อความบนเส้นทางจะไม่ตัดบรรทัดตามกล่องข้อความ: ขึ้นบรรทัดใหม่เองหากต้องการแถวที่สอง
