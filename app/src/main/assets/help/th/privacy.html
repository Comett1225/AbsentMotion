โปรเจกต์และสื่อของคุณ

โปรเจกต์ รูปภาพ วิดีโอ และเสียงที่นำเข้า และทุกอย่างที่คุณส่งออก ยังคงอยู่ในโทรศัพท์ของคุณ สิทธิ์การเข้าถึงรูปภาพ วิดีโอ และเสียงทำให้แอปแสดงคลังของคุณและใช้ไฟล์ที่คุณเลือก บนโทรศัพท์ ไม่มีสิ่งใดถูกอัปโหลด

สิทธิ์การเข้าถึงกล้องและไมโครโฟนใช้เฉพาะโดยกล้องในแอป ขณะที่เปิดอยู่ การบันทึกถูกบันทึกไว้ในโทรศัพท์ การสำรองข้อมูลถูกเขียนไปยัง Documents/AbsentMotion ในโทรศัพท์และอยู่ที่นั่น

ขณะที่การส่งออกทำงาน แอปจะแสดงความคืบหน้าในการแจ้งเตือน เพื่อให้การส่งออกดำเนินต่อได้เมื่อคุณสลับไปยังแอปอื่น บน Android 13 และใหม่กว่า แอปจะขอสิทธิ์การแจ้งเตือนเมื่อส่งออกครั้งแรก การส่งออกทำงานเหมือนเดิมหากคุณปฏิเสธ

หากแอปปิดโดยไม่คาดคิด แอปจะเก็บบันทึกการขัดข้องไว้ในพื้นที่จัดเก็บของตัวเอง: เวลาที่เกิด สาเหตุในหนึ่งประโยค เวอร์ชันแอปและ Android รุ่นโทรศัพท์ สิ่งที่คุณกำลังทำ และข้อผิดพลาดทางเทคนิค เก็บไว้เพียง 20 รายการล่าสุดเท่านั้น ไม่รวมอยู่ในการสำรองข้อมูลโทรศัพท์ และไม่เคยถูกส่งไปที่ใด คุณสามารถอ่าน คัดลอก หรือลบได้ในการตั้งค่า

เมื่อแอปใช้อินเทอร์เน็ต

แอปขอสิทธิ์การเข้าถึงอินเทอร์เน็ตสำหรับสิ่งเหล่านี้เท่านั้น:

  • ฟอนต์ เมื่อคุณเลือกหนึ่งในฟอนต์ที่ดาวน์โหลดได้ แอปจะดาวน์โหลดจาก Google Fonts Google จะได้รับคำขอสำหรับฟอนต์นั้นและที่อยู่ IP ของคุณ เช่นเดียวกับคำขอเว็บใดๆ
  • คำบรรยายอัตโนมัติ ครั้งแรกที่คุณสร้างคำบรรยาย แอปจะแจ้งขนาดของโมเดลการรู้จำเสียงพูด (ประมาณ 57 MB) และดาวน์โหลดจาก Hugging Face การรู้จำเสียงพูดทำงานบนโทรศัพท์
  • AI Enhance และ AI Smooth ครั้งแรกที่คุณใช้อย่างใดอย่างหนึ่ง แอปจะแจ้งขนาดของโมเดลที่ต้องการ (ประมาณ 1 ถึง 11 MB) และดาวน์โหลดจาก GitHub งาน AI เองทำงานบนโทรศัพท์
  • การลบพื้นหลังด้วย AI 2.0 เฉพาะเมื่อคุณเลือกการลบพื้นหลังด้วย AI 2.0 สำหรับการลบพื้นหลัง แอปจะดาวน์โหลดโมเดลหนึ่งครั้ง (ประมาณ 62 MB) จาก GitHub การตัดพื้นหลังเองทำงานบนโทรศัพท์
  • การตรวจสอบอัปเดต หากคุณอนุญาต (แอปจะถามครั้งเดียว สวิตช์อยู่ในการตั้งค่า) แอปจะส่งคำขอ HTTPS ปกติหนึ่งครั้งไปยัง GitHub ทุกครั้งที่เปิด เพื่ออ่านหมายเลขเวอร์ชันล่าสุด ไม่มีสิ่งอื่นถูกส่ง GitHub จะเห็นที่อยู่ IP ของคุณ เช่นเดียวกับคำขอเว็บใดๆ

นอกเหนือจากบิลด์ Play-services ที่อธิบายด้านล่าง ไม่มีสิ่งอื่นถูกส่งไปที่ใด การแปลงข้อความเป็นเสียงพูดใช้เสียงที่มีอยู่ในโทรศัพท์และทำงานแบบออฟไลน์

บิลด์ Play-services

บิลด์ที่มี Google Play services (-play.apk) ลบพื้นหลังด้วย Google ML Kit การลบเองทำงานบนโทรศัพท์ แต่ Google Play services ดาวน์โหลดโมเดลเมื่อจำเป็นครั้งแรกและอาจส่งข้อมูลวินิจฉัยไปยัง Google เช่น ข้อมูลอุปกรณ์ ตัวเลขประสิทธิภาพ และรหัสข้อผิดพลาด ภายใต้นโยบายของ Google เอง บิลด์มาตรฐาน (-foss.apk) ไม่มีไลบรารีของ Google: โมเดลออฟไลน์ของตัวเองเป็นส่วนหนึ่งของแอป จึงไม่มีสิ่งใดถูกดาวน์โหลดหรือส่งสำหรับการลบพื้นหลัง

สัญญาอนุญาตและซอร์ส

AbsentMotion ฟรีและโอเพนซอร์ส เผยแพร่ภายใต้ Apache License 2.0 ซอร์สโค้ดอยู่ที่ หน้าของโปรเจกต์บน GitHub ซอฟต์แวร์ของบุคคลที่สามที่ใช้ (Skia, whisper.cpp, RNNoise, LAME, AndroidX Compose และอื่นๆ) และสัญญาอนุญาตของซอฟต์แวร์เหล่านั้นระบุไว้ใน THIRD_PARTY_NOTICES.md และในแอป: การตั้งค่า เกี่ยวกับ สัญญาอนุญาตโอเพนซอร์ส

AbsentMotion เป็นโปรเจกต์อิสระ ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง หรือสนับสนุนโดยผู้พัฒนาแอปอื่นใด ชื่อของผลิตภัณฑ์อื่นเป็นของผู้เป็นเจ้าของ
