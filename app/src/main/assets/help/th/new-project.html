สารบัญเอฟเฟกต์

การสร้างโปรเจกต์

ทุกการตั้งค่าของแผ่นสร้างโปรเจกต์ใหม่ และการเริ่มต้นจากกล้อง

ในหน้านี้
  • โปรเจกต์หรือแอสเซท
  • ชื่อ
  • รูปร่างของภาพ (อัตราส่วนภาพ)
  • ความละเอียด
  • เฟรมเรต
  • พื้นหลัง
  • ปุ่มที่ด้านล่าง
  • เริ่มต้นจากกล้อง

แตะ + วงกลมที่ด้านล่างของหน้าจอหลัก แผ่นจะเลื่อนขึ้นมาจากด้านล่าง โดยเปิดด้วยค่าที่คุณใช้ครั้งล่าสุด (รูปร่าง ความละเอียด เฟรมเรต และพื้นหลัง ส่วนชื่อจะเป็นชื่อใหม่เสมอ) แตะ Back เพื่อปิดโดยไม่สร้างอะไร

โปรเจกต์หรือแอสเซท

สวิตช์ด้านบนมีสองตัวเลือก PROJECT (ค่าเริ่มต้น) และ ASSET แอสเซทคือชิ้นงานที่ใช้ซ้ำได้โดยมีพื้นหลังโปร่งใส: การตั้งค่าพื้นหลังจะถูกล็อกเป็น Transparent ดู แอสเซท เทมเพลต และพรีเซ็ต

ชื่อ

ชื่อเริ่มต้นเป็น "New Project 1", "New Project 2" ไปเรื่อย ๆ (แอสเซทเริ่มเป็น "New Asset") แตะ X ในช่องเพื่อล้างชื่อ ชื่อว่างจะกลับไปใช้ค่าเริ่มต้น

รูปร่างของภาพ (อัตราส่วนภาพ)

ปุ่มสำหรับ 16:9, 9:16, 4:5, 1:1 และ 4:3 และปุ่มดินสอสำหรับ อัตราส่วนภาพกำหนดเอง ค่าเริ่มต้นคือ 1:1 เลือก 9:16 สำหรับวิดีโอโทรศัพท์ และ 16:9 สำหรับวิดีโอแนวนอน

ความละเอียด

แถว ความละเอียด แสดงขนาดผืนผ้าใบ เช่น 1920 x 1080 สำหรับรูปร่างทั้งห้าแบบ จะเป็นรายการของด้านสั้น:

ตัวเลือกด้านสั้น
2160p (4k)2160
1440p (QHD)1440
1080p (FHD), ค่าเริ่มต้น1080
720p (HD)720
540p (SD), 360p, 270p, 180pตามชื่อ

ด้านยาวจะตามรูปร่าง โปรเจกต์ 16:9 ที่ 1080p คือ 1920 x 1080 โปรเจกต์ 4:5 คือ 1080 x 1350 และโปรเจกต์ 4:3 คือ 1440 x 1080

เมื่อใช้ อัตราส่วนภาพกำหนดเอง รายการจะกลายเป็นช่องตัวเลขสองช่องสำหรับความกว้างและความสูง โดยมีปุ่ม Link วงกลมอยู่ระหว่างกัน เมื่อ Link เปิดอยู่ การเปลี่ยนด้านหนึ่งจะคงรูปร่างที่สองช่องมีตอนที่คุณเปิด Link แต่ละด้านสามารถอยู่ระหว่าง 32 ถึง 4096 พิกเซล แอปจะแก้ไขค่าให้เมื่อคุณออกจากช่อง

ผืนผ้าใบที่ใหญ่ขึ้นจะดูคมชัดขึ้นแต่ใช้หน่วยความจำมากขึ้นและส่งออกนานขึ้น 1080p เป็นตัวเลือกที่ดีสำหรับโปรเจกต์ส่วนใหญ่ คุณสามารถเปลี่ยนความละเอียดภายหลังได้ในการตั้งค่าโปรเจกต์ของตัวแก้ไข ซึ่งจะไม่ปรับขนาดเลเยอร์ของคุณ

เฟรมเรต

เลือก 12, 15, 18, 20, 24, 25, 30, 48, 50 หรือ 60 เฟรมต่อวินาที ค่าเริ่มต้นคือ 60 ใช้ 24 หรือ 30 สำหรับลุคภาพยนตร์และไฟล์ที่เล็กลง และ 60 สำหรับการเคลื่อนไหวเร็วที่ลื่นไหล การตั้งค่านี้กำหนดความถี่ที่ตัวแก้ไขและการส่งออกวาดภาพ คลิปวิดีโอจะคงเฟรมเรตของตัวเองไว้ ดูตัวเลือกการแทรกเฟรมบนหน้า ส่งออก

พื้นหลัง

สีที่อยู่หลังเลเยอร์ของคุณ: Black, White, Light Gray, Green, Blue หรือ Transparent (แสดงเป็นลายตารางหมากรุก) การติดตั้งใหม่จะเริ่มด้วย Transparent พื้นที่โปร่งใสของวิดีโอที่ส่งออกจะออกมาเป็นสีดำ การส่งออก GIF และรูปภาพให้คุณเลือกว่าพื้นที่โปร่งใสจะกลายเป็นอะไร และ PNG จะคงไว้

ปุ่มที่ด้านล่าง

  • CREATE PROJECT (CREATE ASSET สำหรับแอสเซท) สร้างโปรเจกต์และเปิดตัวแก้ไขบนโปรเจกต์นั้น
  • FROM CAMERA เปิดกล้อง: ดูด้านล่าง
  • X ใต้ปุ่มเหล่านั้นปิดแผ่น

หากพื้นที่จัดเก็บไม่เพียงพอ แอปจะแจ้งและจะไม่สร้างโปรเจกต์

เริ่มต้นจากกล้อง

FROM CAMERA เปิดกล้องในแอปด้วยรูปร่างที่คุณเลือก คุณสามารถถ่ายภาพหรือบันทึกวิดีโอ และโปรเจกต์จะถูกสร้างขึ้นรอบ ๆ สิ่งนั้น: ภาพที่บันทึกจะเป็นเลเยอร์แรก และผืนผ้าใบจะมีขนาดตามภาพที่บันทึก (ย่อลงหากจำเป็นเพื่อให้ด้านสั้นไม่เกินความละเอียดที่คุณเลือก)

  • แถวบนมี Flash (ไฟฉายสำหรับวิดีโอ), Timer (ปิด, 3 วินาที, 10 วินาที) และ Grid
  • PHOTO และ VIDEO สลับโหมด แตะปุ่มใหญ่เพื่อถ่ายภาพหรือเริ่มและหยุดบันทึก ขณะบันทึกคุณสามารถหยุดชั่วคราวและบันทึกต่อได้
  • แตะภาพเพื่อโฟกัส หยิกเพื่อซูม และใช้ Switch camera เพื่อสลับระหว่างกล้องหน้าและหลัง
  • ครั้งแรก แอปจะขอสิทธิ์เข้าถึงกล้อง และขอไมโครโฟนหากคุณต้องการเสียง หากไม่มีไมโครโฟน การบันทึกยังทำงานได้แต่จะไม่มีเสียง
  • ภาพถ่ายและวิดีโอจะถูกบันทึกลงแกลเลอรีของคุณใน DCIM/AbsentMotion และสำเนาจะถูกเก็บไว้ในโปรเจกต์
