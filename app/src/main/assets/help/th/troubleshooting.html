แอปปิดตัวเอง

Android จะปิดแอปที่ใช้หน่วยความจำมากเกินไป สิ่งนี้มีแนวโน้มมากที่สุดกับวิดีโอ 4K เอฟเฟกต์หนักๆ หลายตัว หรือแอปอื่นๆ ที่เปิดอยู่พร้อมกัน

  1. เปิด AbsentMotion อีกครั้ง หากแสดง AbsentMotion ปิดโดยไม่คาดคิด ให้แตะ กู้คืน เพื่อรับการแก้ไขล่าสุดของคุณกลับมา
  2. ปิดแอปอื่นๆ แล้วลองโปรเจกต์อีกครั้ง
  3. ลด คุณภาพตัวอย่าง เป็นครึ่งหรือหนึ่งในสี่ในแถบตัวอย่างหรือในการตั้งค่า
  4. เปิด ใช้สำเนาตัวอย่างของวิดีโอขนาดใหญ่ ในการตั้งค่า (เปิดเป็นค่าเริ่มต้น)
  5. ส่งออกที่ความละเอียดต่ำลง หรือแยกโปรเจกต์ที่ยาวมาก

การตั้งค่า บันทึกการแครช แสดงสิ่งที่เกิดขึ้นในหนึ่งประโยคสำหรับแต่ละการแครช คัดลอก คัดลอกไว้เพื่อให้คุณส่งพร้อมรายงานข้อบกพร่องบน GitHub ไม่มีสิ่งใดถูกส่งโดยอัตโนมัติ

โทรศัพท์นี้ไม่สามารถรันตัวแก้ไขได้

AbsentMotion วาดตัวอย่างและการส่งออกด้วยชิปกราฟิกผ่าน Vulkan 1.1 หากไดรเวอร์กราฟิกของโทรศัพท์ไม่มีให้ แอปจะแสดง โทรศัพท์นี้ไม่สามารถรันตัวแก้ไขได้ พร้อมเวอร์ชัน Android และชิปกราฟิกแทนที่จะปิด โปรเจกต์ การตั้งค่า สำรองข้อมูล และบันทึกการแครชของคุณยังคงเปิดได้ คัดลอกรายละเอียด คัดลอกข้อเท็จจริงเพื่อให้คุณเพิ่มลงในรายงานข้อบกพร่องบน GitHub ดู ข้อกำหนดและเวอร์ชัน

สื่อหาย

เลเยอร์ว่างเปล่า หรือการส่งออกระบุ สื่อหาย: รูปภาพ วิดีโอ หรือไฟล์เสียงที่โปรเจกต์ใช้ไม่อยู่บนโทรศัพท์อีกต่อไป

  • เลือกเลเยอร์ เปิด ข้อมูลสื่อ ในเมนูเลเยอร์ แล้วแตะ สลับไฟล์สื่อ เพื่อเลือกไฟล์อีกครั้ง
  • ใช้ รวบรวมสื่อลงในโปรเจกต์ ในเมนูการ์ดโปรเจกต์ขณะที่ไฟล์ยังอยู่ เพื่อให้โปรเจกต์เก็บสำเนาของตัวเอง
  • เปิด เก็บสำเนาสื่อที่นำเข้าไว้ในโปรเจกต์ ในการตั้งค่า

หากคุณส่งออกต่อไป เลเยอร์ที่ใช้ไฟล์ที่หายไปจะถูกตัดออก

ปัญหาการส่งออก

ข้อความสิ่งที่ต้องทำ
พื้นที่จัดเก็บไม่เพียงพอเพิ่มพื้นที่ว่างบนโทรศัพท์หรือเลือกความละเอียดที่เล็กกว่า ขนาดโดยประมาณอยู่บนหน้าจอส่งออก
ไม่รองรับบนโทรศัพท์นี้ตัวเข้ารหัสของโทรศัพท์ไม่สามารถสร้างขนาดหรือตัวแปลงสัญญาณนั้นได้ แตะ ใช้ บนคำแนะนำ หรือเลือก H.264 และขนาดที่เล็กกว่า
การส่งออกช้ามีเพียงตัวเข้ารหัสซอฟต์แวร์เท่านั้นที่ใช้ได้ หรือตัวเข้ารหัสฮาร์ดแวร์ช้าสำหรับการตั้งค่าเหล่านี้ ดำเนินการต่อ หรือเลือกการตั้งค่าที่แนะนำ
การส่งออกช้าลงโทรศัพท์อุ่น มันช้าลงโดยเจตนาเพื่อระบายความร้อน ปล่อยให้เย็น หรือถอดโทรศัพท์ออกจากเคส
การส่งออกล้มเหลว ไม่สามารถวาดเฟรมได้ลองอีกครั้ง หากเกิดซ้ำ ให้ลดความละเอียดหรือปิด การแทรกเฟรม
การส่งออกล้มเหลว ตัวเข้ารหัสวิดีโอยุ่งหรือไม่สามารถสร้างขนาดนี้ได้ปิดแอปอื่นที่เล่นหรือบันทึกวิดีโอ แล้วลองอีกครั้ง หากเกิดซ้ำ ให้เลือกความละเอียดหรือเฟรมเรตที่ต่ำลง
การส่งออกล้มเหลว ตัวถอดรหัสหรือตัวเข้ารหัสวิดีโอหยุดทำงานแอปอื่นกำลังใช้ฮาร์ดแวร์วิดีโอของโทรศัพท์ ปิดแอปที่เล่นหรือบันทึกวิดีโอแล้วลองอีกครั้ง
"ตัวเข้ารหัสวิดีโอของโทรศัพท์กำลังยุ่ง ดังนั้นการส่งออกนี้จึงใช้ตัวเข้ารหัสซอฟต์แวร์ที่ช้ากว่า"ไม่มีอะไรผิดปกติ: การส่งออกใช้เวลานานขึ้น ปิดแอปวิดีโออื่นเพื่อรับตัวเข้ารหัสฮาร์ดแวร์ที่เร็วกว่ากลับมาในครั้งถัดไป
วิดีโอที่เสร็จแล้วแสดงภาพนิ่งพร้อมปุ่มเล่นโทรศัพท์ไม่สามารถเล่นได้ทันที แตะปุ่มเล่นเพื่อลองอีกครั้ง ไฟล์เองถูกบันทึกแล้ว
วิดีโอที่ส่งออกไม่มีเสียงเลเยอร์ที่ซ่อนอยู่ หรือคลิปที่ระดับเสียง 0 % เป็นเสียงเงียบ บรรทัด "ตรวจสอบแล้ว: ..." บนหน้าจอ บันทึกไปยังพื้นที่จัดเก็บ รายงานแทร็กเสียงที่หายไป

การส่งออกยังคงทำงานเมื่อคุณสลับไปยังแอปอื่น และการแจ้งเตือนแสดงความคืบหน้า การปิด AbsentMotion จากรายการแอป最近จะหยุดมัน

พื้นที่จัดเก็บเต็ม

  • ลบโปรเจกต์ที่ไม่ได้ใช้จากหน้าจอหลักและการส่งออกเก่าจาก Movies/AbsentMotion
  • ล้างสำเนาตัวอย่าง ในการตั้งค่าจะเพิ่มพื้นที่ว่างได้ถึง 2 GB
  • สำรองข้อมูลใน Documents/AbsentMotion อาจมีขนาดใหญ่: คัดลอกไปยังคอมพิวเตอร์และลบออกจากโทรศัพท์
  • หากการบันทึกล้มเหลว แอปจะแจ้ง เพิ่มพื้นที่ว่างและดำเนินการต่อ

มันช้า

  • ลด คุณภาพตัวอย่าง
  • ใช้ตัวเลือก เบลอเร็ว ในแถบตัวอย่าง
  • รูปภาพและวิดีโอขนาดใหญ่หนัก ใช้สำเนาตัวอย่างสำหรับวิดีโอ และย่อรูปภาพขนาดใหญ่มากก่อนเพิ่ม
  • เลเยอร์จำนวนมากที่มีเอฟเฟกต์会增加 ซ่อนเลเยอร์ที่คุณไม่ได้ทำงานด้วย (แตะที่ตา)

ข้อความใช้ฟอนต์ผิด

โปรเจกต์ใช้ฟอนต์ที่ไม่มีบนโทรศัพท์นี้ เปิดโปรเจกต์และแตะ ดาวน์โหลด ใน ฟอนต์ที่ไม่มีบนโทรศัพท์นี้ ฟอนต์ต้องมีการเชื่อมต่ออินเทอร์เน็ตหนึ่งครั้ง

คำถาม

ฟรีจริงหรือ? ใช่ ไม่มีการสมัครสมาชิก ไม่มีบัญชี ไม่มีลายน้ำ และไม่มีโฆษณา เป็นโอเพนซอร์สภายใต้ Apache License 2.0

ต้องใช้อินเทอร์เน็ตหรือไม่? ไม่ สิ่งที่เป็นทางเลือกเท่านั้นที่ใช้: การดาวน์โหลด Google Font การดาวน์โหลดโมเดลคำบรรยายหนึ่งครั้ง และการตรวจสอบการอัปเดตที่เป็นทางเลือก ดู ความเป็นส่วนตัว

โปรเจกต์ของฉันอยู่ที่ไหน? ในพื้นที่จัดเก็บส่วนตัวของแอป พร้อมทุกไฟล์สื่อที่คุณเพิ่ม สำรองข้อมูลได้จากการตั้งค่า การส่งออกอยู่ใน Movies, Pictures, Music และ Documents ภายใต้ AbsentMotion

ฉันสามารถย้ายโปรเจกต์ไปยังโทรศัพท์เครื่องอื่นได้หรือไม่? ได้: ส่งออก ชุดโปรเจกต์ คัดลอกไฟล์ .absproj ไปยังโทรศัพท์เครื่องอื่นและเปิดที่นั่น

ฉันสามารถเปิดโปรเจกต์จากตัวแก้ไขอื่นได้หรือไม่? บางส่วน ดู โปรเจกต์ สำรองข้อมูล และนำเข้า

มีเวอร์ชันคอมพิวเตอร์หรือไม่? ไม่ AbsentMotion สร้างสำหรับโทรศัพท์ Android

มีภาษาใดบ้าง? อังกฤษ อินโดนีเซีย ฮินดี โปรตุเกส (บราซิล) สเปน ฟิลิปปินส์ เวียดนาม ไทย มาเลย์ อาหรับ ตุรกี และรัสเซีย เปลี่ยนได้ในการตั้งค่า

ฉันจะรายงานปัญหาหรือขอฟีเจอร์ได้อย่างไร? เปิด issue บน GitHub โปรดอย่ารวมข้อมูลส่วนตัวในนั้น
