Toque no + redondo na parte inferior da tela inicial. Uma folha desliza de baixo para cima. Ela abre com os valores que você usou da última vez (forma, resolução, taxa de quadros e fundo; o nome é sempre novo). Toque em Voltar para fechá-la sem criar nada.

Projeto ou recurso

O botão na parte superior tem duas opções, PROJECT (o padrão) e ASSET. Um recurso é uma peça reutilizável com fundo transparente: sua configuração de fundo fica travada em Transparent. Veja Recursos, modelos e predefinições.

Nome

O nome começa como "Novo projeto 1", "Novo projeto 2" e assim por diante (recursos começam como "Novo recurso"). Toque no X no campo para limpá-lo. Um nome em branco volta ao padrão.

Forma da imagem (proporção)

Botões para 16:9, 9:16, 4:5, 1:1 e 4:3, e um botão de lápis para uma Proporção personalizada. O padrão é 1:1. Escolha 9:16 para vídeo de celular, 16:9 para um vídeo horizontal.

Resolução

A linha Resolução mostra o tamanho da tela, como 1920 x 1080. Para as cinco formas é uma lista do lado curto:

OpçãoLado curto
2160p (4k)2160
1440p (QHD)1440
1080p (FHD), o padrão1080
720p (HD)720
540p (SD), 360p, 270p, 180pcomo nomeado

O lado longo segue a forma. Um projeto 16:9 em 1080p é 1920 x 1080, um projeto 4:5 é 1080 x 1350, e um projeto 4:3 é 1440 x 1080.

Com Proporção personalizada, a lista se torna dois campos numéricos para largura e altura, com um botão Link redondo entre eles. Quando o Link está ativado, alterar um lado mantém a forma que os dois campos tinham quando você ativou o Link. Cada lado pode ter de 32 a 4096 pixels; o app corrige o valor quando você sai do campo.

Uma tela maior parece mais nítida, mas precisa de mais memória e leva mais tempo para exportar. 1080p é uma boa escolha para a maioria dos projetos. Você pode alterar a resolução depois nas configurações do projeto do editor, o que não redimensiona suas camadas.

Taxa de quadros

Escolha 12, 15, 18, 20, 24, 25, 30, 48, 50 ou 60 quadros por segundo. O padrão é 60. Use 24 ou 30 para um visual de cinema e arquivos menores, e 60 para movimentos rápidos suaves. Isso define com que frequência o editor e a exportação desenham uma imagem. Os clipes de vídeo mantêm sua própria taxa de quadros; veja a opção de interpolação de quadros na página Exportar.

Fundo

A cor atrás das suas camadas: Preto, Branco, Cinza-claro, Verde, Azul ou Transparente (mostrado como um tabuleiro de xadrez). Uma instalação nova começa com Transparente. Áreas transparentes de um vídeo exportado saem pretas; exportações de GIF e imagem permitem escolher no que as áreas transparentes se tornam, e PNG as mantém.

Botões na parte inferior

  • CREATE PROJECT (CREATE ASSET para um recurso) cria o projeto e abre o editor nele.
  • O X abaixo deles fecha a folha.

Se não houver armazenamento suficiente, o app avisa e não cria o projeto.
