Desfoque de zoom

Desfoque · Adicionado na versão 2.1.0 ou anterior

Aplica um desfoque radial de zoom a partir de um ponto central, com intensidade ajustável.

O Zoom Blur espalha a imagem para fora a partir de um ponto, como se você estivesse aplicando zoom na câmera. Center é o ponto e Strength é o comprimento dos rastros. Anime o Strength para uma transição de zoom rápida.
