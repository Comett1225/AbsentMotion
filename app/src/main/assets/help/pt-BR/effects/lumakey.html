Chave de luminância

Chave · Adicionado na versão 2.1.0 ou anterior

Remove as partes escuras da camada (ou as claras).

O Luma Key torna as partes escuras de uma camada transparentes (as partes claras com Invert). Threshold é o brilho onde o corte acontece e Softness é o quão gradual o corte é. É útil para filmagens de fogo, fumaça ou faíscas gravadas em fundo preto, ou para fundos brancos com Invert.
