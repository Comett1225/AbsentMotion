Nitidez

Estilizar · Adicionado na versão 2.1.0 ou anterior

Aplica uma máscara de nitidez usando uma vizinhança 3x3 para realçar detalhes finos.

A nitidez realça detalhes finos. Intensidade é o quanto, e Raio é a largura das bordas realçadas. Em excesso, cria halos ao redor das bordas. Para um método de nitidez diferente, experimente Máscara de Desfoque.
