Desenfoque

Desenfoque · Añadido en la versión 2.1.0 o anterior

Un desenfoque suave y uniforme.

Intensidad es el tamaño del desenfoque: 0 es nítido, y los números más altos suavizan más la capa. Funciona en fotos, video, formas, texto y grupos.

  • Anima la Intensidad desde un número alto hasta 0 para enfocar un título o una foto.
  • Para desenfocar todo lo que está detrás de una capa, añade primero una Capa de ajuste y Desenfoque después de ella.
  • Para desenfocar a lo largo del movimiento, usa Desenfoque de movimiento. Para mantener el contorno nítido, usa Desenfoque interior.
