Transformar texto

Texto · Añadido en la versión 3.0.0

Mueve, escala, gira, desvanece y tiñe letras, palabras o líneas dentro de un rango. El ancla define si el escalado y la rotación usan cada componente o el centro de la capa. Mueve el rango con Desplazamiento para que el cambio recorra el texto.

Texto Transformar mueve, escala, gira, desvanece y tiñe letras, palabras o líneas. Establece qué debe ocurrir con las piezas afectadas (Posición, Escala, Rotación, Opacidad, Tinte), luego anima Desplazamiento para que el cambio recorra el texto de principio a fin. Los preajustes Onda y Cascada Giratoria son buenos puntos de partida.
