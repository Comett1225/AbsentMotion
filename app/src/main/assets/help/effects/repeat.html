Repeat

Repeat · Added in version 3.0.0

Dynamically generates multiple copies of the layer.

Repeat makes copies of the layer, one after the other. Count is the number of copies, Offset how far each copy moves from the previous one, Angle and Scale how each turns and grows, and Time delays each copy so they follow the layer like a trail. For other arrangements see Linear Repeat, Radial Repeat and Grid Repeat.
