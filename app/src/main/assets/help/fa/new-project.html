دکمه گرد + در پایین صفحه اصلی را بزنید. برگه‌ای از پایین بالا می‌آید. با مقادیر آخرین بار شما باز می‌شود (شکل، رزولوشن، نرخ فریم و پس‌زمینه؛ نام همیشه جدید است). برای بستن آن بدون ساختن چیزی، Back را بزنید.

پروژه یا دارایی

سوئیچ بالای صفحه دو گزینه دارد، PROJECT (پیش‌فرض) و ASSET. دارایی قطعه‌ای قابل استفاده مجدد با پس‌زمینه شفاف است: تنظیم پس‌زمینه آن روی Transparent قفل است. دارایی‌ها، قالب‌ها و پریست‌ها را ببینید.

نام

نام با «New Project 1»، «New Project 2» و به همین ترتیب شروع می‌شود (دارایی‌ها با «New Asset» شروع می‌شوند). برای پاک کردن آن، X در فیلد را بزنید. نام خالی به پیش‌فرض برمی‌گردد.

شکل تصویر (نسبت ابعاد)

دکمه‌هایی برای 16:9، 9:16، 4:5، 1:1 و 4:3، و دکمه مدادی برای نسبت ابعاد سفارشی. پیش‌فرض 1:1 است. برای ویدیوی گوشی 9:16 و برای ویدیوی افقی 16:9 را انتخاب کنید.

رزولوشن

ردیف Resolution اندازه بوم را نشان می‌دهد، مثل 1920 x 1080. برای پنج شکل، فهرستی از ضلع کوتاه است:

ضلع بلند از شکل پیروی می‌کند. پروژه 16:9 در 1080p برابر 1920 x 1080 است، پروژه 4:5 برابر 1080 x 1350 و پروژه 4:3 برابر 1440 x 1080 است.

با نسبت ابعاد سفارشی، فهرست به دو فیلد عددی برای عرض و ارتفاع تبدیل می‌شود، با یک دکمه گرد Link بین آن‌ها. وقتی Link روشن است، تغییر یک ضلع شکل دو فیلد را در لحظه روشن کردن Link حفظ می‌کند. هر ضلع می‌تواند از 32 تا 4096 پیکسل باشد؛ اپ مقدار را وقتی از فیلد خارج می‌شوید تصحیح می‌کند.

بوم بزرگ‌تر واضح‌تر به نظر می‌رسد اما حافظه بیشتری می‌خواهد و خروجی گرفتن بیشتر طول می‌کشد. 1080p برای بیشتر پروژه‌ها انتخاب خوبی است. می‌توانید رزولوشن را بعداً در تنظیمات پروژه ویرایشگر تغییر دهید، که لایه‌های شما را مقیاس‌دهی مجدد نمی‌کند.

نرخ فریم

۱۲، ۱۵، ۱۸، ۲۰، ۲۴، ۲۵، ۳۰، ۴۸، ۵۰ یا ۶۰ فریم بر ثانیه را انتخاب کنید. پیش‌فرض ۶۰ است. برای ظاهر فیلمی و فایل‌های کوچک‌تر از ۲۴ یا ۳۰ و برای حرکت سریع و روان از ۶۰ استفاده کنید. این تعیین می‌کند ویرایشگر و خروجی هر چند وقت یک‌بار تصویر را رسم کنند. کلیپ‌های ویدیو نرخ فریم خودشان را حفظ می‌کنند؛ گزینه درون‌یابی فریم را در صفحه Export ببینید.

پس‌زمینه

رنگ پشت لایه‌های شما: Black، White، Light Gray، Green، Blue یا Transparent (به‌صورت شطرنجی نمایش داده می‌شود). نصب جدید با Transparent شروع می‌شود. نواحی شفاف یک ویدیوی خروجی‌گرفته‌شده سیاه می‌شوند؛ خروجی GIF و تصویر به شما اجازه می‌دهد انتخاب کنید نواحی شفاف چه شوند، و PNG آن‌ها را حفظ می‌کند.

دکمه‌های پایین

  • CREATE PROJECT (برای دارایی CREATE ASSET) پروژه را می‌سازد و ویرایشگر را روی آن باز می‌کند.
  • X زیر آن‌ها برگه را می‌بندد.

اگر فضای ذخیره‌سازی کافی نباشد، اپ این را می‌گوید و پروژه را نمی‌سازد.
